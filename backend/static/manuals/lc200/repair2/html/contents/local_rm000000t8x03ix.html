DTC    P0230    Fuel Pump Primary Circuit


DESCRIPTION

MONITOR DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK FOR DTC (B1500)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (FUEL PUMP)

CHECK HARNESS AND CONNECTOR (FUEL PUMP ECU - ECM - FUEL PUMP)

REPLACE FUEL PUMP CONTROL ECU

CONFIRM WHETHER DTC OUTPUT RECURS

CHECK HARNESS AND CONNECTOR (FUEL PUMP POWER SOURCE VOLTAGE)

CHECK HARNESS AND CONNECTOR (ECM - FUEL PUMP CONTROL ECU - FUEL PUMP)

CHECK HARNESS AND CONNECTOR (FUEL PUMP CONTROL ECU POWER SOURCE VOLTAGE)

REPLACE FUEL PUMP CONTROL ECU

CONFIRM WHETHER DTC OUTPUT RECURS

INSPECT CIRCUIT OPENING RELAY (C/OPN)

CHECK CIRCUIT OPENING RELAY

CHECK HARNESS AND CONNECTOR (FUEL PUMP ECU - CIRCUIT OPENING RELAY - INTEGRATION RELAY)

CHECK FUSE (IGN)

CHECK HARNESS AND CONNECTOR (ECM - CIRCUIT OPENING RELAY - INTEGRATION RELAY)
