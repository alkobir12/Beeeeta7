DTC    B2273    Ignition 2 Monitor Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (IG2 RELAY MONITOR (INSIDE))

CHECK WHETHER DTC OUTPUT RECURS

INSPECT FUSE (IG2 MAIN)

INSPECT INTEGRATION RELAY (IG2 RELAY)

CHECK HARNESS AND CONNECTOR (MAIN BODY ECU - INTEGRATION RELAY (IG2 RELAY) AND BODY GROUND)
