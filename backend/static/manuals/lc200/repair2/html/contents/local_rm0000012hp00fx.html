RELAY (w/ PTC Heater) > ON-VEHICLE INSPECTION


  1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

  2. REMOVE PTC HEATER RELAY (PTC HTR 1, PTC HTR 2, PTC HTR 3)

  3. INSPECT PTC HEATER RELAY (PTC HTR 1, PTC HTR 2, PTC HTR 3)

  4. INSTALL PTC HEATER RELAY (PTC HTR 1, PTC HTR 2, PTC HTR 3)

  5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
