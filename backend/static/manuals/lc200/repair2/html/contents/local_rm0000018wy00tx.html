DTC    P2121    Throttle / Pedal Position Sensor / Switch "D" Circuit Range / Performance


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (ACCELERATOR PEDAL POSITION SENSOR)

CHECK HARNESS AND CONNECTOR (ACCELERATOR PEDAL POSITION SENSOR - ECM)

REPLACE ACCELERATOR PEDAL ROD ASSEMBLY

CHECK WHETHER DTC OUTPUT RECURS (DTC P2121)

REPLACE ECM

REPAIR OR REPLACE HARNESS OR CONNECTOR

CONFIRM WHETHER MALFUNCTION HAS BEEN SUCCESSFULLY REPAIRED
