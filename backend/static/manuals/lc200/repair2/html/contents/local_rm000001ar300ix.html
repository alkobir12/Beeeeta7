DTC    P1238    Injector Malfunction


DESCRIPTION

MONITOR DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK ANY OTHER DTCS OUTPUT (IN ADDITION TO DTC P1238)

CHECK HARNESS AND CONNECTOR (ENGINE WIRE HARNESS)

READ VALUE USING INTELLIGENT TESTER (COMPENSATORY INJECTION VOLUME FOR EACH CYLINDER)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (FUEL CUT FOR IDENTIFYING MALFUNCTION CYLINDER)

CHECK CYLINDER COMPRESSION PRESSURE OF MALFUNCTIONING CYLINDER

REPLACE FUEL INJECTOR

CHECK WHETHER DTC OUTPUT RECURS (DTC P1238)

REPLACE ECM

REPAIR OR REPLACE HARNESS OR CONNECTOR

CHECK ENGINE TO DETERMINE CAUSE OF LOW COMPRESSION

CONFIRM WHETHER MALFUNCTION HAS BEEN SUCCESSFULLY REPAIRED
