DTC    C1380/64    Stop Light Control Relay Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK STOP LIGHT SWITCH OPERATION

INSPECT SKID CONTROL ECU (STP TERMINAL)

INSPECT SKID CONTROL ECU (STP2 TERMINAL)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (STOP LIGHT RELAY)

RECONFIRM DTC

INSPECT BRK LP RELAY (POWER SOURCE TERMINAL)

INSPECT BRK LP RELAY

INSPECT SKID CONTROL ECU (STPO TERMINAL)

RECONFIRM DTC
