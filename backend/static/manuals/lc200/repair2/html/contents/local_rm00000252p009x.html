DTC    C0210/33    Rear Speed Sensor RH Circuit


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (RR/RL SPEED OPEN)

READ VALUE USING INTELLIGENT TESTER (RR/RL WHEEL SPEED, RR/RL WHEEL DIRECTION)

PERFORM SIGNAL CHECK

INSPECT REAR SPEED SENSOR INSTALLATION

INSPECT SPEED SENSOR TIP

INSPECT REAR SPEED SENSOR

INSPECT SKID CONTROL SENSOR WIRE

CHECK HARNESS AND CONNECTOR (SKID CONTROL ECU - SKID CONTROL SENSOR WIRE)

INSPECT MASTER CYLINDER SOLENOID (SKID CONTROL ECU OUTPUT VOLTAGE)

RECONFIRM DTC

REPLACE REAR SPEED SENSOR

RECONFIRM DTC

INSPECT SPEED SENSOR ROTOR
