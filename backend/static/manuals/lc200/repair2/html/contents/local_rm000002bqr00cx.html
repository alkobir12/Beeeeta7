DTC    B2312    Power Window Switch Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CLEAR DTC

CHECK FOR DTC

CHECK MALFUNCTION LOCATION

READ VALUE USING INTELLIGENT TESTER (DRIVER SIDE POWER WINDOW REGULATOR MOTOR)

CHECK HARNESS AND CONNECTOR (MULTIPLEX NETWORK MASTER SWITCH - FRONT POWER WINDOW REGULATOR MOTOR AND BODY GROUND)

READ VALUE USING INTELLIGENT TESTER (FRONT PASSENGER SIDE POWER WINDOW REGULATOR MOTOR)

INSPECT POWER WINDOW REGULATOR SWITCH ASSEMBLY

CHECK HARNESS AND CONNECTOR (POWER WINDOW REGULATOR SWITCH ASSEMBLY - FRONT POWER WINDOW REGULATOR MOTOR)

READ VALUE USING INTELLIGENT TESTER (REAR POWER WINDOW REGULATOR MOTOR ASSEMBLY LH)

INSPECT REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY LH

CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY LH - POWER WINDOW REGULATOR MOTOR)

READ VALUE USING INTELLIGENT TESTER (REAR POWER WINDOW REGULATOR MOTOR RH)

INSPECT REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY RH

CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY RH - BODY GROUND)
