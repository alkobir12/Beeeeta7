DTC    B2321    Driver Side Door ECU Communication Stop


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CLEAR DTC

CHECK FOR DTC

CHECK HARNESS AND CONNECTOR (MAIN BODY ECU - FRONT POWER WINDOW REGULATOR MOTOR)

CHECK FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY (BATTERY VOLTAGE AND BODY GROUND)

REPLACE FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY

CHECK FOR DTC
