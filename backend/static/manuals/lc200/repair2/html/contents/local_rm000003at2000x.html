DTC    C1782    Power Source Voltage Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (IG VOLTAGE)

RECONFIRM DTC OUTPUT

READ VALUE USING INTELLIGENT TESTER (+B POWER SOURCE VOLTAGE, +B2 POWER SOURCE VOLTAGE)

INSPECT FUSE (AHC-B, AHC-B NO. 2)

CHECK HARNESS AND CONNECTOR (BATTERY - SUSPENSION CONTROL ECU)

CHECK HARNESS AND CONNECTOR (BATTERY - ECU AND BODY GROUND)
