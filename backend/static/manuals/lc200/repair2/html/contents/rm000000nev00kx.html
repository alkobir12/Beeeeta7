CLUTCH UNIT (for 1GR-FE) > INSTALLATION

for Preparation Click here



1. INSTALL CLUTCH DISC ASSEMBLY



  1. Insert SST into the clutch disc, then insert the clutch disc into the flywheel.

    SST
    09301-00110  

    NOTICE:
    Take care not to insert the clutch disc in the wrong direction.



2. INSTALL CLUTCH COVER ASSEMBLY



  1. Align the matchmark on the clutch cover with the one on the flywheel.

  1. In the order shown in the illustration, temporarily install the 6 bolts starting from the bolt located near the knock pin on the top.

  1. Check that the disc is in the center by lightly moving SST up and down, and left and right.

    SST
    09301-00110  

  1. Evenly tighten the bolts by following the order shown in the illustration.

    Torque:
    19 N*m{ 195 kgf*cm , 14 ft.*lbf }



3. INSPECT AND ADJUST CLUTCH COVER ASSEMBLY



  1. Using a dial indicator with a roller instrument, check the diaphragm spring tip alignment.

    Maximum Misalignment:
    1.3 mm (0.0512 in.)




  1. If the alignment is not as specified, adjust the diaphragm spring tip alignment using SST.

    SST
    09333-00013  



4. INSTALL CLUTCH RELEASE FORK SUB-ASSEMBLY



  1. Apply release hub grease to the release fork, release bearing, push rod contact point and pivot points shown in the illustration.

    Grease:
    Toyota Genuine Release Hub Grease or equivalent




  1. Apply clutch spline grease to the input shaft spline.

    Grease:
    Toyota Genuine Clutch Spline Grease or equivalent




  1. Install the release bearing to the clutch release fork with the clip.




  1. Install the release fork support to the transmission unit.

    Torque:
    47 N*m{ 480 kgf*cm , 35 ft.*lbf }

  1. Install the clutch release fork with the clutch release bearing to the transmission unit.

    HINT:
    After installation, move the fork back and forth to check that the release bearing slides smoothly.



5. INSTALL MANUAL TRANSMISSION ASSEMBLY
