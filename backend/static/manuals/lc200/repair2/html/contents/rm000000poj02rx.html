INSPECTION PROCEDURE

1.CHECK DISPLAY SETTING



  1. Enter the display adjustment screen by pressing the "DISP" switch.

  1. Reset the display settings (contrast, brightness) and check that the screen appears normal.




  1. Press the "INFO" switch and then select "Screen Setting".




  1. Set the "Switch Color" to "Blue" (initial setting) and check if the display returns to normal.

    OK:
    Returns to normal.

2.CHECK CABIN

  1. Check that the cabin temperature is higher than -20°C (-4.0°F).

    OK:
    Cabin temperature is higher than -20°C (-4.0°F).

3.CHECK COLOR BAR (DISPLAY CHECK MODE)



  1. Enter the "Display Check" mode and select "Color Bar Check" (Click here).

  1. Check that the color bars match the displayed names.

    OK:
    Color bars match the displayed names.
