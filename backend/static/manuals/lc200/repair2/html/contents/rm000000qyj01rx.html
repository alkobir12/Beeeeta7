DTC    B2784    Antenna Coil Open / Short

for Preparation Click here


DESCRIPTION

This DTC is output when there is an open or short malfunction in the transponder key coil (built into the engine switch).

DTC Code
DTC Detection Condition
Trouble Area
B2784
The antenna coil is open/shorted.
  1. Certification ECU (Smart key ECU assembly)
  2. Engine switch
