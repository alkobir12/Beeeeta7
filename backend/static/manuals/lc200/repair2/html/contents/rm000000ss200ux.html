1. INSTALL DECELERATION SENSOR (for Automatic Transmission)

  1. Connect the sensor connector, and then attach the clamp to the hole of the sensor bracket.

    NOTICE:
    Securely connect the connector.

  1. Install the sensor with the 2 bolts.

    Torque:
    15 N*m{ 148 kgf*cm , 11 ft.*lbf }

    NOTICE:
    1. Make sure that the sensor is oriented correctly.
    2. If the sensor is dropped, replace it.

    3. When installing the sensor, make sure to avoid impacts to the sensor.








2. INSTALL DECELERATION SENSOR (for Manual Transmission)


  1. Connect the sensor connector, and then attach the clamp to the hole of the sensor bracket.






  1. Install the sensor with the 2 bolts.

    Torque:
    15 N*m{ 148 kgf*cm , 11 ft.*lbf }

    NOTICE:
    1. Make sure that the sensor is oriented correctly.
    2. If the sensor is dropped, replace it.
    3. Securely connect the connector.
    4. When installing the sensor, make sure to avoid impacts to the sensor.



3. INSTALL REAR CONSOLE BOX SUB-ASSEMBLY (w/o Cool Box)




  1. Attach the 2 claws.

  1. Install the console box with the 4 bolts and 2 screws.



4. INSTALL COOLING BOX ASSEMBLY (w/ Cool Box)




  1. Attach the 2 claws.

  1. Connect the connector.

  1. Sufficiently apply compressor oil to 2 new O-rings.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings on the 2 cooler pipes.

  1. Connect the 2 cooler pipes with the 2 bolts.

    Torque:
    9.8 N*m{ 100 kgf*cm , 87 in.*lbf }

  1. Install the cooling box with the 4 bolts and 2 screws.



5. INSTALL REAR CONSOLE END PANEL SUB-ASSEMBLY

  1. Attach the 8 claws to install the end panel.
