POWER WINDOW CONTROL SYSTEM > Auto Up Operation does not Fully Close Power Window (Jam Protection Function is Activated)

for Preparation Click here


DESCRIPTION

  1. This symptom may occur to all door windows.
  2. If the door glass or the power window regulator motor does not operate smoothly, the jam protection function may be triggered automatically, resulting in the auto up function being unable to fully close the window.

INSPECTION PROCEDURE

1.PERFORM INITIALIZATION

  1. Initialize the power window regulator motor (Click here).

  1. Check if the power window auto up/down function operates (Click here).

    OK:
    Auto up/down function operates.



NG
Go to step 2
OK

END (PROBLEM DUE TO INITIALIZATION FAILURE) 

2.CHECK MOVEMENT OF DOOR GLASS (LOCATION WHERE JAM PROTECTION FUNCTION OPERATES)

  1. Remove the installation bolt of the door glass and hold the glass by hand. When raising the glass by hand, check that the glass moves smoothly.

    NOTICE:
    1. Make sure that the glass run is not deformed, and that there is no foreign matter on the glass run.
    2. Make sure that the glass run is not deformed, and does not have foreign matter.

    OK:
    Door glass moves smoothly.



NG
INSTALL DOOR GLASS AND/OR GLASS RUN PROPERLY (APPLICABLE LOCATION)
OK

REPLACE POWER WINDOW REGULATOR MOTOR ASSEMBLY (APPLICABLE LOCATION)
