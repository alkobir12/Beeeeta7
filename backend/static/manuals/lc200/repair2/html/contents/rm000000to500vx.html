POWER DOOR LOCK CONTROL SYSTEM > All Doors cannot be Locked / Unlocked Simultaneously

for Preparation Click here


DESCRIPTION

The main body ECU receives switch signals from the multiplex network master switch, and driver side door key cylinder switch signals from the front door lock. The main body ECU activates the door lock motor on each door according to these signals.
