1. INSPECT FRONT SEAT INNER BELT ASSEMBLY (for Driver Side)


  1. for Power Seat, for 4 Way Seat Type:
    Check the buckle switch.




    1. Measure the resistance according to the value(s) in the table below.

      Standard Resistance:
      Tester Connection
      		Condition
      		Specified Condition
      B-4 - B-5
      		Seat belt fastened (Buckle switch is on)
      		Below 1 Ω
      Seat belt unfastened (Buckle switch is off)
      		1 MΩ or higher
      A-1 - C-4
      		Always
      		Below 1 Ω
      A-2 - C-8
      		Always
      		Below 1 Ω

      If the result is not as specified, replace the inner belt assembly.



  1. for 8 Way Seat Type:
    Check the buckle switch.




    1. Measure the resistance according to the value(s) in the table below.

      Standard Resistance:
      Tester Connection
      		Condition
      		Specified Condition
      C-9 - C-13
      		Seat belt fastened (Buckle switch is on)
      		Below 1 Ω
      Seat belt unfastened (Buckle switch is off)
      		1 MΩ or higher
      A-1 - B-4
      		Always
      		Below 1 Ω
      A-2 - B-8
      		Always
      		Below 1 Ω

      If the result is not as specified, replace the inner belt assembly.
