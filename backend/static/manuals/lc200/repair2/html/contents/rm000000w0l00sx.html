THEFT DETERRENT SYSTEM DESCRIPTION
The theft deterrent system is designed to deter vehicle break-ins and theft. If an attempted break-in or theft is detected, the vehicle horns and security horn*1 or theft warning siren (self power siren)*2 will sound, the room light will illuminate, and the headlights*3, taillights*3 and hazard warning lights will flash. The system detects an attempted break-in or theft when any of the following occurs: 1) the vehicle is forcibly entered; 2) the engine hood is forcibly opened; 3) the doors are unlocked without the use of a key; or 4) the cable from the negative (-) battery terminal is disconnected and reconnected.
If the system enters the alarm sounding state, any unlocked doors will automatically lock.
The system has 4 states: disarmed state, arming preparation state, armed and alarm sounding state.

HINT:
  1. *1: w/ Security Horn
  2. *2: w/ Theft Warning Siren (Self Power Siren)
  3. *3: For vehicles with a theft warning siren (self power siren), this part is not related to the theft deterrent system.


FUNCTION OF MAIN COMPONENT

Function
Outline
Security indicator
Informs driver of the theft deterrent system status.
Security horn*1
Sounds when an attempted break-in or theft is detected.
Located in the engine compartment.
Theft warning siren (Self power siren)*2
Sounds when an attempted break-in or theft is detected.
Located on the quarter inner LH.
Taillight*3
Flashes when an attempted break-in or theft is detected.
Map light and rear map light
Illuminates when an attempted break-in or theft is detected.
The map light has intrusion sensor cancel switch.
For vehicles equipped with a tilt sensor, the intrusion sensor cancel switch also functions as tilt sensor OFF switch.
Headlight*3
Begins flashing when an attempted break-in or theft is detected.
Hazard warning light
Begins flashing when an attempted break-in or theft is detected.
Vehicle horns
Sounds when an attempted break-in or theft is detected.
Door courtesy light switch
Detects the door open status (open or closed).
Door lock position switch
Detects the door lock status (locked or unlocked).
Engine hood courtesy switch
Detects the engine hood open status (open or closed).
Back door courtesy switch
Detects the back door open status (open or closed).
Main body ECU
Detects the engine switch condition (off, on (ACC), or on (IG)).
Intrusion sensor*4
If an intrusion is detected, the alarm is activated.
Yaw rate sensor*4
After the theft deterrent system is set, detects vehicle tilt. If vehicle tilt changes, the certification ECU (smart key ECU assembly) determines there was theft.
Glass breakage sensor*5
Sounds alarm when the left or right rear side glass or back door glass is broken, or when there is short in the wire harness.

HINT:
*1: w/ Security Horn
*2: w/ Theft Warning Siren (Self Power Siren)
*3: For vehicles with a theft warning siren (self power siren), this part is not related to the theft deterrent system.
*4: w/ Intrusion Sensor
*5: w/ Glass Breakage Sensor


SYSTEM FUNCTION

  1. Disarmed state:

    1. The alarm function is not operating.
    2. The theft deterrent system is not operating.

  2. Arming preparation state:

    1. The theft deterrent system is not operating.

  3. Armed state:

    1. The theft deterrent system is operating.

  4. Alarm sounding state:

    1. The alarm function is operating (30 +/-5 seconds).
