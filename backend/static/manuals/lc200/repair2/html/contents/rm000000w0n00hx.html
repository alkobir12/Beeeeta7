HINT:
  1. Use these procedures to troubleshoot the theft deterrent system.
  2. *: Use the intelligent tester.
  3. Troubleshooting of the theft deterrent system is based on the premise that the door lock control system, the wireless door lock control system, the lighting system, the horn system, the engine immobiliser system and the entry and start system are operating normally. Check these systems first before troubleshooting the theft deterrent system.
