THEFT DETERRENT SYSTEM > Engine Hood Courtesy Switch Circuit

for Preparation Click here


DESCRIPTION

  1. The engine hood courtesy switch is built into the hood lock. This switch turns on when the engine hood is opened and turns off when the engine hood is closed.

  1. Disconnect the A8 switch connector.

  1. Measure the resistance according to the value(s) in the table below.

    Tester Connection
