HINT:
  1. If a normal code is output during the diagnostic trouble code check although the trouble still occurs, check the electrical circuits for each symptom in the order given in the charts below and proceed to the "See page".
  2. The Matrix Chart is divided into 3 chapters.
    Chapter 1:
    Refer to the table below when the trouble cause is considered to be electrical.
  3. If the instruction "Proceed to next circuit inspection shown in problem symptoms table" is given in the flowchart of each circuit, proceed to the next circuit in the table to continue the check.
  4. If the trouble still occurs even though there are no abnormalities in any of the other circuits, check and replace the ECM.
  5. *: When the circuit is defective, a DTC may be stored.
