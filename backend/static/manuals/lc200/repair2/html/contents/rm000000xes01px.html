DTC    B2275    STSW Monitor Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when the engine start request signal circuit inside the main body ECU is open or shorted.

DTC Code
Detection Condition
Trouble Area
B2275
The engine start request signal circuit inside the main body ECU or other related circuit is malfunctioning.
  1. Main body ECU
  1. ECM
  1. Harness or connector

WIRING DIAGRAM

1.CHECK WHETHER DTC OUTPUT RECURS

  1. Clear the DTCs (Click here).

  1. Depress the brake pedal (for A/T) or clutch pedal (for M/T) with the engine switch on (IG), wait at least 15 seconds, and check whether DTC B2275 is output.
