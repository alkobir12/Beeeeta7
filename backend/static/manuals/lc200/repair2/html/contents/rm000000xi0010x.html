POWER WINDOW CONTROL SYSTEM > Front Passenger Side Power Window does not Operate with Front Passenger Side Power Window Switch

for Preparation Click here


DESCRIPTION

  1. If the manual up/down function does not operate, there may be a malfunction in the power window regulator switch, front power window regulator motor RH or harness or connector.
