for Preparation Click here



CHECK DTC (Using Tester)

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the tester on.

  4. Enter the following menus: Chassis / VGRS / DTC.

  5. Read the DTCs.


CLEAR DTC (Using Tester)

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG) (do not start the engine).

  3. Turn the tester on.

  4. Enter the following menus: Chassis / VGRS / DTC.

  5. Clear the DTCs.


CHECK DTC (Using SST Check Wire)

HINT:
The master warning light comes on in diagnostic mode.

  1. Using SST check wire, connect terminals 13 (TC) and 4 (CG) of the DLC3.

    SST
    09843-18040  

  2. Turn the engine switch on (IG).

  3. "DIAG VGRS" is displayed on the multi-information display and the system starts searching for a malfunction.




  4. If the system is normal, "DIAG VGRS OK" is displayed.




  5. If the system has a malfunction, "DIAG VGRS xx" is displayed ("xx" is a 2-digit DTC).


CLEAR DTC (Using SST Check Wire)

  1. Turn the engine switch on (IG).

  2. Using SST check wire, connect and disconnect terminals 13 (TC) and 4 (CG) of the DLC3 4 times within 8 seconds.

    SST
    09843-18040  

  3. Disconnect SST check wire from the DLC3.

    NOTICE:
    As the stored yaw rate and G sensor value will be cleared by the above operation, it is necessary to obtain the yaw rate and G sensor zero point.

  4. Turn the engine switch off.

    HINT:
    If the problem still exists, DTCs may not be cleared.

  5. Obtain the yaw rate and G sensor zero point (Click here).
