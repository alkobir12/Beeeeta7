1.PRECAUTIONS WHEN WORKING ON ELECTRIC STEERING LOCK

  1. After replacing the steering lock actuator assembly (steering lock ECU), perform the key ID code registration.

  2. If the steering lock actuator assembly (steering lock ECU) is replaced, open and close the driver's door. The engine may not start until the driver's door is opened or closed.

    HINT:
    Opening and closing the driver's door causes the steering lock actuator assembly (steering lock ECU) to memorize the correct steering lock bar position.

  3. When the main body ECU is in sleep mode, it cannot communicate with the intelligent tester. Therefore, checking for DTCs of the smart key system and checking the Data List with the engine switch off cannot be performed. To exit sleep mode, perform the following steps: 1) open the driver's door with the engine switch off, 2) open and close any door several times at 1.5 second intervals.
