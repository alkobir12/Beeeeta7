DTC    C1592/52    Actuator Neutral Position Calibration Incomplete

for Preparation Click here


DESCRIPTION

The steering control ECU first checks the actuator angle neutral position calibration flag after entering test mode. If the ECU detects that steering actuator angle neutral position calibration is incomplete twice, it will store DTC C1592/52.

DTC Code
DTC Detection Condition
Trouble Area
C1592/52
The steering control ECU detects that steering actuator angle neutral position calibration is incomplete twice.
  1. Steering actuator
  2. Steering control ECU
