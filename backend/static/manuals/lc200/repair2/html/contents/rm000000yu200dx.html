DTC    C1595/55    Lost Communication with Steering Angle Sensor Module

DTC    C15C4/68    Steering Angle Signal (Test Mode DTC)

for Preparation Click here


DESCRIPTION

Signal transmission between the steering control ECU and steering angle sensor is performed via serial communication.
If an error occurs between them in serial communication, the ECU will store DTC C1595/55.

DTC Code
DTC Detection Condition
Trouble Area
C1595/55
The steering control ECU detects an error in serial communication between the ECU and steering angle sensor.
  1. Steering angle sensor
  2. Steering control ECU
  3. Harness or connector
C15C4/68
A steering signal indicating a tire angle of 36° or more (to the left or right) is input after entering test mode.*
  1. Steering angle sensor
  2. Steering control ECU
  3. Harness or connector

HINT:
*: A tire angle of 36° and a motor rotation angle of 36° correspond to the steering wheel angle. The amount of change in tire angle and motor rotation angle is from when the mode is changed to test mode.
