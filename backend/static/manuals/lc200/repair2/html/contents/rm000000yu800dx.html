DTC    C15A5/65    Actuator Malfunction

for Preparation Click here


DESCRIPTION

If the steering control ECU detects a malfunction in the lock mechanism, it will turn the master warning light on, store DTC C15A5/65, and stop VGRS operation.

DTC Code
DTC Detection Condition
Trouble Area
C15A5/65
The steering control ECU detects that the LG terminal voltage is abnormal.
  1. Harness or connector
  2. Steering actuator
  3. Steering control ECU
