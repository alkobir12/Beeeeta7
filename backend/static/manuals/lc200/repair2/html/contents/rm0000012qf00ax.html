DTC    B2761    Intrusion Sensor Internal Circuit Malfunction

for Preparation Click here


DESCRIPTION

  1. The intrusion sensor conducts a self-diagnosis immediately after the power is supplied to the sensor (when the theft deterrent system is set).
    If a malfunction is detected in the intrusion wave transmission or wave reception, or the intrusion sensor wave transmission or wave reception circuit, the intrusion sensor sends a signal to the certification ECU (smart key ECU assembly). The ECU then outputs this DTC.

DTC Code
DTC Detection Condition
Trouble Area
B2761
The intrusion sensor outputs a signal for a sensor malfunction.
  1. Intrusion sensor
  2. Map light assembly
  3. Certification ECU (Smart key ECU assembly)

INSPECTION PROCEDURE

1.CHECK FOR DTC

  1. Set the theft deterrent system and check if the same DTC is not output.

    OK:
    DTC B2761 is not output.
