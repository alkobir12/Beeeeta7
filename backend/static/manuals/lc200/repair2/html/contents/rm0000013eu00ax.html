POWER WINDOW CONTROL SYSTEM > All Power Window Up Functions do not Operate with Entry Lock Switch

for Preparation Click here


DESCRIPTION

When an entry lock switch is pressed and held for approximately 3 seconds: 1) the main body ECU receives a signal via the driver side door ECU, 2) the main body ECU transmits a signal to all the power window regulator motor, and 3) all the power window motors are activated to close the windows.

INSPECTION PROCEDURE

1.CHECK BASIC FUNCTION (ENTRY & START SYSTEM (for Entry Function))

  1. Check that the entry lock switch operates (Click here).

    OK:
