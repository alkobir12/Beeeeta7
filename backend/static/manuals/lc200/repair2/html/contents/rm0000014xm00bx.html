1. INSTALL INTAKE AIR TEMPERATURE SENSOR

  1. Install a new gasket to the sensor.




  1. Using a ball joint lock nut wrench, install the sensor.

    Torque:
    without ball joint lock nut wrench:
    29 N*m{ 300 kgf*cm , 22 ft.*lbf }
    with ball joint lock nut wrench:
    19 N*m{ 197 kgf*cm , 14 ft.*lbf }

    NOTICE:
    Do not use a tool such as an impact wrench or equivalent.

    HINT:
    1. Use a torque wrench with a fulcrum length of 300 mm (11.8 in.).
    2. Make sure the ball joint lock nut wrench and torque wrench are connected in a straight line.
