1. INSTALL OUTPUT SHAFT ASSEMBLY



  1. Install the output shaft by lightly tapping on the back side of the intermediate plate with a plastic-faced hammer.



2. INSTALL OUTPUT SHAFT BEARING SHAFT SNAP RING



  1. Using a snap ring expander, install the snap ring to the output shaft bearing.



3. INSTALL NO. 2 SYNCHRONIZER RING

  1. Install the No. 2 synchronizer ring to the input shaft.



4. INSTALL INPUT SHAFT ASSEMBLY



  1. Install the input shaft to the output shaft.

    HINT:
    Align the shifting key of the synchronizer ring with the groove of the clutch hub.

  1. Install the clutch hub and confirm that the gear and synchronizer ring move smoothly.



5. INSTALL COUNTER GEAR

  1. Install the counter gear to the intermediate plate.




  1. Install the center bearing to the counter gear.




  1. Using a snap ring expander, install the snap ring to the outer race.




  1. Using a brass bar and hammer, lightly tap the bearing outer race uniformly to install it.

    NOTICE:
    Do not drop the counter gear. Hold the front side of the counter gear.



6. INSTALL OUTPUT SHAFT REAR BEARING (MTM) RETAINER



  1. Install the output shaft rear bearing retainer to the intermediate plate with the 4 bolts.

    Torque:
    18 N*m{ 185 kgf*cm , 13 ft.*lbf }



7. INSTALL NO. 1 TRANSMISSION HUB SLEEVE



  1. Apply a light coat of gear oil to the sleeve and hub.

  1. Install the No. 1 transmission hub sleeve and 3 shifting keys to the No. 4 transmission clutch hub.

    NOTICE:
    Do not mistake the installation direction of the No. 1 transmission hub sleeve, No. 4 transmission clutch hub, and shifting keys.




  1. Insert the 2 springs under the shifting keys.

    NOTICE:
    Position the key springs so that their end gaps are not aligned.



8. INSTALL REVERSE GEAR BEARING

  1. Coat the reverse gear bearing with gear oil, and install it to the reverse gear.



9. INSTALL REVERSE SYNCHRONIZER RING SET

  1. Coat the reverse synchronizer ring set with gear oil, and install it to the reverse gear.



10. INSTALL REVERSE GEAR



  1. Coat the reverse gear with gear oil, and install it to the output shaft.



11. INSTALL NO. 4 TRANSMISSION CLUTCH HUB



  1. Using SST and a hammer, install the No. 4 transmission clutch hub.

    SST
    09316-60011   (09316-00011)

    HINT:
    Align the shifting key of the synchronizer ring with the groove of the clutch hub.

  1. Install the clutch hub and confirm that the gear and synchronizer ring move smoothly.

13. INSPECT REVERSE GEAR THRUST CLEARANCE



  1. Using a feeler gauge, measure the reverse gear thrust clearance.

    Standard Clearance:
    0.15 to 0.52 mm (0.00591 to 0.0204 in.)

    If the clearance is outside the specification, replace the defective gear or shaft.



14. INSTALL NO. 2 GEAR SHIFT FORK

  1. Install the No. 2 gear shift fork.



15. INSTALL NO. 2 GEAR SHIFT FORK SHAFT



  1. Install the No. 2 gear shift fork shaft to the No. 2 gear shift fork and intermediate plate with the bolt.

    Torque:

  1. Install the No. 1 gear shift fork.



17. INSTALL NO. 1 GEAR SHIFT FORK SHAFT

  1. Apply MP grease to the interlock pin.

  1. Install the interlock pin to the No. 1 gear shift fork shaft.




  1. Install the No. 1 gear shift fork shaft to the No. 2 gear shift fork and intermediate plate with the bolt.

    Torque:
    46 N*m{ 472 kgf*cm , 34 ft.*lbf }

20. INSTALL REVERSE SHIFT FORK

  1. Install the reverse shift fork.



21. INSTALL NO. 4 GEAR SHIFT FORK SHAFT



  1. Using a magnetic finger, install the ball to the intermediate plate.




  1. Using a magnetic finger, install the ball to the reverse shift head.




  1. Install the No. 4 gear shift fork shaft to the reverse gear shift fork and intermediate plate with the bolt.

    Torque:
    34 N*m{ 350 kgf*cm , 25 ft.*lbf }



22. INSTALL SHIFT FORK SHAFT SNAP RING



  1. Using a brass bar and hammer, install the 4 snap rings.



23. INSTALL SHIFT DETENT BALL PLUG



  1. Install the 4 balls and 4 springs to the intermediate plate.

  1. Apply adhesive to 2 or 3 threads of the 4 detent ball plugs.

    Adhesive:

  1. Using a T40 "TORX" socket wrench, install the 4 detent ball plugs.

    Torque:
    19 N*m{ 190 kgf*cm , 14 ft.*lbf }

    Torque:
    18 N*m{ 185 kgf*cm , 13 ft.*lbf }



25. INSTALL INTERMEDIATE PLATE STRAIGHT PIN



  1. Using a plastic-faced hammer, tap 4 new straight pins into the intermediate plate.

    Standard Protrusion Height:
    7.0 to 9.0 mm (0.276 to 0.354 in.)



26. INSTALL TRANSFER ADAPTER STRAIGHT PIN



  1. Using a plastic-faced hammer, tap 2 new straight pins into the transmission case.

    Standard Protrusion Height:
    4.0 to 6.0 mm (0.158 to 0.236 in.)




  1. Using a plastic-faced hammer, tap 2 new straight pins into the transmission case.

    Standard Protrusion Height:
    9.0 to 11.0 mm (0.355 to 0.433 in.)

    Torque:
    12 N*m{ 120 kgf*cm , 9 ft.*lbf }



28. INSTALL MANUAL TRANSMISSION CASE SUB-ASSEMBLY



  1. Apply seal packing to the transmission case, as shown in the illustration.

    Seal Packing:
    Toyota Genuine Seal Packing 1281, Three Bond 1281 or equivalent

    NOTICE:
    Parts must be assembled within 10 minutes of application. Otherwise, the packing (FIPG) material must be removed and reapplied.




  1. Install the transmission case by lightly tapping it into place with a plastic-faced hammer.

    NOTICE:
    Make sure that the oil receiver installed on the transmission side is above the oil application area of the intermediate plate side oil receiver.




  1. Using a snap ring expander, install the 2 snap rings to the counter gear and input shaft.



29. INSTALL REVERSE IDLER GEAR SHAFT WOODRUFF KEY



  1. Install the woodruff key to the reverse idler gear shaft.



30. INSTALL REVERSE IDLER GEAR SHAFT

  1. Install the reverse idler gear shaft to the intermediate plate.



31. INSTALL REVERSE IDLER THRUST WASHER

  1. Install the thrust washer to the reverse idler gear shaft.

    NOTICE:
    1. Align the protrusion of the washer with the groove of the intermediate plate during installation.
    2. Install the washer so that the dimpled surface of the washer contacts the reverse idler gear thrust surface.



32. INSTALL REVERSE IDLER GEAR BUSH OR BEARING

  1. Install the bearing to the reverse idler gear shaft.



33. INSTALL REVERSE IDLER GEAR

  1. Install the reverse idler gear to the reverse idler gear shaft.



34. INSTALL NO. 2 REVERSE IDLER THRUST WASHER

  1. Install the thrust washer to the reverse idler gear shaft.

    NOTICE:
    Install the washer so that the dimpled surface of the washer contacts the reverse idler gear thrust surface.



35. INSTALL TRANSMISSION MAGNET



  1. Install the transmission magnet to the intermediate plate.

  1. Install the oil strainer to the transfer adapter with the 2 bolts.

    12 N*m{ 120 kgf*cm , 9 ft.*lbf }
