FRONT DIFFERENTIAL CARRIER ASSEMBLY > INSTALLATION

for Preparation Click here



1. INSTALL FRONT DIFFERENTIAL CARRIER ASSEMBLY



  1. Install the differential support assembly with bolts E and F.

    Torque:
    100 N*m{ 1020 kgf*cm , 74 ft.*lbf }

  1. Using a jack, slowly raise the front differential carrier assembly to its installation position.

  1. Temporarily install the front differential support assembly with bolts A and B and the nut.

  1. Temporarily install the bolts C and D.

  1. Tighten bolt A.

    Torque:
    120 N*m{ 1224 kgf*cm , 89 ft.*lbf }

  1. Tighten bolt B and the nut.

    Torque:
    120 N*m{ 1224 kgf*cm , 89 ft.*lbf }

  1. Tighten bolts C and D.

    Torque:
    120 N*m{ 1224 kgf*cm , 89 ft.*lbf }

  1. Connect the breather tube to the front differential union.



2. INSTALL FRONT SUSPENSION REBOUND STOPPER SUB-ASSEMBLY LH



  1. Install the suspension rebound stopper LH with the 3 bolts.

    Torque:
    58 N*m{ 591 kgf*cm , 43 ft.*lbf }



3. INSTALL FRONT SUSPENSION REBOUND STOPPER SUB-ASSEMBLY RH



  1. Install the suspension rebound stopper RH with the 3 bolts.

    Torque:
    58 N*m{ 591 kgf*cm , 43 ft.*lbf }



4. INSTALL FRONT DRIVE SHAFT ASSEMBLY LH

  1. Install the front drive shaft (Click here).



5. INSTALL FRONT DRIVE SHAFT ASSEMBLY RH

HINT:
Use the same procedure as the LH side.
