DESCRIPTION

Refer to the System Description (Click here).

P1229 
DTC Detection Drive Pattern
DTC Detection Condition
Trouble Area
Idling for 60 seconds
The actual fuel pressure exceeds the target fuel pressure by 40 MPa or more for 10 seconds (1 trip detection logic).
  1. Short in fuel supply pump (suction control valve) circuit
  2. Fuel supply pump (suction control valve)
  3. Fuel pressure sensor (common rail (for Bank 1))
  4. ECM

Related Data List 
DTC No.
Data List
P1229
  1. Fuel Press
  2. Target Common Rail Pressure
  3. Injection Pressure Correction
  4. Target Pump SCV Current

HINT:
  1. For more information on the fuel supply pump (suction control valve) and common rail system, refer to the System Description (Click here).
  2. When DTC P1229 is stored, check the internal fuel pressure of the common rail by entering the following menus: Powertrain / Engine / Data List / Fuel Press, Target Common Rail Pressure.
    Under a stable condition such as idling or running the engine at 2500 rpm without load, Fuel Press is within +/-5 MPa of Target Common Rail Pressure.
  3. When there is an operating problem with the fuel supply pump (when Fuel Press is more than Target Common Rail Pressure due to a problem with the closing of the suction valve), the values of Injection Pressure Correction and Target Pump SCV Current decrease.


MONITOR DESCRIPTION

  1. P1229 (Fuel over-feed):
    The ECM stores this DTC if the actual fuel pressure inside the common rail remains higher than the target fuel pressure, despite the ECM closing the suction control valve. This DTC indicates that the suction control valve may be stuck open, or there may be a short in its circuit.
    If this DTC is stored, the ECM enters fail-safe mode and limits the engine power. The fail-safe mode continues until the engine switch is turned off.

12.CONFIRM WHETHER MALFUNCTION HAS BEEN SUCCESSFULLY REPAIRED

  1. Connect the intelligent tester to the DLC3.

  1. Clear the DTCs (Click here).

  1. Turn the engine switch off.

  1. Start the engine.

  1. Idle the engine for 60 seconds.

  1. Confirm that the DTC is not output again.

    HINT:
    Perform the following procedure using the tester to determine whether or not the DTC judgment has been carried out.

    1. Enter the following menus: Powertrain / Engine / Utility / All Readiness.

    2. Input DTC P1229.

    3. Check that STATUS is NORMAL. If STATUS is INCOMPLETE or UNKNOWN, increase idling time.
