1. INSTALL PISTON SEAL

  1. Apply lithium soap base glycol grease to a new piston seal.




  1. Install the piston seal to the disc brake cylinder.



2. INSTALL CYLINDER BOOT

  1. Apply lithium soap base glycol grease to the piston and a new cylinder boot.




  1. Install the cylinder boot to the piston as shown in the illustration.



3. INSTALL REAR DISC BRAKE PISTON

  1. Install the cylinder boot to the disc brake cylinder.

    NOTICE:
    Install the boot securely to the grooves of the disc brake cylinder.




  1. Push in the piston by hand and install the cylinder boot onto the grooves of the piston.

    NOTICE:
    Install the boot securely to the grooves of the piston.



4. TEMPORARILY INSTALL REAR DISC BRAKE BLEEDER PLUG

  1. Temporarily install the bleeder plug to the disc brake cylinder.

    HINT:
    The bleeder plug will be tightened to a torque specification in the "Bleed Brake Line" procedure.
