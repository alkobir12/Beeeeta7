1. INSTALL FRONT PROPELLER SHAFT ASSEMBLY

NOTICE:
Refer to the components illustration for the installation direction of the propeller shaft.



  1. for 1VD-FTV:




    1. Align the matchmarks on the propeller shaft flange and differential.

    2. Connect the propeller shaft with the 4 washers and 4 nuts.

      Torque:
      88 N*m{ 900 kgf*cm , 65 ft.*lbf }




    3. Align the matchmarks on the yoke and transfer flange.

    4. Install the propeller shaft with the 4 washers and 4 nuts.

      Torque:
      88 N*m{ 900 kgf*cm , 65 ft.*lbf }



  1. for 1GR-FE, 2UZ-FE and Center Grease Fitting type:




    1. Align the matchmarks on the propeller shaft flange and differential.

    2. Connect the propeller shaft with the 4 washers and 4 nuts.

      Torque:
      88 N*m{ 900 kgf*cm , 65 ft.*lbf }




    3. Align the matchmarks on the propeller shaft flange and transfer flange.

    4. Install the propeller shaft with the 4 washers and 4 nuts.

      Torque:
      88 N*m{ 900 kgf*cm , 65 ft.*lbf }



2. INSTALL PROPELLER SHAFT HEAT INSULATOR



  1. Install the insulator with the 2 bolts.

    Torque:
    16 N*m{ 160 kgf*cm , 12 ft.*lbf }



3. INSTALL NO. 2 ENGINE UNDER COVER



  1. Install the No. 2 engine under cover with the 2 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



4. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY



  1. Install the No. 1 engine under cover with the 10 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



5. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



6. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.
