1. INSTALL TORQUE CONVERTER CLUTCH ASSEMBLY



  1. Using a vernier caliper and straightedge, measure dimension A between the end of the engine and the torque converter contact surface of the drive plate.

  1. Install the torque converter to the transmission housing.




  1. Using a vernier caliper and straightedge, measure dimension B shown in the illustration and check that B is more than A measured in the first step.

    Standard distance:
    B = A + 1.00 mm (0.0394 in.) or more



2. INSTALL TRANSFER ASSEMBLY



  1. Install the transfer with the 8 bolts.

    Torque:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }

    NOTICE:
    Be careful not to damage the oil seal of the transfer adapter.




  1. Install the transfer case lower protector with the 7 bolts.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }

  1. Connect the clamp of the ground cable to the transfer case lower protector.



3. INSTALL AUTOMATIC TRANSMISSION ASSEMBLY



NOTICE:
Check that the 2 straight pins are attached to the engine side.

  1. Install the transmission with the 10 bolts.

    Torque:
    for 17 mm head bolt A:
    71 N*m{ 724 kgf*cm , 52 ft.*lbf }
    for 14 mm head bolt B:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }



4. INSTALL TRANSMISSION HOUSING COVER



  1. Install the transmission housing cover with the 3 bolts.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



5. INSTALL OIL PAN COVER



  1. Install the oil pan cover with the 2 bolts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }



6. CONNECT WIRE HARNESS AND CONNECTOR




  1. Connect the park/neutral position switch connector, 2 transmission wire connectors, 2 speed sensor connectors and 2 or 3 transfer control side connectors.

    HINT:
    Push up the lever until the claw of the transmission wire connector makes a connection sound.

  1. Connect the 8 harness clamps.

  1. Connect the wire harness with the 2 bolts.

    Torque:
    for bolt A:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Tilt up the automatic transmission.




  1. Connect the ground cable with the bolt.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



7. CONNECT BREATHER PLUG HOSE



  1. Connect the 3 breather plug hoses to the wire harness.



8. INSTALL REAR NO. 1 ENGINE MOUNTING INSULATOR



  1. Install the rear engine mounting insulator to the transmission with the 4 bolts.

    Torque:
    59 N*m{ 602 kgf*cm , 44 ft.*lbf }



9. INSTALL NO. 2 FRAME CROSSMEMBER SUB-ASSEMBLY



  1. Install the frame crossmember to the rear engine mounting insulator with the 4 bolts.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }




  1. Install the frame crossmember to the frame with the 4 bolts and 4 nuts.

    Torque:
    110 N*m{ 1122 kgf*cm , 81 ft.*lbf }




  1. Install the engine mounting hole cover.



10. CONNECT OIL COOLER TUBE



  1. Connect the 2 transmission oil cooler hoses as shown in the illustration.

    NOTICE:
    1. Make sure the pinching portion of each clip is facing the direction shown in the illustration.
    2. Make sure the paint mark of each hose is facing outward.

  1. Temporarily install the oil cooler tube to the engine with the bolts A and B. Install the bolt C and tighten it to the specified torque. Then tighten the bolts A and B to the specified torque.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



11. INSTALL DRIVE PLATE AND TORQUE CONVERTER CLUTCH SETTING BOLT



  1. Turn the crankshaft to gain access to the installation locations of the 6 bolts and install the bolts while holding the crankshaft pulley set bolt with a wrench.

    Torque:
    53 N*m{ 540 kgf*cm , 39 ft.*lbf }

    NOTICE:
    First install the black colored bolt and then install the remaining 5 bolts.




  1. Install the oil pan insulator with the 2 bolts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }



12. INSTALL MONOLITHIC CONVERTER ASSEMBLY LH (w/ EGR System)



  1. Set a new gasket to the turbocharger.

  1. Temporarily install the monolithic converter LH with 3 new nuts.

  1. Temporarily install the manifold stay LH with the 3 bolts.

  1. Tighten the 3 nuts of the monolithic converter LH.

    Torque:
    47 N*m{ 479 kgf*cm , 35 ft.*lbf }

  1. Tighten the 3 bolts of the manifold stay LH.

    Torque:
    43 N*m{ 438 kgf*cm , 32 ft.*lbf }

  1. Temporarily install the outlet turbine elbow LH with 3 new nuts.

  1. Temporarily install the manifold stay LH with the 3 bolts.

  1. Tighten the 3 nuts of the outlet turbine elbow LH.

16. INSTALL FRONT NO. 2 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 2 exhaust pipe to the monolithic converter/outlet turbine elbow with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }



17. INSTALL FRONT NO. 1 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 1 exhaust pipe to the converter/outlet turbine elbow with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }



18. INSTALL CENTER EXHAUST PIPE ASSEMBLY



  1. Check the free length.

    1. Using a vernier caliper, measure the free length of the compression spring.

      Free length:
      43 mm (1.69 in.)

      If the free length is less that the minimum, replace the compression spring.

  1. Connect the center exhaust pipe to the 3 exhaust pipe supports.

  1. Set 2 new gaskets to the front No. 1 and No. 2 exhaust pipes.

  1. Install the center exhaust pipe with the 4 bolts and 2 compression springs.

    Torque:
    for center exhaust pipe and front No. 1 exhaust pipe:
    49 N*m{ 496 kgf*cm , 36 ft.*lbf }
    for center exhaust pipe and front No. 2 exhaust pipe:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }

24. INSPECT SHIFT LEVER POSITION

  1. When moving the shift lever from P to R with the engine switch on (IG) and the brake pedal depressed, make sure that it moves smoothly and correctly into position.

  1. Check that the shift lever does not stop when moving the shift lever from R to P, and check that the shift lever does not stick when moving the shift lever from D to S.



  1. Start the engine and make sure that the vehicle moves forward after moving the shift lever from N to D and moves rearward after moving the shift lever to R.
    If there are problems during the above inspections, perform the adjustment using the following procedures.

    1. Move the shift lever to N




    2. Loosen the nut of the floor shift gear shifting rod. Then, with the lever of the floor shift assembly lightly pushed towards the rear of the vehicle, tighten the nut.

      Torque:
      13 N*m{ 130 kgf*cm , 9 ft.*lbf }
