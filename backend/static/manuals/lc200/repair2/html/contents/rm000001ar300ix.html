DTC    P1238    Injector Malfunction

for Preparation Click here


DESCRIPTION

HINT:
  1. For more information on the fuel injector and the common rail system refer to the System Description (Click here).
  2. If DTC P1238 has been stored, refer to the Diagnostic Trouble Code (DTC) Table for Common Rail System (Click here).

The ECM detects combustion deterioration for a specific cylinder.

HINT:
  1. The cylinder which has the compensation value for Injection Feedback Val #1, #2, #3, #4, #5, #6, #7 and #8 that varies from the other cylinders may be malfunctioning.
  2. If DTC P0093 (fuel leaks from high-pressure area) is stored simultaneously, a leakage malfunction of the cylinder has probably occurred.
  3. If DTC P062D (open or short in the No. 1 injector driver (EDU) or fuel injector circuit) is stored simultaneously, there is probably a faulty circuit located between the ECM and the fuel injector including the No. 1 EDU.
  4. If DTC P062E (open or short in the No. 2 injector driver (EDU) or fuel injector circuit) is stored simultaneously, there is probably a faulty circuit located between the ECM and the fuel injector including the No. 2 EDU.
  5. If only DTC P1238 (injector malfunction) has been stored, a fuel injector mechanical malfunction or insufficient compression (valve clearance, etc.) has probably occurred. An open or short malfunction of the ECM, EDU or fuel injector circuit is unlikely.

HINT:
  1. If DTC P1238 is stored, the following symptoms may appear:
    1. Rough idle
    2. Poor driveability
  2. After confirming DTC P1238, check the internal fuel pressure on the intelligent tester by entering the following menus: Powertrain / Engine / Data List / Fuel Press, Target Common Rail Pressure.
    Under a stable condition such as idling or running the engine at 2500 rpm without load, Fuel Press is within +/-5 MPa of Target Common Rail Pressure.


MONITOR DESCRIPTION

  1. P1238 (Injection malfunction, except open or short in fuel injector circuit):
    This DTC will be stored if the engine speed fluctuation between each cylinder is large. The ECM monitors changes in the crankshaft rotation speed using the crankshaft position sensor in order to detect improper combustion. The camshaft position sensor also plays a role in determining which cylinder has the problem. The fluctuation counter increases when irregular crankshaft rotation speed variation exceeds the threshold with the engine idling. Therefore, if any one of the cylinders is operating poorly (rough idle), the ECM stores this DTC.

3.READ VALUE USING INTELLIGENT TESTER (COMPENSATORY INJECTION VOLUME FOR EACH CYLINDER)

  1. Connect the intelligent tester to the DLC3.

  1. Turn the engine switch on (IG) and turn the tester on.

  1. Start the engine and warm it up (engine coolant temperature is 75°C (167°F) or more), and then idle the engine for 1 minute or more.

  1. Enter the following menus: Powertrain / Engine / Data List / Injection Feedback Val #1 to #8.

  1. Read the value.

    Standard value:
    The compensatory injection volume is from -3.0 to 3.0 mm3/st.

    HINT:
    1. If the fuel injector is malfunctioning, the compensatory injection volume remains at -5.0 or 5.0 mm3/st.
    2. The compensatory injection volume is usually from -3.0 to 3.0 mm3/st.
    3. The numbers of the Data List item Injection Feedback Val #1 to #8 do not match the cylinder numbers (refer to the Diesel Injection section of the Data List) (Click here).

  1. Any cylinders that have a higher compensatory injection volume than shown above are considered to be faulty. Use the following steps to inspect and repair the cylinders.

4.PERFORM ACTIVE TEST USING INTELLIGENT TESTER (FUEL CUT FOR IDENTIFYING MALFUNCTION CYLINDER)

  1. Connect the intelligent tester to the DLC3.

  1. Start the engine and turn the tester on.

  1. Enter the following menus: Powertrain / Engine / Active Test / Control the Cylinder #1 to #8 Fuel Cut.

  1. Check the 8 cylinders in sequence to identify a faulty cylinder by performing the power-balance inspection.

    HINT:
    1. If the engine idle speed does not change when a fuel injector is disabled, the cylinder being tested is malfunctioning.
    2. If the cylinder being tested is normal, there will be a significant change in idle speed when the fuel injection is stopped for that cylinder.
