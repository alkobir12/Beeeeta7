NAVIGATION SYSTEM > RDS-TMC Signal Circuit between Radio Receiver and Navigation ECU

for Preparation Click here


DESCRIPTION

Traffic information received by the radio receiver is transmitted to the navigation ECU via this circuit.
If an open or short occurs in this circuit, RDS-TMC information will not be updated or the RDS-TMC will not operate normally.
