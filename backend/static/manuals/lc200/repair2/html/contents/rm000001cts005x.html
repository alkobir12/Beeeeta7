DTC    C1794    Height Control OFF Switch Circuit (Test Mode DTC)

for Preparation Click here


DESCRIPTION

This is the height control system main switch. When the height control switch is pushed, the height control OFF indicator light lights up and height control turns off.
The off condition of the height control will not be canceled until the height control switch is pushed again or the vehicle is driven.

DTC Code
Detection Condition
Trouble Area
C1794
The test mode procedure is performed.
  1. Harness or connector
  2. Suspension control switch (Height control OFF switch)
  3. Suspension control ECU

INSPECTION PROCEDURE

NOTICE:
  1. Before performing troubleshooting, inspect the connectors of related circuits.
  2. If the suspension control ECU or height control sensor is replaced, the vehicle height offset calibration must be performed (Click here).

  1. Remove the suspension control switch (Click here).
