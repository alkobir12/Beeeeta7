DTC    C1210/36    Zero Point Calibration of Yaw Rate Sensor Undone

DTC    C1336/98    Zero Point Calibration of Acceleration Sensor Undone

for Preparation Click here


DESCRIPTION

The skid control ECU receives signals from the yaw rate and G sensor via the CAN communication system.
The yaw rate sensor has a built-in G sensor.
If there is trouble in the bus lines between the yaw rate and G sensor and the CAN communication system, the DTCs U0123/62 (yaw rate sensor communication trouble) and U0124/95 (G sensor communication trouble) are stored.

DTC Code
DTC Detection Condition
Trouble Area
C1210/36
  1. The yaw rate sensor zero point stored in the ECU is cleared.
  2. Zero point calibration has not been completed.
  1. Yaw rate and G sensor
  2. Zero point calibration undone
  3. Harness or connector
  4. Master cylinder solenoid (Skid control ECU)
C1336/98
  1. The G sensor zero point stored in the ECU is cleared.
  2. Zero point calibration has not been completed.
  1. Yaw rate and G sensor
  2. Zero point calibration undone
  3. Harness or connector
  4. Master cylinder solenoid (Skid control ECU)
