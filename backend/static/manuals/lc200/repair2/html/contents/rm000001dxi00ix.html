DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
C1223/43
The ABS control system is abnormal.
ABS control system

HINT:
  1. This DTC is stored when the VSC system detects a malfunction in the ABS system.
  2. When DTC C1223/43 is stored, there is no malfunction in the skid control ECU.
