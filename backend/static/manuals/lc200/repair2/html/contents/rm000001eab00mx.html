DTC    C1268/68    Transfer "L4" Position Switch Circuit

for Preparation Click here


DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
C1268/68
The skid control ECU receives an L4 abnormal status signal from the four wheel drive control ECU.
  1. Center differential lock detection switch
  2. Center differential lock detection switch circuit
  3. Four wheel drive control ECU
  4. ECM
