REAR AIR CONDITIONING UNIT (w/o Heater) > REASSEMBLY

1. INSTALL WIRING AIR CONDITIONING HARNESS SUB-ASSEMBLY


2. INSTALL EVAPORATOR SUB-ASSEMBLY



  1. Sufficiently apply compressor oil to 2 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the evaporator.

  1. Install the evaporator.




  1. Install the rear cooling unit case LH with the 12 screws.



3. INSTALL REAR BLOWER MOTOR



  1. Install the blower motor with the 3 screws.

  1. Connect the connector.



4. INSTALL BLOWER RESISTOR



  1. Install the blower resistor with the 2 screws.

  1. Connect the connector.



5. INSTALL REAR COOLING UNIT EXPANSION VALVE



  1. Using a 4 mm hexagon wrench, install the expansion valve with the 2 hexagon bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }

  1. Attach the clamp.

  1. Connect the connector.



6. INSTALL AIR CONDITIONER ACCESSORY ASSEMBLY



  1. Sufficiently apply compressor oil to 2 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the air conditioner accessory assembly.

  1. Install the air conditioner accessory assembly.

  1. Install the bolt and 2 screws.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }




  1. Install new packing as shown in the illustration.



7. INSTALL DRAIN COOLER HOSE



  1. Attach the claw to install the drain hose.

  1. Install the screw.



8. INSTALL REAR SIDE NO. 3 AIR DUCT



  1. Install the duct with the 2 screws.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }



9. INSTALL COOLING UNIT BRACKET



  1. Install the bracket with the 2 screws.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }
