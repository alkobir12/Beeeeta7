DTC    B1249    Double Locking ECU Communication Stop

for Preparation Click here


DESCRIPTION

DTC B1249 is stored when communication between the double lock door control relay and main body ECU (cowl side junction block LH) stops for more than 10 seconds.

DTC Code
DTC Detection Condition
Trouble Area
B1249
No communication from the double door lock relay for more than 10 seconds.
  1. Double lock door control relay
  2. Main body ECU (cowl side junction block LH)
  3. Harness or connector
