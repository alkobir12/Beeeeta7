GENERAL
This system has the following functions: manual slide open and close; auto slide open and close; manual tilt up and down; auto tilt up and down; and jam protection.

HINT:
If the driver side door is opened with the engine switch off and the sliding roof open, the buzzer sounds and the combination meter indicates that the sliding roof is open.


FUNCTION OF MAIN COMPONENT

Component
Outline
Sliding roof drive gear sub-assembly (Sliding roof ECU)
Sliding roof ECU controls sliding roof motor to rotate forward and backward, which tilts or slides sliding roof glass.
Map light assembly (Sliding roof switch)
Output of operation signals from built-in sliding roof switch to sliding roof ECU are handled by map light.

SYSTEM OPERATION
The sliding roof has the following features.

Function
Outline
Manual slide open and close
This function causes the sliding roof to open (or close) when the OPEN switch (or CLOSE switch) is pressed for less than 0.3 seconds.
The sliding roof stops as soon as switch is released.
Auto slide open and close
This function causes the sliding roof to be fully opened (or closed) when the OPEN switch (or CLOSE switch) is pressed for 0.3 seconds or more.
Manual tilt up and down
This function the causes sliding roof to tilt up (or tilt down) when the UP switch (or DOWN switch) is pressed for less than 0.3 seconds.
Auto tilt up and down
This function causes the sliding roof to be fully tilted up (or tilted down) when the UP switch (or DOWN switch) is pressed for 0.3 seconds or more.
Jam protection function
The jam protection function automatically stops the sliding roof, or stops the sliding roof and makes it open halfway (or fully tilts it upward) if a foreign object gets jammed in the sliding roof during auto close operation (or auto tilt down operation).
Key-off operation
The key-off operation function makes it possible to operate sliding roof for approximately 45 seconds after the engine switch is turned off if the front doors are not opened.
Transmitter-linked open/close operation*
When the main body ECU receives an unlock signal from the transmitter continuously for 3.0 seconds or more, the sliding roof ECU activates the sliding roof motor to open/tilt up the sliding roof.
Similarly, when the main body ECU receives a lock signal from the transmitter continuously for 3.0 seconds or more, the sliding roof ECU activates the sliding roof motor to close the sliding roof.
Key-linked open/close operation*
When the key is not in the vehicle, the driver side door is locked, and the key inserted into the driver side door key cylinder is turned and maintained in the lock position for 3.0 seconds or more, the sliding roof ECU activates the sliding roof motor to close the sliding roof while the key is turned.
Similarly, when the driver side door is unlocked and the key in driver side door is turned and maintained in the unlock position for 3.0 seconds or more, the sliding roof ECU activates the sliding roof motor to open/tilt up the sliding roof.
Entry lock switch-linked close operation*
When the certification ECU (smart key ECU assembly) receives a lock signal from the entry lock switch (driver door) continuously for 3.0 seconds or more, the sliding roof ECU activates the sliding roof motor to close the sliding roof.

HINT:
*: w/ Remote Function
