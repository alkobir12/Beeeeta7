DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
01-D5*1,*4
When either condition below is met:
  1. Device that the sub-code shows is (was) disconnected from the system when turning engine switch on (IG) or on (ACC).
  2. Communication condition with the device that the code shows cannot be obtained when the engine starts.
  1. Power source circuit of component shown by sub-code
  2. AVC-LAN circuit between radio receiver and component shown by sub-code
  3. Component shown by sub-code
01-DB*2,*4
Device indicated by the sub-code is (was) disconnected from the system after the engine starts.
01-D9*1,*4
Device that had functioned before the engine stopped is (was) disconnected from the system when the engine switch is (was) in on (IG) or on (ACC).
01-DA*4
When either condition below is met:
  1. No response is identified when changing modes.
  2. Detected when the sound and image do not change by switch operation.
01-DB*1,*4
Dual alarm is detected.
01-DE*3,*4
Code is stored when the slave device has been disconnected after the engine starts.

HINT:
  1. *1: Even if no failure is detected, a trouble code may be recorded depending on the battery condition or engine start voltage.
  2. *2: If the power connector is disconnected after the engine starts, this code is recorded after 180 seconds.
  3. *3: This code may be stored if an engine start is attempted while the engine is running.
  4. *4: If the device is reported as not existing during verification, check the power source circuit and AVC-LAN circuit for the device.

NOTICE:
  1. Before starting troubleshooting, be sure to clear DTCs to clear codes stored due to the reasons described in the Hint above. Then, check for DTCs and troubleshoot according to the output DTCs.
  2. The radio receiver is the master unit.
  3. Be sure to clear and recheck for DTCs after the inspection is completed to confirm that no DTCs are output.
