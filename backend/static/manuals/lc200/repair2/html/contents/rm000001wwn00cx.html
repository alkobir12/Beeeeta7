DTC    01-DF    Master Error

for Preparation Click here


DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
01-DF*
When either condition below is met:
  1. Device with display fails and master is switched to audio device.
  2. A communication error between the sub-master (audio) and master occurs.
  1. Radio receiver power source circuit
  2. AVC-LAN circuit between radio receiver and component which has stored this code
  3. Radio receiver assembly
  4. Component which has stored this code

HINT:
*: When 210 seconds have elapsed after disconnecting the power supply connector of the master component with the engine switch on (IG) or on (ACC), this code is stored.

NOTICE:
  1. Before starting troubleshooting, be sure to clear DTCs to clear codes stored due to the reasons described in the Hint above. Then, check for DTCs and troubleshoot according to the output DTCs.
  2. The radio receiver is the master unit.
  3. Be sure to clear and recheck for DTCs after the inspection is completed to confirm that no DTCs are output.
