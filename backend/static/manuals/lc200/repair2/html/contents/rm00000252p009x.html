DTC    C0210/33    Rear Speed Sensor RH Circuit

DTC    C0215/34    Rear Speed Sensor LH Circuit

DTC    C1238/38    Foreign Object is Attached on Tip of Rear Speed Sensor RH

DTC    C1239/39    Foreign Object is Attached on Tip of Rear Speed Sensor LH

for Preparation Click here


DESCRIPTION

The speed sensor detects wheel speed and sends the appropriate signals to the ECU. These signals are used to control the Multi-terrain ABS, EBD, BA, VSC, A-TRC, CRAWL, downhill assist control and hill-start assist control systems. This speed sensor contains a sensor IC, which consists of 2 MREs (Magnetic Resistance Element). The speed sensor rotor, which consists of 48 sets of N and S poles that are arranged in a circle, is integrated with the inner race of the hub bearing.
To detect the rotation direction, the output waves are used to determine the relationship of the pulses that are generated by 2 MREs. Upon receiving this signal, the sensor IC outputs a forward or backward wave to the skid control ECU.



DTC Code
DTC Detection Condition
Trouble Area
C0210/33
C0215/34
When any of the following conditions is detected:
1. At a vehicle speed of 10 km/h (6 mph) or more, the pulses are not input for 1 second.
2. A momentary interruption of the speed sensor signal occurs at least 255 times when switching the engine switch on (IG) and off.
3. Continuous noise occurs in the speed sensor signals at a vehicle speed of 20 km/h (12 mph) or more.
4. The speed sensor signal circuit is open for 0.12 seconds or more.
  1. Rear speed sensor RH
  2. Rear speed sensor LH
  3. Harness or connector
  4. Speed sensor rotor
  5. Sensor installation
  6. Master cylinder solenoid (Skid control ECU)
C1238/38
C1239/39
Noise in the speed sensor signals occurs 75 times or more for 5 seconds when the vehicle speed is 20 km/h (12 mph) or more.
  1. Rear speed sensor RH
  2. Rear speed sensor LH
  3. Speed sensor rotor
  4. Sensor installation
  5. Master cylinder solenoid (Skid control ECU)

HINT:
  1. DTC C0210/33 and C1238/38 are for the rear speed sensor RH.
  2. DTC C0215/34 and C1239/39 are for the rear speed sensor LH.
