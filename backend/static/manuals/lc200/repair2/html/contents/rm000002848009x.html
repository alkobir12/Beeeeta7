1. INSTALL ACCELERATOR PEDAL SENSOR ASSEMBLY

NOTICE:
  1. Avoid physical shocks to the accelerator pedal assembly.
  2. Do not disassemble the accelerator pedal assembly.




  1. Install the accelerator pedal with the 2 nuts.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }

  1. Connect the accelerator pedal position sensor connector.



2. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.
