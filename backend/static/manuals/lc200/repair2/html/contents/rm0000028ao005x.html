CRANKSHAFT POSITION SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL CRANKSHAFT POSITION SENSOR

  1. Apply a light coat of engine oil to the O-ring of the sensor.

    NOTICE:
    1. When reusing the sensor, inspect the O-ring.
    2. If the O-ring has scratches or cuts, replace the sensor.




  1. Install the sensor with the bolt.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

  1. Connect the sensor connector.



2. CONNECT COOLER COMPRESSOR ASSEMBLY

  1. Fix the cooler compressor in place with the stud bolt.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }




  1. Install the cooler compressor with the nut and 3 bolts in several steps in the sequence shown in the illustration.

    Torque:
    24 N*m{ 250 kgf*cm , 18 ft.*lbf }

  1. Connect the cooler compressor connector.



3. INSTALL GENERATOR ASSEMBLY



  1. Install the generator with the 2 bolts.

    Torque:
    43 N*m{ 438 kgf*cm , 32 ft.*lbf }




  1. Connect the wire harness clamp bracket with the bolt.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Install the wire harness clamp to the bracket.

  1. Connect the generator wire with the nut.

    Torque:
    9.8 N*m{ 100 kgf*cm , 87 in.*lbf }

  1. Install the terminal cap.

  1. Connect the generator connector.




  1. Connect the wire harness clamp bracket with the nut.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



4. INSTALL FAN AND GENERATOR V BELT



  1. While turning the belt tensioner counterclockwise, align the holes, and then insert a bar of φ6 mm (0.236 in.) into the holes to fix the belt tensioner in place.



  1. Install the fan and generator V belt.

    HINT:

    If it is hard to install the fan and generator V belt, perform the following procedures.
    1. Put the fan and generator V belt on all parts except the vane pump, as shown in the illustration.
    2. While releasing the belt tension by turning the belt tensioner counterclockwise, put the fan and generator V belt on the vane pump.

  1. While turning the belt tensioner counterclockwise, remove the bar.



5. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY

  1. Install the engine under cover with the 10 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



6. INSTALL FRONT FENDER APRON SEAL LH



  1. Install the seal with the 4 clips.



7. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



9. INSTALL V-BANK COVER



  1. Install the V-bank cover with the 2 nuts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }



10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
