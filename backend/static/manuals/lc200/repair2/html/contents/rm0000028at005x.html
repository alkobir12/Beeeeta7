KNOCK SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL KNOCK SENSOR



  1. Install the 2 sensors with the 2 bolts as shown in the illustration.

    Torque:
    20 N*m{ 204 kgf*cm , 15 ft.*lbf }

  1. Connect the 2 sensor connectors.



2. INSTALL NO. 1 WATER OUTLET PIPE



  1. for 2 Nuts and Bolt Type
    Install the water outlet pipe with the 2 nuts and bolt.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

  1. for 3 Bolts Type
    Install the water outlet pipe with the 3 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

  1. Connect the 4 wire harness clamps.



3. INSTALL CYLINDER HEAD SUB-ASSEMBLY RH (for Bank 1)

  1. Install the cylinder head RH (Click here).



4. INSTALL ENGINE ASSEMBLY

  1. Install the engine (Click here).



5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
