DTC    B2289    Key Collation Waiting Time Over

for Preparation Click here


DESCRIPTION

This DTC is stored when there is a LIN communication problem between the main body ECU and certification ECU (smart key ECU assembly) or when there is a problem in the engine immobiliser system.

DTC Code
Detection Condition
Trouble Area
B2289
When either of the following conditions is met:
  1. Communication or the communication line is abnormal among the main body ECU, certification ECU (smart key ECU assembly), steering lock ECU and ID code box (immobiliser code ECU).
  2. The immobiliser system malfunctions.
  1. Main body ECU
  2. Engine switch
  3. Certification ECU (smart key ECU assembly)
  4. Key
  5. Engine immobiliser system
  6. Harness or connector
