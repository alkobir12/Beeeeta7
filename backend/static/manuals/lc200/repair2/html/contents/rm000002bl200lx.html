1. INSPECT SPEED SENSOR NT



  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Condition
    		Specified Condition
    1 - 2
    		20°C (68°F)
    		560 to 680 Ω

    If the result is not as specified, replace the sensor.
