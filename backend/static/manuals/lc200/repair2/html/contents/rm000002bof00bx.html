1. INSTALL FAN AND GENERATOR V BELT



  1. Set the V belt onto every part except the belt tensioner, as shown in the illustration.

  1. Loosen the V belt by turning the belt tensioner counterclockwise.

  1. Set the V belt to the belt tensioner.




  1. Check that the belt fits properly in the ribbed grooves.

    HINT:
    Make sure to check by hand that the belt has not slipped out of the grooves on the bottom of the pulley.




  1. Check that the arrow on the belt tensioner is within area "A".
    If the arrow is outside area "A", replace the fan and generator V belt.

    HINT:
    When a new belt is installed, the arrow should be within area "B". If not, the fan and generator V belt is not installed correctly.



2. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY



  1. Install the No. 1 engine under cover with the 10 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



3. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



4. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



5. INSTALL AIR CLEANER HOSE ASSEMBLY



  1. Install the air cleaner hose so that the protrusion of the air cleaner cap aligns with the groove of the hose as shown in the illustration.

  1. Tighten the 2 clamps.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Connect the vacuum transmitting hose.

  1. Connect the No. 2 ventilation hose.



6. INSTALL V-BANK COVER SUB-ASSEMBLY



  1. Attach the 2 V-bank cover hooks to the bracket.

  1. Install the V-bank cover with the 2 nuts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }
