STARTER (for 1.4 kW Type) > REASSEMBLY

for Preparation Click here




1. INSTALL STARTER ARMATURE ASSEMBLY

  1. Install the starter armature to the starter yoke.



2. INSTALL STARTER BRUSH HOLDER ASSEMBLY

  1. Install a new O-ring to the groove of the starter yoke.




  1. Place the brush holder on the starter yoke.

  1. Using a screwdriver, hold the brush spring back.

  1. Connect the brush to the brush holder.

  1. Connect the 4 brushes.

    NOTICE:
    Check that the positive (+) lead wires are not grounded.




  1. Install 2 new O-rings and the end cover with the 2 screws.

    Torque:
    1.5 N*m{ 15 kgf*cm , 13 in.*lbf }

  1. Install the dust protector as shown in the illustration.



3. INSTALL STARTER CLUTCH SUB-ASSEMBLY



  1. Apply grease to the steel ball, return spring, clutch roller, retainer and idler gear.

  1. Install the steel ball.

  1. Install a new O-ring to the starter housing.

  1. Insert the return spring into the magnet starter switch hole.

  1. Install the starter clutch, idler gear, retainer and clutch roller.




  1. Install the starter housing to the magnet starter switch with the 2 bolts.

    Torque:
    5.9 N*m{ 60 kgf*cm , 52 in.*lbf }

  1. Install the dust protector as shown in the illustration.



4. INSTALL STARTER YOKE ASSEMBLY



  1. Install a new O-ring to the groove of the starter yoke.

  1. Align the protrusion of the starter yoke with the groove of the magnet starter switch.




  1. Install the starter yoke with the 2 through bolts.

    Torque:
    5.9 N*m{ 60 kgf*cm , 52 in.*lbf }

  1. Connect the lead wire to terminal C with the nut.

    Torque:
    5.9 N*m{ 60 kgf*cm , 52 in.*lbf }
