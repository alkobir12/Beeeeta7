STARTER (for 1.6 kW Type) > REASSEMBLY

for Preparation Click here


HINT:
Use high temperature-resistant grease to lubricate the bearings and sliding parts when assembling the starter.



1. INSTALL STARTER CENTER BEARING CLUTCH SUB-ASSEMBLY



  1. Apply high-temperature grease to the starter drive lever set pin, as shown in the illustration.




  1. Install the starter drive lever set pin to the starter center bearing clutch.

  1. Install the starter center bearing clutch and starter drive lever set pin together to the starter drive housing.



2. INSTALL PLANETARY GEAR



  1. Apply high-temperature grease to the planetary gears and pin parts of the planetary shaft.

  1. Install the 3 planetary gears onto the pins of the starter center bearing clutch.



3. INSTALL STARTER ARMATURE ASSEMBLY



  1. Apply high-temperature grease to the plate washer, armature shaft, bearing and a new snap ring.

  1. Install the starter armature and plate washer into the starter commutator end frame.




  1. Using snap ring pliers, install a new snap ring.

    NOTICE:
    1. Be sure to install the snap ring in the armature shaft groove securely.
    2. Be sure to properly install the snap ring because it expands easily.




  1. Check the snap ring length.

    1. Using a vernier caliper, measure the snap ring length.

      Maximum length:
      5.0 mm (0.197 in.)

      If the length is more than the maximum, replace the snap ring.



4. INSTALL STARTER COMMUTATOR END FRAME COVER



  1. Install the starter commutator end frame cover into the starter commutator end frame.



5. INSTALL STARTER ARMATURE PLATE



  1. Align the claw of the armature plate with the groove inside the starter yoke, and install the starter armature plate.



6. INSTALL STARTER COMMUTATOR END FRAME ASSEMBLY



  1. Align the starter commutator end frame rubber with the groove of the starter yoke.

  1. Install the starter commutator end frame to the starter yoke.

    NOTICE:
    The magnet of the starter yoke may attract the starter armature when the starter commutator end frame is installed, causing the magnet to break.



7. INSTALL STARTER YOKE ASSEMBLY



  1. Align the claw of the starter yoke with the groove inside the starter drive housing.




  1. Install the starter yoke with the 2 bolts.

    Torque:
    6.0 N*m{ 61 kgf*cm , 53 in.*lbf }



8. INSTALL REPAIR SERVICE STARTER KIT



  1. Apply high-temperature grease to the plunger and hook.




  1. Hang the plunger hook of the repair service starter kit on the drive lever.

  1. Install the plunger and return spring.




  1. Install the repair service starter kit with the 2 screws.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }




  1. Connect the lead wire to the terminal with the nut.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }
