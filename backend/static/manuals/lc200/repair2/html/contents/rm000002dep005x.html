STARTER (for 2.0 kW Type) > REASSEMBLY

for Preparation Click here


HINT:
Use high temperature-resistant grease to lubricate the bearings and sliding parts when assembling the starter.



1. INSTALL STARTER ARMATURE ASSEMBLY

  1. Apply high-temperature grease to the bearings, and install it to the starter yoke.



2. INSTALL STARTER BRUSH HOLDER ASSEMBLY

  1. Place the brush holder on the armature.




  1. Using a screwdriver, connect the 4 brushes.

    NOTICE:
    Check that the positive (+) lead wires are not grounded.

  1. Install a new O-ring to the groove of the starter yoke.




  1. Install the end frame with the 2 screws.

    Torque:
    3.8 N*m{ 39 kgf*cm , 34 in.*lbf }



3. INSTALL MAGNET STARTER SWITCH ASSEMBLY

  1. Apply high-temperature grease to the steel ball and install it to the clutch shaft hole.




  1. Apply high-temperature grease to the return spring, clutch roller, retainer and idler gear.

  1. Insert the return spring into the magnet starter switch hole.

  1. Install the starter clutch, idler gear, retainer and clutch roller to the starter housing.




  1. Install the starter housing to the magnet starter switch with the 2 screws.

    Torque:
    9.3 N*m{ 95 kgf*cm , 82 in.*lbf }



4. INSTALL STARTER YOKE ASSEMBLY

  1. Install a new O-ring to the groove of the starter yoke.




  1. Align the key of the starter yoke with the groove of the magnet starter switch.




  1. Install the starter yoke and armature with the 2 bolts.

    Torque:
    9.3 N*m{ 95 kgf*cm , 82 in.*lbf }

  1. Connect the lead wire to the magnet switch terminal with the nut.

    Torque:
    5.9 N*m{ 60 kgf*cm , 52 in.*lbf }
