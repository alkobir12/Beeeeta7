KNOCK SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL KNOCK SENSOR



  1. Install the 2 sensors with the 2 nuts as shown in the illustration.

    Torque:
    20 N*m{ 204 kgf*cm , 15 ft.*lbf }

  1. Connect the 2 sensor connectors.



2. INSTALL AIR PUMP WITH BRACKET AND AIR SWITCHING VALVE



  1. Install the air pump with bracket with the 2 bolts and 2 nuts in the order shown in the illustration.

    Torque:
    16 N*m{ 163 kgf*cm , 12 ft.*lbf }

  1. Connect the pressure sensor connector.

  1. Connect the air switching valve connector.



3. INSTALL NO. 2 AIR INJECTION SYSTEM HOSE



  1. Install the hose.



4. INSTALL WATER BY-PASS PIPE SUB-ASSEMBLY

  1. Apply soapy water to the O-ring.

  1. Install a new O-ring to the water by-pass pipe.




  1. Push in the water by-pass pipe.

  1. Install the water by-pass pipe with the bolt.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }

  1. Connect the 2 vacuum switching valve hoses to the water by-pass pipe clamp.

  1. Connect the wire harness clamp.

  1. Connect the connector.



5. INSTALL INTAKE MANIFOLD

  1. Install the intake manifold (Click here).



6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



7. INSPECT FOR FUEL LEAK

  1. Connect the intelligent tester to the DLC3.

  1. Turn the engine switch on (IG) and intelligent tester ON.

    NOTICE:
    Do not start the engine.

  1. Enter the following menus: Powertrain / Engine and ECT / Active Test / Activate the Fuel Pump Speed Control.

  1. Check that there are no fuel leaks after doing maintenance anywhere on the fuel system.
