1. INSTALL CANISTER

  1. Install the outlet charcoal canister hose to the canister.

  1. Install the charcoal canister hose to the canister.

  1. Install the 2 fuel hose clamps to the canister.




  1. Install the canister with the 3 bolts.

    Torque:
    20 N*m{ 199 kgf*cm , 14 ft.*lbf }




  1. Connect the outlet charcoal canister hose.

  1. Connect the charcoal canister hose.




  1. Connect the hose.
