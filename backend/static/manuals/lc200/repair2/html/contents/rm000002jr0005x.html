DTC    B2074    Driver Side Seat Belt Buckle Switch Circuit Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when there is a malfunction in the front seat inner belt buckle switch circuit for the driver side. The seat belt control ECU receives buckle switch condition information from the center airbag sensor via the CAN communication line and controls the pre-crash safety system.
When DTC B2074 is stored, DTC B1655 is also output.

DTC Code
DTC Detection Condition
Trouble Area
B2074
Malfunction in the front seat inner belt (buckle switch) circuit.
  1. Front seat inner belt LH assembly
  2. Center airbag sensor
  3. Seat belt control ECU
  4. CAN communication system
