CUSTOMIZING FUNCTION WITH INTELLIGENT TESTER (REFERENCE)

NOTICE:
  1. When the customer requests a change in a function, first make sure that the function can be customized.
  2. Be sure to make a note of the current settings before customizing.
  3. When troubleshooting a function, first make sure that the function is set to the default setting.

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the intelligent tester on.

  4. Enter the following menus: Customize Setting.

  5. Select the setting by referring to the table below.

    Air Conditioner 
    Display
    		Default
    		Contents
    		Setting
    Set Temperature Shift
    		Normal
    		Function to set the temperature shift.
    		+2 C/+1 C/Normal/-1 C/-2 C
    Evaporator Control
    		Automatic
    		Function to set the evaporator control to the automatic position (Automatic) to save power, or to the coldest position (Manual) to dehumidify the air and to prevent the windows from fogging up.
    		Manual/Automatic
    Compressor/Air Inlet DEF operation
    		Link
    		Function to automatically turn the A/C on when the FRONT DEF button is pressed.
    		Normal/Link
    Compressor Mode
    		Automatic
    		Function to turn the A/C on automatically by pressing the AUTO button when the blower is on and the A/C is off.
    		Manual/Automatic
    Air Inlet Mode
    		Automatic
    		Function to automatically change to recirculation mode when the A/C is turned on.
    		Manual/Automatic
    Foot/DEF Auto Mode
    		ON
    		Function to turn the airflow from FOOT/DEF on automatically when auto mode is on.
    		ON/OFF
    Foot/DEF Automatic Blow Up Function
    		ON
    		Function to change the blower level automatically when the defroster is on.
    		ON/OFF
    Ambient Temperature Shift
    		Normal
    		Function to control the shifted ambient temperature in relation to the displayed ambient temperature.
    		+3 C/+2 C/+1 C/Normal/-1 C/-2 C/-3 C
    Button Press Buzzer
    		ON
    		Function to sound a buzzer when a button is pressed.
    		ON/OFF
