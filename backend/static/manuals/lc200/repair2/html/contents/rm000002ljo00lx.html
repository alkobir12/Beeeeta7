FRONT SEAT OUTER BELT ASSEMBLY > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL FRONT SHOULDER BELT ANCHOR ADJUSTER ASSEMBLY



  1. Align the adjuster positioning hole with the claw, and install the adjuster with the 2 bolts.

    HINT:
    First install the lower bolt, and then install the upper bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



2. INSTALL FRONT SEAT OUTER BELT ASSEMBLY



NOTICE:
When installing the retractor, make sure the claws of the vehicle (labeled "a" in the illustration) only contact the installation areas of the retractor.

  1. Align the claws of the vehicle with the seat belt retractor positioning holes.

  1. Install the seat belt with the bolt.

    Torque:
    8.5 N*m{ 87 kgf*cm , 75 in.*lbf }




  1. Connect the pretensioner connector labeled A as shown in the illustration.

  1. Connect the tension reducer connector labeled B.

  1. w/ Pre-Crash Safety System:
    Connect the pre-crash safety connector labeled C.




  1. Install the shoulder anchor to the shoulder belt anchor adjuster with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



3. INSTALL CENTER PILLAR GARNISH LH



  1. for 9 Speakers:
    Connect the speaker connector.

  1. Attach the clip and 3 guides to install the front pillar garnish.



4. INSTALL REAR ASSIST GRIP ASSEMBLY



HINT:
Use the same procedure to install the rear assist grip on the other side.

  1. Attach the 2 claws to install the rear assist grip.

  1. Install the 2 bolts.




  1. Attach the 4 claws to install the 2 assist grip plugs.



5. INSTALL CENTER LOWER PILLAR GARNISH



HINT:
  1. for Manual Seat:
    When installing the center lower pillar garnish, move the front seat and seatback to the foremost upright position.
  2. for Power Seat:
    When installing the center pillar garnish cover, connect the cable to the negative (-) battery terminal and operate the power seat switch to move the front seat and seatback to the foremost upright position.
  3. for Manual Seat:
    After moving the front seat, disconnect the cable from the negative (-) battery terminal.

  1. Attach the 2 claws and 7 clips to install the center lower pillar garnish.




  1. Install the seat belt anchor with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



6. INSTALL CENTER PILLAR GARNISH COVER

HINT:
  1. for Manual Seat:
    When installing the center pillar garnish cover, move the front seat and seatback to the foremost upright position.
  2. for Power Seat:
    When installing the center pillar garnish cover, connect the cable to the negative (-) battery terminal and operate the power seat switch to move the front seat and seatback to the foremost upright position.
  3. for Power Seat:
    After moving the front seat, disconnect the cable from the negative (-) battery terminal.




  1. Attach the 2 clips and 2 guides to install the cover.



7. INSTALL REAR DOOR SCUFF PLATE



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



8. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.



9. INSTALL FRONT DOOR SCUFF PLATE



  1. Attach the 7 claws and 4 clips to install the scuff plate.



10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
