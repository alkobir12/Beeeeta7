FRONT WIPER RUBBER > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for both the RH and LH side.
  2. The procedures listed below are for the LH side.



1. INSTALL WIPER RUBBER LH



  1. Install the 2 backing plates to the rubber.

    NOTICE:
    Make sure the backing plates are facing the proper direction.




  1. Install the wiper rubber to the claw of the wiper blade in the direction indicated by the arrow in the illustration.

    HINT:
    Install the wiper rubber so that the head part (large side) of the wiper rubber faces the arm axle side.

  1. Attach the head part (large side) of the wiper rubber to the rear end side claw of the wiper blade.

    HINT:
    Push the wiper blade into the grooves of the wiper rubber to attach if completely.



2. INSTALL FRONT WIPER BLADE LH



  1. Install the wiper blade as shown in the illustration.
