REAR DOOR > REASSEMBLY

for Preparation Click here


HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL REAR DOOR WEATHERSTRIP LH



  1. Attach the 21 clips to install the weatherstrip.

    HINT:
    If clips are damaged during installation, replace them.



2. INSTALL REAR DOOR CHECK ASSEMBLY LH

  1. Apply MP grease to the sliding areas of the door check.




  1. Install the door check to the door panel with the 2 nuts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Apply adhesive to the threads of the bolt.

    Adhesive:
    Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent

  1. Install the bolt.

    Torque:
    27 N*m{ 275 kgf*cm , 20 ft.*lbf }



3. INSTALL REAR DOOR CHECK COVER LH



  1. Install the door check cover.



4. INSTALL DOOR ELECTRICAL KEY OSCILLATOR (for Entry Function)



  1. Install the door electrical key oscillator with the screw.



5. INSTALL NO. 4 ELECTRICAL KEY WIRE HARNESS (for Entry Function)



  1. Connect the connector.

  1. Attach the 2 clamps to install the wire harness to the frame.



6. INSTALL REAR DOOR OUTSIDE HANDLE FRAME SUB-ASSEMBLY LH

  1. Apply MP grease to the sliding parts on the rear door outside handle frame sub-assembly.




  1. Attach the 2 claws to install the rear door outside handle frame sub-assembly.




  1. Using a T30 "TORX" wrench, install the front door outside handle frame sub-assembly with the screw.

    Torque:
    4.0 N*m{ 41 kgf*cm , 35 in.*lbf }




  1. for Entry Function:

    1. Attach the clamp.



7. INSTALL REAR NO. 2 DOOR OUTSIDE HANDLE PAD LH



  1. Attach the 2 claws to install the rear No. 2 door rear outside handle pad.



8. INSTALL REAR NO. 1 DOOR OUTSIDE HANDLE PAD LH



  1. Attach the 3 claws to install the rear No. 1 door outside handle pad.



9. INSTALL REAR DOOR OUTSIDE HANDLE ASSEMBLY LH



  1. Insert the front end of the rear door outside handle assembly into the rear door outside handle frame.

    NOTICE:
    If the bellcrank lever is not pulled and held when installing the outside handle, the bellcrank lever will interfere with the outside handle and the release plate may be damaged

  1. Insert the rear end of the rear door outside handle assembly into the rear door outside handle frame. Next, slide the rear door outside handle assembly toward the front of the vehicle to install it.




  1. Using a T30 ''TORX'' socket, tighten the screw.

  1. for Entry Function:

    1. Connect the connector.



10. INSTALL REAR DOOR OUTSIDE HANDLE COVER LH



  1. Attach the claw to install the rear door outside handle cover.




  1. Using a T30 ''TORX'' socket, install the cover with the screw.



11. INSTALL REAR DOOR INSIDE LOCKING CABLE ASSEMBLY LH



  1. Install the rear door inside locking cable assembly.




  1. Attach the 3 claws.



12. INSTALL REAR DOOR LOCK REMOTE CONTROL CABLE ASSEMBLY LH



  1. Install the rear door lock remote control cable assembly.




  1. Attach the claw.



13. INSTALL REAR DOOR LOCK ASSEMBLY LH

  1. Apply MP grease to the sliding parts of the rear door lock assembly.




  1. Insert the rear door lock assembly to the rear door outside handle release plate, and set it to the rear door panel.

  1. Make sure that the rear door outside handle frame release plate is securely connected to the rear door lock assembly.

  1. Using a T30 ''TORX'' wrench, install the door lock with the 3 screws.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



14. INSTALL REAR DOOR LOCK CHILD PROTECTION COVER LH


15. INSTALL REAR DOOR FRONT WINDOW FRAME MOULDING LH

  1. Clean the vehicle body surface.

    1. Using a heat light, heat the vehicle body surface.

    2. Remove the double-sided tape from the vehicle body surface.

    3. Wipe off any tape adhesive residue with cleaner.



  1. Install a new window frame moulding.

    1. Using a heat light, heat a new window frame moulding and the vehicle body surface.

    2. Remove the peeling paper from the face of the window frame moulding.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.




    3. Attach the clip and double-sided tape to install the window frame moulding.

      HINT:
      Press the window frame moulding firmly to install it.



16. INSTALL REAR DOOR BELT MOULDING ASSEMBLY LH



  1. Attach the claw to install the belt moulding.



17. INSTALL REAR NO. 1 POWER WINDOW REGULATOR MOTOR ASSEMBLY LH

  1. Apply MP grease to the sliding and rotating areas of the regulator motor.




  1. Using a T25 ''TORX'' driver, install the motor with the 3 screws.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }

    HINT:
    A new rear window regulator uses self-tapping screws to thread new installation holes when the self-tapping screws are inserted.



18. INSTALL REAR DOOR WINDOW REGULATOR SUB-ASSEMBLY LH



  1. Apply MP grease to the sliding parts of the rear door window regulator sub-assembly.

  1. Loosely install the temporary bolt onto the window regulator.

  1. Insert the window regulator into the door panel. Use the temporary bolt to hang the window regulator on the door panel.

    NOTICE:
    Be careful not to drop the window regulator as it may become damaged.

  1. Temporarily install the window regulator with the 3 bolts.

  1. Tighten the 4 bolts in the order shown in the illustration.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



19. REMOVE REAR NO. 2 DOOR FRAME GARNISH LH



  1. Attach a new clip to install the rear door frame garnish.



20. INSTALL REAR DOOR FRAME GARNISH LH



  1. Attach a new clip to install the rear door frame garnish.



21. INSTALL REAR DOOR GLASS SUB-ASSEMBLY LH



  1. Slide the rear door glass sub-assembly as shown in the illustration to install it.



22. INSTALL REAR DOOR QUARTER WINDOW WEATHERSTRIP LH

  1. Install the rear door quarter window glass to the rear door quarter window weatherstrip.



23. INSTALL REAR DOOR QUARTER WINDOW GLASS LH



  1. Install the quarter glass together with the rear door quarter window weatherstrip in the direction indicated by the arrow in the illustration.



24. INSTALL REAR DOOR REAR LOWER WINDOW FRAME SUB-ASSEMBLY LH



  1. Install the rear door rear lower window frame with the 2 bolts and screw.



25. INSTALL REAR DOOR GLASS RUN LH



  1. Install the rear door glass run.



26. INSTALL REAR DOOR PANEL PROTECTOR LH



  1. Attach the claw to install the door panel protector.



27. INSTALL REAR DOOR SERVICE HOLE COVER LH

  1. Apply butyl tape to the door.




  1. Pass the rear door lock remote control cable and rear door inside locking cable through a new rear door service hole cover.

    NOTICE:
    1. When installing the service hole cover, pull the links and connectors through the service hole cover.
    2. There should be no wrinkles or folds after attaching the service hole cover.
    3. After attaching the service hole cover, check the sealing quality.




  1. Connect the 2 connectors.

  1. Attach the 6 clamps.




  1. Install the bolt as shown in the illustration.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



28. INSTALL REAR SPEAKER SET (w/ Rear Speaker)

  1. Install the speaker with the 3 screws.

    NOTICE:

  1. Connect the connector.
