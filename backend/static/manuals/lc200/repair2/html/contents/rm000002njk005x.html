CLOCK SYSTEM OUTLINE (w/ Navigation System)

  1. The clock can be set through the multi-display screen.

  2. The navigation system receives time data from Global Positioning System (GPS) satellites. The clock receives time data from the navigation system every minute, and corrects the time.


COMMUNICATION SYSTEM OUTLINE (w/ Navigation System)

  1. Components of the clock system communicate with each other via the AVC-LAN.

  2. The radio receiver has enough resistance (60 to 80 Ω) necessary for transmitting communication signals. This is essential for communication.

  3. If a short circuit or open circuit occurs in the AVC-LAN circuit, communication is interrupted and the clock system will stop functioning.
