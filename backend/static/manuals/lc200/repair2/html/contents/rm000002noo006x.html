POWER MIRROR CONTROL SYSTEM (w/ Retract Mirror) > Power Mirrors do not Return to Memorized Position

for Preparation Click here


SYSTEM DESCRIPTION

When the seat memory switch 1, seat memory switch 2 or seat memory switch 3 is pressed, the position control ECU and switch mirror position signal is sent through the CAN communication line to the outer mirror control ECU. The outer mirror control ECU then activates the mirror control motors to move the mirrors to the previously recorded positions.
