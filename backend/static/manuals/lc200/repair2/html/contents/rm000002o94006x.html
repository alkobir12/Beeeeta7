FRONT PASSENGER AIRBAG ASSEMBLY > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the RHD and LHD.
  2. The procedures listed below are the LHD side.



1. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY



  1. Attach the 5 hooks (A).

  1. Attach the 5 hooks (B) to install the front passenger airbag on the instrument panel.




  1. Install the 2 screws.




  1. Connect the 2 connectors and install the instrument panel wire assembly to the front passenger airbag.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Attach the claw and install the wire.



2. INSTALL INSTRUMENT PANEL SAFETY PAD

  1. Install the instrument panel safety pad (Click here).



3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



4. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
