REAR AIRBAG SENSOR > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL REAR AIRBAG SENSOR



  1. Check that the engine switch is turned off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.

  1. Install the rear airbag sensor with the bolt.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

    NOTICE:
    1. If the rear airbag sensor has been dropped, or there are any cracks, dents or other defects in the case, bracket or connector, replace it with a new one.
    2. When installing the rear airbag sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

  1. Check that there is no looseness in the installation parts of the rear airbag sensor.

  1. Connect the connector.



2. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH (w/ Sliding Roof)



  1. Attach the 4 claws to install the quarter trim cover.

  1. Install the 7 screws.




  1. w/ Rear Heater:
    Install the duct with the 8 screws.



3. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH (w/o Sliding Roof)

  1. w/ Rear Heater:
