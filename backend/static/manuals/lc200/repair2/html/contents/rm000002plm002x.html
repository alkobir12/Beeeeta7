HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL SELF POWER SIREN ASSEMBLY



  1. Connect the connector.

  1. Install the siren with the 2 bolts.



2. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH



HINT:
When installing the front quarter trim panel, operate the reclining adjuster release handle and move the No. 1 rear seat to the position shown in the illustration.



  1. w/ Rear No. 2 Seat, except Face to Face Seat Type:

    1. w/o Rear Air Conditioning System:
      Connect the rear seat lock control lever cable.

    2. w/ Rear Air Conditioning System:
      Connect the thermistor connector and rear seat lock control lever cable.

    3. Attach the 18 clips and 2 claws to install the quarter trim panel.



    4. Install the clip and bolt.

      Torque:
      12 N*m{ 122 kgf*cm , 9 ft.*lbf }






  1. w/o Rear No. 2 Seat or w/ Rear No. 2 Seat, for Face to Face Seat Type:

    1. Attach the 18 clips and 2 claws to install the quarter trim panel.



    2. Install the clip.






  1. w/ Rear No. 2 Seat, except Face to Face Seat Type:
    Install the rear No. 2 seat belt anchor with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the vehicle body.




  1. Install the rear No. 1 seat belt anchor with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }




  1. Attach the 3 claws to install the cover.



3. INSTALL REAR SEAT COVER CAP (w/ Rear No. 2 Seat)



HINT:
Use the same procedure to install the rear seat cover cap on the other side.

  1. Attach the 3 claws to install the rear seat cover cap.



4. INSTALL NO. 1 TONNEAU COVER HOLDER CAP (w/ Tonneau Cover)



HINT:
Use the same procedure to install the tonneau cover holder cap on the other side.

  1. Attach the 2 claws to install the tonneau cover holder cap.



5. INSTALL REAR DOOR SCUFF PLATE LH



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



6. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.



7. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



8. INSTALL REAR NO. 2 SEAT ASSEMBLY (for Face to Face Seat Type)



  1. Temporarily install the rear No. 2 seat with the 4 bolts.

  1. Tighten the bolts in the order shown in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }



9. INSTALL REAR SIDE SEAT LEG PROTECTOR LH (for Face to Face Seat Type)



  1. Attach the 2 claws to install the protector.



10. INSTALL REAR NO. 2 SEAT ASSEMBLY (except Face to Face Seat Type)



  1. Temporarily install the seat assembly with the 4 bolts.

    NOTICE:
    Be careful not to damage the vehicle body.

  1. Tighten the bolts in the order shown in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }



11. INSTALL REAR NO. 2 SEAT HINGE COVER LH (except Face to Face Seat Type)



  1. Attach the clip and 2 claws to install the cover.



12. INSTALL REAR SEAT CUSHION HINGE COVER LH (except Face to Face Seat Type)



  1. Attach the 3 claws to install the cover.

  1. Return the seat to the upright position.



13. INSTALL REAR NO. 2 SEAT HEADREST ASSEMBLY LH (except Face to Face Seat Type)
