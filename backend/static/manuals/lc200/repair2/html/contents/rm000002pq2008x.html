1. INSTALL CAMSHAFT POSITION SENSOR



  1. Apply a light coat of engine oil to the O-ring.

    NOTICE:
    When reusing the sensor, inspect the O-ring.
    If the O-ring has scratches or cuts, replace the sensor.




  1. Install the sensor with the bolt.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Connect the sensor connector.



2. INSTALL NO. 1 ENGINE COVER SUB-ASSEMBLY



  1. Install the engine cover with the 2 nuts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }
