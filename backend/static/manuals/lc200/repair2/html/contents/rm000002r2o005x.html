DTC    U0155    Lost Communication with Instrument Panel Cluster Control Module (Combination Meter)

for Preparation Click here


DESCRIPTION

When the clearance warning ECU self-diagnosis determines that the CAN communication system is malfunctioning, this DTC is stored.

DTC Code
DTC Detection Condition
Trouble Area
U0155
Lost communication with the Instrument Panel Cluster (IPC) control module.
CAN communication system

HINT:
When 2 or more DTCs starting with "U" are output simultaneously, inspect the connectors and wire harness of each ECU.
