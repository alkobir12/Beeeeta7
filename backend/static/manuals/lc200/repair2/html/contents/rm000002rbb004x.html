FRONT POWER SEAT CONTROL SYSTEM (w/ Seat Position Memory System) > Wireless-linked Return Function does not Operate

for Preparation Click here


DESCRIPTION

When a door is unlocked, the certification ECU (smart key ECU) sends a door unlock signal and key ID signal to the position control ECU and switch. When the position control ECU and switch receives the door unlock signal, it stores the key ID. When the driver door is opened, the memory call and memory command information of the stored key ID is sent to each driving position related control ECU. Each control ECU receives the memory commands and performs the memory call operation according to predetermined control timing values.

INSPECTION PROCEDURE

1.CHECK ENTRY UNLOCK FUNCTION AND WIRELESS UNLOCK FUNCTION

  1. Check that the driver side door unlocks when holding the driver side door outside handle, or when pressing the transmitter unlock switch.

    OK:
    Driver side door unlocks normally.

  1. Perform a memory operation properly. Check that the buzzer sounds to indicate the completion of the memory operation.

    NOTICE:
    1. The seat position will not be recorded if the seat memory SET switch and 2 or more of the seat memory switches (for example, seat memory switch 1 and seat memory switch 2) are pressed simultaneously.
    2. If a memorizing operation has failed, release all switches. The seat memory function does not operate unless the switches are released.
