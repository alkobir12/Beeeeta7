DTC    B2768    Tilt Sensor Internal Circuit Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when one of the following occurs: 1) yaw rate sensor power supply malfunction; 2) yaw rate sensor open malfunction; or 3) EEPROM malfunction.

DTC Code
DTC Detection Condition
Trouble Area
B2768
If one of the following is detected:
  1. A yaw rate sensor power supply malfunction.
  2. A yaw rate sensor open malfunction.
  3. An EEPROM malfunction.
  1. Yaw rate sensor
  2. Certification ECU (Smart key ECU assembly)

INSPECTION PROCEDURE

1.CHECK FOR DTC (OPERATION)

  1. Clear DTCs (Click here).

  1. Turn the engine switch on (IG), then off.

  1. Set the theft deterrent system to the armed state.

  1. Check that the security indicator changes from illuminated to flashing.

  1. Set the theft deterrent system to the disarmed state.

  1. Check for DTCs (Click here).

    OK:
    DTC B2768 is not output.



NG
Go to step 2

USE SIMULATION METHOD TO CHECK (Click here)  

2.CHECK YAW RATE SENSOR (OPERATION)

  1. Temporarily replace the yaw rate sensor that has a tilt determining function with a new or normally functioning one (Click here).

  1. Check that the system operates normally.

    OK:
    DTC B2768 is not output.
