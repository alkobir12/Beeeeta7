DTC    B2789    No Response from ID BOX

for Preparation Click here


DESCRIPTION

This DTC is stored when LIN communication between the certification ECU (smart key ECU assembly) and ID code box (immobiliser code ECU) stops for 10 seconds or more.

DTC Code
DTC Detection Condition
Trouble Area
B2789
No communication between the certification ECU (smart key ECU assembly) and ID code box (immobiliser code ECU) for 10 seconds or more.
  1. ID code box (immobiliser code ECU)
  2. Certification ECU (smart key ECU assembly)
  3. Harness or connector

When using the intelligent tester with the engine switch off to troubleshoot:
Connect the intelligent tester to the vehicle, and turn a courtesy switch on and off at 1.5 second intervals until communication between the intelligent tester and vehicle begins.
