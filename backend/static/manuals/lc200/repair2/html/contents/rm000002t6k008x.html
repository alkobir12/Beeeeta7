CHECK POWER DOOR LOCK OPERATION

  1. Check the basic function.

    1. Check that all doors lock when the door lock control switch (for manual operation) is turned to lock and all doors unlock when turned to unlock.

    2. Check that all doors lock when the driver side door lock key cylinder is turned to lock using the key.

    3. When the engine switch is on (IG) and the driver seat belt is fastened, check that the manual unlock prohibition function operates when the doors are locked using the transmitter or key.

    4. Check that only the driver side door unlocks when turned to unlock once again within 3 seconds using the key (2-step unlocking function).

  2. Check the key lock-in prevention function.

    NOTICE:
    In order to prevent the key from being locked in, the inspection should be made with the driver side door glass open.


    1. Turn the engine switch on (IG) or on (ACC).

    2. With the driver side door open, check that all doors unlock immediately after the door lock knob for the driver side door is locked.

    3. With the driver side door open, check that all doors unlock immediately after the door control switch (for manual operation) is turned to lock.

    4. With the driver side door open, lock the driver side door lock knob and hold it for 2 seconds or more, and then close the driver side door then check that all doors unlock.

  3. Check the security function.

    1. Close all doors with the driver side door glass open so that the door control switch can be operated from outside the vehicle.

    2. Remove the key from the inside of the vehicle, open the driver side door and then close and lock the door without using the key. Then, check that all doors do not unlock when the door control switch (for manual operation) is turned to unlock from outside the vehicle.

    3. Remove the key from the inside of the vehicle, then close and lock the driver side door with the key operation. Under this condition, check that all doors do not unlock when the door control switch (for manual operation) is turned to unlock from outside the vehicle.

    4. Remove the key from the inside of the vehicle, close the driver side door and lock the door with the wireless door lock operation. Then, check that all doors do not unlock when the door control switch (for manual operation) is turned to unlock from outside the vehicle.

      HINT:
      Check that the security function is canceled under the following conditions:

      1. The engine switch is turned on (IG).
      2. The driver side door is unlocked using the key.
      3. The door control switch (for manual operation) is turned to unlock after the door lock knob is unlocked manually.
      4. The doors are unlocked by wireless operation.

  4. Check the illumination function.

    1. Set the map light switch to the DOOR position.

    2. With all the doors locked, check that all doors unlock when the driver side door lock cylinder is turned to unlock using the key and that the map light turns on.

    3. Check that the map light turns off in approximately 15 seconds after the doors have not been opened.


CHECK DOUBLE LOCKING FUNCTION

CAUTION:
Do not activate the double locking function when there are people in the vehicle because the doors cannot be opened from the inside of the vehicle.
Under emergency conditions, such as if the power has been cut, this function can be cancelled by inserting the key (mechanical key) into the driver door key cylinder and turning it to the unlock side.

  1. Check that the double locking function is set.

    1. Open all the windows.

    2. Turn the engine switch off.

    3. Open and close the driver side door, and make sure that all doors, including the back door, are closed securely.

    4. Press the transmitter lock switch twice within 5 seconds, and check that the hazard warning lights flash once at this time to indicate that the double locking function has been set.

      HINT:
      The double locking function can be turned on by pressing the lock switch on the outside handle 2 times within 3 seconds.

    5. Try to unlock each door using the inside handle, and check that none of the doors unlock.

      NOTICE:
      The double locking function does not affect the back door.

  2. Check that the double locking function is canceled.

    1. Press the transmitter unlock switch while the double locking function is set, and check that the hazard warning lights flash twice at this time to indicate that the system is canceled.

    2. Check that the doors can be opened by using both the inside and outside handles.

      NOTICE:
      If the battery of the transmitter is depleted, only the driver side door can be opened using the key. However, the theft deterrent system still remains on. The theft alarm will sound when the door is opened without using the transmitter.
