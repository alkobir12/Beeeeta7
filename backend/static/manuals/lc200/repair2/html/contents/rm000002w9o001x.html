AIR FUEL RATIO SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL AIR FUEL RATIO SENSOR (for Bank 2 Sensor 1)



  1. Temporarily install the sensor to the exhaust manifold by hand.




  1. Using SST, tighten the sensor.

    SST
    09224-00010  

    Torque:
    without SST:
    44 N*m{ 449 kgf*cm , 32 ft.*lbf }
    with SST:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }

    HINT:
    1. Use a torque wrench with a fulcrum length of 30 cm (11.8 in.). If using a torque wrench with a length that is not 30 cm (11.8 in.), calculate the torque specification for the torque wrench and SST based on the "without SST" torque specification (Click here).
    2. Make sure SST and the wrench are connected in a straight line.

3. INSTALL EXHAUST MANIFOLD SUB-ASSEMBLY LH



  1. Set a new gasket to the cylinder head LH with the oval shape facing rearward.

    NOTICE:
    Be careful of the installation direction.




  1. Install the exhaust manifold with 6 new nuts.

    Torque:
    30 N*m{ 306 kgf*cm , 22 ft.*lbf }

  1. Connect the air fuel ratio sensor connector.



4. INSTALL NO. 2 MANIFOLD STAY



  1. Install the No. 2 manifold stay with the 3 bolts.

    Torque:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }



5. INSTALL EXHAUST MANIFOLD SUB-ASSEMBLY RH



  1. Set a new gasket to the cylinder head RH with the oval shape facing forward.

    NOTICE:
    Be careful of the installation direction.




  1. Install the exhaust manifold with 6 new nuts.

    Torque:
    30 N*m{ 306 kgf*cm , 22 ft.*lbf }

  1. Connect the air fuel ratio sensor connector.



6. INSTALL MANIFOLD STAY



  1. Install the No. 1 manifold stay with the 3 bolts.

    Torque:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }



7. INSTALL FRONT EXHAUST PIPE ASSEMBLY

  1. Install 2 new gaskets to the front exhaust pipe.

  1. Install the front exhaust pipe to the exhaust manifold RH with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }

  1. Install the 2 compression springs and 2 bolts to the center exhaust pipe.

    Torque:
    43 N*m{ 438 kgf*cm , 32 ft.*lbf }

  1. Connect the heated oxygen sensor connector.



8. INSTALL FRONT NO. 2 EXHAUST PIPE ASSEMBLY

  1. Install 2 new gaskets to the front No. 2 exhaust pipe.

  1. Install the front No. 2 exhaust pipe to the exhaust manifold LH with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }

  1. Install the 2 bolts to the center exhaust pipe.

    Torque:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }

  1. Connect the heated oxygen sensor connector.



9. INSPECT FOR EXHAUST GAS LEAK
If gas is leaking, tighten the areas necessary to stop the leak. Replace damaged parts as necessary.

13. INSTALL FRONT FENDER APRON SEAL REAR RH



  1. Install the fender apron seal with the 4 clips.
