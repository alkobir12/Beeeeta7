ENTRY AND START SYSTEM (for Entry Function) > Driver Side Door Entry Unlock Function does not Operate

for Preparation Click here


DESCRIPTION

If the driver side door entry unlock function does not operate but the entry lock function operates, the communication line between the vehicle and electrical key transmitter is normal. The part at fault may be a touch sensor circuit (certification ECU (smart key ECU assembly) → driver side door outside handle → driver side door electrical key oscillator).

WIRING DIAGRAM

1.CHECK POWER DOOR LOCK OPERATION

  1. When the master switch assembly door control switch is operated, check that the locked doors unlock.
