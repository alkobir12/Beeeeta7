PURGE VALVE > INSTALLATION

for Preparation Click here



1. INSTALL PURGE VSV



  1. Install the purge VSV with the bolt.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }




  1. Connect the 2 purge line hoses.

  1. Connect the purge VSV connector.



2. INSTALL V-BANK COVER



  1. Install the V-bank cover with the 2 nuts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }



3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
