CUSTOMIZING FUNCTION WITH INTELLIGENT TESTER (REFERENCE) (w/ Remote Function)

NOTICE:
  1. When the customer requests a change in a function, first make sure that the function can be customized.
  2. Be sure to make a note of the current settings before customizing.
  3. When troubleshooting a function, first make sure that the function is set to the default setting.

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the intelligent tester on.

  4. Enter the following menus: Body / Utility / Customize / Slide Roof.

  5. Select the setting by referring to the table below.

    Slide Roof 
    Display (Item)
    		Default
    		Contents
    		Setting
    Door Key Related Open
    		ON
    		The function to manually open the sliding roof linked with the power window if holding the driver side door key for 3 seconds or more to unlock position when the engine switch is off.
    		ON/OFF
    Door Key Related Close
    		ON
    		The function to manually close the sliding roof linked with the power window if holding the driver side door key for 3 seconds or more to lock position when the engine switch is off.
    		ON/OFF
    Wireless Key Related Open
    		ON
    		The function to manually open the sliding roof linked with the power window if pressing the transmitter unlock switch for 3 seconds or more when the engine switch is off.
    		ON/OFF
    Wireless Key Related Close
    		ON
    		The function to manually close the sliding roof linked with the power window if pressing the transmitter lock switch for 3 seconds or more when the engine switch is off.
    		ON/OFF
    Door Handle Lock Button
    		ON
    		The function to manually close the sliding roof linked with the power window if pushing the door lock switch for 3 seconds or more when the engine switch is off and the key is outside vehicle.
    		ON/OFF
    Door Key Related Operation
    		Slide
    		The function to select tilt up or slide open of manual sliding roof operation linked with the power window activated by holding the driver side door key for 3 seconds or more to unlock position when the engine switch is off.
    		Tilt/Slide
    Wireless Key Related Operation
    		Slide
    		The function to select tilt up or slide open of manual sliding roof operation linked with the power window activated by pressing on the transmitter unlock switch for 3 seconds or more when the engine switch is off.
    		Tilt/Slide
