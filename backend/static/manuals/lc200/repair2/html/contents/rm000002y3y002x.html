POWER MIRROR CONTROL SYSTEM DESCRIPTION

  1. This system has the following functions: automatic glare-resistant electrochromic (EC) mirror, reverse shift-linked mirror, electrical remote control type mirror, memory function, and rear window defogger-linked mirror heater.


FUNCTION OF MAIN COMPONENT

Components
Function
Vertical mirror motor
Receives a signal from the mirror control ECU and adjusts the remote control mirror vertically.
Horizontal mirror motor
Receives a signal from the mirror control ECU and adjusts the remote control mirror horizontally.
Mirror retract motor
Receives a signal from the mirror control ECU, and retracts and returns the remote control mirror.
Mirror heater*1
Receives a signal from the A/C amplifier and starts the mirror heater.
EC mirror cell*2
Varies the reflection rate of the mirror through the function of the EC elements.
Mirror retract switch
Retracts and returns the remote control mirror. Mirror retract and return signals are sent to the mirror control ECU from the main body ECU.
Mirror master switch
Consists of R and L switches. One must be chosen before the mirror control switches can be operated.
Outer mirror control ECU
Sends operation signals to each motor.
Mirror control switch
Mirror R and L signals are sent to the outer mirror control ECU from the outer mirror switch.
After selecting the R or L switch, the right, left, up and down control switches change the angle of the mirror.
Mirror position sensor
Detects the remote control mirror position. This data is detected by the mirror control ECU.
Seat memory switch*3
When the seat memory SET switch and seat memory switch are pressed simultaneously, a signal is input to the outer mirror control ECU and the position control ECU and switch, which records the mirror position.
When the seat memory switch is pressed, a signal is input to the mirror control ECU and sent to the position control ECU and switch which changes the mirror position to the recorded position.

HINT:
*1: w/ Mirror Heater
*2: w/ EC Mirror
*3: w/ Seat Position Memory System


SYSTEM OPERATION

  1. The remote control mirror has the following features.

    Function
    		Outline
    Manual electrical retractable mirror
    		Retracts and returns the remote control mirrors when the mirror retract switch is pressed.
    Reverse shift-linked mirror
    		Directs the mirror surface downward to improve visibility when driving in reverse and all the conditions below are met:
    1. The engine switch is on (IG).
    2. The shift lever is moved from other than R to R.
    3. The mirror master switch is in the R or L position.
    Electrical remote control type mirror
    		When the mirror control switch is operated, this function moves the mirror surface vertically or horizontally to enable the driver to attain optimal mirror angle. Setting the mirror master switch to the R position operates the right mirror, and setting it to the L position operates the left mirror.
    Rear window defogger-linked mirror heater*1
    		Automatically turns on the mirror heater when the rear window defogger switch is turned on.
    The rear window defogger and mirror heater automatically turn off after 15 min.
    Automatic glare-resistant EC mirror*2
    		Reduces glare/reflection in the mirror during nighttime driving for safe driving conditions.
    Glare/reflection from vehicle headlights from behind could blind the driver and cause dangerous driving conditions.
    Memory function*3
    		Stores the adjusted mirror position in the outer mirror control ECU.

    HINT:
    *1: w/ Mirror Heater
    *2: w/ EC Mirror
    *3: w/ Seat Position Memory System
