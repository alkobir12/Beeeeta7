1. INSTALL TRANSMISSION FLOOR SHIFT ASSEMBLY



  1. Install the floor shift with the 4 bolts. Tighten the bolts in the order shown in the illustration.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }

  1. Connect the 2 connectors.



2. CONNECT FLOOR SHIFT GEAR SHIFTING ROD SUB-ASSEMBLY



  1. Turn the control shaft lever RH of the park/neutral position switch counterclockwise until it stops, and then turn it clockwise 2 notches to set it to the N position.

  1. Move the shift lever to N.




  1. Temporarily install the floor shift gear shifting rod with the nut.

  1. Tighten the nut while lightly pushing the lever rearward.

    Torque:
    13 N*m{ 130 kgf*cm , 9 ft.*lbf }



3. INSTALL REAR CONSOLE BOX SUB-ASSEMBLY (w/o Cool Box)




  1. Attach the 2 claws.

  1. Install the console box with the 4 bolts and 2 screws.



4. INSTALL COOLING BOX ASSEMBLY (w/ Cool Box)




  1. Attach the 2 claws.

  1. Connect the connector.

  1. Sufficiently apply compressor oil to 2 new O-rings.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings on the 2 cooler pipes.

  1. Connect the 2 cooler pipes with the 2 bolts.

    Torque:
    9.8 N*m{ 100 kgf*cm , 87 in.*lbf }

  1. Install the cooling box with the 4 bolts and 2 screws.



5. INSTALL CONSOLE REAR END PANEL SUB-ASSEMBLY



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the end panel.



6. INSTALL NO. 1 COOLER COVER (w/ Cool Box)



  1. Attach the claw on the upper part of the cooler cover, and then attach the clamp on the lower part of the cooler cover to install it.



7. INSTALL UPPER CONSOLE PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 14 claws to install the console panel.



8. INSTALL CONSOLE CUP HOLDER BOX SUB-ASSEMBLY



  1. Attach the 4 claws to install the box.



9. INSTALL REAR UPPER CONSOLE PANEL SUB-ASSEMBLY



  1. Attach the 9 claws to install the panel.



10. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



11. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



12. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



13. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



14. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.

    NOTICE:
    1. Do not operate the cooler compressor before charging refrigerant as the cooler compressor will not work properly without any refrigerant, and will overheat.
    2. Approximately 200 g (7.05 oz.) of refrigerant may need to be charged after bubbles disappear. The refrigerant amount should be checked by measuring its quantity, and not with the sight glass.



16. CHECK FOR REFRIGERANT GAS LEAK (w/ Cool Box)

  1. After recharging the refrigerant gas, check for refrigerant gas leakage using a halogen leak detector.

  1. Perform the operation under these conditions:

    1. Stop the engine.
    2. Secure good ventilation (the halogen leak detector may react to volatile gases other than refrigerant, such as evaporated gasoline or exhaust gas).
    3. Repeat the test 2 or 3 times.
    4. Make sure that some refrigerant remains in the refrigeration system. When compressor is off: approximately 392 to 588 kPa (4.0 to 6.0 kgf/cm2, 57 to 85 psi).




  1. Using a halogen leak detector, check the refrigerant line for leakage.

  1. If a gas leak is not detected on the drain hose, remove the blower motor control (blower resistor) from the cooling unit. Insert the halogen leak detector sensor into the unit and perform the test.

  1. Disconnect the connector and wait for approximately 20 minutes. Bring the halogen leak detector close to the pressure switch and perform the test.



17. INSPECT SHIFT LEVER POSITION

  1. When moving the shift lever from P to R with the engine switch on (IG) and the brake pedal depressed, make sure that it moves smoothly and correctly into position.

  1. Check that the shift lever does not stop when moving the shift lever from R to P, and check that the shift lever does not stick when moving the shift lever from D to S.

  1. Start the engine and make sure that the vehicle moves forward after moving the shift lever from N to D and moves rearward after moving the shift lever to R.
    If the operation cannot be performed as specified, inspect the park/neutral position switch assembly and check the shift lever assembly installation condition.
