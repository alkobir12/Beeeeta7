EXHAUST MANIFOLD (w/o Secondary Air Injection System) > INSTALLATION

for Preparation Click here



1. INSTALL EXHAUST MANIFOLD SUB-ASSEMBLY LH



  1. Place a new gasket on the cylinder head with the "L" mark facing the manifold side.

    NOTICE:
    Be careful of the installation direction.




  1. Temporarily install the exhaust manifold with 8 new nuts, and then uniformly tighten the nuts in several steps, in the sequence shown in the illustration.

    Torque:
    44 N*m{ 449 kgf*cm , 32 ft.*lbf }



2. INSTALL NO. 2 EXHAUST MANIFOLD HEAT INSULATOR

  1. Temporarily install the heat insulator with the 4 bolts.




  1. Uniformly tighten the 4 bolts in several steps, in the sequence shown in the illustration.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }



3. INSTALL NO. 2 MANIFOLD STAY



  1. Install the manifold stay with the 3 bolts.

    Torque:
    for bolt A:
    36 N*m{ 367 kgf*cm , 27 ft.*lbf }
    for bolt B:
    71 N*m{ 724 kgf*cm , 52 ft.*lbf }



4. INSTALL EXHAUST MANIFOLD SUB-ASSEMBLY RH



  1. Place a new gasket on the cylinder head with the "R" mark facing the manifold side.

    NOTICE:
    Be careful of the installation direction.




  1. Temporarily install the exhaust manifold with 8 new nuts, and then uniformly tighten the nuts in several steps, in the sequence shown in the illustration.

    Torque:
    44 N*m{ 429 kgf*cm , 32 ft.*lbf }



5. INSTALL NO. 1 EXHAUST MANIFOLD HEAT INSULATOR

  1. Temporarily install the heat insulator with the 4 bolts.




  1. Uniformly tighten the 4 bolts in several steps, in the sequence shown in the illustration.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }



6. INSTALL NO. 1 MANIFOLD STAY



  1. Install the manifold stay with the 3 bolts.

    Torque:
    for bolt A:
    36 N*m{ 367 kgf*cm , 27 ft.*lbf }
    for bolt B:
    71 N*m{ 724 kgf*cm , 52 ft.*lbf }



7. INSTALL FRONT NO. 2 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 2 exhaust pipe to the exhaust manifold LH with 3 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }

  1. Connect the air fuel ratio sensor connector.

  1. Connect the heated oxygen sensor connector.



8. INSTALL FRONT EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front exhaust pipe to the exhaust manifold with 3 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }

  1. Connect the air fuel ratio sensor connector.

  1. Connect the heated oxygen sensor connector.

  1. Attach the heated oxygen sensor wire clamp.



9. INSTALL CENTER EXHAUST PIPE ASSEMBLY

  1. Install the center exhaust pipe to the 3 exhaust pipe supports.

  1. Install 2 new gaskets to the front exhaust pipe and front No. 2 exhaust pipe.

  1. Install the 4 bolts.

    Torque:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }



10. INSTALL TAILPIPE ASSEMBLY

  1. Install the tailpipe to the 2 exhaust pipe supports.

  1. Install a new gasket to the center exhaust pipe.




  1. Connect the tailpipe and center exhaust pipe with a new clamp.

    Torque:
    32 N*m{ 326 kgf*cm , 24 ft.*lbf }

    HINT:
    Install the clamp within the angle range shown in the illustration.



11. INSTALL NO. 2 ENGINE UNDER COVER



  1. Install the No. 2 engine under cover with the 2 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



12. INSTALL ENGINE OIL LEVEL DIPSTICK GUIDE



  1. Apply a light coat of engine oil to a new O-ring.

  1. Install a new O-ring to the guide.

  1. Install the dipstick guide with the bolt.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Install the dipstick.



13. CONNECT COOLER COMPRESSOR



  1. Connect the compressor. Then install it and the No. 1 compressor stay with the nut and 3 bolts.

    Torque:
    for bolt:
    45 N*m{ 459 kgf*cm , 33 ft.*lbf }
    for nut:
    25 N*m{ 250 kgf*cm , 18 ft.*lbf }

    HINT:
    Tighten the bolts in the order shown in the illustration to install the cooler compressor.

  1. Install the cooler refrigerant suction hose with the bolt.

    Torque:
    9.8 N*m{ 100 kgf*cm , 87 in.*lbf }

  1. Connect the connector.



14. INSPECT FOR EXHAUST GAS LEAK
If gas is leaking, tighten the areas necessary to stop the leak. Replace damaged parts as necessary.
