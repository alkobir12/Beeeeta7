METER / GAUGE SYSTEM > Operating Light Control Rheostat does not Change Light Brightness

for Preparation Click here


DESCRIPTION

w/ Multi-information Display:
When the light control rheostat knob is turned to the left, the combination meter and vehicle interior illumination will become brighter. When the light control rheostat knob is turned to the right, the combination meter and vehicle illumination will dim.
