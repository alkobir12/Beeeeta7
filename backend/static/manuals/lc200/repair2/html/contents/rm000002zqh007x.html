SIDE AIRBAG SENSOR > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the RH and LH.
  2. The procedures listed below are the LH side.



1. INSTALL SIDE AIRBAG SENSOR



  1. Check that the engine switch is off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.

  1. Install the side airbag sensor with the bolt.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

    NOTICE:
    1. If the side airbag sensor has been dropped, or there are any cracks, dents or other defects in the case, bracket or connector, replace it with a new one.
    2. When installing the side airbag sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

  1. Check that there is no looseness in the installation parts of the side airbag sensor.

  1. Connect the connector.



2. INSTALL FRONT DOOR TRIM BOARD SUB-ASSEMBLY LH

  1. Connect the connector.




  1. Connect the front door lock remote control cable and front door inside locking cable to the front door inside handle sub-assembly.




  1. Attach the 4 claws and 13 clips to install the front door trim board sub-assembly.

  1. Install the 3 screws.



3. INSTALL ASSIST GRIP COVER LH



  1. Attach the 8 claws to install the door assist grip cover to the door trim panel.



4. INSTALL MULTIPLEX NETWORK MASTER SWITCH ASSEMBLY



  1. Install the multiplex network master switch assembly with the 3 screws.



5. INSTALL FRONT DOOR INSIDE HANDLE BEZEL LH



  1. Attach the 4 claws to install the bezel.



6. INSTALL FRONT DOOR LOWER FRAME BRACKET GARNISH LH



  1. Attach the clip and claw, and install the front door lower frame bracket garnish.



7. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



8. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
