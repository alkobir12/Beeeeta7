4WD CONTROL ECU > INSTALLATION

for Preparation Click here



1. INSTALL FOUR WHEEL DRIVE CONTROL ECU



  1. Install the ECU with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

  1. Connect the 2 ECU connectors.



2. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (for RHD)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



3. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL (for RHD)



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



4. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (for RHD)

  1. w/ Floor Under Cover:

    1. Install the No. 1 instrument panel under cover (Click here).



5. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH (for RHD)



  1. Attach the 2 claws to install the panel garnish.



6. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH (for RHD)



  1. Attach the 3 claws to install the panel garnish.



7. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH (for RHD)



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



8. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL (for RHD)



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



9. INSTALL LOWER NO. 2 INSTRUMENT PANEL FINISH PANEL (for LHD)



  1. Connect the connector.

  1. Attach the 3 claws to install the finish panel.

  1. Install the 4 bolts.



10. INSTALL INSTRUMENT PANEL BOX DOOR KNOB (for LHD)



  1. Attach the 2 claws to install the knob.



11. INSTALL NO. 3 INSTRUMENT CLUSTER FINISH PANEL GARNISH (for LHD)



  1. Attach the 6 claws to install the panel garnish.



12. INSTALL FRONT PASSENGER SIDE KNEE AIRBAG ASSEMBLY (for LHD)



  1. Attach the 6 claws to install the panel garnish.



13. INSTALL COWL SIDE TRIM BOARD RH



  1. Attach the 2 clips to install the trim board.

  1. Install the cap nut.



14. INSTALL NO. 2 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (for LHD)

  1. w/ Floor Under Cover:

    1. Install the No. 2 instrument panel under cover (Click here).



15. INSTALL FRONT DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.
