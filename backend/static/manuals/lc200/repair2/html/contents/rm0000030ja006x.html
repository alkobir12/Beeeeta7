AIR INJECTION DRIVER (w/ Secondary Air Injection System) > INSTALLATION

for Preparation Click here



1. INSTALL AIR INJECTION CONTROL DRIVER ASSEMBLY



  1. Install the air injection control driver assembly with the 3 bolts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }




  1. Connect the wire harness clamp.

  1. Connect the wire harness with the bolt.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Connect the 2 air injection control driver connectors.



2. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
