ENGINE HOOD COURTESY SWITCH > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL HOOD LOCK ASSEMBLY



  1. Apply MP grease to the sliding areas of the lock.




  1. Connect the hood lock control cable.




  1. Connect the connector.

  1. Install the hood lock with the 2 bolts and nut.

    Torque:
    5.5 N*m{ 57 kgf*cm , 49 in.*lbf }

  1. Install a new hood lock nut cap.



2. INSTALL HOOD LOCK CONTROL CABLE COVER



  1. Attach the claw to install the cover.

  1. Install the 3 screws.



3. INSTALL RADIATOR GRILLE



  1. Attach the 2 clips and 8 claws to install the radiator grille.

  1. Install the 3 screws.



4. INSTALL UPPER RADIATOR SUPPORT SEAL

  1. for Gasoline Engine:
    Install the upper radiator support seal (Click here).

  1. for Diesel Engine:
    Install the upper radiator support seal (Click here).
