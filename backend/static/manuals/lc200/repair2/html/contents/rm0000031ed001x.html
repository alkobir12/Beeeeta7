FUEL SYSTEM > ON-VEHICLE INSPECTION

for Preparation Click here



1. INSPECT FUEL PRESSURE

  1. Read Data List.

    1. Warm up the engine.

    2. Turn the engine switch off.

    3. Connect the intelligent tester to the DLC3.

    4. Turn the engine switch on (IG).

    5. Turn the intelligent tester ON.

    6. Enter the following menus: Powertrain / Engine / Data List.

    7. Read the Data List.

      Tester Display
      		Measurement Item/Range (Display)
      		Normal Condition
      Fuel Press
      		Fuel pressure / Min.: 0 kPa, Max.: 250000 kPa
      		27000 to 37000 kPa: Idling
      Target Common Rail Pressure
      		Target common rail pressure / Min.: 0 kPa, Max.: 250000 kPa
      		25000 to 180000 kPa



2. INSPECT FOR FUEL LEAK

  1. Perform Active Test.

    1. Connect the intelligent tester to the DLC3.

    2. Turn the engine switch on (IG).

    3. Start the engine.

    4. Turn the intelligent tester ON.

    5. Enter the following menus: Powertrain / Engine / Active Test.

    6. Perform the Active Test.

      Tester Display
      		Test Detail
      		Control Range
      		Diagnostic Note
      Test the Fuel Leak
      		Pressurizes fuel inside common rail and checks for fuel leaks
      		Stop/Start
      1. The fuel inside the common rail is pressurized to the specified value and the engine speed increases to 2000 rpm when Start is selected.
      2. The above conditions are preserved while Start is selected.



3. BLEED AIR FROM FUEL SYSTEM



  1. Using the hand pump indicated by the arrow in the illustration, bleed the fuel system. Continue pumping until pumping becomes difficult.



4. CHECK FUEL FILTER WARNING LIGHT AND DRAIN WATER


  1. w/o Multi-information Display:




    1. Check if the fuel filter warning light is illuminated.

      NOTICE:
      When the fuel filter warning light illuminates, the fuel filter is clogged. Replace the filter (Click here).




    2. Check if the fuel filter warning light is blinking.

      NOTICE:
      When the fuel filter warning light is blinking and the buzzer sounds, immediately drain the water in the fuel filter.

  1. w/ Multi-information Display:
    Check the fuel filter multi-information display.

    NOTICE:
    When the fuel system warning is displayed on the multi-information display and the buzzer sounds, replace the fuel filter (Click here) or drain the water in the fuel filter.



  1. Drain water.



    1. Detach the fuel hose clamp.



    2. Disconnect the clogging switch connector and level warning switch connector.




    3. Remove the 2 nuts and lift up the fuel filter assembly.

    4. Connect a hose to the drain cock. Place the other end of the hose into a container under the drain cock.

    5. Loosen the drain cock to drain water.

    6. Tighten the drain cock by hand.

      NOTICE:
      Do not use any tools in this procedure.



    7. Install the fuel filter assembly with the 2 nuts.

      Torque:
      20 N*m{ 199 kgf*cm , 14 ft.*lbf }




    8. Connect the clogging switch connector and level warning switch connector.

    9. Attach the fuel hose clamp.
