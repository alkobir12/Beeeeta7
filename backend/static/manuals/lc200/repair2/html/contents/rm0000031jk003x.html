EGR COOLER (w/ EGR System) > INSTALLATION

for Preparation Click here



1. INSTALL STUD BOLT



  1. Using an E6 "TORX" socket wrench, install the 4 stud bolts to the EGR cooler.

    Torque:
    6.0 N*m{ 61 kgf*cm , 53 in.*lbf }



2. INSTALL NO. 8 WATER BY-PASS HOSE



  1. Install the 2 hoses.



3. INSTALL NO. 3 WATER BY-PASS PIPE



  1. Connect the 2 hoses and install the water by-pass pipe with the bolt.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



4. INSTALL NO. 1 AND NO. 2 EGR VALVE ASSEMBLIES

  1. Install the No. 1 and No. 2 EGR valve assemblies (Click here).
