OIL LEVEL SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL ENGINE OIL LEVEL SENSOR



  1. Install a new gasket to the sensor.

  1. Install the sensor with the 4 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

  1. Connect the sensor connector.



2. CONNECT OIL COOLER TUBE (for Automatic Transmission)



  1. Temporarily install the oil cooler tube to the engine with the 2 bolts A and B.

  1. Install the bolt C and tighten it to the specified torque. Then tighten the bolt A and B to the specified torque.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



3. ADD ENGINE OIL

  1. Add fresh oil.

    Standard Engine Oil:

    Oil Grade
    		Oil Viscosity (SAE)
    G-DLD-1, API CF-4, API CF or ACEA B1
    (You may also use API CE or CD)
    		- 5W-30
    - 10W-30
    - 15W-40
    - 20W-50
    (5W-30 is best choice for fuel economy and good starting in cold weather).


    Standard Capacity:

    Item
    		Specified Condition
    Drain and refill with oil filter change
    		9.0 liters (9.5 US qts, 8.0 Imp. qts)
    Drain and refill without oil filter change
    		8.0 liters (8.5 US qts, 7.0 Imp. qts)
    Dry fill
    		9.7 liters (10.3 US qts, 8.5 Imp. qts)

  1. Install the oil filler cap.



4. INSPECT FOR ENGINE OIL LEAK

  1. Warm up the engine and check for an engine oil leak.



5. CHECK ENGINE OIL LEVEL

  1. Warm up the engine, stop the engine and wait 5 minutes. The engine oil level should be between the dipstick low level mark and full level mark.
    If low, check for leakage and add oil up to the full level mark.

    NOTICE:
    Do not fill engine oil above the full level mark.



6. INSTALL NO. 2 ENGINE UNDER COVER



  1. Install the engine under cover with the 2 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



7. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY



  1. Install the engine under cover with the 10 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



8. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH



  1. Install the splash shield with the clip, and then install the 3 bolts and screw.



9. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH

  1. Install the splash shield with the clip, and then install the 3 bolts and screw.



10. INSTALL FRONT FENDER APRON SEAL REAR RH



  1. Install the front fender apron seal rear RH with the 4 clips.



11. INSTALL FRONT FENDER APRON SEAL FRONT RH



  1. Install the front fender apron seal front RH with the 3 clips.



12. INSTALL FRONT WHEEL RH

Torque:
for Aluminum Wheel:
131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
for Steel Wheel:
209 N*m{ 2131 kgf*cm , 154 ft.*lbf }
