RELAY > INSTALLATION

for Preparation Click here



1. INSTALL WINCH MAIN RELAY

  1. Install the relay with the 3 nuts.

    Torque:
    9.3 N*m{ 95 kgf*cm , 83 in.*lbf }

  1. Connect the 2 wires with the 2 nuts.

    Torque:
    9.4 N*m{ 96 kgf*cm , 84 in.*lbf }



  1. Connect the connector.





2. INSTALL UPPER RADIATOR SUPPORT SEAL

  1. for Gasoline Engine:
    Install the upper radiator support seal (Click here).

  1. for Diesel Engine:
    Install the upper radiator support seal (Click here).



3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
