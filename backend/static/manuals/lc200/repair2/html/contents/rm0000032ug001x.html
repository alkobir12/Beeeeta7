1. INSTALL PISTON AND SPRING



  1. Apply lithium soap base glycol grease to the circumference of the cups and the contact surfaces of the piston and push rod.

  1. Install the spring and piston to the master cylinder.



2. INSTALL CLUTCH MASTER CYLINDER PUSH ROD



  1. Fix the master cylinder in a vise.

  1. Install the push rod and plate to the master cylinder.

  1. Using snap ring pliers, install the snap ring.

  1. Install a new boot.

  1. Install the clevis to the push rod, and then temporarily install the nut.

    HINT:
    The lock nut will be tightened to a torque specification in the "Inspect and Adjust Clutch Pedal Sub-assembly" procedure.



3. INSTALL CLUTCH RESERVOIR GROMMET



  1. Install a new grommet and the inlet union.

  1. Using a pin punch and hammer, tap in the slotted spring pin as shown in the illustration.
