CAUTION:
When using the intelligent tester, observe the following items for safety reasons:
  1. Read its instruction books before using the tester.
  2. Prevent the tester cable from being caught on the pedals, shift lever and steering wheel when driving with the tester connected to the vehicle.
  3. When driving the vehicle for testing purposes using the tester, 2 persons are required. One person drives the vehicle, and the other operates the tester.

NOTICE:
Perform Reset Memory (AT initialization) for 4WD when replacing the automatic transmission assembly, engine assembly or ECM (Click here).

HINT:
Reset Memory cannot be completed only by disconnecting the cable from the negative (-) battery terminal.
