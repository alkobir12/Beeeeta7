FRONT BUMPER (for Standard) > INSTALLATION

for Preparation Click here


HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL FRONT UPPER CENTER BUMPER RETAINER



  1. Install the bumper retainer with the 3 bolts.



2. INSTALL HEADLIGHT ASSEMBLY LH

  1. for Standard:
    Install the headlight assembly LH (Click here).

  1. for HID Headlight:
    Install the headlight assembly LH (Click here).



3. INSTALL HEADLIGHT ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



4. INSTALL FRONT BUMPER SIDE SUPPORT LH



  1. Attach the 3 clips to install the side support.

  1. Install the 2 screws.



5. INSTALL FRONT BUMPER SIDE SUPPORT RH

HINT:
Use the same procedures described for the LH side.



6. INSTALL FRONT NO. 2 BUMPER EXTENSION SUB-ASSEMBLY LH



  1. Install the bumper extension with the 4 nuts.

    Torque:
    67 N*m{ 683 kgf*cm , 49 ft.*lbf }



7. INSTALL FRONT NO. 2 BUMPER EXTENSION SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL FRONT BUMPER REINFORCEMENT SUB-ASSEMBLY



  1. Install the reinforcement with the 6 nuts.

    Torque:
    71 N*m{ 724 kgf*cm , 52 ft.*lbf }



9. INSTALL FRONT BUMPER ENERGY ABSORBER



  1. Install the energy absorber.



10. INSTALL FRONT BUMPER COVER



HINT:
For the front bumper cover with garnish, use the procedures described below.

  1. w/ Headlight Cleaner System:
    Connect the headlight cleaner hose.

  1. w/o TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Attach the 10 claws to install the bumper cover.

  1. w/ TOYOTA Parking Assist-sensor System or w/ Fog Light:
    Connect the No. 4 engine room wire connector and attach the 10 claws to install the bumper cover.



  1. Install the 3 clips, 4 screws and 4 bolts.





  1. Using a T30 "TORX" socket, install the 6 screws.





11. INSTALL RADIATOR GRILLE ASSEMBLY



  1. Attach the 2 clips and 8 claws to install the radiator grille.

  1. Install the 3 screws.



12. INSTALL UPPER RADIATOR SUPPORT SEAL


  1. Install the radiator support seal with the 7 clips.





13. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



14. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL (for HID Headlight)

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
