REAR BUMPER (w/ Towing Hitch) > REASSEMBLY

for Preparation Click here



1. INSTALL REAR NO. 2 STEP COVER



  1. Attach the 4 claws to install the step cover.

  1. Install the 2 screws and 2 clips.



2. INSTALL REAR LOWER BUMPER COVER

  1. Install the rear lower bumper cover with the clip.



3. INSTALL REAR FOG LIGHT ASSEMBLY LH



  1. Attach the claw to install the fog light.

  1. Install the 2 nuts.



4. INSTALL REAR FOG LIGHT ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



5. INSTALL REAR BUMPER ENERGY ABSORBER



  1. Attach the 8 claws to install the energy absorber.



6. INSTALL NO. 2 ULTRASONIC SENSOR RETAINER (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 2 ultrasonic sensor retainer on the other side.

  1. Align the keyhole and protrusion as shown in the illustration.

  1. Install the ultrasonic sensor retainer to the rear bumper.

    NOTICE:
    Do not damage the bumper with the protrusion when installing the retainer.



7. INSTALL NO. 3 ULTRASONIC SENSOR RETAINER (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 3 ultrasonic sensor retainer on the other side.

  1. Attach the claw to install the ultrasonic sensor retainer as shown in the illustration.



8. INSTALL NO. 2 ULTRASONIC SENSOR (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 2 ultrasonic sensor on the other side.

  1. Attach the 2 claws to install the ultrasonic sensor.

  1. Connect the connector.



9. INSTALL NO. 3 ULTRASONIC SENSOR (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 3 ultrasonic sensor on the other side.

  1. Attach the 3 claws to install the ultrasonic sensor.

  1. Connect the connector.



10. INSTALL NO. 2 FRAME WIRE


  1. w/ TOYOTA Parking Assist-sensor System, w/ Rear Fog Light:
    Install the No. 2 frame wire.

    1. Attach the 16 clamps to install the frame wire.



    2. Connect the 6 connectors.





  1. w/ TOYOTA Parking Assist-sensor System, w/o Rear Fog Light:
    Install the No. 2 frame wire.

    1. Attach the 14 clamps to install the frame wire.



    2. Connect the 4 connectors.





  1. w/o TOYOTA Parking Assist-sensor System, w/ Rear Fog Light:
    Install the No. 2 frame wire.

    1. Attach the 13 clamps to install the frame wire.



    2. Connect the 2 connectors.
