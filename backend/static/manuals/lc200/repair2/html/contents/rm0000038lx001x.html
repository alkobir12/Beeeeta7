SIDE STEP > REASSEMBLY

for Preparation Click here


HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL REAR SIDE DOOR STEP PLATE COVER LH



  1. Temporarily install the step plate cover with the 2 screws.

    HINT:
    Make sure the screws are loose so that the step plate moulding can be installed.



2. INSTALL NO. 1 SIDE DOOR STEP PLATE MOULDING


  1. Install the step plate moulding.




    HINT:

    Push in the step plate moulding until it in the position shown in the illustration.

  1. Tighten the installation screws of the step plate cover.



3. INSTALL FRONT SIDE DOOR STEP PLATE COVER LH



  1. Install the step plate cover with the 2 screws.



4. INSTALL STEP PANEL REAR LH

  1. Install a nose piece to an air riveter or hand riveter.

  1. Insert the mandrel part of a new rivet into the nose piece.




  1. Using the riveter, install the rear step panel shown in the illustration.

    HINT:
    If the rivet cannot be cut, pull it once and cut it.

    NOTICE:


    1. Do not pry the rivet with the riveter, as this will cause damage to the riveter and mandrel.


    2. Confirm that the rivets are seated properly against the rear step panel.
    3. Do not tilt the riveter when installing the rivet to the rear step panel.
    4. Do not leave any space between the rivet head and rear step panel.


    5. Do not leave any space between the rear step panel and rear side door step plate cover. Firmly hold together the 2 items while installing the rivet.



5. INSTALL NO. 3 SIDE STEP BRACKET LH



  1. Install the side step bracket with the 2 bolts.



6. INSTALL NO. 2 SIDE STEP BRACKET LH



  1. Install the side step bracket with the 2 bolts.



7. INSTALL NO. 1 SIDE STEP BRACKET LH



  1. Install the side step bracket with the 2 bolts.
