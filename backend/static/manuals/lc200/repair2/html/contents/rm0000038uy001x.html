2. INSTALL NO. 1 ROOM LIGHT ASSEMBLY (w/ Rear Seat Entertainment System)



  1. Install the 2 bulbs.



3. INSTALL NO. 1 ROOF LINING TRIM COVER (w/ Rear Seat Entertainment System)



  1. Attach the 4 claws to install the room light trim cover.



4. INSTALL NO. 2 ROOF LINING TRIM COVER (w/ Rear Seat Entertainment System)



  1. Attach the 4 claws to install the room light trim cover.
