HINT:
When only replacing the room light bulbs, use the following procedures.



1. INSTALL MAP LIGHT BULB



  1. Turn the 2 map light bulbs in the direction indicated by the arrow to install them.



2. INSTALL MAP LIGHT ASSEMBLY (w/ Sliding Roof)

  1. Connect the connector.

  1. Attach the 2 clips and 2 guides to install the map light.

  1. Install the 2 screws.



  1. Attach the 2 claws to close the 2 covers.





3. INSTALL MAP LIGHT ASSEMBLY (w/o Sliding Roof)

  1. Connect the connector.

  1. Attach the 2 clips and 2 guides to install the map light.

  1. Install the 2 screws.



  1. Attach the 2 claws to close the 2 covers.
