HINT:
  1. Use the same procedures for the RHD and LHD.
  2. The procedures listed below are for the LHD.



1. INSTALL HEADLIGHT DIMMER SWITCH ASSEMBLY



  1. Install the headlight dimmer switch onto the steering column making sure that the stopper protrusions and cutout parts align.




  1. While loosening the band clamp, attach the claw to install the headlight dimmer switch.

  1. Connect the connector.



2. INSTALL WINDSHIELD WIPER SWITCH ASSEMBLY



  1. Attach the claw to install the wiper switch.



3. INSTALL SPIRAL CABLE

  1. Install the spiral cable (Click here).
