FRONT SEAT ASSEMBLY (for Manual Seat) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL FRONT SEAT ASSEMBLY LH

  1. Place the front seat assembly in the cabin.

    NOTICE:
    Be careful not to damage the vehicle body.

  1. Connect the seat wire connectors under the seat.

  1. Temporarily install the front seat assembly with the 4 bolts.

  1. Operate the seat track adjusting handle to move the seat to the rearmost position.




  1. Tighten the bolts in the order indicated in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }

  1. Operate the seat track adjusting handle to move the seat to the foremost position.




  1. Tighten the bolts in the order indicated in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }



2. INSTALL REAR INNER SEAT TRACK BRACKET COVER LH



  1. Attach the 3 claws to install the seat track cover.



3. INSTALL REAR OUTER FRONT SEAT TRACK COVER LH



  1. Attach the 3 claws to install the seat track cover.



4. INSTALL FRONT INNER SEAT TRACK BRACKET COVER LH



  1. Attach the 2 claws to install the seat track bracket cover.



5. INSTALL FRONT OUTER SEAT TRACK BRACKET COVER LH



  1. Attach the 2 claws to install the seat track bracket cover.



6. INSTALL FRONT SEAT HEADREST ASSEMBLY


7. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

  1. Connect the cable to the negative (-) battery terminal.

    NOTICE:
    When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).

  1. Restore the Autoaway/Return function setting to the previous condition by changing the customize parameter (Click here).



8. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
