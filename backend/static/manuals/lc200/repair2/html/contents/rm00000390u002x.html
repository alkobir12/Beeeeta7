CAUTION:
Wear protective gloves. Sharp areas on the parts may injure your hands.

HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL FRONT SEAT WIRE LH


2. INSTALL SEAT POSITION SENSOR

  1. Check that the engine switch is off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.




  1. Using a 1.0 mm (0.0393 in.) feeler gauge, install the seat position sensor.

    NOTICE:
    1. If the seat position sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace the seat position sensor with a new one.
    2. When installing the seat position sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

    HINT:
    Be sure that the clearance between the seat position sensor and the seat rail is within 0.6 to 1.4 mm (0.0236 to 0.0551 in.).

  1. Using a T30 "TORX" socket wrench, install the seat position sensor with the screw.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Make sure that the clearance between the seat position sensor and the seat rail is within 0.6 to 1.4 mm (0.0236 to 0.0551 in.).

  1. Check that there is no looseness in the installation parts of the seat position sensor.

  1. Connect the connector.

  1. Install the seat slide position sensor protector to the seat position sensor.



3. INSTALL SEAT HEATER CONTROL SUB-ASSEMBLY (w/ Seat Heater System)



  1. Attach the claw to install the seat heater control.

  1. Attach the clamp and connect the seat heater control connector.



4. INSTALL FRONT LOWER SEAT CUSHION SHIELD RH



  1. Attach the hook to install the lower cushion shield.

  1. Install the screw.



5. INSTALL FRONT LOWER SEAT CUSHION SHIELD LH

  1. Attach the hook to install the lower cushion shield.

  1. Install the screw.



6. INSTALL UPPER ACTIVE HEADREST UNIT



  1. Install the upper active headrest unit to the lower active headrest unit with the cable clamp and nut.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



7. INSTALL LOWER ACTIVE HEADREST UNIT



  1. Install the lower active headrest unit together with the upper active headrest unit with the 8 nuts.

    Torque:
    Upper active headrest unit:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }
    Lower active headrest unit:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



8. INSTALL LUMBAR SUPPORT ADJUSTER ASSEMBLY LH (for Driver Side)



  1. Attach the 3 claws to install the bush.




  1. Install the lumbar support adjuster with the 2 screws.

  1. Connect the lumbar support adjuster connector.




  1. Attach the 4 hooks to install the seatback spring.

  1. Install the 4 springs.



9. INSTALL OUTSIDE RECLINING ADJUSTER COVER RH



  1. Attach the claw to install the reclining adjuster cover.

  1. Install the screw.



10. INSTALL OUTSIDE RECLINING ADJUSTER COVER LH

  1. Attach the claw to install the reclining adjuster cover.

  1. Install the screw.



11. INSTALL INSIDE RECLINING ADJUSTER COVER RH



  1. Attach the claw to install the cover.

  1. Install the 2 screws.

  1. Attach the wire harness clamp.



12. INSTALL INSIDE RECLINING ADJUSTER COVER LH

  1. Attach the claw to install the cover.

  1. Install the 2 screws.

  1. Attach the wire harness clamp.



13. INSTALL FRONT SEATBACK HEATER ASSEMBLY LH (w/ Seat Heater System)

  1. Set the seatback heater with the name stamp side facing the seatback cover.



  1. Install the seatback heater with new tack pins.





14. INSTALL FRONT SEPARATE TYPE SEATBACK COVER



  1. Attach the fastening tape to install the seatback cover with new hog rings.

  1. Using hog ring pliers, install the seatback cover

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.




  1. Connect the seatback cover bracket to the seatback pad.



15. INSTALL SEATBACK COVER WITH PAD

  1. Install the seatback cover with pad to the seatback frame.




  1. Install the seatback cover bracket to the seat frame with the nut.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

    CAUTION:
    After the seatback trim cover is assembled, make sure the side airbag strap is not twisted.




  1. Attach the 9 hooks.

  1. Using hog ring pliers, install 3 new hog rings to the seat frame.



16. INSTALL FRONT SEAT HEADREST SUPPORT

  1. Attach the 4 claws to install the 2 headrest supports.



17. INSTALL FRONT SEATBACK BOARD SUB-ASSEMBLY LH



  1. Move the seatback board in the direction of the arrow to attach the 2 hooks and install the seatback board.

  1. Install the 2 screws.



18. INSTALL FRONT SEAT CUSHION HEATER ASSEMBLY LH (w/ Seat Heater System)

  1. Set the seat cushion heater with the name stamp side facing the seat cushion cover.



  1. Install the seat cushion heater with new tack pins.





19. INSTALL FRONT SEPARATE TYPE SEAT CUSHION COVER



  1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



20. INSTALL SEAT CUSHION COVER WITH PAD



  1. Attach the hooks to install the seat cushion cover with pad.

  1. Bend the 2 seat frame claws downward.




  1. Connect the seat heater control connector and attach the wire harness clamp.




  1. for Front Passenger Side:

    1. Attach the 2 clamps to install the seat belt warning sensor connector.

    2. Connect the seat belt warning sensor connector.




  1. Connect the seat heater connector and attach the 2 wire harness clamps.




  1. Install the 2 clips.



21. INSTALL FRONT POWER SEAT SWITCH LH



  1. Install the switch with the 3 screws.

  1. w/ Seat Position Memory System:
    Connect the 2 connectors.

  1. w/o Seat Position Memory System:
    Connect the connector.



22. INSTALL FRONT INNER SEAT CUSHION SHIELD LH



  1. Attach the 2 claws and clip to install the cushion shield.

  1. Install the screw.



23. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH



  1. Install the front seat inner belt assembly with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding parts of the front seat adjuster.

  1. Connect the connectors and attach the clamps.



24. INSTALL LUMBAR SWITCH (for Driver Side)



  1. Install the lumbar switch with the 2 screws.



25. INSTALL FRONT INNER NO. 1 SEAT CUSHION SHIELD LH



  1. Attach the claw to install the cushion shield.

  1. Install the screw.



26. INSTALL FRONT SEAT CUSHION SHIELD LH



  1. for Driver Side:
    Connect the lumbar switch connectors.

  1. Attach the 2 claws to install the cushion shield.

  1. Install the 3 screws.




  1. Install the 2 screws.

  1. Attach the 2 rubber bands to the hooks.



27. INSTALL RECLINING POWER SEAT SWITCH KNOB



  1. Attach the 2 claws to install the knob.



28. INSTALL SLIDE AND VERTICAL POWER SEAT SWITCH KNOB



  1. Attach the 2 claws to install the knob.
