REAR NO. 2 SEAT ASSEMBLY (except Face to Face Seat Type) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL REAR SEAT LOCK STRIKER SUB-ASSEMBLY



  1. Install the 4 seat lock strikers with 8 bolts.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }

  1. Return the floor carpet to its original position.



2. INSTALL NO. 3 SEAT CUSHION COVER



  1. Attach the 8 claws and 4 clips to install the 4 seat cushion covers.



3. INSTALL FOLD SEAT LEG LOCK SUB-ASSEMBLY



  1. Install the fold seat leg lock with the 2 nuts.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }

  1. Attach the 2 cable clamps.



4. INSTALL REAR ROOF NO. 1 AIR DUCT (w/ Rear Air Conditioning System)



  1. Install the duct with the clip.




  1. Attach the 2 claws to install the cooler plate.



5. INSTALL REAR SEAT LOCK CONTROL LEVER SUB-ASSEMBLY LH

  1. Attach the 4 claws to install the seat lock control lever.



6. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH

  1. w/ Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).

  1. w/o Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).



7. INSTALL REAR SEAT COVER CAP



HINT:
Use the same procedure to install the rear seat cover cap on the other side.

  1. Attach the 3 claws to install the rear seat cover cap.



8. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



9. INSTALL REAR DOOR SCUFF PLATE LH



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



10. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.



11. INSTALL REAR NO. 2 SEAT ASSEMBLY



  1. Temporarily install the seat assembly with the 4 bolts.

    NOTICE:
    Be careful not to damage the vehicle body.

  1. Tighten the bolts in the order shown in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }



12. INSTALL REAR NO. 2 SEAT HINGE COVER LH



  1. Attach the clip and 2 claws to install the cover.



13. INSTALL REAR SEAT CUSHION HINGE COVER LH



  1. Attach the 3 claws to install the cover.

  1. Return the seat to the upright position.



14. INSTALL REAR NO. 2 SEAT HEADREST ASSEMBLY LH
