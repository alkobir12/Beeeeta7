REAR NO. 2 SEAT ASSEMBLY (except Face to Face Seat Type) > REASSEMBLY

for Preparation Click here


CAUTION:
Wear protective gloves. Sharp areas on the parts may injure your hands.

HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL NO. 2 SEAT RECLINING RELEASE HANDLE SUB-ASSEMBLY

  1. Install the release handle with the bolt.



2. INSTALL REAR SEATBACK LOCK STRIKER COVER LH

  1. Attach the 2 clamps to install the cover.



3. INSTALL REAR NO. 2 SEATBACK COVER LH

  1. Attach the 3 claws to install the cover.



4. INSTALL REAR SEATBACK LOCK STRIKER ASSEMBLY LH



  1. Install the lock striker with the 2 nuts.

    Torque:
    8.5 N*m{ 87 kgf*cm , 75 in.*lbf }



5. INSTALL REAR SEAT LOCK CONTROL CABLE



  1. Attach the 2 clamps to install the lock control cable.

  1. Attach the 2 cable clamps to connect the 2 cables.



6. INSTALL REAR INNER SEAT RECLINING COVER RH



  1. Attach the claw to install the cover.

  1. Install the screw.



7. INSTALL REAR INNER SEAT RECLINING COVER LH

  1. Attach the claw to install the cover.

  1. Install the screw.



8. INSTALL NO. 3 SEATBACK COVER SUB-ASSEMBLY LH



  1. Using hog ring pliers, install the seatback cover to the seatback pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



9. INSTALL SEATBACK COVER WITH PAD



  1. Using hog ring pliers, install the seatback cover with pad to the seatback frame with a new hog rings.



  1. LH Side:




    1. Attach the 8 claws to install the 4 headrest supports.

    2. Install the rear seat protector.




    3. Insert the center headrest storage bag.




    4. Attach the 2 hooks.




    5. Close the fastener.



  1. RH Side:




    1. Attach the 4 claws to install the 2 headrest supports.

    2. Install the rear seat protector.




    3. Attach the hook.



10. INSTALL REAR SEAT HEADREST HANDLE

  1. Install the snap ring to the headrest handle.




  1. Install the headrest handle to the headrest.



11. INSTALL REAR SEAT HEADREST ASSEMBLY (w/ Folding Headrest)



  1. While releasing the lock inside the headrest support with a screwdriver, install the headrest.

    HINT:
    Tape the screwdriver tip before use.



12. INSTALL REAR SEAT HEADREST ASSEMBLY (w/o Folding Headrest)


13. INSTALL REAR SEAT HINGE PAWL GUIDE



  1. Install the guide with the screw.



14. INSTALL REAR SEAT HINGE PAWL GUIDE



  1. Attach the 5 claws to install the guide.



15. INSTALL REAR LOWER SEATBACK LOCK BEZEL



  1. Attach the 3 claws and clip to install the seatback lock bezel.



16. INSTALL REAR NO. 2 SEATBACK CUSHION



  1. Install the seatback cushion with the screw.



17. INSTALL NO. 3 FOLD SEAT LOCK CONTROL CABLE ASSEMBLY



  1. Attach the 2 clamps to install the 2 cables.




  1. Attach the 2 cable clamps to connect the 2 cables.



18. INSTALL NO. 2 SEAT STAY SUB-ASSEMBLY



  1. Install the seat stay with the bolt.



19. INSTALL NO. 3 SEAT CUSHION COVER SUB-ASSEMBLY LH



  1. Attach the fastening tape to install the seatback cover.

  1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



20. INSTALL NO. 3 SEAT CUSHION PAD LH


21. INSTALL SEAT CUSHION COVER WITH PAD


22. INSTALL REAR SEAT CUSHION CARPET



  1. Install the seat cushion carpet with new tack pins.



23. INSTALL REAR NO. 2 SEAT INNER BELT SUB-ASSEMBLY


  1. Install the 2 belts.



    NOTICE:
    1. Make sure the claws are facing away from the seat.
    2. Do not overlap the anchor part of the seat belt and protruding parts of the seat.



24. INSTALL REAR SEAT INNER BELT SUB-ASSEMBLY (for LH Side)



  1. Install the belt with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the seat.

    HINT:
    The rear No. 2 seat inner belt is fixed with the same nut as the rear seat inner belt. Therefore, connect it when installing the rear seat inner belt.



25. INSTALL REAR SEAT OUTER BELT SUB-ASSEMBLY (for RH Side)



  1. Install the belt with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the seat.

    HINT:
    The rear No. 2 seat inner belt is fixed with the same nut as the rear seat outer belt. Therefore, connect it when installing the rear seat outer belt.



26. INSTALL SEAT CUSHION LOCK RELEASE LEVER ASSEMBLY LH



  1. Attach the 2 cable clamps to connect the 2 cables.




  1. Attach the claw to install the release lever.

  1. Install the 2 screws.



27. INSTALL SEAT STAND FRAME CAP



  1. Attach the 2 claws to install the stand frame cap.



28. INSTALL REAR SEAT LOCK COVER LH



  1. Attach the 2 clamps to install the cover.

  1. Install the 2 screws.



29. INSTALL NO. 3 SEAT LEG COVER NO. 2



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



30. INSTALL NO. 3 SEAT FRONT BRACKET COVER LH



  1. Attach the 4 claws to install the cover.



31. INSTALL REAR SEAT CUSHION UNDER COVER LH



  1. Install the cover with the 8 screws.




  1. Attach the 16 claws.



32. INSTALL 3RD SEAT CUSHION LOCK COVER



  1. Attach the 4 claws to install the 2 covers.



33. INSTALL 3RD SEAT LINK SUB-ASSEMBLY LH



  1. Install the seat link with the bolt and nut.

    Torque:
    8.5 N*m{ 87 kgf*cm , 75 in.*lbf }



34. INSTALL NO. 2 SEAT LEG COVER NO. 2



  1. Install the seat leg cover with the screw.



35. INSTALL REAR NO. 3 SEAT LEG COVER LH



  1. Install the seat leg cover with the 2 screws.




  1. Install the spring of the seat stay ball-joint.

  1. Connect the seat stay to the seat frame.



36. INSTALL REAR SEAT REAR BRACKET COVER REAR

  1. Attach the 2 claws to install the cover.



37. INSTALL RECLINING ADJUSTER COVER RH



  1. Attach the 5 claws in the order shown in the illustration to install the cover.

  1. Install the screw.



38. INSTALL RECLINING ADJUSTER COVER LH



  1. Attach the 3 claws in the order shown in the illustration to install the cover.

  1. Install the screw.



39. INSTALL NO. 2 RECLINING ADJUSTER RELEASE HANDLE LH



  1. Install the release handle with the screw.



40. INSTALL SEAT ADJUSTER BOLT COVER



  1. Attach the 2 claws to install the cover.
