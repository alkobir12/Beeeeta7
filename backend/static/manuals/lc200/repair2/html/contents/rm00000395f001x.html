FRONT SEAT CUSHION HEATER (w/ Seat Heater System) > INSTALLATION

for Preparation Click here


CAUTION:
Wear protective gloves. Sharp areas on the parts may injure your hands.

HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL FRONT SEAT CUSHION HEATER ASSEMBLY LH

  1. Set the seat cushion heater with the name stamp side facing the seat cushion cover.



  1. Install the seat cushion heater with new tack pins.





2. INSTALL FRONT SEPARATE TYPE SEAT CUSHION COVER



  1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



3. INSTALL SEAT CUSHION COVER WITH PAD



  1. Attach the hooks to install the seat cushion cover with pad.

  1. Bend the 2 seat frame claws downward.




  1. Connect the seat heater control connector and attach the wire harness clamp.




  1. for Front Passenger Side:

    1. Attach the 2 clamps to install the seat belt warning sensor connector.

    2. Connect the seat belt warning sensor connector.




  1. Connect the seat heater connector and attach the 2 wire harness clamps.




  1. Install the 2 clips.



4. INSTALL FRONT POWER SEAT SWITCH LH



  1. Install the switch with the 3 screws.

  1. w/ Seat Position Memory System:
    Connect the 2 connectors.

  1. w/o Seat Position Memory System:
    Connect the connector.



5. INSTALL FRONT INNER SEAT CUSHION SHIELD LH



  1. Attach the 2 claws and clip to install the cushion shield.

  1. Install the screw.



6. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH



  1. Install the front seat inner belt assembly with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding parts of the front seat adjuster.

  1. Connect the connectors and attach the clamps.



7. INSTALL FRONT SEAT CUSHION SHIELD LH



  1. for Driver Side:
    Connect the lumbar switch connectors.

  1. Attach the 2 claws to install the cushion shield.

  1. Install the 3 screws.




  1. Install the 2 screws.

  1. Attach the 2 rubber bands to the hooks.



8. INSTALL RECLINING POWER SEAT SWITCH KNOB



  1. Attach the 2 claws to install the knob.



9. INSTALL SLIDE AND VERTICAL POWER SEAT SWITCH KNOB



  1. Attach the 2 claws to install the knob.



10. INSTALL FRONT SEAT ASSEMBLY LH

  1. Install the front seat assembly (Click here).
