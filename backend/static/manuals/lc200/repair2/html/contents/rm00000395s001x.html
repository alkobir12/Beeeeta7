REAR SEAT CUSHION HEATER (for 60/40 Split Seat Type 40 Side) > INSTALLATION

for Preparation Click here


CAUTION:
Wear protective gloves. Sharp areas on the parts may injure your hands.

HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL REAR SEAT CUSHION HEATER ASSEMBLY

  1. Set the seat cushion heater with the name stamp side facing the seat cushion cover.



  1. Install the seat cushion heater with new tack pins.





2. INSTALL REAR SEPARATE TYPE SEAT CUSHION COVER



  1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.




  1. Attach the 3 pieces of fastening tape.



3. INSTALL SEAT CUSHION COVER WITH PAD

  1. Install the seat cushion cover with pad.

  1. w/ Rear Seat Side Airbag:
    Pass the side airbag wire harness through the hole in the seat cushion.



  1. w/ Seat Heater System:




    1. Pass the seatback heater wire harness through the hole in the seat cushion.




    2. Connect the 2 seat heater connectors.

  1. w/ Rear Seat Side Airbag:
    Attach the side airbag wire harness clamps.



4. INSTALL REAR SEAT UNDER TRAY COVER RH



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



5. INSTALL REAR UNDER SIDE COVER LH



  1. Attach the 2 claws and clip to install the cover.

  1. Install the 5 screws.



6. INSTALL REAR SEAT COVER



  1. Attach the 2 claws to install the cover.

  1. Install the 3 screws.




  1. Attach the 12 claws.



7. INSTALL REAR NO. 1 SEAT HINGE SUB-ASSEMBLY RH



  1. Attach the cable clamp to connect the cable.




  1. Install the hinge with the 2 nuts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. w/ Rear Seat Side Airbag:
    Attach the wire harness clamp.

  1. w/ Seat Heater System:
    Attach the wire harness clamp.



8. INSTALL REAR NO. 1 SEAT HINGE SUB-ASSEMBLY LH



  1. Install the hinge with the 2 nuts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



9. INSTALL REAR NO. 2 SEAT PROTECTOR

  1. Install the wire harness, and attach the 2 claws to close the protector.




  1. Attach the claw to install the protector to the seat hinge.

  1. Install the clip.




  1. w/ Rear Seat Side Airbag:
    Attach the claw to install the wire harness connector.

  1. w/ Seat Heater System:
    Attach the claw to install the wire harness connector.



10. INSTALL REAR NO. 2 SEAT LEG SIDE COVER



  1. Pass the fold seat stopper band through the seat leg side cover and attach it to the seat cushion frame with the bolt.




  1. Attach the 3 claws to install the seat leg side cover.

  1. Install the 4 screws.



11. INSTALL UPPER SEAT TRACK RAIL COVER RH



  1. Attach the 2 claws to install the cover.



12. INSTALL UPPER SEAT TRACK RAIL COVER LH



  1. Attach the 2 claws to install the cover.



13. INSTALL REAR NO. 1 SEAT RECLINING COVER LH



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



14. INSTALL REAR NO. 1 SEAT RECLINING COVER RH



  1. Attach the 3 claws in the order shown in the illustration to install the cover.

  1. Install the 2 screws.



15. INSTALL RECLINING ADJUSTER RELEASE HANDLE RH



  1. Install the release handle with the screw.



16. INSTALL SEAT ADJUSTER BOLT COVER



  1. Attach the 2 claws to install the cover.



17. INSTALL REAR NO. 1 SEAT ASSEMBLY RH

  1. Install the rear No. 1 seat assembly (Click here).
