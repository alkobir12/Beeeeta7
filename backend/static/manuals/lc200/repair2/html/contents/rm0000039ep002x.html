REAR NO. 1 SEAT OUTER BELT ASSEMBLY > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL REAR SHOULDER BELT ANCHOR PLATE SUB-ASSEMBLY LH



  1. Align the anchor plate positioning hole with the claw, and install the anchor plate with the 2 bolts.

    HINT:
    First install the upper bolt, and then install the lower bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



2. INSTALL REAR NO. 1 SEAT OUTER BELT ASSEMBLY LH



NOTICE:
w/ Pretensioner:
When installing the retractor, make sure the claws of the vehicle (labeled "a" in the illustration) only contact the installation areas of the retractor.

  1. Align the claws with the seat belt positioning holes and install the retractor of the seat belt as shown in the illustration.

  1. Install the seat belt with the 2 bolts.

    HINT:
    First install bolt A, and then install bolt B.

    Torque:
    for bolt A:
    8.5 N*m{ 87 kgf*cm , 75 in.*lbf }
    for bolt B:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }




  1. w/ Pretensioner:
    Connect the pretensioner connector as shown in the illustration.




  1. Install the seat belt shoulder anchor with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



3. INSTALL REAR FRONT QUARTER TRIM PANEL ASSEMBLY LH



  1. Pass the seat belt anchor through the quarter trim garnish.

  1. Attach the clip and 2 guides to install the quarter trim garnish.

  1. Install the screw.



4. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH



HINT:
When installing the front quarter trim panel, operate the reclining adjuster release handle and move the No. 1 rear seat to the position shown in the illustration.



  1. w/o Tonneau Cover:

    1. w/o Rear Air Conditioning System:
      Connect the rear seat lock control lever cable.

    2. w/ Rear Air Conditioning System:
      Connect the thermistor connector and rear seat lock control lever cable.

    3. Attach the 18 clips and 2 claws to install the quarter trim panel.



    4. Install the clip and bolt.

      Torque:
      12 N*m{ 122 kgf*cm , 9 ft.*lbf }






  1. w/ Tonneau Cover:

    1. Attach the 18 clips and 2 claws to install the quarter trim panel.



    2. Install the screw and clip.






  1. w/ Rear No. 2 Seat, for LH side:

    1. Install the rear No. 2 seat belt anchor LH with the bolt.

      Torque:
      42 N*m{ 428 kgf*cm , 31 ft.*lbf }

      NOTICE:
      Do not overlap the anchor part of the seat belt and protruding parts of the vehicle body.




  1. w/ Rear No. 2 Seat, for RH side:

    1. Install the rear No. 2 seat belt anchor with the bolt.

      Torque:
      42 N*m{ 428 kgf*cm , 31 ft.*lbf }




    2. Attach the 3 claws to install the cover.




  1. Install the rear No. 1 seat belt anchor with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }




  1. Attach the 3 claws to install the cover.



5. INSTALL REAR NO. 2 SEAT COVER BEZEL



  1. Attach the 6 clips to install the rear No. 2 seat cover bezel.



6. INSTALL NO. 1 TONNEAU COVER HOLDER CAP (w/ Tonneau Cover)



HINT:
Use the same procedure to install the tonneau cover holder cap on the other side.

  1. Attach the 2 claws to install the tonneau cover holder cap.



7. INSTALL REAR DOOR SCUFF PLATE LH



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



8. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.



9. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



10. INSTALL REAR NO. 2 SEAT ASSEMBLY (w/ Rear No. 2 Seat)

  1. Install the rear No. 2 seat assembly (Click here).



11. INSTALL TONNEAU COVER ASSEMBLY

  1. Install the tonneau cover assembly.



12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL


13. CHECK SRS WARNING LIGHT
