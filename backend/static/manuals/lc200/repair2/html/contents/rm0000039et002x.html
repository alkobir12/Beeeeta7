REAR NO. 2 SEAT INNER BELT ASSEMBLY > INSTALLATION

for Preparation Click here



1. INSTALL REAR NO. 2 SEAT INNER BELT SUB-ASSEMBLY


  1. Install the 2 belts.



    NOTICE:
    1. Make sure the claws are facing away from the seat.
    2. Do not overlap the anchor part of the seat belt and protruding parts of the seat.



2. INSTALL REAR SEAT INNER BELT SUB-ASSEMBLY (for LH Side)



  1. Install the belt with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the seat.

    HINT:
    The rear No. 2 seat inner belt is fixed with the same nut as the rear seat inner belt. Therefore, connect it when installing the rear seat inner belt.



3. INSTALL REAR SEAT OUTER BELT SUB-ASSEMBLY (for RH Side)



  1. Install the belt with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the seat.

    HINT:
    The rear No. 2 seat inner belt is fixed with the same nut as the rear seat outer belt. Therefore, connect it when installing the rear seat outer belt.



4. INSTALL NO. 3 SEAT LEG COVER NO. 2



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



5. INSTALL NO. 3 SEAT FRONT BRACKET COVER LH



  1. Attach the 4 claws to install the cover.



6. INSTALL REAR SEAT CUSHION UNDER COVER LH



  1. Install the cover with the 8 screws.




  1. Attach the 16 claws.



7. INSTALL 3RD SEAT LINK SUB-ASSEMBLY LH



  1. Install the seat link with the bolt and nut.

    Torque:
    8.5 N*m{ 87 kgf*cm , 75 in.*lbf }



8. INSTALL NO. 2 SEAT LEG COVER NO. 2



  1. Install the seat leg cover with the screw.



9. INSTALL REAR NO. 3 SEAT LEG COVER LH



  1. Install the seat leg cover with the 2 screws.




  1. Install the spring of the seat stay ball-joint.

  1. Connect the seat stay to the seat frame.



10. INSTALL REAR SEAT REAR BRACKET COVER REAR

  1. Attach the 2 claws to install the cover.



11. INSTALL RECLINING ADJUSTER COVER RH



  1. Attach the 5 claws in the order shown in the illustration to install the cover.

  1. Install the screw.



12. INSTALL RECLINING ADJUSTER COVER LH



  1. Attach the 3 claws in the order shown in the illustration to install the cover.

  1. Install the screw.



13. INSTALL NO. 2 RECLINING ADJUSTER RELEASE HANDLE LH



  1. Install the release handle with the screw.



14. INSTALL SEAT ADJUSTER BOLT COVER



  1. Attach the 2 claws to install the cover.



15. INSTALL REAR NO. 2 SEAT ASSEMBLY (for LH Side)

  1. Install the rear No. 2 seat assembly (Click here).
