DOOR CONTROL RECEIVER > INSTALLATION

for Preparation Click here



1. INSTALL DOOR CONTROL RECEIVER



  1. Install the receiver with the bolt.

    Torque:
    15 N*m{ 153 kgf*cm , 11 ft.*lbf }

  1. Connect the connector.



2. INSTALL REAR UPPER PILLAR GARNISH RH

HINT:
Use the same procedures described for the LH side.



3. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY RH



HINT:
When installing the front quarter trim panel, operate the reclining adjuster release handle and move the No. 1 rear seat to the position shown in the illustration.



  1. w/ Rear No. 2 Seat, except Face to Face Seat Type:

    1. w/o Rear Air Conditioning System:
      Connect the rear seat lock control lever cable.

    2. w/ Rear Air Conditioning System:
      Connect the thermistor connector and rear seat lock control lever cable.

    3. Attach the 16 clips and 2 claws to install the quarter trim panel.



    4. Install the clip and bolt.

      Torque:
      12 N*m{ 122 kgf*cm , 9 ft.*lbf }






  1. w/o Rear No. 2 Seat or w/ Rear No. 2 Seat, for Face to Face Seat Type:

    1. Attach the 16 clips and 2 claws to install the quarter trim panel.



    2. Install the clip.






  1. w/ Rear No. 2 Seat, except Face to Face Seat Type:

    1. Install the rear No. 2 seat belt anchor with the bolt.

      Torque:
      42 N*m{ 428 kgf*cm , 31 ft.*lbf }




    2. Attach the 3 claws to install the cover.




  1. Install the rear No. 1 seat belt anchor with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }




  1. Attach the 3 claws to install the cover.



4. INSTALL REAR SEAT COVER CAP (w/ Rear No. 2 Seat, except Face to Face Seat Type)



HINT:
Use the same procedure to install the rear seat cover cap on the other side.

  1. Attach the 3 claws to install the rear seat cover cap.



5. INSTALL NO. 1 TONNEAU COVER HOLDER CAP (w/ Tonneau Cover)



HINT:
Use the same procedure to install the tonneau cover holder cap on the other side.

  1. Attach the 2 claws to install the tonneau cover holder cap.



6. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



7. INSTALL REAR DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.

  1. Install the rear No. 2 seat assembly RH (Click here).



10. INSTALL REAR NO. 2 SEAT ASSEMBLY RH (except Face to Face Seat Type)

  1. Install the rear No. 2 seat assembly RH (Click here).
