POWER OUTLET SOCKET > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL POWER OUTLET SOCKET COVER



  1. Attach the 2 claws to install the socket cover.



2. INSTALL POWER OUTLET SOCKET ASSEMBLY



  1. Align the protrusion on the backside of the socket with the groove of the cover. Then push the socket into the cover.



3. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



4. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



5. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



6. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



7. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.
