NETWORK GATEWAY ECU (for RHD) > INSTALLATION

for Preparation Click here



1. INSTALL NETWORK GATEWAY ECU



  1. Install the ECU with the bolt.

  1. Connect the connector.



2. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



3. INSTALL NO. 1 SWITCH HOLE BASE



  1. Connect the connectors.

  1. Attach the 4 claws to install the switch hole base.



4. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (w/ Driver Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



5. INSTALL LOWER INSTRUMENT PANEL SUB-ASSEMBLY (w/o Driver Side Knee Airbag)



  1. Attach the 4 claws to install the instrument panel.

  1. Install the 2 bolts.



6. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



7. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 2 claws to install the panel garnish.



8. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 3 claws to install the panel garnish.



9. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



10. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



11. INSTALL FRONT DOOR SCUFF PLATE RH

  1. w/ Sliding Roof:
    Install the front door scuff plate (Click here ).

  1. w/o Sliding Roof:
    Install the front door scuff plate (Click here).



12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL (w/ Driver Side Knee Airbag)

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



13. CHECK SRS WARNING LIGHT (w/ Driver Side Knee Airbag)

  1. Check the SRS warning light (Click here).
