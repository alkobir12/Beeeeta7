STEERING COLUMN ASSEMBLY (for Manual Tilt and Manual Telescopic Steering Column) > INSTALLATION

for Preparation Click here



1. CONNECT NO. 2 STEERING INTERMEDIATE SHAFT



  1. Align the part of the dust cover labeled A with the No. 2 steering intermediate shaft, and install the No. 2 steering intermediate shaft assembly to the steering link assembly.

  1. Install the bolt.

    Torque:
    35 N*m{ 360 kgf*cm , 26 ft.*lbf }

    NOTICE:
    Be careful not to damage the dust cover.



2. INSTALL STEERING COLUMN HOLE COVER SUB-ASSEMBLY



  1. Install the 4 bolts and nut.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

    NOTICE:
    Do not fold back the boot part of the steering hole cover or extend it excessively. if it is extended excessively, return it to its original position.

    HINT:
    Install the steering intermediate shaft assembly from the inside of the vehicle.

  1. Using needle nose pliers, lock the clamp to the steering column hole cover to install it.

    NOTICE:
    Be careful when performing the operation as the clamp may not lock if the claws of the clamp are deformed.



3. CONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY



  1. Align the matchmarks on the No. 2 steering intermediate shaft assembly and the steering intermediate shaft assembly.

    HINT:
    Install the steering intermediate shaft from the inside of the vehicle.

  1. Install the bolt.

    Torque:
    35 N*m{ 360 kgf*cm , 26 ft.*lbf }



4. INSTALL STEERING COLUMN ASSEMBLY



  1. Align the matchmarks on the steering intermediate shaft and the steering column.

  1. Install the bolt.

    Torque:
    35 N*m{ 360 kgf*cm , 26 ft.*lbf }




  1. Install the steering column with the 4 nuts.

    Torque:
    26 N*m{ 265 kgf*cm , 19 ft.*lbf }



5. INSTALL NO. 3 AIR DUCT SUB-ASSEMBLY



  1. Remove the clip.

  1. Detach the 2 claws and remove the duct.



6. INSTALL WIRE HARNESS PROTECTOR AND WIRE HARNESS



  1. Attach the 2 claws to connect the wire harness protector and wire harness.



7. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (w/ Driver Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



8. INSTALL LOWER INSTRUMENT PANEL SUB-ASSEMBLY (w/o Driver Side Knee Airbag)



  1. Attach the 4 claws and connect the DLC3.

  1. Install the instrument panel with the 5 bolts.



9. INSTALL NO.1 SWITCH HOLE BASE



  1. Connect the connectors.

  1. Attach the 4 claws to install the switch hole base.



10. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



11. INSTALL COWL SIDE TRIM BOARD LH



  1. Attach the 2 clips to install the trim board.

  1. Install the cap nut.



12. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



13. INSTALL FRONT DOOR SCUFF PLATE LH



  1. Attach the 7 claws and 4 clips to install the scuff plate.



14. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY (w/o Multi-information Display)



  1. Attach the 9 claws to install the finish panel.



15. REMOVE INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY (w/ Multi-information Display)



  1. Connect the connector.

  1. Attach the 9 claws to install the finish panel.



16. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 2 claws to install the panel garnish.



17. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 3 claws to install the panel garnish.



18. INSTALL INSTRUMENT SIDE PANEL LH



  1. Attach the 6 claws to install the side panel.



19. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



20. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



21. INSTALL COMBINATION SWITCH ASSEMBLY WITH SPIRAL CABLE SUB-ASSEMBLY



  1. Using pliers, grip the claws of the clamp and install the combination switch assembly with spiral cable sub-assembly to the steering column assembly with the clamp.




  1. Connect the 5 connectors to the combination switch with spiral cable.



22. INSTALL UPPER STEERING COLUMN COVER



  1. Attach the claw to install the upper steering column cover.

  1. Attach the 4 clips to install the upper steering column cover onto the instrument cluster finish panel.



23. INSTALL LOWER STEERING COLUMN COVER



  1. Attach the 2 claws to install the lower steering column cover.

    NOTICE:
    Do not damage the tilt and telescopic switch.

  1. Install the 3 screws.

    Torque:
    2.0 N*m{ 20 kgf*cm , 18 in.*lbf }



24. INSTALL STEERING WHEEL ASSEMBLY



  1. Align the matchmarks on the steering wheel assembly and steering main shaft assembly.

  1. Install the steering wheel assembly set nut.

    Torque:
    50 N*m{ 510 kgf*cm , 37 ft.*lbf }



25. INSTALL STEERING PAD



  1. Support the steering pad with one hand.

  1. Connect the 2 connectors to the steering pad.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Connect the horn connector.

  1. Confirm that the circumference groove of the "TORX" screw fits in the screw case, and place the steering pad onto the steering wheel.

  1. Using a T30 "TORX" socket wrench, tighten the 2 screws.

    Torque:
    8.8 N*m{ 90 kgf*cm , 78 in.*lbf }



26. INSTALL LOWER NO. 2 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.



27. INSTALL LOWER NO. 3 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.



28. CHECK FRONT WHEELS FACING STRAIGHT AHEAD


29. INSTALL FRONT WHEELS


30. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
  1. Reset the AUTO TILT AWAY function setting to the previous condition by changing the customize parameter (Click here).
  2. When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
