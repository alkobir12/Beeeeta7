1. HANDLING PRECAUTIONS FOR STEERING ACTUATOR ASSEMBLY

NOTICE:
  1. Be careful that the No. 2 seal lip or boot does not turn outward while carrying or installing the steering actuator assembly. If installing a new steering actuator assembly, make sure that the spiral center lock pin is securely inserted.

  2. Do not use the steering actuator assembly if it has been dropped.





2. INSTALL STEERING ACTUATOR ASSEMBLY

  1. Make sure that the power steering link assembly is centered.




  1. Install the steering actuator assembly.

    1. If installing a new steering actuator assembly:
      Install the steering actuator assembly with the white paint on the upper surface of the spiral case facing down.

      NOTICE:
      Do not pull out the center lock pin.




    2. If reinstalling the removed steering actuator assembly:

      1. Slowly turn the spiral case clockwise until it locks.
      2. Turn the spiral case two turns counterclockwise from the lock position.
      3. Align the slit of the sliding yoke with the alignment mark (▲).
      4. Install the steering actuator assembly with the white paint on the upper surface of the spiral case facing down.




  1. Align the matchmarks on the No. 2 steering intermediate shaft and steering actuator.

    NOTICE:
    1. Do not fold back the boot part of the steering hole cover or turn it excessively. If it is turned excessively, return it to its original position.
    2. Do not turn the actuator body and the spiral case.

    HINT:
    Install the steering actuator from the inside of the vehicle.

  1. Install the bolt.

    Torque:
    35 N*m{ 360 kgf*cm , 26 ft.*lbf }




  1. Using needle nose pliers, lock the clamp to the steering column hole cover to install it.

    NOTICE:
    Be careful when performing the operation as the clamp may not lock if the claws of the clamp are deformed.




  1. Move the lock in the direction of the arrow and connect the steering actuator connector.

    HINT:
    When a new actuator is installed, remove the center lock pin.

  1. Connect the connector.



3. INSTALL STEERING COLUMN ASSEMBLY



  1. Align the matchmarks on the steering actuator and steering column.

  1. Install the bolt.

    Torque:
    35 N*m{ 360 kgf*cm , 26 ft.*lbf }




  1. Install the steering column with the 4 nuts.

    Torque:
    26 N*m{ 265 kgf*cm , 19 ft.*lbf }



4. INSTALL NO. 3 AIR DUCT SUB-ASSEMBLY



  1. Attach the 2 claws to install the duct.

  1. Install the clip.



5. CONNECT WIRE HARNESS PROTECTOR AND WIRE HARNESS



  1. Attach the 3 claws to connect the wire harness protector and wire harness.



6. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (w/ Driver Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



7. INSTALL LOWER INSTRUMENT PANEL SUB-ASSEMBLY (w/o Driver Side Knee Airbag)



  1. Attach the 4 claws and connect the DLC3.

  1. Install the instrument panel with the 5 bolts.



8. INSTALL NO. 1 SWITCH HOLE BASE



  1. Connect the connectors.

  1. Attach the 4 claws to install the switch hole base.



9. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



10. INSTALL COWL SIDE TRIM BOARD LH



  1. Attach the 2 clips to install the trim board.

  1. Install the cap nut.



11. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



12. INSTALL FRONT DOOR SCUFF PLATE LH



  1. Attach the 7 claws and 4 clips to install the scuff plate.



13. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY (w/o Multi-information Display)



  1. Attach the 9 claws to install the finish panel.



14. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY (w/ Multi-information Display)



  1. Connect the connectors.

  1. Install the combination meter with the 4 screws.



15. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 2 claws to install the panel garnish.



16. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 3 claws to install the panel garnish.



17. INSTALL INSTRUMENT SIDE PANEL LH



  1. Attach the 6 claws to install the side panel.



18. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



19. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



20. INSTALL COMBINATION SWITCH ASSEMBLY WITH SPIRAL CABLE SUB-ASSEMBLY



  1. Using pliers, grip the claws of the clamp and install the combination signal switch assembly with spiral cable sub-assembly to the steering column assembly with the clamp.




  1. Connect the 5 connectors to the combination switch with spiral cable.



21. INSTALL TILT AND TELESCOPIC SWITCH



  1. Attach the claw to install the switch.

  1. Connect the switch connector.



22. INSTALL UPPER STEERING COLUMN COVER



  1. Attach the claw to install the upper steering column cover.

  1. Attach the 4 clips to the instrument cluster finish panel.



23. INSTALL LOWER STEERING COLUMN COVER



  1. Attach the 2 claws to install the lower steering column cover.

    NOTICE:
    Do not damage the tilt and telescopic switch.

  1. Install the 3 screws.

    Torque:
    1.5 N*m{ 15 kgf*cm , 13 in.*lbf }



24. INSTALL STEERING WHEEL ASSEMBLY



  1. Align the matchmarks on the steering wheel assembly and steering main shaft assembly.

  1. Install the steering wheel assembly set nut.

    Torque:
    50 N*m{ 510 kgf*cm , 37 ft.*lbf }



25. INSTALL STEERING PAD



  1. Support the steering pad with one hand.

  1. Connect the 2 connectors to the steering pad.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Connect the horn connector.

  1. Confirm that the circumference groove of the "TORX" screw fits in the screw case, and place the steering pad onto the steering wheel.

  1. Using a T30 "TORX" socket wrench, tighten the 2 screws.

    Torque:
    8.8 N*m{ 90 kgf*cm , 78 in.*lbf }



26. INSTALL LOWER NO. 2 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.



27. INSTALL LOWER NO. 3 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.
