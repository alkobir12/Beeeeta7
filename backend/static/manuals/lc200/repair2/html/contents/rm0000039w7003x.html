FUEL PUMP > REASSEMBLY

for Preparation Click here



NOTICE:
Do not disconnect the hoses indicated in the illustration.




1. INSTALL FUEL PUMP (for Double Tank Type)



  1. Connect the fuel pump wire harness connector to the fuel pump.




  1. Apply a light coat of gasoline to a new O-ring. Then install the spacer and O-ring to the fuel pump.




  1. Attach the 2 claws to the claw holes to install the fuel pump.



2. INSTALL NO. 1 FUEL SUB-TANK (for Single Tank Type)



  1. Attach the 3 claws to the claw holes to install the fuel sub-tank.



3. INSTALL NO. 1 FUEL SUB-TANK (for Double Tank Type)



  1. Attach the 3 claws to the claw holes to install the fuel sub-tank.




  1. Attach the jet pump to the sub-tank.

    HINT:
    Make sure the 2 protrusions of the jet pump are properly installed into the sub-tank.




  1. Connect the fuel pump connector.



4. INSTALL FUEL SENDER GAUGE ASSEMBLY



  1. Set the sender gauge to the fuel sub-tank. Then slide the sender gauge downward to install it.




  1. Connect the fuel sender gauge connector.
