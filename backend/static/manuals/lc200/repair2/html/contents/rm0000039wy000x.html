FUEL SUB TANK > INSTALLATION

for Preparation Click here



1. INSTALL FUEL TANK TO FILLER PIPE HOSE



  1. Install the hose to the fuel sub tank as shown in the illustration.

    HINT:
    1. Align the fuel sub tank side mark with the hose side mark when installing the hose.


    2. Tighten the hose clamp until the end of the hose clamp contacts the stopper as shown in the illustration.



2. INSTALL NO. 3 FUEL HOSE



  1. Install the fuel hose to the fuel sub tank as shown in the illustration.

    HINT:
    1. Align the fuel sub tank side mark with the hose side mark when installing the hose.


    2. Tighten the hose clamp until the end of the hose clamp contacts the stopper as shown in the illustration.



3. INSTALL FUEL TANK BREATHER HOSE



  1. Install the breather hose to the fuel sub tank.



4. INSTALL FUEL AND EVAPORATION VENT TUBE SUB-ASSEMBLY



  1. Install a new gasket to the fuel and evaporation vent tube.

  1. Install the fuel and evaporation vent tube with the 6 bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }



5. INSTALL FUEL TANK EVAPORATION VENT TUBE SUB-ASSEMBLY



  1. Install the 2 fuel tank evaporation vent tubes.



6. INSTALL FUEL HOSE



  1. Install the 3 fuel hoses.



7. INSTALL FUEL SENDER GAUGE ASSEMBLY



  1. Install a new gasket to the sender gauge.

    NOTICE:
    Be careful not to bend the arm of the fuel sender gauge.

  1. Install the sender gauge with the 5 screws.

    Torque:
    1.5 N*m{ 15 kgf*cm , 13 in.*lbf }



8. INSTALL FLOOR NO. 3 WIRE



  1. Attach the wire harness clamp to the fuel sub tank.

  1. Connect the sender gauge connector.



9. INSTALL FUEL SUB TANK SUB-ASSEMBLY

  1. Set the fuel sub tank on a transmission jack and raise the fuel sub tank.

    NOTICE:
    Do not allow the fuel sub tank to contact the vehicle, especially the differential.




  1. Connect the 2 fuel tank bands with the 2 bolts.

    Torque:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }

  1. Connect the floor No. 3 wire connector.

  1. Attach the 3 wire harness clamps.



10. CONNECT FUEL TANK TO FILLER PIPE HOSE



  1. Connect the hose to the filler pipe.



11. CONNECT NO. 3 FUEL HOSE



  1. Connect the fuel hose to the filler pipe.



12. CONNECT FUEL TANK BREATHER HOSE



  1. Connect the breather hose to the filler pipe.



13. CONNECT FUEL HOSE



  1. Connect the 3 fuel hoses.



14. CONNECT FUEL TANK EVAPORATION VENT TUBE



  1. Connect the 2 fuel evaporation vent tubes.



15. INSTALL FUEL TANK CAP ASSEMBLY


16. INSTALL NO. 1 SPARE WHEEL STOPPER



  1. Install the spare wheel stopper with the 2 bolts.

    Torque:
    32 N*m{ 326 kgf*cm , 24 ft.*lbf }



17. INSTALL SPARE WHEEL CARRIER CROSSMEMBER AND SPARE WHEEL CARRIER BRACKET


  1. Install the spare wheel carrier crossmember and 2 brackets to the vehicle body with the 6 bolts labeled C.

    Torque:
    for bolt C:
    20 N*m{ 204 kgf*cm , 15 ft.*lbf }




  1. Temporarily install the bolt labeled A, and then tighten the bolt labeled A and bolts labeled B.

    Torque:
    for bolt A:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
    for bolt B:
    20 N*m{ 204 kgf*cm , 15 ft.*lbf }



18. INSTALL TAILPIPE ASSEMBLY



  1. Connect the tailpipe to the 2 exhaust pipe supports.

  1. Set a new gasket to the center exhaust pipe.

  1. Connect the tailpipe to the center exhaust pipe with a new clamp.

    HINT:
    Install the clamp within the angle range shown in the illustration.

  1. Tighten the bolt.

    Torque:
    32 N*m{ 326 kgf*cm , 24 ft.*lbf }



19. BLEED AIR FROM FUEL SYSTEM



  1. Using the hand pump indicated by the arrow in the illustration, bleed the fuel system. Continue pumping until pumping becomes difficult.



20. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).

  1. Connect the cables to the negative (-) main battery and sub-battery terminals.



21. INSPECT FOR FUEL LEAK

  1. Perform Active Test.

    1. Connect the intelligent tester to the DLC3.

    2. Turn the engine switch on (IG).

    3. Start the engine.

    4. Turn the intelligent tester ON.

    5. Enter the following menus: Powertrain / Engine / Active Test.

    6. Perform the Active Test.

      Tester Display
      		Test Detail
      		Control Range
      		Diagnostic Note
      Test the Fuel Leak
      		Pressurizes fuel inside common rail and checks for fuel leaks
      		Stop/Start
      1. The fuel inside the common rail is pressurized to the specified value and the engine speed increases to 2000 rpm when Start is selected.
      2. The above conditions are preserved while Start is selected.
