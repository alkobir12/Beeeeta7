INNER REAR VIEW MIRROR > INSTALLATION

for Preparation Click here



1. INSTALL INNER REAR VIEW MIRROR ASSEMBLY (w/ EC Mirror)



  1. Using a T20 "TORX" socket wrench, install the inner rear view mirror with the screw.

    Torque:
    1.5 N*m{ 15 kgf*cm , 13 in.*lbf }

  1. Connect the connector.



2. INSTALL INNER REAR VIEW MIRROR STAY HOLDER COVER (w/ EC Mirror)



  1. Attach the 2 claws to install the cover.



3. INSTALL INNER REAR VIEW MIRROR ASSEMBLY (w/o EC Mirror)



  1. Install the mirror in the direction of the white arrow.

  1. Install the cover with the 2 claws.
