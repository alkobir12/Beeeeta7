DTC    U1002 (CAN No. 2 BUS)    Lost Communication with Gateway Module (Network Gateway ECU)

for Preparation Click here


DESCRIPTION

If 2 or more DTCs are output during the DTC check, one side of the CAN branch wire may be open (One side of the CANH [branch wire]/CANL [branch wire] of the ECU and/or sensor is open).

DTC Code
Symptoms
Trouble Area
U1002 (CAN No. 2 BUS)
Lost communication with the gateway module (network gateway ECU).
  1. Movement control bus circuit
  2. 4WD control ECU branch wire or connector
  3. Yaw rate sensor branch wire or connector
  4. Seat belt control ECU branch wire or connector*1
  5. Clearance warning ECU branch wire or connector*2
  6. Parking assist ECU branch wire or connector*3
  7. Master cylinder solenoid (skid control ECU) branch wire or connector
  8. Steering angle sensor branch wire or connector
  9. Network gateway ECU main wire or connector
  10. Suspension control ECU branch wire or connector*4
  11. Steering control ECU branch wire or connector*5
  12. 4WD control ECU
  13. Yaw rate sensor
  14. Seat belt control ECU*1
  15. Clearance warning ECU*2
  16. Parking assist ECU*3
  17. Master cylinder solenoid (skid control ECU)
  18. Steering angle sensor
  19. Suspension control ECU*4
  20. Steering control ECU*5
  21. Network gateway ECU
  22. No. 4 junction connector
  23. No. 5 junction connector
  24. No. 6 junction connector
  25. No. 7 junction connector
  26. No. 1 CAN junction connector

HINT:
*1: w/ Pre-Crash Safety System
*2: w/ TOYOTA Parking Assist-sensor System
*3: w/ Parking Assist Monitor System
*4: w/ Active Height Control Suspension System
*5: w/ Variable Gear Ratio Steering System

1.DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

  1. Disconnect the cable from the negative (-) battery terminal before measuring the resistances of the main wire and the branch wire.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.

    NOTICE:
    When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
