OIL PUMP > INSTALLATION

for Preparation Click here



1. INSTALL MANUAL TRANSMISSION OIL PUMP COVER O-RING

  1. Install a new oil pump cover O-ring to the oil pump cover.



2. INSTALL OIL PUMP DRIVE ROTOR STRAIGHT PIN



  1. Apply MP grease to the straight pins.

  1. Install the 2 straight pins.



3. INSTALL TRANSMISSION OIL PUMP COVER

  1. Align the oil pump drive rotor groove with the straight pin, and install the oil pump cover to the transfer adapter.

  1. Apply adhesive to 2 or 3 threads of the bolts.

    Adhesive:
    Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent




  1. Install the oil pump cover with the 5 bolts.

    Torque:
    17 N*m{ 170 kgf*cm , 12 ft.*lbf }



4. INSTALL TRANSFER ASSEMBLY

  1. Install the transfer assembly (Click here).



5. INSTALL MANUAL TRANSMISSION ASSEMBLY

  1. Install the manual transmission assembly (Click here).
