1. INSTALL MANUAL TRANSMISSION OIL PUMP COVER O-RING

  1. Install a new O-ring to the oil pump relief valve seat.



2. INSTALL OIL PUMP RELIEF VALVE SEAT



  1. Coat the oil pump relief valve seat with gear oil.

  1. Install the relief valve seat into the oil pump cover.



3. INSTALL TRANSMISSION OIL PUMP COVER BALL



  1. Install the ball into the oil pump cover.



4. INSTALL TRANSMISSION OIL PUMP COVER COMPRESSION SPRING



  1. Install the compression spring into the oil pump cover.



5. INSTALL NO. 1 MANUAL TRANSMISSION OIL PUMP COVER PLUG



  1. Using a hexagon wrench, install the oil pump cover plug.

    Torque:
    18 N*m{ 185 kgf*cm , 13 ft.*lbf }



6. INSTALL MANUAL TRANSMISSION OIL PUMP DRIVEN ROTOR



  1. Coat the oil pump driven rotor with gear oil.

  1. Install the oil pump driven rotor into the oil pump cover.



7. INSTALL MANUAL TRANSMISSION OIL PUMP DRIVE ROTOR



  1. Coat the oil pump drive rotor with gear oil.

  1. Install the oil pump drive rotor into the oil pump cover.



8. INSTALL TRANSMISSION OIL PUMP COVER OIL SEAL



  1. Using SST and a hammer, tap a new oil seal into the oil pump cover in accordance with the dimension specified in the illustration.

    SST
    09950-70010   (09951-07150)
    09950-60010   (09951-00640)

    Dimension A:
    35.3 to 35.9 mm (1.39 to 1.41 in.)
