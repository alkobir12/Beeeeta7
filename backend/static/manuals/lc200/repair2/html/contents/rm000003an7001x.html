STABILIZER CONTROL VALVE (w/ KDSS) > REASSEMBLY

for Preparation Click here



1. INSTALL STABILIZER CONTROL ADAPTER SHUTTER VALVE (for Lower Chamber Side)



  1. Apply a small amount of suspension fluid to a new O-ring and install it to the shutter valve.

  1. Install the shutter valve to the adapter housing.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



2. INSTALL STABILIZER CONTROL ADAPTER SHUTTER VALVE (for Upper Chamber Side)

HINT:
Use the same procedures described for the lower chamber side.



3. INSTALL OIL NOZZLE VALVE SUB-ASSEMBLY (for Lower Chamber Side)

  1. Before installing the oil nozzle valve, apply suspension fluid to the oil nozzle valve O-ring.




  1. Install the oil nozzle valve to the adapter housing.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



4. INSTALL OIL NOZZLE VALVE SUB-ASSEMBLY (for Upper Chamber Side)

HINT:
Use the same procedures described for the lower chamber side.



5. INSTALL SERVICE VALVE CAP (for Lower Chamber Side)



  1. Install the valve cap to the oil nozzle valve.

    Torque:
    0.6 N*m{ 6.0 kgf*cm , 5.0 in.*lbf }



6. INSTALL SERVICE VALVE CAP (for Upper Chamber Side)

HINT:
Use the same procedures described for the lower chamber side.
