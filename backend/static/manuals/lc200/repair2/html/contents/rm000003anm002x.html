DTC    P0503    Vehicle Speed Sensor "A" Intermittent / Erratic / High

for Preparation Click here


DESCRIPTION

If a malfunction (a rapid change in vehicle speed) in the vehicle speed signal being output from the master cylinder solenoid (skid control ECU) is detected while the cruise control is in operation, the ECM determines there to be a momentary interruption and noise, and outputs a DTC.

DTC Code
DTC Detection Condition
Trouble Area
P0503
A momentary interruption and noise are detected when a rapid change of the vehicle speed occurs while the cruise control is in operation.
  1. Vehicle speed sensor
  2. Vehicle speed sensor signal circuit
  3. ECM
  4. Combination meter

INSPECTION PROCEDURE

This DTC code may be output under the vehicle stability control system at the same time. In that case, perform troubleshooting for the vehicle stability control system first.
1.CHECK DTC (VEHICLE STABILITY CONTROL SYSTEM OR ANTI-LOCK BRAKE SYSTEM)

  1. Using the intelligent tester, enter the following menus: Chassis / ABS/VSC/TRAC / Trouble Code.

2.CHECK DTC (CRUISE CONTROL SYSTEM)

  1. Using the intelligent tester, enter the following menus: Powertrain / Cruise Control / Trouble Code.

  1. Clear the DTC (Click here).

  1. Perform the following to make sure the DTC detection conditions are met.

    HINT:
    If the detection conditions are not met, the system cannot detect the malfunction.

    1. Drive the vehicle at a speed of 45 km/h (28 mph) or more.

    2. Turn the cruise control main switch on.

    3. Push the -SET switch to activate the cruise control.
