REAR DIFFERENTIAL LOCK POSITION SWITCH (w/ Differential Lock) > INSTALLATION

for Preparation Click here



1. INSTALL NO. 1 TRANSFER INDICATOR SWITCH


  1. Using a SST, install a new gasket and the indicator switch.

    SST
    09922-10010  



    Torque:
    without SST:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }
    with SST:
    28 N*m{ 283 kgf*cm , 20 ft.*lbf }

    NOTICE:
    1. Rotate SST in the direction shown in the illustration.
    2. Use a torque wrench with a fulcrum length of 300 mm (11.8 in.).

  1. Connect the connector.



2. INSTALL REAR DIFFERENTIAL LOCK ACTUATOR PROTECTOR



  1. Install the protector with the 2 nuts.

    Torque:
    35 N*m{ 357 kgf*cm , 26 ft.*lbf }



3. INSTALL DIFFERENTIAL PROTECTOR ASSEMBLY



  1. Attach the protector with the bolt and nut.

    Torque:
    15 N*m{ 150 kgf*cm , 11 ft.*lbf }

  1. Connect the 2 connector clamps and wire harness clamp.

    NOTICE:
    Make sure the wire harness of the No. 4 transfer indicator switch fits inside the protector.
