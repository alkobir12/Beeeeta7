PILLAR SPEAKER (for Front Side) > INSTALLATION

for Preparation Click here



1. INSTALL FRONT NO. 3 SPEAKER ASSEMBLY



  1. Attach the 3 claws to install the speaker.



2. INSTALL FRONT PILLAR GARNISH LH



  1. for 9 Speakers:
    Connect the speaker connector.

  1. Attach the clip and 3 guides to install the front pillar garnish.



3. INSTALL ASSIST GRIP SUB-ASSEMBLY



HINT:
Use the same procedure to install the front assist grip on the other side.

  1. Attach the 2 claws to install the front assist grip.

  1. Install the 2 bolts.




  1. Attach the 4 claws to install the 2 assist grip plugs.



4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
