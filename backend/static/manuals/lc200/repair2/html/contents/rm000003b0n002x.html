EXHAUST PIPE > INSTALLATION

for Preparation Click here


CAUTION:
  1. Wear protective gloves and protective glasses when installing the exhaust pipe.
  2. The exhaust pipe is extremely hot immediately after the engine has stopped.
  3. Confirm that the exhaust pipe has cooled down before removing it.



1. INSTALL OUTLET TURBINE ELBOW LH (w/o EGR System)



  1. Set a new gasket to the turbocharger.

  1. Temporarily install the outlet turbine elbow LH with 3 new nuts.

  1. Temporarily install the manifold stay LH with the 3 bolts.

  1. Tighten the 3 nuts of the outlet turbine elbow LH.

    Torque:
    47 N*m{ 479 kgf*cm , 35 ft.*lbf }

  1. Tighten the 3 bolts of the manifold stay LH.

    Torque:
    43 N*m{ 438 kgf*cm , 32 ft.*lbf }

5. INSTALL FRONT NO. 2 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 2 exhaust pipe to the monolithic converter/outlet turbine elbow with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }



6. INSTALL FRONT NO. 1 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 1 exhaust pipe to the converter/outlet turbine elbow with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }



7. INSTALL CENTER EXHAUST PIPE ASSEMBLY



  1. Check the free length.

    1. Using a vernier caliper, measure the free length of the compression spring.

      Free length:
      43 mm (1.69 in.)

      If the free length is less that the minimum, replace the compression spring.

  1. Connect the center exhaust pipe to the 3 exhaust pipe supports.

  1. Set 2 new gaskets to the front No. 1 and No. 2 exhaust pipes.

  1. Install the center exhaust pipe with the 4 bolts and 2 compression springs.

    Torque:
    for center exhaust pipe and front No. 1 exhaust pipe:
    49 N*m{ 496 kgf*cm , 36 ft.*lbf }
    for center exhaust pipe and front No. 2 exhaust pipe:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }



8. INSTALL TAILPIPE ASSEMBLY



  1. Connect the tailpipe to the 2 exhaust pipe supports.

  1. Set a new gasket to the center exhaust pipe.

  1. Connect the tailpipe to the center exhaust pipe with a new clamp.

    HINT:
    Install the clamp within the angle range shown in the illustration.

  1. Tighten the bolt.

    Torque:
    32 N*m{ 326 kgf*cm , 24 ft.*lbf }



9. INSPECT FOR EXHAUST GAS LEAK

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



11. INSTALL FRONT FENDER APRON SEAL REAR LH



  1. Install the fender apron seal with the 4 clips.



12. INSTALL FRONT FENDER APRON SEAL REAR RH



  1. Install the fender apron seal with the 4 clips.
