DTC    B2071    Stop Light Control Relay Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when a malfunction in the stop light operation relay circuit of the vehicle stability control system is detected. This circuit consists of the master cylinder solenoid (skid control ECU) and seat belt control ECU. Signals are sent from the master cylinder solenoid (skid control ECU) via the CAN communication line.

DTC Code
DTC Detection Condition
Trouble Area
B2071
Malfunction in the brake system is detected.
  1. CAN communication system
  2. Vehicle stability control system
  3. Seat belt control ECU
