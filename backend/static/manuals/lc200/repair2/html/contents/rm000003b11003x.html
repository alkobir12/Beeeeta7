DTC    U0122    Lost Communication with Vehicle Stability Control Module

DTC    U0151    Lost Communication with Airbag ECU

for Preparation Click here


DESCRIPTION

The seat belt control ECU receives signals from the master cylinder solenoid (skid control ECU) and the center airbag sensor via the CAN communication line.

DTC Code
DTC Detection Item
Inspection Area
U0122
Skid control ECU communication error.
  1. CAN communication system
  2. Master cylinder solenoid (skid control ECU)
  3. Seat belt control ECU
U0151
Center airbag sensor communication error.
  1. CAN communication system
  2. Seat belt control ECU
  3. Center airbag sensor
