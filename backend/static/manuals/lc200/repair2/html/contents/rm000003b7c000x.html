1. INSTALL HEADLIGHT LEVELING MOTOR LH



  1. Insert the headlight leveling motor LH in the direction indicated by the arrow (1) in the illustration.

  1. Turn the aiming screw in the direction indicated by the arrow (2) in the illustration to connect the shaft.

  1. Turn the headlight leveling motor LH in the direction indicated by the arrow (3) in the illustration to install it.



2. INSTALL DISCHARGE HEADLIGHT BULB



  1. Lock the set spring as shown in the illustration to install the discharge headlight bulb.

    NOTICE:
    Do not touch the glass part of the bulb.




  1. Turn the headlight control ECU socket in the direction indicated by the arrow to connect the socket.




  1. Turn the back cover in the direction indicated by the arrow to install it.



3. INSTALL CLEARANCE LIGHT BULB



  1. Turn the bulb in the direction indicated by the arrow to install it.



4. INSTALL FRONT TURN SIGNAL LIGHT BULB



  1. Turn the bulb in the direction indicated by the arrow to install it.



5. INSTALL NO. 1 HEADLIGHT BULB



  1. Turn the bulb in the direction indicated by the arrow to install it.
