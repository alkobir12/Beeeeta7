CURTAIN SHIELD AIRBAG ASSEMBLY > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL CURTAIN SHIELD AIRBAG ASSEMBLY (w/ Rear No. 2 Seat)



  1. Install the curtain shield airbag with the 13 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

    NOTICE:
    Do not twist the curtain shield airbag when installing it.




  1. After installing the bolts, put the curtain shield airbag onto the bracket and close the dual lock fastener.

  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.



2. INSTALL CURTAIN SHIELD AIRBAG ASSEMBLY (w/o Rear No. 2 Seat)


  1. Install the curtain shield airbag with the 10 bolts.



    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

    NOTICE:
    Do not twist the curtain shield airbag when installing it.

  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.



3. INSTALL ROOF HEADLINING ASSEMBLY (w/ Sliding Roof)

  1. Install the roof headlining (Click here).



4. INSTALL ROOF HEADLINING ASSEMBLY (w/o Sliding Roof)

  1. Install the roof headlining (Click here).



5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:

6. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
