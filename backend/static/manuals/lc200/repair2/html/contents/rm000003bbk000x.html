DTC    C1791    Absorber Control Switch Circuit (Test Mode DTC)

for Preparation Click here


DESCRIPTION

This circuit is used for sending the signal to the suspension control ECU to switch to the damping mode selected by the damping force control switch.

DTC Code
Detection Condition
Trouble Area
C1791
The test mode procedure is performed.
  1. Harness or connector
  2. Suspension control switch (Damping forcer control switch)
  3. Suspension control ECU
