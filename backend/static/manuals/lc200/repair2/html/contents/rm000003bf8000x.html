OIL MAINTENANCE INFORMATION MODE RESET OPERATION (for 1VD-FTV, w/ Multi-information Display)

NOTICE:
  1. When "Oil Maintenance Reqd" or "Oil Maintenance Reqd Soon" is displayed, change the engine oil and perform this procedure.
  2. After the engine oil is changed, perform this procedure so that "Oil Maintenance Reqd" or "Oil Maintenance Reqd Soon" does not display.

HINT:
  1. The oil change maintenance system displays "Oil Maintenance Reqd" or "Oil Maintenance Reqd Soon" in the multi-information display to inform the driver that it is time to change the oil based on the distance driven
  2. The ODO/TRIP switch is in the light control rheostat.

  1. Turn the engine switch on (IG), and use the ODO/TRIP switch to change the screen display to TRIP A.

  2. Turn the engine switch off.

  3. While holding in the ODO/TRIP switch, turn the engine switch on (IG).




  4. After a 5 second count, reset will end

    NOTICE:
    1. If the engine switch is turned off during the reset operation, reset mode will be canceled.
    2. If the ODO/TRIP switch is turned off during the reset operation, reset mode will be canceled.

TIMING BELT INFORMATION MODE RESET OPERATION (w/ Multi-information Display, for 2UZ-FE, for China, for General Countries, for Middle East)

NOTICE:
  1. When "T-BELT Maintenance Reqd" is displayed, replace the timing belt and perform this procedure.
  2. After the timing belt is replaced, perform this procedure so that "T-BELT Maintenance Reqd" does not display.

HINT:
  1. The timing belt maintenance system displays "Maintenance Reqd" in the multi-information display to inform the driver that it is time to replace the timing belt based on the distance driven.
  2. The ODO/TRIP switch is in the light control rheostat.

  1. Turn the engine switch on (IG), and use the ODO/TRIP switch to change the screen display to TRIP B.

  2. Turn the engine switch off.




  3. While holding in the ODO/TRIP switch, turn the engine switch on (IG).

    HINT:
    "T-Belt Maintenance Reset" will be displayed.




  4. Press and hold the ODO/TRIP switch for 5 seconds or more.

    HINT:
    A 5 second count will begin on the display.




  5. After the 5 second count finishes, "T-Belt Maintenance Reset OK" is displayed and T-BELT reset mode is complete.

  6. While "T-Belt Maintenance Reset OK" is displayed, turn the ODO/TRIP switch from off to on.

    HINT:
    While "T-Belt Maintenance Reset OK" is displayed, if the ODO/TRIP switch is not turned from off to on, the normal display will return.

  7. After the ODO/TRIP switch is turned on, enter the setting mode and change to T-BELT display mode.

    HINT:
    The T-BELT display mode will display the previously set value (the interval until the next time the timing belt needs to be replaced). However, the first time this is performed, the default setting from when the vehicle is delivered (150,000 km or 90,000 miles) is displayed.



  8. Change the set value by repeatedly turning the ODO/TRIP switch on and off (the value must be changed within 5 seconds). (procedure A)



    HINT:
    Perform this procedure only when changing the previously set value.

    NOTICE:
    If the ODO/TRIP switch is not turned from on to off for 30 seconds or more during this step, the previously set value will be maintained and the TRIP B display will return (reset will not complete).

  9. When the display changes to the desired setting, press the ODO/TRIP switch for 5 seconds or more to finish setting mode. (procedure B)




  10. The set value is stored in the EEPROM, "T-Belt Maintenance Reset COMPLETE" is displayed (for 1 second), the buzzer (multi-display warning) sounds simultaneously, and reset mode is completed. (procedure C)

    HINT:

    If the set value is not stored in the EEPROM, "T-Belt Maintenance Reset UNFINISHED" is displayed for 6 seconds, and the normal display returns.

    NOTICE:
    1. When not changing the previously set value, do not perform the operations in procedure A above, only perform procedures B and C.
    2. If the starter signal is received during the reset operation, reset mode is canceled and cannot be resumed until the engine switch is turned off and on (IG) again.


TIMING BELT INFORMATION MODE RESET OPERATION (w/o Multi-information Display, for 2UZ-FE, for China, for Middle East)

NOTICE:
  1. When the T-BELT indicator light is illuminated, replace the timing belt and perform this procedure.
  2. After the timing belt is replaced, perform this procedure so that the T-BELT indicator light does not turn on.

HINT:
  1. The timing belt maintenance system turns on the T-BELT indicator light to inform the driver that it is time to replace the timing belt based on the distance driven.
  2. The TRIP meter reset knob is on the bottom right side of the combination meter.




  1. Turn the engine switch on (IG), and use the TRIP meter reset knob to change the screen display to TRIP A.

  2. Turn the engine switch off.

  3. While holding in the TRIP meter reset knob, turn the engine switch on (IG).

  4. Press and hold the TRIP meter reset knob (on) for 5 seconds or more.

    HINT:
    If the TRIP meter reset knob is released (off is detected) within 5 seconds, the ODO/TRIP display, indicator display, and the integrated value will return to the state before the reset operation began.

  5. After the TRIP meter reset knob is turned off, turn the TRIP meter reset knob on again within 5 seconds.

  6. After the TRIP meter reset knob is turned on, enter the setting mode and change to T-BELT display mode.



  7. Change the set value in increments by turning the TRIP meter reset knob (the value must be changed within 5 seconds). (procedure A)



    HINT:
    Perform this procedure only when changing the previously set value.

    NOTICE:
    If the TRIP meter reset knob is not turned from on to off for 30 seconds or more during this step, the previously set value will be maintained and the TRIP B display will return (reset will not complete).

  8. When the display changes to the desired setting, press the TRIP meter reset knob for 5 seconds or more to finish setting mode. (procedure B)

  9. The ODO display area changes to the TRIP B display, the warning indicator turns off simultaneously and reset mode is completed. (procedure C)

    NOTICE:
    When not changing the previously set value, do not perform the operations in procedure A above, only perform procedures B and C.
