DTC    B1501    Sub Fuel Sender Open Detected

for Preparation Click here


DESCRIPTION

HINT:
Trouble code B1501 is only output for double tank equipped vehicles

This DTC is stored when the combination meter detects a fuel sender gauge malfunction via the CAN.

DTC Code
DTC Detection Condition
Trouble Area
B1501
When the combination meter detects a fuel sender gauge malfunction.
  1. Harness or connector
  2. Combination meter assembly
  3. Fuel sender gauge assembly
