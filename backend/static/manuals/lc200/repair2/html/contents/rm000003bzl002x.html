REAR STABILIZER BAR (w/ KDSS) > INSTALLATION

for Preparation Click here



1. INSTALL REAR SUSPENSION CONTROL BLEEDER PLUG



  1. Install the 2 suspension control bleeder plugs to the rear stabilizer control cylinder.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



2. INSTALL REAR STABILIZER LINK ASSEMBLY



  1. Install the rear stabilizer link with the bolt and nut.

    Torque:
    208 N*m{ 2121 kgf*cm , 153 ft.*lbf }

    NOTICE:
    Make sure the bolt is facing the correct direction.



3. INSTALL REAR NO. 2 STABILIZER LINK



  1. Install the No. 2 rear stabilizer link with the 2 bolts and 2 nuts.

    Torque:
    97 N*m{ 989 kgf*cm , 72 ft.*lbf }

    NOTICE:
    Make sure the bolts are facing the correct direction.



4. TEMPORARILY INSTALL REAR STABILIZER CONTROL CYLINDER

  1. Temporarily install the rear stabilizer control cylinder to the frame with the bolt.




  1. Install the rear stabilizer control tube and 2 new gaskets to the rear stabilizer control cylinder with the 2 union bolts.

    Torque:
    69 N*m{ 704 kgf*cm , 51 ft.*lbf }

  1. Install the bolt.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



5. INSTALL STABILIZER LINK SUB-ASSEMBLY



  1. Install the stabilizer link to the stabilizer bar with the bolt and nut.

    Torque:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }

    NOTICE:
    Make sure the bolt is facing the correct direction.




  1. Make sure that all parts are facing as shown in the illustration and install the stabilizer end bracket, retainers and cushions with a new nut.

    Torque:
    30 N*m{ 306 kgf*cm , 22 ft.*lbf }



6. INSTALL REAR STABILIZER BAR SUB-ASSEMBLY



  1. Install the 2 bushes to the outer side of the bush stoppers on the rear stabilizer bar as shown in the illustration.

    NOTICE:
    Install the stabilizer bush so that the bump is on the inner side of the vehicle.




  1. Install the 2 stabilizer bar brackets with the 4 bolts.

    Torque:
    58 N*m{ 591 kgf*cm , 43 ft.*lbf }

    NOTICE:
    1. Install the stabilizer bar bracket so that the protrusion is on the lower side.
    2. Tighten the bolts in 4 steps, in the order shown in the illustration.




  1. Install the stabilizer end bracket with the 2 bolts.

    Torque:
    30 N*m{ 306 kgf*cm , 22 ft.*lbf }




  1. Install the stabilizer link assembly to the ball joint dust cover protector.




  1. Install the stabilizer bar to the stabilizer link with the nut.

    Torque:
    100 N*m{ 1020 kgf*cm , 74 ft.*lbf }

    HINT:
    1. If the ball joint turns together with the nut, use a 6 mm hexagon wrench to hold the stud bolt.
    2. If the rear stabilizer control cylinder extends and it is difficult to temporarily install the stabilizer link to the stabilizer bar, raise the stabilizer control arm with a jack and temporarily install the stabilizer link.



7. BLEED AIR FROM SUSPENSION FLUID

  1. Bleed air from the suspension fluid (Click here).



8. INSPECT FOR SUSPENSION FLUID LEAK

CAUTION:
Fluid is pumped into the system at a high pressure of approximately 3 MPa (30.6 kgf/cm2, 435 psi). If a fluid leak is discovered, immediately release the pressure and repair the fluid leak.

  1. Perform a driving test.



  1. Check for fluid leakage from the parts and connections.





9. INSTALL EXHAUST CENTER PIPE ASSEMBLY

  1. for 2UZ-FE:
    Install the center exhaust pipe (Click here).

  1. for 1VD-FTV:
    Install the center exhaust pipe (Click here).



10. INSTALL TAILPIPE ASSEMBLY

  1. for 2UZ-FE:
    Install the tailpipe (Click here).

  1. for 1VD-FTV:
    Install the tailpipe (Click here).



11. STABILIZE SUSPENSION

  1. Install the rear wheels.

    Torque:
    for aluminum wheel:
    131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
    for steel wheel:
    209 N*m{ 2131 kgf*cm , 154 ft.*lbf }

  1. Lower the vehicle.

  1. Press down on the vehicle several times to stabilize the suspension.



12. TIGHTEN REAR STABILIZER CONTROL CYLINDER

  1. Tighten the bolt.

    Torque:
    90 N*m{ 918 kgf*cm , 66 ft.*lbf }

    NOTICE:
    Perform this procedure with all 4 wheels on the ground.



13. INSTALL REAR STABILIZER CONTROL TUBE INSULATOR



  1. Install the rear stabilizer control tube insulator with the 2 bolts.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }



14. MEASURE VEHICLE HEIGHT

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Set the tire pressure to the specified value(s) (Click here).

  1. Bounce the vehicle to stabilize the suspension.




  1. Measure the distance from the ground to the top of the bumper and calculate the difference in the vehicle height between left and right. Perform this procedure for both the front and rear wheels.

    Height difference of left and right sides:
    15 mm (0.591 in.) or less

    HINT:
    If not as specified, perform the vehicle tilt calibration.



15. CLOSE STABILIZER CONTROL WITH ACCUMULATOR HOUSING SHUTTER VALVE

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Using a 5 mm hexagon socket wrench, tighten the lower and upper chamber shutter valves of the stabilizer control with accumulator housing.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



16. INSTALL STABILIZER CONTROL VALVE PROTECTOR



  1. Install the valve protector with the 3 bolts.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }

  1. Attach the clamp, and connect the connector to the valve protector.
