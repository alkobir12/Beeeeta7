1. INSTALL RAIN SENSOR TAPE

HINT:
Only perform this procedure when replacing the rain sensor tape.




  1. Apply new rain sensor tape to the rain sensor surface, indicated by the hatched area.

    NOTICE:
    1. Keep the exposed adhesive on the tape free from dust and fingerprints.
    2. Apply the tape exactly according to the specifications below.
    3. When installing a new rain sensor, peel the release paper off from the silicon sheet first.
    4. Be careful not to leave any air bubbles in the rain sensor tape when installing it.

    Specification:
    Area
    		Measurement
    A
    		15 mm (0.591 in.)
    B
    		8 mm (0.315 in.)



2. INSTALL RAIN SENSOR

NOTICE:
  1. Make sure the adhesive between the bracket and windshield glass is normal.
  2. If there is any residue left from the rain sensor tape on the windshield, remove it.
  3. Clean the glass surface with cloth or similar material.
  4. Make sure there are no air bubbles between the rain sensor and windshield.




  1. Securely attach the rain sensor to the bracket.

  1. Push in the stopper.

    NOTICE:
    The stopper can be used a maximum of 5 times.

  1. Connect the connector.



3. INSTALL RAIN SENSOR COVER


  1. Push in the stopper in the direction of the arrow labeled (1) to install the rain sensor cover.



  1. Slide the No. 2 cover in the direction of the arrow labeled (2) to fix it in place.
