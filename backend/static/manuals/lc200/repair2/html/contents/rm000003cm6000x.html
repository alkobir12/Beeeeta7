DOOR CONTROL RELAY (for LHD) > INSTALLATION

for Preparation Click here



1. INSTALL DOUBLE LOCK DOOR CONTROL RELAY ASSEMBLY



  1. Install the double door lock control relay assembly with the screw.



2. INSTALL COWL SIDE JUNCTION BLOCK RH



  1. Install the cowl side junction block RH with the bolt and nut.

  1. Connect the connector.



3. INSTALL LOWER NO. 2 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connector.

  1. Attach the 3 claws to install the finish panel.

  1. Install the 4 bolts.



4. INSTALL INSTRUMENT PANEL BOX DOOR KNOB



  1. Attach the 2 claws to install the knob.



5. INSTALL NO. 3 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 6 claws to install the panel garnish.



6. INSTALL LOWER INSTRUMENT PANEL (w/o Passenger Side Knee Airbag)



  1. Attach the 4 claws to install the instrument panel.

  1. Install the 2 bolts.



7. INSTALL FRONT PASSENGER SIDE KNEE AIRBAG ASSEMBLY (w/ Passenger Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Attach the 4 claws to install the front passenger side knee airbag.

  1. Install the 4 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



8. INSTALL NO. 2 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Attach the 4 claws to install the under cover.



9. INSTALL FRONT DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.



10. INSTALL INSTRUMENT SIDE PANEL RH (w/ Airbag Cut Off Switch)



  1. Connect the connector.

  1. Attach the 6 claws to install the side panel.



11. INSTALL INSTRUMENT SIDE PANEL RH (w/o Airbag Cut Off Switch)



  1. Attach the 6 claws to install the side panel.



12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



13. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
