FRONT ACCELERATION SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL ACCELERATION SENSOR (for Driver Side)



  1. Install the sensor with the bolt.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Connect the connector.



2. INSTALL ACCELERATION SENSOR (for Front Passenger Side)



  1. Install the sensor with the bolt.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Connect the connector.



3. INSTALL STEERING CONTROL ECU WITH JUNCTION BLOCK (for LHD)



  1. Vehicle front side:

    1. Connect the 5 connectors.

  1. Vehicle rear side:

    1. Install the steering control ECU with junction block to the vehicle with the 2 bolts and nut .

      Torque:
      8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

    2. Attach the 2 clamps.

    3. Connect the 7 connectors.



4. INSTALL STEERING CONTROL ECU WITH JUNCTION BLOCK (for RHD)



  1. Vehicle front side:

    1. Connect the 3 connectors.

  1. Vehicle rear side:

    1. Install the steering control ECU with junction block to the vehicle with the bolt and 2 nuts.

      Torque:
      8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

    2. Connect the 2 connectors.



5. INSTALL LOWER NO. 2 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connector.

  1. Attach the 3 claws to install the finish panel.

  1. Install the 4 bolts.
