FRONT STABILIZER BAR (w/o KDSS) > INSTALLATION

for Preparation Click here



1. INSTALL NO. 1 FRONT STABILIZER BAR BUSH



  1. Install the 2 bushes to the outer side of the bush stoppers on the front stabilizer bar as shown in the illustration.

    NOTICE:
    Be sure to install the front No. 1 stabilizer bar bushes so that the cut and bump of each bush faces the under of the vehicle.



2. INSTALL FRONT STABILIZER BAR



  1. Set the stabilizer bracket so that the arrow mark is facing the front side of the vehicle.




  1. Temporarily install the 2 stabilizer brackets and front stabilizer bar with the 4 bolts.



3. TEMPORARILY INSTALL FRONT STABILIZER LINK ASSEMBLY LH

  1. Temporarily install the stabilizer link with the nut and bolt.




  1. Tighten the nut.

    Torque:
    128 N*m{ 1305 kgf*cm , 94 ft.*lbf }



4. TEMPORARILY INSTALL FRONT STABILIZER LINK ASSEMBLY RH



  1. Temporarily install the stabilizer link with the nut and bolt.

  1. Tighten the nut.

    Torque:
    128 N*m{ 1305 kgf*cm , 94 ft.*lbf }



5. TIGHTEN NO. 1 FRONT STABILIZER BRACKET LH



  1. Tighten the 2 bolts.

    Torque:
    87 N*m{ 887 kgf*cm , 64 ft.*lbf }

    NOTICE:
    Tighten the bolts in 3 steps, in the order shown in the illustration.



6. TIGHTEN NO. 1 FRONT STABILIZER BRACKET RH



  1. Tighten the 2 bolts.

    Torque:
    87 N*m{ 887 kgf*cm , 64 ft.*lbf }

    NOTICE:
    Tighten the bolts in 3 steps, in the order shown in the illustration.



7. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY



  1. Install the No. 1 engine under cover with the 10 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



8. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



9. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



10. STABILIZE SUSPENSION

  1. Install the front wheels.

    Torque:
    for aluminum wheel:
    131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
    for steel wheel:
    209 N*m{ 2131 kgf*cm , 154 ft.*lbf }

  1. Lower the vehicle.

  1. Press down on the vehicle several times to stabilize the suspension.



11. TIGHTEN FRONT STABILIZER LINK ASSEMBLY LH



  1. Tighten the bolt.

    Torque:
    135 N*m{ 1376 kgf*cm , 100 ft.*lbf }

    NOTICE:
    Perform this procedure with all 4 wheels on the ground.



12. TIGHTEN FRONT STABILIZER LINK ASSEMBLY RH



  1. Tighten the bolt.

    Torque:
    135 N*m{ 1376 kgf*cm , 100 ft.*lbf }

    NOTICE:
    Perform this procedure with all 4 wheels on the ground.
