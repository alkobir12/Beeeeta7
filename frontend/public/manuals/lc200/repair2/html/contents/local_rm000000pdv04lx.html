DTC    P0016    Crankshaft Position - Camshaft Position Correlation (Bank 1 Sensor A)


DESCRIPTION

MONITOR DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK ANY OTHER DTCS OUTPUT (IN ADDITION TO DTC P0016 OR P0018)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (OPERATE OCV)

CHECK VALVE TIMING

INSPECT CAMSHAFT OIL CONTROL VALVE

REPLACE CAMSHAFT TIMING TUBE ASSEMBLY

CONFIRM WHETHER DTC OUTPUT RECURS
