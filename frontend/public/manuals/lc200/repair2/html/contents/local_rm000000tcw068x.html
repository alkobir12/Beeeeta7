DTC    P0335    Crankshaft Position Sensor "A" Circuit


DESCRIPTION

MONITOR DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (ENGINE SPD)

INSPECT CRANK POSITION SENSOR (RESISTANCE)

CHECK HARNESS AND CONNECTOR (CRANK POSITION SENSOR - ECM)

CHECK SENSOR INSTALLATION (CRANK POSITION SENSOR)

CHECK CRANKSHAFT POSITION SENSOR PLATE NO. 1 (TEETH OF SENSOR PLATE)

REPLACE CRANKSHAFT POSITION SENSOR

CHECK WHETHER DTC OUTPUT RECURS
