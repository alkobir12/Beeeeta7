ECD SYSTEM > Black Smoke Emitted


INSPECTION PROCEDURE

READ OUTPUT DTC (RELATED TO ENGINE)

READ VALUE USING INTELLIGENT TESTER (INJECTION VOLUME AND INJECTION FEEDBACK VAL #1 TO #8)

PERFORM ENGINE SPEED ACCELERATION

CHECK INTAKE AIR CONTROL SYSTEM AND EXHAUST SYSTEM

INSPECT MASS AIR FLOW METER

CHECK TURBOCHARGING PRESSURE

READ VALUE USING INTELLIGENT TESTER (DATA LIST)

CHECK CYLINDER COMPRESSION PRESSURE

CHECK HARNESS AND CONNECTOR (FUEL INJECTOR - EDU)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (CONTROL THE CYLINDER FUEL CUT)

READ VALUE USING INTELLIGENT TESTER (COOLANT TEMP)

READ VALUE USING INTELLIGENT TESTER (MAP)

READ VALUE USING INTELLIGENT TESTER (ENGINE SPEED)

READ VALUE USING INTELLIGENT TESTER (ACCEL POSITION 1 AND 2)

READ VALUE USING INTELLIGENT TESTER (INTAKE AIR)

READ VALUE USING INTELLIGENT TESTER (FUEL PRESS)

INSPECT ENGINE COOLANT TEMPERATURE SENSOR

CHECK HARNESS AND CONNECTOR (MANIFOLD ABSOLUTE PRESSURE SENSOR - ECM)

INSPECT CRANKSHAFT POSITION SENSOR

CHECK HARNESS AND CONNECTOR (ACCELERATOR PEDAL POSITION SENSOR - ECM)

INSPECT INTAKE AIR TEMPERATURE SENSOR

INSPECT COMMON RAIL (for Bank 1) (FUEL PRESSURE SENSOR)

CHECK HARNESS AND CONNECTOR (FUEL PRESSURE SENSOR - ECM)

REPLACE ECM
