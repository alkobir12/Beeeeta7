POWER WINDOW CONTROL SYSTEM > Driver Side Power Window does not Operate with Power Window Master Switch


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK LIN COMMUNICATION SYSTEM

CHECK FOR DTC (B2312)

READ VALUE USING INTELLIGENT TESTER (POWER WINDOW REGULATOR MOTOR)

CHECK HARNESS AND CONNECTOR (MULTIPLEX NETWORK MASTER SWITCH - BATTERY AND BODY GROUND)

CHECK HARNESS AND CONNECTOR (FRONT POWER WINDOW REGULATOR MOTOR - BATTERY AND BODY GROUND)

CHECK HARNESS AND CONNECTOR (MULTIPLEX NETWORK MASTER SWITCH - FRONT POWER WINDOW REGULATOR MOTOR)

INSPECT FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY LH

INSPECT FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY RH
