POWER WINDOW CONTROL SYSTEM > Front Passenger Side Power Window does not Operate with Front Passenger Side Power Window Switch


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK LIN COMMUNICATION SYSTEM

CHECK FOR DTC (B2312)

READ VALUE USING INTELLIGENT TESTER (FRONT PASSENGER SIDE POWER WINDOW REGULATOR MOTOR)

CHECK HARNESS AND CONNECTOR (POWER WINDOW REGULATOR SWITCH - BODY GROUND)

CHECK HARNESS AND CONNECTOR (FRONT POWER WINDOW REGULATOR MOTOR - BATTERY AND BODY GROUND)

CHECK HARNESS AND CONNECTOR (POWER WINDOW REGULATOR SWITCH - FRONT POWER WINDOW REGULATOR MOTOR)

INSPECT FRONT PASSENGER SIDE POWER WINDOW REGULATOR SWITCH ASSEMBLY
