POWER WINDOW CONTROL SYSTEM > Rear Power Window LH does not Operate with Rear Power Window Switch LH


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK LIN COMMUNICATION SYSTEM

CHECK FOR DTC (B2312)

READ VALUE USING INTELLIGENT TESTER (REAR POWER WINDOW REGULATOR MOTOR LH)

CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR SWITCH LH - BODY GROUND)

CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR MOTOR LH - BATTERY AND BODY GROUND)

CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR SWITCH LH - REAR POWER WINDOW REGULATOR MOTOR LH)

INSPECT REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY LH
