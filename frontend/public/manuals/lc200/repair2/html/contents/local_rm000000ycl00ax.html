FRONT POWER SEAT CONTROL SYSTEM (w/ Seat Position Memory System) > One or more Power Seat Motors do not Operate


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK FRONT POWER SEAT OPERATION

READ VALUE USING INTELLIGENT TESTER (FRONT POWER SEAT SWITCH)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (FRONT POWER SEAT MOTOR)

INSPECT FRONT SEAT ASSEMBLY (FRONT POWER SEAT MOTOR)

CHECK HARNESS AND CONNECTOR (POSITION CONTROL ECU AND SWITCH - POWER SEAT MOTOR)

INSPECT LUMBAR SUPPORT SWITCH

INSPECT LUMBAR SUPPORT ADJUSTER ASSEMBLY

CHECK HARNESS AND CONNECTOR (LUMBAR SUPPORT SWITCH - BATTERY AND BODY GROUND)
