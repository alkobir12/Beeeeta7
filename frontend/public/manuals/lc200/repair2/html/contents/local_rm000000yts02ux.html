DTC    B1653/35    Seat Position Airbag Sensor Circuit Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK VEHICLE CONDITION

CHECK FOR DTC

CHECK CONNECTION OF CONNECTORS

CHECK CONNECTORS

CHECK FLOOR WIRE (CENTER AIRBAG SENSOR - SEAT POSITION SENSOR)

CHECK SEAT POSITION SENSOR (FRONT SEAT INNER BELT LH)

REPLACE SEAT POSITION SENSOR (FRONT SEAT INNER BELT LH)

CHECK CENTER AIRBAG SENSOR

CHECK FOR DTC

CHECK CONNECTION OF CONNECTORS

CHECK CONNECTORS

CHECK NO. 2 FLOOR WIRE (CENTER AIRBAG SENSOR - SEAT POSITION SENSOR)

CHECK SEAT POSITION SENSOR (FRONT SEAT INNER BELT RH)

REPLACE SEAT POSITION SENSOR

CHECK CENTER AIRBAG SENSOR
