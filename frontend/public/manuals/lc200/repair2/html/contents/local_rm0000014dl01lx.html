SEAT BELT WARNING SYSTEM > Front Passenger Side Seat Belt Warning Light Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK FOR DTC

PERFORM ACTIVE TEST USING INTELLIGENT TESTER

CHECK NAVIGATION SYSTEM

INSPECT FUSE (ECU-IG NO. 1)

CHECK HARNESS AND CONNECTOR (MULTI-DISPLAY - COMBINATION METER, BATTERY AND BODY GROUND)

CHECK DISPLAY AND NAVIGATION ASSEMBLY (MULTI-DISPLAY)

INSPECT FUSE (ECU-IG NO. 2)

CHECK HARNESS AND CONNECTOR (CLOCK - COMBINATION METER, BATTERY AND BODY GROUND)

CHECK CLOCK

REPLACE FRONT SEAT INNER BELT ASSEMBLY

CHECK FRONT PASSENGER SIDE SEAT BELT WARNING LIGHT
