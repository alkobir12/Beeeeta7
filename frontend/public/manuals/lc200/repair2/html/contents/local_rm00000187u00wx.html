DTC    P0105    Manifold Absolute Pressure / Barometric Pressure Circuit


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

READ VALUE USING INTELLIGENT TESTER (MANIFOLD ABSOLUTE PRESSURE)

CHECK HARNESS AND CONNECTOR (MANIFOLD ABSOLUTE PRESSURE SENSOR - ECM)

CHECK ECM TERMINAL VOLTAGE (VC TERMINAL)

REPLACE MANIFOLD ABSOLUTE PRESSURE SENSOR

CHECK WHETHER DTC OUTPUT RECURS

REPLACE ECM

REPAIR OR REPLACE HARNESS OR CONNECTOR

CONFIRM WHETHER MALFUNCTION HAS BEEN SUCCESSFULLY REPAIRED
