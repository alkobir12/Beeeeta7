DTC    C1741    Front Height Control Solenoid Valve RH Circuit Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (NO. 1 HEIGHT CONTROL VALVE)

RECONFIRM DTC OUTPUT

CHECK HARNESS AND CONNECTOR (NO. 1 HEIGHT CONTROL VALVE - SUSPENSION CONTROL ECU)

CHECK HARNESS AND CONNECTOR (BODY GROUND BETWEEN ECU - NO. 1 HEIGHT CONTROL VALVE)

INSPECT NO. 1 HEIGHT CONTROL VALVE

CHECK HARNESS AND CONNECTOR (BODY GROUND BETWEEN ECU - FRONT SUSPENSION CONTROL VALVE)

CHECK HARNESS AND CONNECTOR (SUSPENSION CONTROL ECU - FRONT SUSPENSION CONTROL VALVE)
