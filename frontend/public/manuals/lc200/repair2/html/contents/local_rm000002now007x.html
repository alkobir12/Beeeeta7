DTC    P0299    Turbocharger / Supercharger Underboost


DESCRIPTION

INSPECTION PROCEDURE

CHECK ANY OTHER DTCS OUTPUT (IN ADDITION TO DTC P0299)

CHECK INTAKE AND EXHAUST SYSTEM

INSPECT TURBOCHARGER SUB-ASSEMBLY (for Bank 1 or Bank 2)

CHECK CONNECTION OF VACUUM HOSE

READ VALUE USING INTELLIGENT TESTER (MAP)

READ VALUE USING INTELLIGENT TESTER (ACTUAL THROTTLE POSITION)

READ VALUE USING INTELLIGENT TESTER (ACTUAL EGR VALVE POS.)

READ VALUE USING INTELLIGENT TESTER (INJECTION FEEDBACK VAL #1 TO #8)

CONFIRM WHETHER MALFUNCTION HAS BEEN SUCCESSFULLY REPAIRED
