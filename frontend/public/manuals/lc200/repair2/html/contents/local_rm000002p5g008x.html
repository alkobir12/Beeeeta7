DTC    B1655/37    Driver Side Seat Belt Buckle Switch Circuit Malfunction


DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK VEHICLE CONDITION

CHECK FOR DTC

CHECK CONNECTION OF CONNECTORS

CHECK CONNECTORS

CHECK FLOOR WIRE (CENTER AIRBAG SENSOR - FRONT SEAT INNER BELT LH)

CHECK FRONT SEAT INNER BELT LH (SEAT BELT BUCKLE SWITCH)

REPLACE FRONT SEAT INNER BELT LH

CHECK CENTER AIRBAG SENSOR

CHECK FOR DTC

CHECK CONNECTION OF CONNECTORS

CHECK CONNECTORS

CHECK NO. 2 FLOOR WIRE (CENTER AIRBAG SENSOR - FRONT SEAT INNER BELT RH)

CHECK FRONT SEAT INNER BELT RH (SEAT BELT BUCKLE SWITCH)

REPLACE FRONT SEAT INNER BELT RH

CHECK CENTER AIRBAG SENSOR
