POWER MIRROR CONTROL SYSTEM (w/ Retract Mirror) > Power Retractable Mirrors do not Operate with Power Retract Mirror Switch


SYSTEM DESCRIPTION

WIRING DIAGRAM

INSPECTION PROCEDURE

CHECK DTC

READ VALUE USING INTELLIGENT TESTER (MIRROR RETRACT SWITCH)

PERFORM ACTIVE TEST USING INTELLIGENT TESTER (MIRROR RETRACT FUNCTION)

INSPECT OUTER MIRROR SWITCH ASSEMBLY (RETRACTABLE OUTER MIRROR SWITCH)

CHECK HARNESS AND CONNECTOR (OUTER MIRROR SWITCH - MAIN BODY ECU AND BODY GROUND)

INSPECT OUTER REAR VIEW MIRROR ASSEMBLY LH

CHECK HARNESS AND CONNECTOR (OUTER REAR VIEW MIRROR LH - OUTER MIRROR CONTROL ECU)

INSPECT OUTER REAR VIEW MIRROR ASSEMBLY RH

CHECK HARNESS AND CONNECTOR (OUTER REAR VIEW MIRROR RH - OUTER MIRROR CONTROL ECU)
