NAVIGATION SYSTEM > Display does not Dim when Light Control Switch is Turned ON

for Preparation Click here


INSPECTION PROCEDURE

1.CHECK IMAGE QUALITY SETTING



  1. Enter the display adjustment screen by pressing the "DISPLAY" switch.

  1. Turn the light control switch to the TAIL position.

  1. Check if "Day Mode" on the display is ON.

    OK:
    "Day Mode" is ON.



NG
Go to step 2
OK

TURN "DAY MODE" SETTING OFF 

2.CHECK VEHICLE SIGNAL (DISPLAY VEHICLE SIGNAL)



  1. Enter the "Display Check" mode (Vehicle Signal Check) (Click here).

  1. Cover the automatic light control sensor on the instrument panel with a cloth.

  1. Set the instrument panel light control to less than maximum (to activate the dimmer function that works when the light control switch is in the TAIL position).

  1. Check that the display changes between DIM and BRIGHT according to the light control switch operation.

    OK:
    Light Control Switch
    		Display
    TAIL or HEAD
    		DIM
    OFF
    		BRIGHT

    HINT:
    The display is updated once per second. It is normal for the display to lag behind the actual switch operation.



NG
PROCEED TO NEXT CIRCUIT INSPECTION SHOWN IN PROBLEM SYMPTOMS TABLE (Click here)
OK

REPLACE MULTI-DISPLAY (Click here)
