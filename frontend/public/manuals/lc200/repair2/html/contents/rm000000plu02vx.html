DESCRIPTION

The cruise control main switch is used to operate 7 functions: SET, - (COAST), TAP-DOWN, RES (RESUME), + (ACCELERATION), TAP-UP, and CANCEL. The SET, TAP-DOWN and - (COAST) functions, and the RES (RESUME), TAP-UP and + (ACCELERATION) functions are operated with the same switch. The cruise control main switch is an automatic return type switch which turns on only while operating it in each arrow direction and turns off after releasing it. The internal contact point of the cruise control main switch is turned on with the switch operation. Then the ECM reads the resistance value that has been changed by the switch operation to control SET, - (COAST), RES (RESUME), + (ACCELERATION) and CANCEL.
