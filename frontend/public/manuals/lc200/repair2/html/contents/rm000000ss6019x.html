STEERING ANGLE SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL STEERING ANGLE SENSOR



  1. Align the installation holes on the steering sensor with the pins on the spiral cable.

  1. Attach the 6 claws and install the steering sensor to the spiral cable.



2. INSTALL SPIRAL CABLE SUB-ASSEMBLY



  1. Align the pins on the spiral cable with the installation holes on the steering sensor.

  1. Attach the 6 claws and install the spiral cable to the steering sensor.

  1. Check that the front wheels are facing straight ahead.

  1. Set the turn signal switch to the neutral position.

    CAUTION:
    If it is not in the neutral position, the pin of the turn signal switch may be snapped.




  1. Attach the 3 claws to install the spiral cable with steering sensor.

    CAUTION:
    When replacing the spiral cable with a new one, remove the lock pin before installing the steering wheel assembly.

  1. Connect the connectors to the spiral cable with steering sensor.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.



3. INSTALL UPPER STEERING COLUMN COVER



  1. Attach the claw to install the upper steering column cover.

  1. Attach the 4 clips to install the upper steering column cover onto the instrument cluster finish panel.



4. INSTALL LOWER STEERING COLUMN COVER



  1. Attach the 2 claws to install the lower steering column cover.

    NOTICE:
    Do not damage the tilt and telescopic switch.

  1. Install the 3 screws.

    Torque:
    2.0 N*m{ 20 kgf*cm , 18 in.*lbf }



5. ADJUST SPIRAL CABLE

  1. Check that the engine switch is off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.




  1. Rotate the spiral cable with steering sensor counterclockwise slowly by hand until it feels firm.

    CAUTION:
    Do not turn the spiral cable with steering sensor by the airbag wire harness.




  1. Rotate the spiral cable with steering sensor clockwise approximately 2.5 turns to align the marks.

    CAUTION:
    Do not turn the spiral cable with spiral sensor by the airbag wire harness.

    HINT:
    The spiral cable with steering sensor will rotate approximately 2.5 turns to both the left and right from the center.



6. INSTALL STEERING WHEEL ASSEMBLY



  1. Align the matchmarks on the steering wheel assembly and steering main shaft assembly.

  1. Install the steering wheel assembly set nut.

    Torque:
    50 N*m{ 510 kgf*cm , 37 ft.*lbf }



7. INSTALL STEERING PAD

  1. With the steering pad installed on the vehicle, perform a visual check. If there are any defects as mentioned below, replace the steering pad with a new one:
    Cuts, minute cracks or marked discoloration on the steering pad top surface or in the grooved portion.

  1. Make sure that the horn sounds.

    HINT:
    If the horn does not sound, inspect the horn system.



8. INSTALL LOWER NO. 2 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.



9. INSTALL LOWER NO. 3 STEERING WHEEL COVER



  1. Attach the 2 claws to install the cover.



10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
  1. Reset the Autoaway/Return function setting to the previous condition by changing the customize parameter (Click here).
  2. When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



11. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
