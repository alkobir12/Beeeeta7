HINT:
If the following conditions are detected while the cruise control is in operation, the system clears the stored vehicle speed in the ECM and cancels the cruise control operation.

CRUISE main indicator light blinks
  1. There is an open or short in the stop light switch circuit
  2. There is a problem with the vehicle speed signal
Turn the cruise control main switch on again
CRUISE main indicator light goes off
  1. There is a problem with the throttle position sensor and the motor*1
  2. There is a problem with the fuel injection system*2
Turn the cruise control main switch on again
CRUISE main indicator light blinks
  1. There is a problem with the input circuit of the stop light switch circuit
  2. There is a problem with the cancel circuit
  1. Turn the cruise control main switch on again
  2. Turn the engine switch off then on again
CRUISE main indicator light remains on
(Cruise control is canceled)

  2. The VSC system is operated
Push the cruise control main switch to +RES
  1. The vehicle speed is less than the stored speed by approx. 16 km/h (10 mph) or more
