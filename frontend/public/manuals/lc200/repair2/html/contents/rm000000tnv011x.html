FUNCTION OF MAIN COMPONENT

Components
Function
Multiplex network master switch
The door control switch on the master switch locks/unlocks all doors.
Door courtesy light switch
Turns on when the door is open and off when the door is closed. Outputs the door status (open or closed) to the main body ECU.
Driver side door lock
  1. The built-in motor locks/unlocks the door.
  2. The built-in door control switch position (key-linked) detects the door key cylinder status (lock or unlock) and outputs the data to the main body ECU.
  3. The built-in position switch detects the door status (locked or unlocked) and outputs the data to the main body ECU. This switch turns off when the door is locked and on when the door is unlocked.

SYSTEM DESCRIPTION

  1. The power door lock system locks/unlocks all doors.

    1. The door control switch of the master switch uses the LIN line to send lock/unlock request signals to the main body ECU.
    2. The driver door key cylinder lock/unlock request signals are sent to the main body ECU from the driver side door lock.
    3. The main body ECU receives the request signals and locks/unlocks each door.
    The door control system has the following functions:

    Function
    		Outline
    Manual lock and unlock function
    		Locks/unlocks all doors by the door control switch lock operation (manual operation).
    Key-linked lock and unlock function
    		Linked with the door key cylinder.
    Locks/unlocks all doors when the lock/unlock operation is possible.
    Key lock-in prevention function
    		When the door control transmitter is in the vehicle, performing the door lock operation with the lock switch on the outer handle will not lock the door and will sound a buzzer.
    Manual unlock prohibition function
    		When the doors are locked using the transmitter or key with the engine switch on (IG) and the driver side seat belt fastened, unlock operations using the door control switches are prohibited.
    2-step unlock function
    		Unlocks only the driver side door by turning the key cylinder once and unlocks the other doors by turning it twice.

    HINT:
    This function is OFF by default.

    Double locking function
    		Prevents the doors from being unlocked through the operation of the inside door knobs and also from the outside of the vehicle.
