INSTRUMENT PANEL SPEAKER > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL FRONT NO. 2 SPEAKER ASSEMBLY



  1. for 9 Speakers Models:

    1. Connect the connector.

    2. Temporarily install the speaker by aligning the positioning pins of the speaker with the instrument panel.

    3. Install the speaker with the 2 bolts.

      NOTICE:
      1. Do not touch the cone part of the speaker.
      2. When installing the speaker to the instrument panel be careful that the wires do not get caught between the parts.



  1. except 9 Speakers Models:




    1. Connect the connector.

    2. Temporarily install the speaker by aligning the positioning pins of the speaker with the instrument panel.

    3. Install the speaker with the 2 bolts.

      NOTICE:
      1. Do not touch the cone part of the speaker.
      2. When installing the speaker to the instrument panel be careful that the wires do not get caught between the parts.



2. INSTALL NO. 1 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY



  1. Attach the 4 claws to install the panel.



3. INSTALL FRONT PILLAR GARNISH LH



  1. for 9 Speakers:
    Connect the speaker connector.

  1. Attach the clip and 3 guides to install the front pillar garnish.



4. INSTALL ASSIST GRIP SUB-ASSEMBLY



HINT:
Use the same procedure to install the front assist grip on the other side.

  1. Attach the 2 claws to install the front assist grip.

  1. Install the 2 bolts.




  1. Attach the 4 claws to install the 2 assist grip plugs.



5. INSTALL FRONT NO. 4 SPEAKER ASSEMBLY

  1. Connect the speaker connector.

  1. Temporarily install the speaker by aligning the positioning pins of the speaker with the instrument panel.




  1. Install the speaker with the 2 bolts.

    NOTICE:
    1. Do not touch the cone part of the speaker.
    2. When installing the speaker to the instrument panel be careful that the wires do not get caught between the parts.



6. INSTALL NO. 1 SPEAKER OPENING COVER ASSEMBLY



  1. Attach the 8 claws to install the opening cover.



7. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
