NAVIGATION ECU > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL NO. 2 DISC PLAYER BRACKET



  1. Align the protrusions of the bracket, labeled A, with the indentations of the navigation module board.

  1. Install the bracket with the 2 screws labeled B.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



2. INSTALL NO. 1 DISC PLAYER BRACKET



  1. Align the protrusions of the bracket, labeled A, with the indentations of the navigation module board.

  1. Install the bracket with the 2 screws labeled B.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



3. INSTALL NAVIGATION MODULE BOARD WITH DISC PLAYER BRACKET



  1. Connect the navigation module board connectors.

  1. Install the navigation module board with disc player bracket with the nut and 2 screws.

    Torque:
    Nut:
    12 N*m{ 122 kgf*cm , 8 ft.*lbf }

  1. Attach the clamp.



4. INSTALL LOWER NO. 2 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connector.

  1. Attach the 3 claws to install the finish panel.

  1. Install the 4 bolts.



5. INSTALL INSTRUMENT PANEL BOX DOOR KNOB



  1. Attach the 2 claws to install the knob.



6. INSTALL FRONT PASSENGER SIDE KNEE AIRBAG ASSEMBLY (w/ Passenger Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Attach the 4 claws to install the front passenger side knee airbag.

  1. Install the 4 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



7. INSTALL LOWER INSTRUMENT PANEL (w/o Passenger Side Knee Airbag)



  1. Attach the 4 claws to install the instrument panel.

  1. Install the 2 bolts.



8. INSTALL NO. 2 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Attach the 4 claws to install the under cover.



9. INSTALL FRONT DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.



10. INSTALL NO.3 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 6 claws to install the panel garnish.



11. INSTALL INSTRUMENT SIDE PANEL RH (w/ Airbag Cut Off Switch)



  1. Connect the connector.

  1. Attach the 6 claws to install the side panel.



12. INSTALL INSTRUMENT SIDE PANEL RH (w/o Airbag Cut Off Switch)



  1. Attach the 6 claws to install the side panel.



13. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



14. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
