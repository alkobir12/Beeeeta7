DTC    B2271    Ignition Hold Monitor Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when the IG output circuits inside the main body ECU are open or shorted.

DTC Code
Detection Condition
Trouble Area
B2271
The IG1 No. 3 relay actuation circuit or integration relay (IG2 relay) actuation circuit inside the main body ECU is abnormal.
  1. Main body ECU
  1. AM2 fuse
  1. Harness or connector
