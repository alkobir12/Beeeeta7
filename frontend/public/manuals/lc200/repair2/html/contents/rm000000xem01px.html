DTC    B2273    Ignition 2 Monitor Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when a malfunction occurs in the IG2D output circuit, which is between the integration relay (IG2 relay) actuation circuit inside the main body ECU and the integration relay (IG2 relay).

DTC Code
Detection Condition
Trouble Area
B2273
The integration relay (IG2 relay) actuation circuit inside the main body ECU or other related circuit is malfunctioning.
  1. Main body ECU
  2. IG2 MAIN fuse
  3. Integration relay (IG2 relay)
  4. Harness or connector
