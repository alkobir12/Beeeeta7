DTC    B2277    Detecting Vehicle Submersion

for Preparation Click here


DESCRIPTION

This DTC is stored when the submersion circuit monitor inside the main body ECU detects that the vehicle has been submerged in water.

DTC Code
Detection Condition
Trouble Area
B2277
The submersion circuit monitor inside the main body ECU detects that the vehicle is submerged in water.
Main body ECU

INSPECTION PROCEDURE

HINT:
Before commencing troubleshooting, check if the main body ECU is wet. If it is, replace the main body ECU.

1.CHECK WHETHER DTC OUTPUT RECURS

  1. Clear the DTCs (Click here).

  1. Check whether DTC B2277 is output 30 seconds or more after the engine switch is turned on (IG).
