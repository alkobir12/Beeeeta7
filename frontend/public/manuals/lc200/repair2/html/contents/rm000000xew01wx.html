DTC    B2284    Brake Signal Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when there is an inconsistency between the circuit between the main body ECU and stop light switch, and the CAN communication signal between the main body ECU and ECM.

DTC No.
Detection Condition
Trouble Area
B2284
The circuit between the main body ECU and stop light switch, and the CAN communication signal between the main body ECU and ECM are inconsistent.
  1. Main body ECU
  2. Stop light switch
  3. STOP fuse
  4. Harness or connector
