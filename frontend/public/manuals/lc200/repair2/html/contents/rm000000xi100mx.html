POWER WINDOW CONTROL SYSTEM > Rear Power Window LH does not Operate with Rear Power Window Switch LH

for Preparation Click here


DESCRIPTION

  1. If the manual up/down function does not operate, there may be a malfunction in the rear power window regulator switch, power window rear regulator motor LH, harness or connector.

WIRING DIAGRAM




INSPECTION PROCEDURE

1.CHECK LIN COMMUNICATION SYSTEM

  1. Check for LIN communication system DTCs related to the power window control system (Click here).

    OK:
    LIN communication system DTCs are not output.



NG
GO TO LIN COMMUNICATION SYSTEM (Click here)
OK


2.CHECK FOR DTC (B2312)

  1. Check if DTC B2312 is output (Click here).

    OK:
    DTC B2312 is not output.



NG
GO TO DTC B2312 (Click here)
OK


3.READ VALUE USING INTELLIGENT TESTER (REAR POWER WINDOW REGULATOR MOTOR LH)

  1. Use the Data List to check if the power window regulator motor is functioning properly (Click here).

    RL-Door Motor 
    Tester Display

    RL Door P/W Up SW

    OFF: Rear power window LH switch not operated
    		-
    RL Door P/W Down SW
    		Rear power window LH manual down signal / ON or OFF
    		ON: Rear power window LH manual down switch operated
    OFF: Rear power window LH switch not operated
    		-

    The display changes according to operation of the rear power window switch LH.

    Tester Connection

    Tester Connection

    		Specified Condition

6.CHECK HARNESS AND CONNECTOR (REAR POWER WINDOW REGULATOR SWITCH LH - REAR POWER WINDOW REGULATOR MOTOR LH)



  1. Disconnect the J10 switch connector.

  1. Disconnect the J11 motor connector.

  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Condition
    		Specified Condition
    J10-6 (UP) - J11-10 (UP)
    		Always
    		Below 1 Ω
    J10-7 (DOWN) - J11-7 (DOWN)
    		Always
    		Below 1 Ω
    J10-8 (AUTO) - J11-4 (AUTO)
    		Always
    		Below 1 Ω
    J10-6 (UP) or J11-10 (UP) - Body ground
    		Always
    		10 kΩ or higher
    J10-7 (DOWN) or J11-7 (DOWN) - Body ground
    		Always
    		10 kΩ or higher
    J10-8 (AUTO) or J11-4 (AUTO) - Body ground
    		Always
    		10 kΩ or higher



NG
REPAIR OR REPLACE HARNESS OR CONNECTOR
OK


7.INSPECT REAR POWER WINDOW REGULATOR SWITCH ASSEMBLY LH

  1. Remove the rear power window regulator switch (Click here).

  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Switch Condition
    		Specified Condition
    J10-6 (UP) - J10-1 (GND)
    		Manual up operation
    		Below 1 Ω
    J10-7 (DOWN) - J10-1 (GND)
    		Manual down operation
    		Below 1 Ω
