HINT:
The VGRS system stores data when a trouble code is set which can be viewed using the intelligent tester.


FREEZE FRAME DATA OF STEERING CONTROL ECU

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG) and check the freeze frame data by following the prompts on the tester screen.
