ENTRY AND START SYSTEM (for Entry Function) > Rear Door LH Entry Lock and Unlock Functions do not Operate

for Preparation Click here


DESCRIPTION

When the rear door LH entry lock and unlock functions do not operate, one of the following may be malfunctioning: 1) power door lock system, 2) rear door electrical key oscillator LH, or 3) certification ECU (smart key ECU assembly).

HINT:
For vehicles with entry function for rear doors.

3.CHECK WAVE ENVIRONMENT



  1. Bring the electrical key transmitter near the rear door outside handle LH, and perform a rear door LH entry lock and unlock operation check.

    NOTICE:
    If the key is brought within 0.2 m (0.656 ft.) of the door handle, communication is not possible.

    HINT:
    1. When the electrical key transmitter is brought near the rear door outside handle LH, the possibility of wave interference decreases, and it can be determined if wave interference is causing the problem symptom.
    2. If the operation check is normal, the possibility of wave interference is high. Also, added vehicle components may cause wave interference. If installed, remove them and perform the operation check.

    4. Enter the following menus:
      for LHD

      for RHD

    5. When the electrical key transmitter is in the position shown in the illustration, check that the wireless door lock buzzer sounds.

      HINT:
