This system lock/unlocks the doors remotely. The wireless door lock control system has the following features:
  1. The certification ECU (smart key ECU assembly) performs the code identification process and the main body ECU (cowl side junction block LH) controls the door lock. A serial data link is provided for communication between the certification ECU (smart key ECU assembly) and main body ECU (cowl side junction block LH).
  2. A key-integrated type transmitter is used and it contains the following 3 switches: lock switch, unlock switch and panic switch*.

    HINT:
    *: w/ Panic Switch

  3. An LED is mounted on the transmitter to show if the battery is depleted.

FUNCTION OF MAIN COMPONENTS

Component
Function
Door control transmitter
  1. Contains lock, unlock, and panic switches*1.
  2. Transmits weak electric waves (recognition codes and function codes) to door control receiver.
  3. Illuminates indicator light (LED) during transmission.
Door control receiver
Receives weak electric waves (recognition codes and function codes) from door control transmitter via electrical key antenna and changes waves to code data.
Front door courtesy light switch
Rear door courtesy light switch
Back door courtesy light switch
Turns on when door is open and off when door is closed. Outputs door status (open or closed) to main body ECU (cowl side junction block LH).
Door lock position switch
Transmits door lock positions of each door to main body ECU (cowl side junction block LH).
Wireless door lock buzzer*2
Emits beep (answer-back) when doors are locked or unlocked by wireless operation
Certification ECU (smart key ECU assembly)
Matches code data with registered code and outputs code data to main body ECU (cowl side junction block LH).

HINT:
*1: w/ Panic Switch
*2: Except Europe and China


SYSTEM FUNCTION

  1. The wireless door lock control system has the following functions:

    Function
    		Outline
    All door lock function
    		Pressing the lock switch locks all the doors and retracts the outer mirrors.
    All door unlock function
    		Pressing unlock switch unlocks all the doors and returns the outer mirrors.
    2-step unlock function*1
    		Pressing the unlock switch once unlocks only the driver side door and returns the outer mirrors.
    Pressing the unlock switch twice within 3 seconds unlocks all the doors.
    Power window (and sliding roof*2) open function*7
    		After locking all the doors with the door control transmitter operation, pressing the unlock switch for 3 seconds or more opens all the power windows (and the sliding roof*2).
    Power window (and sliding roof*2) close function*7
    		After locking all the doors with the door control transmitter operation, pressing the unlock switch for 3 seconds or more closes all the power windows (and the sliding roof*2).
    Chattering prevention function
    		If a switch is pressed, the corresponding switch operation is performed once. If a switch is held down, the corresponding switch operation occurs only once and does not repeatedly activate. Lastly, when pressing a switch at 1 second intervals, the corresponding operation activates once for every press of the switch.
    Answer-back function
    - Buzzer answer-back*3
    - Hazard answer-back
    1. When the doors are locked, the turn signal lights flash once. When the doors are unlocked, the turn signal lights flash twice and the wireless warning buzzer sounds twice.
    2. When the transmitter is used for opening the power windows and sliding roof, this function causes the buzzer to sound to indicate that the operation begins.
    Automatic lock function
    		If no doors are opened within 30 seconds after they are unlocked by the door control transmitter, all the doors will lock again automatically.
    Panic alarm function*4
    		Holding down the panic switch for more than 1 second sets off the theft deterrent alarm (the horn and security horn sounds, the hazard warning lights, headlights, and taillights flash, and the map light and spot light illuminate).
    Fail-safe function
    		When the key is in the vehicle, the doors cannot be locked by the lock switch.
    Illuminated entry function
    1. Pressing the unlock switch causes dome light (map light and rear map light), illumination and all the door unlock operation to occur simultaneously.
    2. If the doors have not been opened, the dome light (map light and rear map light) turns off in approximately 15 seconds.
    Door ajar warning function*5
    		If any door is open or ajar, pressing the lock switch will cause the wireless door lock buzzer to sound for about 10 seconds.
    Memory call function*6
    		If the unlock switch of a memory call registered transmitter is pressed and the driver door is opened, the following parts move to the memory call position: front seat, front seat belt anchor, steering wheel and outer mirrors.
    Transmitter recognition code registration function
    		Enables 7 modes for registering (writing and storing) transmitter recognition codes in the EEPROM.

    HINT:
    *1: This function can be enabled by changing the customize parameter.
    *2: w/ Sliding Roof System
    *3: Except Europe and China
    *4: w/ Panic Switch
    *5: Except China
    *6: w/ Memory Call Function
    *7: w/ Remote Function
