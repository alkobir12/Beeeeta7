CUSTOMIZING FUNCTION WITH INTELLIGENT TESTER (REFERENCE)

NOTICE:
  1. When the customer requests a change in a function, first make sure that the function can be customized.
  2. Be sure to make a note of the current settings before customizing.
  3. When troubleshooting a function, first make sure that the function is set to the default setting.

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the intelligent tester on.

  4. Enter the following menus: Customize Setting.

  5. Select the setting by referring to the table below.

    Wireless Door Lock 
    Display
    		Default
    		Contents
    		Setting
    Hazard Answer Back
    		ON
    		When the lock switch on the transmitter is pressed, this function illuminates the hazard warning lights once. When the unlock switch is pressed, the hazard warning lights illuminate twice.
    		ON/OFF
    Wireless Control
    		ON
    		Function that turns the wireless door lock function ON or OFF.
    		ON/OFF
    Open Door Warning*1
    		ON
    		If a door is not completely closed and the transmitter lock switch is pressed, this function makes the buzzer sound for 10 seconds.
    		ON/OFF
    Panic Alarm Function*2
    		ON
    		Function to operate the theft deterrent system by continuously pressing the panic switch on transmitter for 2.5 seconds.
    		ON/OFF
    Unlock 2 Operation
    		OFF
    		Function that unlocks the driver side door when the unlock switch on the transmitter is pressed once, and unlocks all doors when the switch is pressed twice. If the setting is OFF, pressing the unlock switch once makes all the doors unlock.
    		ON/OFF
    Auto Lock Time
    		30 s
    		Function to change the time until relocking after unlocking with the wireless door lock function.
    		30 s/60 s/120 s
    Wireless Auto Lock
    		ON
    		Function to control the automatic relocking of doors after unlocking with the wireless door lock function.
    		ON/OFF
    Wireless Buzzer Resp
    		ON*3
    		Wireless buzzer response function.
    		ON/OFF
    Wireless Buzzer Volume
    		Level 7
    		This function changes the wireless buzzer volume.
    		Level 0/Level 1/Level 2/Level 3/Level 4/Level 5/Level6/Level 7

    HINT:
    *1: Except China
    *2: w/ Panic Switch
    *3: Except Europe and China
