CUSTOMIZING FUNCTION WITH TECHSTREAM (REFERENCE)

NOTICE:
  1. When the customer requests a change in a function, first make sure that the function can be customized.
  2. Be sure to make a note of the current settings before customizing.
  3. When troubleshooting a function, first make sure that the function is set to the default setting.

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the intelligent tester on.

  4. Enter the following menus: Customize Setting.

  5. Select the setting by referring to the table below.

    Seat Belt Warning 
    Display
    		Default
    		Contents
    		Setting
    D-Seatbelt Warning Buzzer
    		ON
    		If driver side seat belt is unfastened and the vehicle is driven at approximately 20 km/h (12.5 mph) or more, this system sound the seat belt warning buzzer
    		ON/OFF
    P-Seatbelt Warning Buzzer
    		ON
    		If front passenger side seat belt is unfastened and the vehicle is driven at approximately 20 km/h (12.5 mph) or more, this system sound the seat belt warning buzzer
    		ON/OFF
