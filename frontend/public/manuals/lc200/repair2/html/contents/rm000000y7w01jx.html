DTC    B2276    ACCR Signal Circuit Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when a malfunction is detected in the ACCR signal output by the main body ECU.

DTC Code
Detection Condition
Trouble Area
B2276
The ACCR output circuit inside the main body ECU or other related circuit is malfunctioning.
  1. Main body ECU
  2. ECM
  3. Harness or connector

WIRING DIAGRAM




INSPECTION PROCEDURE

1.CHECK WHETHER DTC OUTPUT RECURS

  1. Clear the DTCs (Click here).

  1. Check whether DTC B2276 is output 50 seconds or more after the engine switch is turned on (IG).
