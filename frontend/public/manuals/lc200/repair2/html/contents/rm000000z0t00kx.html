CUSTOMIZING FUNCTION WITH INTELLIGENT TESTER (REFERENCE) (w/ REMOTE FUNCTION)

NOTICE:
  1. When the customer requests a change in a function, first make sure the function(s) can be customized.
  2. Be sure to make note of the current settings before customizing.
  3. When troubleshooting a function, first make sure that the function is set to the default setting.

  1. Connect the intelligent tester to the DLC3.

  2. Turn the engine switch on (IG).

  3. Turn the intelligent tester on.

  4. Enter the following menus: Utility / Customize Setting / Power Window.

  5. Select the setting by referring to the table below.

    Power Window 
    Display (Item)
    		Default
    		Contents
    		Setting
    Door Key P/W Up
    		ON
    		Function that raises all the power windows when, with the engine switch off, a key is used to hold the driver door key cylinder to the lock position for more than 2.3 sec.
    		ON/OFF
    Door Key P/W Down
    		ON
    		Function that lowers all the power windows when, with the engine switch off, a key is used to hold the driver door key cylinder to the unlock position for more than 2.3 sec.
    		ON/OFF
    P/W Up W/ Transmit
    		ON
    		Function that raise all the power windows when, with the engine switch off, the unlock switch on the transmitter is pressed and held for more than 3.0 sec.
    		ON/OFF
    P/W Down W/ Transmit
    		ON
    		Function that lowers all the power windows when, with the engine switch off, the unlock switch on the transmitter is pressed and held for more than 3.0 sec.
    		ON/OFF
    P/W Up W/ Smart
    		ON
    		Function that raises all the power windows when, with the engine switch off, the entry lock switch on the driver side door outside handle is pressed and held for more than 3.0 sec.
    		ON/OFF
