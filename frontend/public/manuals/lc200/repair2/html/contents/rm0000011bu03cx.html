HINT:
  1. Illustrations may differ from the actual vehicle depending on the device settings and options. Therefore, some detailed areas may not be exactly the same as on the actual vehicle.
  2. If the system cannot enter the diagnostic mode, inspect all AVC-LAN communication components and repair or replace problem parts (Click here).
  3. After the engine switch is turned on (IG), check that the map is displayed before starting the diagnostic mode. Otherwise, some items cannot be checked.


START DIAGNOSTIC MODE

  1. Turn the engine switch on (IG).




  2. Press the "DISP" switch.




  3. From the display quality adjustment screen, touch the corners of the screen in the following order: upper left → lower left → upper left → lower left → upper left → lower left.

  4. The diagnostic mode starts and the "System Check Mode" screen will be displayed. Service inspection starts automatically and the result will be displayed.


FINISH DIAGNOSTIC MODE

  1. Turn the engine switch off.


DIAGNOSIS MENU



  1. Press the "MENU" switch on the "System Check Mode" screen.




  2. The "Diagnosis MENU" screen will be displayed.


CHECK DTC (WITH DIAGNOSTIC MODE)


  1. Read the system check result.




    1. If the check result is "EXCH", "CHEK" or "Old", touch the displayed check result.




    2. View the results on the "Unit Check Mode" screen and record them.




    3. When proceeding to view the results of another device, press the "Service" switch.




    4. Return to the "System Check Mode" screen.

      HINT:
      To check other items, repeat from the first step.



  2. Read the communication diagnostic check result.




    1. Return to the "System Check Mode" screen, and press the "LAN Mon" switch.




    2. The "LAN Monitor" screen is displayed.




    3. If the check result is "CHEK" or "Old", touch the displayed check result.




    4. View the results on the individual communication diagnostic screen and record them.

      HINT:
      1. If all check results are "No Err", the system judges that no DTC is stored.


      2. The sub-code (relevant device) will be indicated by its physical address.


DTC CLEAR/RECHECK (WITH DIAGNOSTIC MENU)



  1. Clear DTC

    1. Press the "Code CLR" switch for 3 seconds.

    2. The check results are cleared.




  2. Recheck

    1. Press the "Recheck" switch.




    2. Confirm that all diagnostic codes are "OK" when the check results are displayed.
      If a code other than "OK" is displayed, troubleshoot again.




    3. Press the "LAN Mon" switch to change to "LAN Monitor" mode.




    4. Confirm that all diagnostic codes are "No Err".
      If a code other than "No Err" is displayed, troubleshoot again.
