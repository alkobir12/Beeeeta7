REAR WIPER MOTOR > INSTALLATION

for Preparation Click here



1. INSTALL REAR WIPER MOTOR ASSEMBLY



  1. Temporarily install the rear wiper motor assembly with the 3 bolts.

  1. Tighten the 3 bolts.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

  1. Connect the connector.



2. INSTALL REAR WIPER MOTOR GROMMET



  1. Install the rear wiper motor grommet with the position mark facing upward as shown in the illustration.



3. INSTALL REAR WIPER ARM

  1. Operate the rear wiper, and stop the rear wiper motor at the automatic stop position.




  1. Clean the wiper pivot serration with a wire brush.




  1. Set the head of the blade on the defogger line.

  1. Install the nut and rear wiper arm.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

  1. Close the cover.



4. INSTALL BACK DOOR GARNISH



  1. Attach the 14 clips to install the back door garnish.



5. INSTALL POWER BACK DOOR MAIN SWITCH (for Parallel Seat Type)



  1. Attach the 2 claws to install the power back door main switch.



6. INSTALL NO. 2 BACK DOOR SERVICE HOLE COVER (for Parallel Seat Type)



  1. Connect the connector.

  1. Attach the 4 claws to install service hole cover.



7. INSTALL ASSIST GRIP (for Parallel Seat Type)



  1. Install the assist grip with the 2 screws.



8. INSTALL BACK DOOR SIDE GARNISH LH



  1. Attach the 3 clips to install the back door side garnish.



9. INSTALL BACK DOOR SIDE GARNISH RH

HINT:
Use the same procedures described for the LH side.



10. INSTALL CENTER BACK DOOR GARNISH



  1. Attach the 5 clips and 2 claws to install the back door garnish.
