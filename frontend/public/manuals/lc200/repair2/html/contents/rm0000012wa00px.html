1.FUEL INJECTOR COMPENSATION CODE

  1. Each fuel injector has different fuel injection characteristics. In order to optimize fuel injection performance, the ECM compensates for these differences by adjusting the fuel injection duration of each fuel injector according to its compensation code. Fuel injector compensation codes are unique, 30 digit, alphanumeric values printed on the head portion of each fuel injector.




  2. When a fuel injector is replaced, the new fuel injector compensation code must be input into the ECM.

  3. When the ECM is changed, all of the existing fuel injector compensation codes must be input into the new ECM.

  4. If an incorrect fuel injector compensation code is input into the ECM, the engine assembly may rattle or engine idling may become rough. In addition, engine failure may occur and the life of the engine may be shortened.


2.FOR USING INTELLIGENT TESTER

CAUTION:
  1. Observe the following items for safety reasons:
    1. Before using the tester, read its instruction manual.
    2. Prevent the tester cable from being caught on the pedals, shift lever or steering wheel when driving with the tester connected to the vehicle.
    3. When driving the vehicle for testing purposes using the tester, two persons are required. One person drives the vehicle, and the other operates the tester.
