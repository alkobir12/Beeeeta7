VALVE BODY ASSEMBLY > INSTALLATION

for Preparation Click here



1. INSTALL TRANSMISSION VALVE BODY ASSEMBLY



  1. Install the spring and check ball body.




  1. Insert the pin of the manual valve into the hole of the manual valve lever.




  1. Install the 19 bolts.

    Torque:
    11 N*m{ 112 kgf*cm , 8 ft.*lbf }

    HINT:
    Each bolt length is indicated below.
    36 mm (1.42 in.) for bolt A
    25 mm (0.984 in.) for bolt B
    45 mm (1.77 in.) for bolt C
    50 mm (1.97 in.) for bolt D

  1. Install the detent spring and detent spring cover with the bolt.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



2. CONNECT TRANSMISSION WIRE



  1. Connect the 9 connectors to the solenoid valves.

  1. Connect the 2 ATF temperature sensors with the 2 clamps and 2 bolts.

    Torque:
    for bolt A:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }
    for bolt B:
    11 N*m{ 112 kgf*cm , 8 ft.*lbf }

    HINT:
    Each bolt length is indicated below.
    12 mm (0.472 in.) for bolt A

    36 mm (1.41 in.) for bolt B



3. INSTALL VALVE BODY OIL STRAINER ASSEMBLY



  1. Coat a new O-ring with ATF and install it to the oil strainer.

  1. Install the oil strainer with the 4 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



4. INSTALL AUTOMATIC TRANSMISSION OIL PAN SUB-ASSEMBLY



  1. Install the 4 transmission oil cleaner magnets to the oil pan.




  1. Install a new gasket and the oil pan with the 12 bolts.

    Torque:
    7.4 N*m{ 75 kgf*cm , 65 in.*lbf }


    NOTICE:

    1. Make sure that there is no oil or foreign matter on the gasket seal surface and oil pan contact surface.
    2. Install the gasket so that there is no slack in the gasket, and make sure the entire circumference of the seal surface is level.
    3. Make sure that the 9 gasket drop prevention protrusions are set on the oil pan.
    4. When tightening the bolts of the oil pan, make sure that the gasket is not pinched between the gasket tightening area sleeve and the transmission seal surface.



5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



6. ADD AUTOMATIC TRANSMISSION FLUID

  1. Add automatic transmission fluid (Click here).



7. INSTALL OIL PAN PROTECTOR ASSEMBLY



  1. Install the oil pan protector with the 4 bolts.

    Torque:
    63 N*m{ 642 kgf*cm , 46 ft.*lbf }



8. INSTALL NO. 2 ENGINE UNDER COVER



  1. Install the under cover with the 6 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
