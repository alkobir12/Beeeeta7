NAVIGATION SYSTEM > The Other Caller cannot Hear Your Voice, or Your Voice is too Quiet or Distorted

for Preparation Click here


INSPECTION PROCEDURE

1.CHECK CELLULAR PHONE

  1. Check if the other side can hear your voice properly.

    OK:
    Your voice can be heard correctly.



NG
REPLACE CELLULAR PHONE
OK


2.CHECK SETTINGS



  1. Check if the mute switch is set to on.

    OK:
    Mute switch is not set to on.



NG
TURN MUTE SWITCH OFF
OK


3.CHECK SETTINGS



  1. Enter the "Handsfree Voice Quality Set" mode (Click here).

  1. Check if the Send Voice Level is set to "0".

    HINT:
    The Send Voice Level can be set to 11 different levels, -5 to +5, with a 3 dB difference.

  1. Check if the Send Voice Level is set to the minimum or maximum level.

    HINT:
    When the Send Voice Level is set to the minimum or maximum level, the sound may be distorted.

    OK:
    The Send Voice Level is set to "0".



NG
SET SEND VOICE LEVEL TO "0"
OK


4.CHECK MICROPHONE (DISPLAY CHECK MODE)



  1. Enter the "Mic & Voice Recognition Check" mode (Click here).

  1. When a voice is input into the microphone, check that the microphone input level meter changes according to the input voice.

    OK:
    All check results are normal.



NG
GO TO "MICROPHONE CIRCUIT BETWEEN OVERHEAD J/B AND MULTI-DISPLAY" (Click here)
OK

REPLACE MULTI-DISPLAY (Click here)
