STEERING KNUCKLE > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL STEERING KNUCKLE OIL SEAL LH



  1. Using SST and a press, press in a new oil seal.

    SST
    09950-60020   (09951-01030)
    09950-70010   (09951-07100)

    NOTICE:
    1. The oil seal is a non-reusable part.
    2. Do not damage the steering knuckle oil seal.



2. INSTALL STEERING KNUCKLE LH

  1. Install the steering knuckle to the front suspension upper arm with the nut.

    Torque:
    110 N*m{ 1122 kgf*cm , 81 ft.*lbf }

  1. Install a new clip.

    HINT:
    If the holes for the clip are not aligned, tighten the nut up to another 60°.



3. CONNECT FRONT LOWER BALL JOINT ATTACHMENT LH



  1. Connect the attachment to the steering knuckle with the 2 bolts.

    Torque:
    300 N*m{ 3059 kgf*cm , 221 ft.*lbf }



4. CONNECT TIE ROD END SUB-ASSEMBLY LH

  1. Connect the tie rod end LH to the steering knuckle with the nut.

    Torque:
    69 N*m{ 704 kgf*cm , 51 ft.*lbf }

  1. Install a new cotter pin.

    HINT:
    If the holes for the cotter pin are not aligned, tighten the nut up to another 60°.



5. INSTALL FRONT AXLE HUB SUB-ASSEMBLY LH

  1. Install the front axle hub (Click here).



6. CONNECT FRONT SPEED SENSOR LH



  1. Using a 5 mm hexagon socket, install the speed sensor with the bolt.

    Torque:
    8.3 N*m{ 85 kgf*cm , 73 in.*lbf }

    NOTICE:
    1. Make sure there are no pieces of iron or other foreign matter attached to the sensor tip.
    2. While inserting the speed sensor into the knuckle hole, do not strike or damage the sensor tip.
    3. After installing the speed sensor, make sure there is no clearance or foreign matter between the sensor stay part and the knuckle.
    4. Make sure there is no foreign matter attached to the magnetic rotor.




  1. Install the skid control sensor clamp and sensor wire with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }



7. INSTALL FRONT WHEEL

Torque:
for Aluminum Wheel:
131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
for Steel Wheel:
209 N*m{ 2131 kgf*cm , 154 ft.*lbf }

NOTICE:

9. CHECK SPEED SENSOR SIGNAL

  1. Check the speed sensor signal (Click here).



10. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).



11. MEASURE VEHICLE HEIGHT (w/ KDSS)

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Set the tire pressure to the specified value(s) (Click here).

  1. Bounce the vehicle to stabilize the suspension.




  1. Measure the distance from the ground to the top of the bumper and calculate the difference in the vehicle height between left and right. Perform this procedure for both the front and rear wheels.

    Height difference of left and right sides:
    15 mm (0.591 in.) or less

    HINT:
    If not as specified, perform the vehicle tilt calibration.



12. CLOSE STABILIZER CONTROL WITH ACCUMULATOR HOUSING SHUTTER VALVE (w/ KDSS)

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Using a 5 mm hexagon socket wrench, tighten the lower and upper chamber shutter valves of the stabilizer control with accumulator housing.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



13. INSTALL STABILIZER CONTROL VALVE PROTECTOR (w/ KDSS)



  1. Install the valve protector with the 3 bolts.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }

  1. Attach the clamp, and connect the connector to the valve protector.
