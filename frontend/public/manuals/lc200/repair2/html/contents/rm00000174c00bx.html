CLUTCH PEDAL (for RHD) > INSTALLATION

for Preparation Click here



1. INSTALL CLUTCH PEDAL SPRING HOLDER



  1. Apply MP grease to the contact surface of the spring holder.

  1. Install the clutch pedal spring holder to the clutch pedal bracket.



2. INSTALL CLUTCH PEDAL BUSH



  1. Apply MP grease to the inside and outside of 2 new bushes.

  1. Install the 2 bushes to the clutch pedal.



3. INSTALL CLUTCH PEDAL SHAFT COLLAR



  1. Apply MP grease to the clutch pedal shaft collar.

  1. Install the clutch pedal shaft collar to the clutch pedal.



4. INSTALL NO. 2 CLUTCH PEDAL CUSHION



  1. Install the clutch pedal cushion to the clutch pedal.



5. INSTALL CLUTCH PEDAL PAD

  1. Install the clutch pedal pad to the clutch pedal.



6. INSTALL CLUTCH PEDAL SUB-ASSEMBLY



  1. Install the clutch pedal to the clutch pedal bracket with the nut, washer and bolt.

    Torque:
    34 N*m{ 350 kgf*cm , 25 ft.*lbf }

    HINT:
    Install the bolt from the right side of the vehicle.



7. INSTALL CLUTCH PEDAL SPRING



  1. Apply MP grease to the pins of the clutch pedal bracket and clutch pedal.

  1. Connect the spring to the clutch pedal, and connect the spring to the clutch pedal bracket with a new E-ring.



8. INSTALL TURNOVER SPRING



  1. Apply MP grease to the contact surfaces of the spring holder, clutch pedal and spring.

  1. Move the pedal to the full stroke position.

  1. Install the spring to the clutch pedal and spring holder.



9. INSTALL CLUTCH PEDAL BRACKET SUB-ASSEMBLY



  1. Install the clutch pedal bracket to the vehicle, and then temporarily install the bolt.

    HINT:
    The bolt will be tightened to a torque specification in the "Install Clutch Master Cylinder Assembly" procedure.

  1. Connect the clutch start switch connector.

  1. w/ Cruise Control System:
    Connect the clutch switch connector.



10. INSTALL CLUTCH MASTER CYLINDER ASSEMBLY

  1. Install the clutch master cylinder assembly (Click here).
