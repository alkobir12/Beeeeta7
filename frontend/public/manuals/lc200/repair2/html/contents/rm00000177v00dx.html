1. INSTALL INPUT SHAFT FRONT BEARING



  1. Using SST and a press, install the input shaft front bearing to the input shaft.

    SST
    09316-20011  

    HINT:
    Make sure that the groove of the bearing faces the correct direction as shown in the illustration.



2. INSTALL FRONT BEARING SHAFT SNAP RING

3. INSTALL INPUT SHAFT BEARING

  1. Apply MP grease to the 12 roller bearings.

  1. Install the 12 roller bearings into the input shaft.
