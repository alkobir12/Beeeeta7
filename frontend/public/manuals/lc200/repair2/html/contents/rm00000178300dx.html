1. INSTALL FRONT COUNTER GEAR BEARING OR ROLLER

  1. Apply gear oil to a new side race and bearing.




  1. Install a new inner race and the side race to the bearing as shown.

  1. Using SST and a press, install the bearing (with inner race and side race).

    SST
    09316-60011   (09316-00011, 09316-00021)



2. INSTALL FRONT NO. 1 COUNTER GEAR BEARING SNAP RING



  1. Select a new snap ring that will allow minimum clearance.
