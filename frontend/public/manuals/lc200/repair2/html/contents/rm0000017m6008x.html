1. INSTALL OIL PUMP RELIEF VALVE

  1. Coat the relief valve with engine oil and insert the relief valve and spring into the valve hole.

  1. Install the relief valve plug.

    Torque:
    49 N*m{ 500 kgf*cm , 36 ft.*lbf }



2. INSTALL OIL PUMP COVER



  1. Apply fresh engine oil to the drive and driven rotors.

  1. Place the drive and driven rotors into the timing chain cover with the matchmarks facing the oil pump cover side.




  1. Install the oil pump cover with the 7 bolts.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

  1. Install a new O-ring onto the oil pump cover.

  1. Install a new O-ring onto the oil pipe.



3. INSTALL OIL PUMP OUTLET PIPE



  1. Install the outlet pipe with the 3 bolts.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }
