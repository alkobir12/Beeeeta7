1. INSTALL COOLER DRYER



  1. Using pliers, install the cooler dryer.




  1. Apply a sufficient amount of compressor oil to the contact surfaces of a new O-ring and the cap.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install O-ring to the cap.




  1. Using a 14 mm socket hexagon wrench, install the cap to the modulator.

    Torque:
    2.9 N*m{ 30 kgf*cm , 26 in.*lbf }



2. INSTALL COOLER CONDENSER ASSEMBLY



  1. Install the cooler condenser as shown in the illustration.



3. INSTALL RADIATOR SUPPORT SUB-ASSEMBLY



  1. Install the radiator support with the 8 bolts.

    Torque:
    21.7 N*m{ 221 kgf*cm , 16 ft.*lbf } for bolt A
    9.8 N*m{ 100 kgf*cm , 7 ft.*lbf } for bolt B



4. INSTALL HOOD LOCK ASSEMBLY



  1. Apply MP grease to the sliding areas of the lock.




  1. Connect the hood lock control cable.

  1. Install the hood lock.




  1. Install the 2 bolts and nut.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

  1. Connect the connector.



5. INSTALL HOOD LOCK CONTROL CABLE COVER



  1. Attach the claw to install the cable cover.

  1. Install the 3 screws.



6. INSTALL HOOD LOCK SUPPORT BRACE SUB-ASSEMBLY



  1. Install the brace with the 3 bolts and nut.

    Torque:
    21.7 N*m{ 221 kgf*cm , 16 ft.*lbf } for bolt
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf } for nut

  1. Install the hood lock nut cap.



7. INSTALL OIL COOLER ASSEMBLY (w/ Air Cooled Transmission Oil Cooler)



  1. Temporarily install the oil cooler to the radiator support.

    NOTICE:
    Securely attach the 2 claws of the oil cooler into the hole of the radiator support.

  1. Install the 4 bolts in the sequence shown in the illustration.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



8. INSTALL TRANSMISSION OIL COOLER AIR DUCT (w/ Air Cooled Transmission Oil Cooler)



  1. Install the oil cooler air duct with the 4 bolts in the sequence shown in the illustration.

    Torque:
    4.9 N*m{ 50 kgf*cm , 43 in.*lbf }



9. INSTALL SHROUD BLOWER ASSEMBLY (w/ Rear Air Conditioning System)



  1. Install the shroud blower with the bolt.

    Torque:
    9.8 N*m{ 100 kgf*cm , 7 ft.*lbf }

  1. Connect the connector.



10. INSTALL LOW PITCHED HORN ASSEMBLY

  1. Connect the horn connector.



  1. Install the horn with the bolt.

    Torque:
    19 N*m{ 194 kgf*cm , 14 ft.*lbf }






11. INSTALL HIGH PITCHED HORN ASSEMBLY

  1. Connect the horn connector.



  1. Install the horn with the bolt.

    Torque:
    19 N*m{ 194 kgf*cm , 14 ft.*lbf }






12. CONNECT COOLER REFRIGERANT LIQUID PIPE A



  1. Remove the attached vinyl tape from the hose and the connecting part of the cooler condenser.

  1. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the pipe joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install O-ring on the liquid pipe A.

  1. Connect the liquid pipe A to the cooler condenser with the bolt.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }

    NOTICE:
    1. When tightening the bolt, do not allow any tools to contact the pipe.
    2. When tightening the bolt, hold a part of the pipe near the connector.



13. CONNECT NO. 1 COOLER REFRIGERANT DISCHARGE HOSE



  1. Remove the attached vinyl tape from the pipe and the connecting part of the cooler condenser.

  1. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install O-ring on the discharge hose.

  1. Connect the discharge hose to the cooler condenser with the 2 bolts.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }

    NOTICE:
    1. When tightening the bolts, do not allow any tools to contact the pipe.
    2. When tightening the bolts, hold a part of the pipe near the connector.

17. WARM UP ENGINE

  1. Warm up the engine at less than 1850 rpm for 2 minutes or more after charging the refrigerant.

    NOTICE:
    Be sure to warm up the compressor when turning the A/C switch is on after removing and installing the cooler refrigerant lines (including the compressor), to prevent damage to the compressor.



18. CHECK FOR REFRIGERANT GAS LEAK

  1. After recharging the refrigerant gas, check for refrigerant gas leakage using a halogen leak detector.

  1. Perform the operation under these conditions:

    1. Stop the engine.
    2. Secure good ventilation (the halogen leak detector may react to volatile gases other than refrigerant, such as evaporated gasoline or exhaust gas).
    3. Repeat the test 2 or 3 times.
    4. Make sure that some refrigerant remains in the refrigeration system. When compressor is off: approximately 392 to 588 kPa (4.0 to 6.0 kgf/cm2, 57 to 85 psi).




  1. Using a halogen leak detector, check the refrigerant line for leakage.

  1. If a gas leak is not detected on the drain hose, remove the blower motor control (blower resistor) from the cooling unit. Insert the halogen leak detector sensor into the unit and perform the test.

  1. Disconnect the connector and wait for approximately 20 minutes. Bring the halogen leak detector close to the pressure switch and perform the test.
