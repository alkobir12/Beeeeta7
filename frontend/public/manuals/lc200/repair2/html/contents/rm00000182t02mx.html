DESCRIPTION


DTC No.
DTC Detection Condition
Trouble Area
58-40
A navigation antenna error.
  1. Harness or connector
  1. Navigation antenna
  1. Navigation ECU
58-41
An error of the power source to the navigation antenna.
80-40
A navigation antenna error.
80-41
An error of the power source to the navigation antenna.

INSPECTION PROCEDURE

HINT:
After the inspection is completed, clear the DTCs (Click here).

1.CHECK HARNESS AND CONNECTOR (NAVIGATION ANTENNA - NAVIGATION ECU)

  1. Check that the navigation antenna cord is securely connected to the navigation ECU.

    OK:
    The cord is securely connected.



NG
REPAIR OR REPLACE HARNESS OR CONNECTOR
OK


2.INSPECT NAVIGATION ANTENNA



  1. Disconnect the navigation antenna connector.

  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Condition
    		Specified Condition
    1 - Shield
    		Always
    		50 to 500 Ω

REPLACE NAVIGATION ANTENNA (Click here)
OK


3.DTC CLEAR AND RECHECK

  1. Clear the DTCs (Click here).

  1. Recheck for DTCs and check if the same trouble code is output.

    OK:
    No DTC is output.
