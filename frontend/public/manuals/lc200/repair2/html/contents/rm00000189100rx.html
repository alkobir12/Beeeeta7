1. INSTALL GENERATOR ROTOR ASSEMBLY



  1. Place the drive end frame on the pulley.

  1. Install the rotor to the drive end frame.



2. INSTALL GENERATOR COIL ASSEMBLY



  1. Place the generator washer on the rotor.




  1. Using a 21 mm socket wrench and a press, slowly press in the coil assembly.




  1. Install the 4 bolts.

    Torque:
    5.9 N*m{ 60 kgf*cm , 52 in.*lbf }



3. INSTALL GENERATOR BRUSH HOLDER ASSEMBLY



  1. While pushing the 2 brushes toward the inside of the brush holder, insert a pin (diameter 1.0 mm (0.0394 in.)) into the brush holder hole.




  1. Install the generator brush holder with the 2 screws.

    Torque:
    1.8 N*m{ 18 kgf*cm , 16 in.*lbf }

  1. Pull out the pin from the generator brush holder.



4. INSTALL GENERATOR REAR END COVER



  1. Install the terminal insulator to the generator rectifier end frame.

    NOTICE:
    Pay attention to the mounting orientation of the terminal insulator.




  1. Install the end cover with the 3 nuts.

    Torque:
    4.6 N*m{ 46 kgf*cm , 40 in.*lbf }



5. INSTALL GENERATOR PULLEY



SST

HINT:
SST 1-A and B
09820-06010
SST 2
09820-06021

  1. Install the pulley onto the rotor shaft by tightening the pulley nut by hand.

  1. Hold SST 1-A with a torque wrench, and tighten SST 1-B clockwise to the specified torque.

    Torque:
    39 N*m{ 398 kgf*cm , 29 ft.*lbf }

    NOTICE:
    Check that SST is secured to the rotor shaft.




  1. Mount SST 2 in a vise.

  1. Insert SST 1-A and B into SST 2, and attach the pulley nut to SST 2.




  1. Tighten the pulley nut by turning SST 1-A in the direction shown in the illustration.

    Torque:
    133 N*m{ 1351 kgf*cm , 98 ft.*lbf }

  1. Remove the generator from SST 2.




  1. Turn SST 1-B, and remove SST 1-A and B.

  1. Turn the pulley and check that the pulley moves smoothly.
