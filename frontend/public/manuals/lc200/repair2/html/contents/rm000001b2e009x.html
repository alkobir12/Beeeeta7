for Preparation Click here



1. INSTALL REAR SPEED SENSOR LH



  1. Install the speed sensor with the nut.

    Torque:
    8.3 N*m{ 85 kgf*cm , 73 in.*lbf }

    NOTICE:
    1. Make sure there are no pieces of iron or other foreign matter attached to the sensor tip.
    2. While inserting the speed sensor into the knuckle hole, do not strike or damage the sensor tip.
    3. After installing the speed sensor, make sure there is no clearance or foreign matter between the sensor stay part and the knuckle.
    4. Make sure there is no foreign matter attached to the speed sensor rotor.



2. INSTALL REAR SPEED SENSOR RH



  1. Install the speed sensor with the nut.

    Torque:
    8.3 N*m{ 85 kgf*cm , 73 in.*lbf }

    NOTICE:
    1. Make sure there are no pieces of iron or other foreign matter attached to the sensor tip.
    2. While inserting the speed sensor into the knuckle hole, do not strike or damage the sensor tip.
    3. After installing the speed sensor, make sure there is no clearance or foreign matter between the sensor stay part and the knuckle.
    4. Make sure there is no foreign matter attached to the speed sensor rotor.



3. INSTALL SKID CONTROL SENSOR WIRE



  1. Install the sensor clamp with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    NOTICE:
    Make sure the clamp rotation stopper touches the installation position.

  1. Connect the connector.

    NOTICE:
    1. Securely insert the connector.
    2. When connecting the connector, do not twist the wire harness.




  1. Install the sensor clamp with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    NOTICE:
    Make sure the clamp rotation stopper touches the installation position.




  1. Connect the speed sensor RH connector.

    NOTICE:
    1. Securely connect the connector.
    2. When connecting the connector, do not twist the wire harness.



  1. Attach the 3 clamps.



    NOTICE:
    1. When attaching the clamps, do not twist the wire harness.
    2. When attaching the clamps, securely insert them as shown in the illustration.



  1. Attach the 5 clamps.



    NOTICE:
    1. When attaching the clamps, do not twist the wire harness.
    2. When attaching the clamps, securely insert them as shown in the illustration.



  1. Attach the 2 clamps, and install the sensor clamp with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }







  1. Connect the speed sensor LH connector.

    NOTICE:
    1. Securely connect the connector.
    2. When connecting the connector, do not twist the wire harness.



4. INSTALL REAR WHEEL

Torque:
for Aluminum Wheel:
131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
for Steel Wheel:
209 N*m{ 2131 kgf*cm , 154 ft.*lbf }
