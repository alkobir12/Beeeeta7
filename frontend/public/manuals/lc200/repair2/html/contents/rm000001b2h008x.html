FRONT SPEED SENSOR > INSTALLATION

for Preparation Click here



1. INSTALL FRONT SPEED SENSOR LH



  1. Using a 5 mm hexagon wrench, install the speed sensor with the bolt.

    Torque:
    8.3 N*m{ 85 kgf*cm , 73 in.*lbf }

    NOTICE:
    1. Make sure there are no pieces of iron or other foreign matter attached to the sensor tip.
    2. While inserting the speed sensor into the knuckle hole, do not strike or damage the sensor tip.
    3. After installing the speed sensor, make sure there is no clearance or foreign matter between the sensor stay part and the knuckle.
    4. Make sure there is no foreign matter attached to the speed sensor rotor.



2. INSTALL FRONT SKID CONTROL SENSOR WIRE LH


  1. w/o AHC:




    1. Connect the connector.

    2. Install the harness clamp with the bolt.

      Torque:
      13 N*m{ 127 kgf*cm , 9 ft.*lbf }

      NOTICE:
      1. When installing the clamp, do not twist the wire harness.
      2. Make sure the clamp rotation stopper touches the installation position.



  1. w/ AHC:




    1. Connect the 2 connectors.

    2. Install the harness clamp with the bolt.

      Torque:
      13 N*m{ 127 kgf*cm , 9 ft.*lbf }

      NOTICE:
      1. When installing the clamp, do not twist the wire harness.
      2. Make sure the clamp rotation stopper touches the installation position.




  1. Install the 2 harness clamps with the 2 bolts.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    NOTICE:
    1. When installing the clamps, do not twist the wire harness.
    2. Make sure the clamp rotation stopper touches the installation position.




  1. Install the harness clamp with the nut.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    NOTICE:
    1. When installing the clamp, do not twist the wire harness.
    2. Make sure the clamp rotation stopper touches the installation position.




  1. Install the harness clamp with bolt

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    NOTICE:
    Install the bracket so that the rotation stopper touches the knuckle.

  1. Connect the speed sensor connector.

    NOTICE:
    Securely connect the connector.

4. INSTALL FRONT SKID CONTROL SENSOR WIRE RH


  1. w/o AHC:




    1. Install the skid control sensor clamp with the bolt (labeled A).

      Torque:
      for bolt A:
      5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

    2. Attach the connector to the skid control sensor clamp and then connect the connector.

    3. Install the 2 harness clamps with the 2 bolts.

      Torque:
      13 N*m{ 127 kgf*cm , 9 ft.*lbf }

      NOTICE:
      1. When installing the clamps, do not twist the wire harness.
      2. Make sure the clamp rotation stopper touches the installation position.



  1. w/ AHC:

    2. Attach the connector to the skid control sensor clamp and then connect the connector.

    3. Install the 2 harness clamps with the 2 bolts.

      Torque:
      13 N*m{ 127 kgf*cm , 9 ft.*lbf }

      NOTICE:
      1. When installing the clamps, do not twist the wire harness.
      2. Make sure the clamp rotation stopper touches the installation position.




    4. Install the harness clamp with the bolt.

      Torque:
      13 N*m{ 127 kgf*cm , 9 ft.*lbf }

    5. Connect the connector.




  1. Install the harness clamp with the nut.
