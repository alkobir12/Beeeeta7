FAIL-SAFE OPERATION
  1. If there is a problem with sensor signals or hydraulic brake booster systems, the ABS control will be prohibited, but EBD control continues as much as possible. If EBD control is impossible, the BRAKE warning light comes on to warn the driver (Click here).
  2. If system components have any malfunction before starting control, the fail-safe function immediately stops the operation.
    If system components have any malfunction during control, the fail-safe function gradually stops the control so as not to trigger a sudden change in vehicle conditions.
    If it is impossible to control the systems, the warning light comes on to inform the driver of termination of the systems (Click here).

HINT:
If the hydraulic brake booster encounters a malfunction, brake performance is gradually lost and ABS, BA control system control is prohibited.

  1. ABS, Multi Terrain ABS, EBD and BA system:

    Malfunction Area
    		Control Method
    ABS system
    (Multi Terrain ABS)
    		ABS, BA control prohibited
    BA system

    EBD system
    		ABS, EBD, BA control prohibited
