FREEZE FRAME DATA

  1. If a DTC is stored when the brake control system operates, the skid control ECU stores the current vehicle (sensor) state as freeze frame data.
    The skid control ECU stores the number of times (maximum: 31) the engine switch has been turned from off to on (IG) since the last time the brake control system was activated.

    HINT:
    1. The skid control ECU will not count the number of times the engine switch is turned on (IG) if the vehicle does not drive at a speed of at least 7 km/h (4.3 mph) or a DTC is stored.
    2. Freeze frame data at the time the brake control system operates: The skid control ECU stores and updates the data whenever the brake control system operates. When the ECU stores data at the time a DTC is stored, the data stored when the brake control system operated may be cleared.
    3. Freeze frame data at the time a DTC is stored: When the skid control ECU stores data at the time a DTC is stored, no updates will be performed until the data is cleared.

  2. Connect the intelligent tester to the DLC3.

  3. Turn the engine switch on (IG).

  4. Turn the intelligent tester on.

  5. Enter the following menus: Chassis / ABS/VSC/TRC / Utility / ABS History.

  6. On the intelligent tester display, select the freeze frame data.
