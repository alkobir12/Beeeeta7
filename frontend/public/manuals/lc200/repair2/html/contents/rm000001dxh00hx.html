DTC    C1336/98    Zero Point Calibration of Acceleration Sensor Undone

for Preparation Click here


DESCRIPTION

The skid control ECU receives signals from the G sensor.

DTC Code
DTC Detection Condition
Trouble Area
C1336/98
  1. The G sensor zero point stored in the ECU is cleared.
  2. Zero point calibration has not been completed.
  1. G sensor
  2. Zero point calibration undone
  3. Harness or connector
  4. Master cylinder solenoid (Skid control ECU)
