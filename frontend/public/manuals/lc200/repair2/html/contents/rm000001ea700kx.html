DTC    C1251/51    Open in Pump Motor Circuit

for Preparation Click here


DESCRIPTION

The motor relay (semiconductor relay) is built into the master cylinder solenoid and drives the pump motor based on a signal from the skid control ECU.

DTC Code
DTC Detection Condition
Trouble Area
C1251/51
There is an open in the motor system circuit (motor input circuit).
  1. Pump motor wire harness connection
  2. Brake booster with accumulator pump assembly
  3. Master cylinder solenoid (Skid control ECU)
