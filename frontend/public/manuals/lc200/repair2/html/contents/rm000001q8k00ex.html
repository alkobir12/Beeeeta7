BRAKE PEDAL (for RHD) > REASSEMBLY

for Preparation Click here



1. INSTALL BRAKE PEDAL SUPPORT SUB-ASSEMBLY


2. INSTALL STOP LIGHT SWITCH MOUNTING ADJUSTER

  1. Install the stop light switch mounting adjuster to the brake pedal support.



3. INSTALL BRAKE PEDAL PAD



  1. Install the brake pedal pad onto the brake pedal.



4. INSTALL BRAKE PEDAL LEVER SUB-ASSEMBLY

  1. Apply lithium soap base glycol grease to the 2 brake pedal link pins, 2 pedal shaft collars and 2 brake pedal links.

  1. Install the brake pedal lever, 2 brake pedal shaft collars and 2 brake pedal links to the brake pedal.

  1. Install 2 new E-rings to each brake pedal link.



5. INSTALL BRAKE PEDAL SUB-ASSEMBLY

  1. Apply lithium soap base glycol grease to the 2 collars and 4 brake pedal bushes.

  1. Install the 2 collars and 4 brake pedal bushes to the brake pedal and brake pedal lever.




  1. Install the brake pedal sub-assembly to the brake pedal support with the bolt and nut.

    Torque:
    34 N*m{ 350 kgf*cm , 25 ft.*lbf }



6. INSTALL BRAKE PEDAL SUPPORT REINFORCEMENT



  1. Install the brake pedal support reinforcement to the brake pedal support sub-assembly.

  1. Temporarily assemble the brake pedal support sub-assembly, brake pedal support reinforcement and brake pedal lever with the bolt and nut.



7. INSTALL BRAKE PEDAL RETURN SPRING

  1. Apply lithium soap base glycol grease to the contact points of the spring and the brake pedal support sub-assembly and brake pedal support reinforcement.




  1. Install the spring.
