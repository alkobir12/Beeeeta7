BUS CHECK (COMMUNICATION MALFUNCTION ECU)

HINT:
Only CAN communication system DTCs for each ECU can be displayed on the intelligent tester.




  1. Select "Bus Check" from the "System Select" screen on the intelligent tester.




  2. Select "Communication Malfunction DTC" from the "Bus Check" screen, and then select "Enter".




  3. Select the system of the DTC to be checked and select "Details".




  4. CAN communication system DTCs are displayed.


BUS CHECK (COMMUNICATION BUS CHECK)

HINT:
The ECUs and sensors that are properly connected to the CAN communication system can be displayed using the intelligent tester.




  1. Select "Communication Bus Check" from the "Bus Check" screen.




  2. The screen displays the ECUs and sensors that are properly connected to the CAN communication system.

    HINT:
    If any properly connected ECUs or sensors are not displayed, there is a communication stop in the system (Click here).




  3. "There is no system connected to the communication bus" is displayed if there are no ECUs or sensors connected to the CAN bus.
