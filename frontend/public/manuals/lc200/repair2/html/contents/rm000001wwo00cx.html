DTC    01-E0    Registration Complete Indication Error

DTC    01-E3    Registration Demand Transmission

DTC    01-E4    Multiple Frame Incomplete

for Preparation Click here


DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
01-E0
A "registration complete" signal from the master device cannot be received.
-
01-E3
A registration demand signal from the slave device is output, or a registration demand signal is output by receiving a connection confirmation signal from the sub-master device.
-
01-E4
Multiple frame transmission is incomplete.
-

HINT:
Even if no failure is detected, a trouble code may be recorded depending on the battery condition or engine start voltage.


INSPECTION PROCEDURE

HINT:
After the inspection is completed, clear the DTCs.
These DTCs do not indicate a malfunction.
