SKID CONTROL BUZZER > INSTALLATION

for Preparation Click here



1. INSTALL SKID CONTROL BUZZER ASSEMBLY (for LHD)



  1. Connect the buzzer connector.

    NOTICE:
    Securely connect the connector.

  1. Attach the clamp to install the buzzer.

    NOTICE:
    1. Securely insert the clamp into the bracket.
    2. If the buzzer is dropped, replace it.



2. INSTALL SKID CONTROL BUZZER ASSEMBLY (for RHD)



  1. Connect the buzzer connector.

    NOTICE:
    Securely connect the connector.

  1. Attach the clamp to install the buzzer.

    NOTICE:
    1. Securely insert the clamp into the bracket.
    2. If the buzzer is dropped, replace it.



3. INSTALL NO. 1 SWITCH HOLE BASE



  1. Connect the connectors.

  1. Attach the 4 claws to install the switch hole base.



4. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



5. INSTALL COWL SIDE TRIM BOARD



  1. Attach the 2 clips to install the trim board.

  1. Install the cap nut.



6. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



7. INSTALL FRONT DOOR SCUFF PLATE


8. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
