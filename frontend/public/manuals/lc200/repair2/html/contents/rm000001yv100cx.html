DESCRIPTION


DTC Code
DTC Detection Condition
Trouble Area
62-7D
When either condition below is met:
  1. Incompatible MP3/WMA file is used.
  2. File extension is MP3/WMA, but header information cannot be read and playback is not possible.
  1. CD
  2. Radio receiver assembly
62-7E
When either condition below is met:
  1. No audio data is recorded on the disc.
  2. No playable files (MP3/WMA) are on the disc.
62-7F
Copyright protection exists and playback is not possible.
63-7D
When either condition below is met:
  1. Incompatible MP3/WMA file is used.
  2. File extension is MP3/WMA, but header information cannot be read and playback is not possible.
63-7E
When either condition below is met:
  1. No audio data is recorded on the disc.
  2. No playable files (MP3/WMA) are on the disc.
