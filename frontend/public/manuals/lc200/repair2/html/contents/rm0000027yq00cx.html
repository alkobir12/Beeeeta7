DTC    B2272    Ignition 1 Monitor Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when a malfunction occurs in the IG1D output circuit, which is between the IG1 No. 3 relay actuation circuit inside the main body ECU and the IG1 No. 3 relay.

DTC Code
Detection Condition
Trouble Area
B2272
The IG1 No. 3 relay actuation circuit inside the main body ECU or other related circuit is malfunctioning.
  1. Main body ECU
  2. Harness or connector
