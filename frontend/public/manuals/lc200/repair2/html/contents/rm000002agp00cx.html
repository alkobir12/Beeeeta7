WIRELESS DOOR LOCK CONTROL SYSTEM > No Answer-Back

for Preparation Click here


DESCRIPTION

In some cases, wireless door lock control functions are normal but the turn signal lights and wireless door lock buzzer are not. Malfunctions may be present in the main body ECU, certification ECU (smart key ECU assembly), turn signal lights, and/or wireless door lock buzzer signal outputs.*

NOTICE:
  1. Before performing the inspection, check that there are no problems related to the CAN communication system and LIN communication system.
  2. When troubleshooting a function, first make sure that the answer-back function is set to the default setting.
  3. Check that DTC B1242 is not output.
  4. When troubleshooting a function, first make sure that the open door warning function is set to the default setting.

HINT:
*: For Europe and China, there is no buzzer sound answer-back function.
