FRONT CRANKSHAFT OIL SEAL > INSTALLATION

for Preparation Click here



1. INSTALL FRONT CRANKSHAFT OIL SEAL



  1. Apply MP grease to the lip of a new oil seal.

  1. Using SST and a hammer, tap in the oil seal until its surface is flush with the timing chain cover edge.

    SST
    09226-10010  



2. INSTALL CRANKSHAFT PULLEY



  1. Using SST, install the crankshaft pulley with the pulley set bolt.

    SST
    09213-54015   (91651-60855)
    09330-00021  

    Torque:
    250 N*m{ 2549 kgf*cm , 184 ft.*lbf }
