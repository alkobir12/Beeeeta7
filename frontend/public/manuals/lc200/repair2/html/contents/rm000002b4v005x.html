for Preparation Click here



1. INSTALL REAR CRANKSHAFT OIL SEAL



  1. Apply MP grease to the lip of a new oil seal.

  1. Using SST and a hammer, tap in the oil seal until its surface is flush with the rear oil seal retainer edge.

    SST
    09223-78010  



2. INSTALL DRIVE PLATE AND RING GEAR SUB-ASSEMBLY (for Automatic Transmission)



  1. Using SST, hold the crankshaft.

    SST
    09213-54015   (91651-60855)
    09330-00021  

  1. Temporarily install the front spacer, drive plate and rear spacer with the 8 bolts.




  1. Tighten the 8 bolts uniformly in several steps in the order shown in the illustration.

    Torque:
    83 N*m{ 846 kgf*cm , 61 ft.*lbf }

    NOTICE:
    Do not start the engine for at least 1 hour after installing.



3. INSTALL FLYWHEEL SUB-ASSEMBLY (for Manual Transmission)



  1. Using SST, hold the crankshaft.

    SST
    09213-54015   (91651-60855)
    09330-00021  

  1. Temporarily install the flywheel with the 8 bolts.




  1. Install and tighten the 8 mounting bolts uniformly in several steps.

    Torque:
    83 N*m{ 846 kgf*cm , 61 ft.*lbf }



4. INSTALL CLUTCH DISC ASSEMBLY (for Manual Transmission)



  1. Insert SST into the clutch disc, then insert the clutch disc into the flywheel.

    SST
    09301-00110  

    NOTICE:
    Take care not to insert the clutch disc in the wrong direction.



5. INSTALL CLUTCH COVER ASSEMBLY (for Manual Transmission)



  1. Align the matchmark on the clutch cover with the one on the flywheel.

  1. In the order shown in the illustration, temporarily install the 6 bolts starting from the bolt located near the knock pin on the top.

  1. Check that the disc is in the center by lightly moving SST up and down, and left and right.

    SST
    09301-00110  

  1. Evenly tighten the bolts by following the order shown in the illustration.

    Torque:
    19 N*m{ 195 kgf*cm , 14 ft.*lbf }



6. INSPECT AND ADJUST CLUTCH COVER ASSEMBLY



  1. Using a dial indicator with a roller instrument, check the diaphragm spring tip alignment.

    Maximum Misalignment:
    1.3 mm (0.0512 in.)




  1. If the alignment is not as specified, adjust the diaphragm spring tip alignment using SST.

    SST
    09333-00013
