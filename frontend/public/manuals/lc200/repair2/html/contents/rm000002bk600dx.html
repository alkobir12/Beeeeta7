1. INSTALL VALVE STEM OIL SEAL

HINT:
The intake valve stem oil seal is light brown and the exhaust valve stem oil seal is gray.




  1. Apply a light coat of engine oil to the valve stem oil seal.




  1. Using SST, push in a new valve stem oil seal.

    SST
    09201-41020  



2. INSTALL VALVE SPRING SEAT



  1. Install the valve spring seat.



3. INSTALL VALVE



  1. Apply plenty of engine oil to the tip area of the exhaust valve shown in the illustration.




  1. Place the cylinder head on wooden blocks.

  1. Install the valve, inner compression spring and valve spring retainer to the cylinder head.

    NOTICE:
    Install the same parts in the same combination to their original locations.

  1. Using SST, compress the inner compression spring and place the valve spring retainer lock around the valve stem.

    SST
    09202-70020   (09202-00010)




  1. Using a pin punch 5 and hummer, lightly tap the valve stem tip to ensure a proper fit.

    NOTICE:
    Be careful not to damage the valve stem tip.



4. INSTALL VALVE LIFTER



  1. Apply engine oil to the valve stem end and valve lifter, and install the valve lifter to the valve stem.

  1. Check that the valve lifter rotates smoothly by hand.
