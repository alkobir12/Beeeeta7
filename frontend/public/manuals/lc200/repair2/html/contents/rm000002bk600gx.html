CYLINDER HEAD > REASSEMBLY

for Preparation Click here



1. INSTALL NOZZLE HOLDER CLAMP SEAT



  1. Install the nozzle holder clamp seat.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



2. INSTALL VALVE SPRING SEAT PLATE WASHER





3. INSTALL VALVE STEM OIL SEAL



  1. Apply a light coat of engine oil to the valve guide bush.

  1. Using SST, push in a new valve stem oil seal.

    SST
    09201-41020  

  1. Check that the protrusion height of the valve stem oil seal labeled A in the illustration is as specified.

    Standard protrusion height:
    Below 14.7 mm (0.579 in.)



4. INSTALL VALVE



  1. Apply plenty of engine oil to the tip area of the valve as shown in the illustration.




  1. Place the cylinder head on a wooden block.

  1. Install the valve, inner compression spring and valve spring retainer to the cylinder head.

    NOTICE:
    Install the same parts in the same combination to their original locations.

  1. Using SST, compress the inner compression spring and place the valve spring retainer lock around the valve stem.

    SST
    09202-70020   (09202-00010)




  1. Using a plastic-faced hammer, lightly tap the valve stem tip to ensure a proper fit.

    NOTICE:
    Be careful not to damage the valve stem tip.
