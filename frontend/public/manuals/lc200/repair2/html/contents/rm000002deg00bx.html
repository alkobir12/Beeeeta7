STARTER (for 1.6 kW Type) > INSTALLATION

for Preparation Click here



1. INSTALL STARTER ASSEMBLY



  1. Install the starter with the 2 bolts.

    Torque:
    58 N*m{ 591 kgf*cm , 43 ft.*lbf }




  1. Connect the starter connector.

  1. Connect the starter wire with the nut.

    Torque:
    9.8 N*m{ 100 kgf*cm , 87 in.*lbf }

  1. Install the terminal cap.



2. INSTALL FRONT FENDER APRON SEAL REAR LH



  1. Install the fender apron seal with the 4 clips.



3. INSTALL FRONT FENDER APRON SEAL LH



  1. Install the fender apron seal with the 4 clips.



4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
