EXHAUST PIPE > INSTALLATION

for Preparation Click here



1. INSTALL FRONT EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front exhaust pipe to the exhaust manifold RH with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }

  1. Connect the heated oxygen sensor connector.



2. INSTALL HEATED OXYGEN SENSOR (for Bank 2 Sensor 2)



  1. Temporarily install the sensor to the exhaust pipe by hand.




  1. Using SST, tighten the sensor.

    SST
    09224-00010  

    Torque:
    without SST:
    44 N*m{ 449 kgf*cm , 32 ft.*lbf }
    with SST:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }

    HINT:
    1. Use a torque wrench with a fulcrum length of 30 cm (11.8 in.). If using a torque wrench with a length that is not 30 cm (11.8 in.), calculate the torque specification for the torque wrench and SST based on the "without SST" torque specification (Click here).
    2. Make sure SST and the wrench are connected in a straight line.



3. INSTALL FRONT NO. 2 EXHAUST PIPE ASSEMBLY

  1. Install a new gasket and the front No. 2 exhaust pipe to the exhaust manifold LH with 2 new nuts.

    Torque:
    54 N*m{ 554 kgf*cm , 40 ft.*lbf }




  1. Connect the heated oxygen sensor connector.

    HINT:
    Hook the wire harness to the bracket.



4. INSTALL CENTER EXHAUST PIPE ASSEMBLY



  1. Check the free length.

    1. Using a vernier caliper, measure the free length of the compression spring.

      Minimum free length:
      43 mm (1.693 in.)

      If the free length is less than the minimum, replace the compression spring.

  1. Connect the center exhaust pipe to the 3 exhaust pipe supports.

  1. Install 2 new gaskets to the front exhaust pipe and front No. 2 exhaust pipe.

  1. Install the center exhaust pipe with the 4 bolts and 2 compression springs.

    Torque:
    for center exhaust pipe and front exhaust pipe:
    43 N*m{ 438 kgf*cm , 32 ft.*lbf }
    for center exhaust pipe and front No. 2 exhaust pipe:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }



5. INSTALL TAILPIPE ASSEMBLY

  1. Install the tailpipe to the 2 exhaust pipe supports.

  1. Set a new gasket to the center exhaust pipe.




  1. Connect the tailpipe to the center pipe with a new clamp.

    Torque:
    32 N*m{ 326 kgf*cm , 24 ft.*lbf }

    HINT:
    Install the clamp within the angle range shown in the illustration.



6. INSTALL HEATED OXYGEN SENSOR (for Bank 1 Sensor 2)



  1. Temporarily install the sensor to the exhaust pipe by hand.




  1. Using SST, tighten the sensor.

    SST
    09224-00010  

    Torque:
    without SST:
    44 N*m{ 449 kgf*cm , 32 ft.*lbf }
    with SST:
    40 N*m{ 408 kgf*cm , 30 ft.*lbf }

    HINT:
    1. Use a torque wrench with a fulcrum length of 30 cm (11.8 in.). If using a torque wrench with a length that is not 30 cm (11.8 in.), calculate the torque specification for the torque wrench and SST based on the "without SST" torque specification (Click here).
    2. Make sure SST and the wrench are connected in a straight line.




  1. Connect the sensor connector.



7. INSPECT FOR EXHAUST GAS LEAK
If gas is leaking, tighten the areas necessary to stop the leak. Replace damaged parts as necessary.
