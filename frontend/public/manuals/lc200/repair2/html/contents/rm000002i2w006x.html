IGNITION COIL AND SPARK PLUG > INSTALLATION

for Preparation Click here



1. INSTALL SPARK PLUG

  1. Install the 6 spark plugs.

    Torque:
    20 N*m{ 204 kgf*cm , 15 ft.*lbf }



2. INSTALL IGNITION COIL ASSEMBLY



  1. Install the 6 ignition coils with the 6 bolts.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

  1. Connect the 6 ignition coil connectors.



3. INSTALL NO. 2 SURGE TANK STAY



  1. for Manual Transmission:

    1. Temporarily install the No. 2 surge tank stay with the 2 bolts labeled A and nut labeled B.

    2. Tighten the bolts labeled A.

      Torque:
      21 N*m{ 214 kgf*cm , 15 ft.*lbf }

    3. Tighten the nut labeled B.

      Torque:
      20 N*m{ 204 kgf*cm , 15 ft.*lbf }




  1. for Automatic Transmission:
    Install the No. 2 surge tank stay with the 2 bolts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }



4. INSTALL AIR CLEANER CAP SUB-ASSEMBLY



  1. Install the air cleaner cap and fasten the 2 hook clamps.



5. INSTALL NO. 2 AIR CLEANER HOSE



  1. Align the protrusion of the pre-cleaner with the groove of the No. 2 air cleaner hose as shown in the illustration.




  1. Tighten the 2 hose clamps.

    Torque:
    4.0 N*m{ 41 kgf*cm , 35 in.*lbf }

    HINT:
    Tighten the clamp until the end of the clamp band is within both limit marks.



6. INSTALL V-BANK COVER



  1. Install the V-bank cover with the 2 nuts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }
