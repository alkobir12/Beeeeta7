FRONT SEAT INNER BELT ASSEMBLY > INSTALLATION

for Preparation Click here



1. INSTALL FRONT SEAT INNER BELT ASSEMBLY (for Manual Seat)



  1. Install the front seat inner belt assembly with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding part of the front seat adjuster.

  1. Connect the connectors and attach the clamps.



2. INSTALL FRONT SEAT INNER BELT ASSEMBLY (for Power Seat)



  1. Install the front seat inner belt assembly with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding parts of the front seat adjuster.

  1. Connect the connectors and attach the clamps.
