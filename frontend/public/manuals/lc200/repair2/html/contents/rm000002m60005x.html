FRONT WIPER SYSTEM

  1. When the wiper switch is in any position other than "OFF" and the blades are frozen, a malfunction is detected by the cowl side junction block LH and the wiper operation is stopped.

    HINT:
    Recovery condition: the engine switch is turned off.

  2. When the rain sensor is broken and the wiper switch is in the AUTO position, the front wiper system is changed to the intermittent mode.

    HINT:
    Recovery condition: the signal level error cancellation is received from the rain sensor.

  3. When the rain sensor overheats and the front wiper is in the HI operation mode, the front wiper system is changed to the LO operation mode.

    HINT:
    Recovery condition: the engine switch is turned off or the wiper switch is turned to any position other than INT or LO.

  4. When the front controller malfunctions, the front wiper system can be set to the HI operation mode with the combination switch only.

    HINT:
    Recovery condition: the front controller returns to normal.
