WASHER MOTOR (for Rear Side) > INSTALLATION

for Preparation Click here



1. INSTALL REAR WASHER MOTOR AND PUMP ASSEMBLY



  1. Install the washer motor together with the gasket in the direction shown in the illustration.

    HINT:
    Make sure the gasket is positioned as shown in the illustration.



2. INSTALL WINDSHIELD WASHER JAR ASSEMBLY



  1. Temporarily install the windshield washer jar with the 4 bolts.

  1. Tighten the 4 bolts in the order shown in the illustration to install the windshield washer jar.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }




  1. w/ Headlight Cleaner System:

    1. Connect the 2 connectors.

    2. Attach the clamp.

    3. Connect the headlight cleaner hose to the headlight cleaner motor and pump.

  1. w/o Headlight Cleaner System:

    1. Connect the connector.

    2. Attach the clamp.



3. INSTALL WASHER INLET SUB-ASSEMBLY



  1. Install the washer inlet with the clip.



4. FILL WINDSHIELD WASHER JAR AND PUMP ASSEMBLY WITH WASHER FLUID



  1. Connect the washer hose to the windshield washer motor and pump, and fill the washer jar with washer fluid.



5. INSTALL FRONT FENDER LINER LH

  1. Install the fender liner with the 12 clips and 2 new grommets.

  1. Using a T30 "TORX" socket, install the 2 screws.



  1. Install the 2 screws.





6. INSTALL BODY ROCKER PANEL MOULDING ASSEMBLY LH

  1. Clean the vehicle body surface.

    1. Using a heat light, heat the vehicle body surface.

    2. Remove the double-sided tape from the vehicle body.

    3. Wipe off any tape adhesive residue with cleaner.



  1. If reusing the rocker panel moulding:
    Clean the rocker panel moulding.

    1. Using a heat light, heat the rocker panel moulding.

    2. Remove the double-sided tape from the rocker panel moulding.

    3. Wipe off any tape adhesive residue with cleaner.



    4. Apply new double-sided tape to the rocker panel moulding, as shown in the illustration.





  1. Install the rocker panel moulding.

    1. Using a heat light, heat the vehicle body and rocker panel moulding.

    2. Remove the peeling paper from the face of the rocker panel moulding.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    3. Attach the 10 clips to install the rocker panel moulding.



    4. Install the 8 side mudguard retainers and screw.





7. INSTALL SIDE STEP ASSEMBLY LH


  1. Install the side step with the 6 bolts.

    Torque:
    30 N*m{ 306 kgf*cm , 22 ft.*lbf }






8. INSTALL FRONT FENDER MUDGUARD LH

  1. Remove the 8 side mudguard retainers and screw.



  1. Detach the 10 clips and remove the rocker panel moulding.
