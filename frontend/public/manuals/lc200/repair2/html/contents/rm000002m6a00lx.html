WASHER NOZZLE (for Front Side) > INSTALLATION

for Preparation Click here



1. INSTALL WASHER NOZZLE SUB-ASSEMBLY



  1. Attach the 3 clamps to install the washer nozzle.

  1. Connect the hose.



2. INSTALL COWL TOP VENTILATOR LOUVER SUB-ASSEMBLY



  1. Push the ventilator louver in the direction indicated by the arrow in the illustration to attach the 17 claws and 2 clips and install the ventilator louver.



3. INSTALL HOOD TO COWL TOP SEAL



  1. Attach the 12 clips and 4 clamps to install the hood to cowl top seal.




  1. Install the washer hose.



4. INSTALL FRONT FENDER MAIN SEAL LH



  1. Attach the 3 clips to install the fender main seal.



5. INSTALL FRONT FENDER MAIN SEAL RH

HINT:
Use the same procedures described for the LH side.



6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



7. INSTALL FRONT WIPER ARM LH



  1. Stop the wiper motor at the automatic stop position.

  1. Clean the wiper pivot serration with a wire brush.




  1. Install the wiper arm and blade with the nut. Make sure that the wiper arm and blade comes to the position shown in the illustration.

    Standard Measurement:
    Position
    		Specified Condition
    A
    		16.8 to 36.8 mm (0.661 to 1.45 in.)

    Torque:
    25 N*m{ 255 kgf*cm , 18 ft.*lbf }

    HINT:
    Hold down the wiper arm hinge with your hand while tightening the nut.



8. INSTALL FRONT WIPER ARM RH



  1. Stop the wiper motor at the automatic stop position.

  1. Clean the wiper pivot serration with a wire brush.




  1. Install the wiper arm and blade with the nut. Make sure that the wiper arm and blade comes to the position shown in the illustration.

    Standard Measurement:
    Position
    		Specified Condition
    B
    		20.0 to 40.0 mm (0.787 to 1.57 in.)

    Torque:
    25 N*m{ 255 kgf*cm , 18 ft.*lbf }

    HINT:
    Hold down the wiper arm hinge with your hand while tightening the nut.

  1. Operate the front wipers while spraying washer fluid on the windshield glass. Make sure that the front wipers function properly and there is no interference with the vehicle body.
