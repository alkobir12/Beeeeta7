for Preparation Click here


HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL HOOD LOCK CONTROL CABLE ASSEMBLY (for LHD)

  1. Pass the cable into the engine room.

  1. Pass the cable rear side through the grommet until the cable stopper is attached to the grommet.

  1. Pass the cable front side through the upper radiator support.



  1. Connect the clamps shown in the illustration.





2. INSTALL HOOD LOCK CONTROL CABLE ASSEMBLY (for RHD)

  1. Pass the cable into the engine room.

  1. Pass the cable rear side through the grommet until the cable stopper is attached to the grommet.

  1. Pass the cable front side through the upper radiator support.



  1. Connect the clamps shown in the illustration.





3. INSTALL HOOD LOCK CONTROL LEVER SUB-ASSEMBLY



  1. Connect the hood lock control cable and attach the 2 claws to install the hood lock lever.



4. INSTALL FRONT FENDER MAIN SEAL LH (for LHD)



  1. Attach the 3 clips to install the fender main seal.



5. INSTALL FRONT FENDER MAIN SEAL RH (for RHD)



  1. Attach the 3 clips to install the fender main seal.



6. INSTALL HOOD LOCK ASSEMBLY



  1. Apply MP grease to the sliding areas of the lock.




  1. Connect the hood lock control cable.

  1. Install the hood lock.




  1. Install the 2 bolts and nut.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

  1. Connect the connector.



7. INSTALL HOOD LOCK NUT CAP



  1. Install a new hood lock nut cap.



8. INSTALL HOOD LOCK CONTROL CABLE COVER



  1. Attach the claw to install the cable cover.

  1. Install the 3 screws.



9. INSTALL RADIATOR GRILLE



  1. Attach the 2 clips and 8 claws to install the radiator grille.

  1. Install the 3 screws.



10. INSTALL UPPER RADIATOR SUPPORT SEAL


  1. Install the radiator support seal with the 7 clips.
