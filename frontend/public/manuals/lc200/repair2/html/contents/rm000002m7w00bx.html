HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.



1. INSTALL FRONT DOOR WEATHERSTRIP LH



  1. Attach the 21 clips to install the weatherstrip.

    HINT:
    If clips are damaged during installation, replace them.



2. INSTALL FRONT DOOR CHECK ASSEMBLY LH



  1. Apply MP grease to the sliding areas of the door check.

  1. Install the door check to the door panel with the 2 nuts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Apply adhesive to the threads of the bolt.

    Adhesive:
    Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent

  1. Install the bolt.

    Torque:
    27 N*m{ 275 kgf*cm , 20 ft.*lbf }



3. INSTALL FRONT DOOR CHECK COVER LH



  1. Install the door check cover.



4. INSTALL FRONT NO. 2 DOOR STIFFENER CUSHION

  1. Clean the installation surface.

    1. Using a heat light, heat the installation surface.

      HINT:
      When installing the door stiffener cushion, heat the vehicle body and door stiffener cushion using a heat light.

      Standard Heating Temperature:
      Item
      		Temperature
      Door Stiffener Cushion
      		20 to 30°C (68 to 86°F)
      Vehicle Body
      		40 to 60°C (104 to 140°F)

      NOTICE:
      Do not heat the back door garnish and vehicle body excessively.

    2. Remove the double-sided tape from the installation surface.

    3. Wipe off any tape adhesive residue with cleaner.



  1. Install a new door stiffener cushion.

    1. Using a heat light, heat a new door stiffener cushion and the installation surface.

      HINT:
      When installing the door stiffener cushion, heat the vehicle body and door stiffener cushion using a heat light.

      Standard Heating Temperature:
      Item
      		Temperature
      Door Stiffener Cushion
      		20 to 30°C (68 to 86°F)
      Vehicle Body
      		40 to 60°C (104 to 140°F)

      NOTICE:
      Do not heat the back door garnish and vehicle body excessively.

    2. Remove the peeling paper from the face of the door stiffener cushion.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    3. Attach the 2 clamps and double-sided tape to install the door stiffener cushion.

      HINT:
      Press the door stiffener firmly to install it.




    4. Install the 2 bolts.

8. INSTALL FRONT DOOR OUTSIDE HANDLE FRAME SUB-ASSEMBLY LH



  1. Attach the 2 claws to install the front door outside handle frame sub-assembly.




  1. Using a T30 "TORX" wrench, install the front door outside handle frame sub-assembly with the screw.

    Torque:
    4.0 N*m{ 41 kgf*cm , 35 in.*lbf }

    NOTICE:
    A cover should be inserted between the screw and door panel.



9. INSTALL FRONT DOOR INSIDE LOCKING CABLE ASSEMBLY LH



  1. Install the front door inside locking cable.

  1. Attach the 3 claws.



10. INSTALL FRONT DOOR LOCK REMOTE CONTROL CABLE ASSEMBLY LH



  1. Install the front door lock remote control cable.



11. INSTALL FRONT DOOR LOCK ASSEMBLY LH



  1. Apply MP grease to the sliding parts of the front door lock assembly.

  1. Insert the front door lock open rod to the front door lock assembly.

  1. Make sure that the front door lock open rod is securely connected to the front door lock assembly.

  1. Using a T30 "TORX" wrench, install the door lock with the 3 screws.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



12. INSTALL FRONT DOOR REAR OUTSIDE HANDLE PAD LH



  1. Attach the 2 claws to install the pad.



13. INSTALL FRONT DOOR FRONT OUTSIDE HANDLE PAD LH



  1. Attach the 3 claws to install the pad.



14. INSTALL FRONT DOOR HANDLE ASSEMBLY OUTSIDE LH



  1. Pull and hold the bellcrank lever of the frame.

  1. Install the handle by pushing it in the direction of the arrow in the illustration.




  1. Using a T30 ''TORX'' socket, install the screw.

  1. Connect the connector.



15. INSTALL FRONT DOOR OUTSIDE HANDLE COVER LH



  1. Attach the 2 claws to install the front door outside handle cover to the front door lock cylinder.




  1. Using a T30 ''TORX'' socket, install the cover (with the door lock cylinder) with the screw.

    Torque:
    4.0 N*m{ 41 kgf*cm , 35 in.*lbf }

  1. Install the hole plug.



16. INSTALL FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY LH



  1. Apply MP grease to the sliding and rotating areas of the regulator motor.

  1. Using a T25 ''TORX'' driver, install the motor with the 3 screws.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }

    HINT:
    A new front window regulator uses self-tapping screws to thread new installation holes when the self-tapping screws are inserted.



17. INSTALL FRONT DOOR WINDOW REGULATOR SUB-ASSEMBLY LH



  1. Apply MP grease to the sliding and rotating areas of the window regulator.

    NOTICE:
    Do not apply grease to the spring of the window regulator.

  1. Loosely install the temporary bolt onto the window regulator.

  1. Insert the window regulator into the door panel. Use the temporary bolt to hang the window regulator on the door panel.

    NOTICE:
    Be careful not to drop the window regulator as it may become damaged.

  1. Temporarily install the window regulator with the 5 bolts.

  1. Tighten the 6 bolts in the order shown in the illustration.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



18. INSTALL FRONT DOOR REAR WINDOW FRAME MOULDING LH

  1. Clean the vehicle body surface.

    1. Using a heat light, heat the vehicle body surface.

    2. Remove the double-sided tape from the vehicle body surface.

    3. Wipe off any tape adhesive residue with cleaner.



  1. Install a new window frame moulding.

    1. Using a heat light, heat a new window frame moulding and the vehicle body surface.

    2. Remove the peeling paper from the face of the window frame moulding.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.




    3. Attach the clip and double-sided tape to install the window frame moulding.

      HINT:
      Press the window frame moulding firmly to install it.



19. INSTALL FRONT DOOR BELT MOULDING SUB-ASSEMBLY LH



  1. Attach the claw to install the belt moulding.



20. INSTALL LOWER DOOR FRAME GARNISH LH

24. INSTALL FRONT INNER DOOR GLASS WEATHERSTRIP LH

  1. Install the front inner door glass weatherstrip LH.



25. INSTALL FRONT DOOR SERVICE HOLE COVER LH



  1. Apply butyl tape to the door.

  1. Pass the front door lock remote control cable and front door inside locking cable through a new front door service hole cover.

    NOTICE:
    1. When installing the service hole cover, pull the links and connectors through the service hole cover.
    2. There should be no wrinkles or folds after attaching the service hole cover.
    3. After attaching the service hole cover, check the sealing quality.




  1. Connect the 2 connectors.

  1. Attach the 9 clamps.

  1. Install the bolt as shown in the illustration.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



26. INSTALL SIDE AIRBAG SENSOR ASSEMBLY LH



  1. Check that the engine switch is off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.

  1. Install the side airbag sensor with the bolt.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

    NOTICE:
    1. If the side airbag sensor has been dropped, or there are any cracks, dents or other defects in the case, bracket or connector, replace it with a new one.
    2. When installing the side airbag sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

  1. Check that there is no looseness in the installation parts of the side airbag sensor.

  1. Connect the connector.
