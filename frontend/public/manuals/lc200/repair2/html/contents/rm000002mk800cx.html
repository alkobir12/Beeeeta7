REAR DOOR SPEAKER > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL REAR SPEAKER SET


  1. Temporarily install the speaker by attaching the claw of the speaker to the door panel.



  1. Install the speaker with the 3 screws.

    NOTICE:
    Do not touch the cone part of the speaker.

  1. Connect the connector.



2. INSTALL REAR DOOR TRIM BOARD SUB-ASSEMBLY

  1. Connect the connector.




  1. Connect the rear door lock remote control cable and rear door inside locking cable to the rear door inside handle sub-assembly.




  1. Attach the 4 claws and 9 clips to install the rear door trim board sub-assembly.

  1. Install the 3 screws.



3. INSTALL DOOR ASSIST GRIP COVER LH



  1. Attach the 9 claws to install the door assist grip cover to the door trim panel.



4. INSTALL REAR DOOR ARMREST BASE PANEL ASSEMBLY LH



  1. Connect the connector.

  1. Attach the 7 claws to install the rear door armrest base panel.



5. INSTALL REAR DOOR INSIDE HANDLE BEZEL LH



  1. Attach the 4 claws to install the bezel.



6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
