DTC    U0129    Lost Communication with Brake System Control Module

for Preparation Click here


DESCRIPTION

The combination meter communicates with the skid control ECU via the CAN line.

DTC Code
DTC Detection Condition
Trouble Area
U0129
When 15 seconds have elapsed after the engine is started and IG voltage is 10.5 V or more while no communication with the skid control ECU continues for 3 seconds or more (no communication with the ECM or skid control ECU continues for 60 seconds or more).
CAN communication system
