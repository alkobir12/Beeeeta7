FRONT AIRBAG SENSOR > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL FRONT AIRBAG SENSOR



  1. Check that the engine switch is off.

  1. Check that the cable is disconnected from the battery negative (-) terminal.

    CAUTION:
    Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to disable the SRS system.

  1. Connect the connector.

  1. Install the front airbag sensor with the nut.

    Torque:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }

    NOTICE:
    1. If the front airbag sensor has been dropped, or there are any cracks, dents or other defects in the case, bracket or connector, replace it with a new one.
    2. When installing the front airbag sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

  1. Check that there is no looseness in the installation parts of the front airbag sensor.



2. INSTALL HEADLIGHT ASSEMBLY

  1. Install the headlight assembly (Click here).



3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
