DTC    U0100/56    Lost Communication with ECM / PCM "A"

DTC    U0122/56    Lost Communication with Vehicle Dynamics Control Module

DTC    U0126/56    Lost Communication with Steering Angle Sensor Module

for Preparation Click here


DESCRIPTION

The steering control ECU receives signals from the skid control ECU, ECM and steering angle sensor via CAN communication. When DTCs indicating a CAN communication system malfunction are output, repair the CAN communication system first.

DTC Code
DTC Detection Condition
Trouble Area
U0100/56
The steering control ECU detects an error in reception (from ECM) via CAN communication.
  1. CAN communication system
  2. ECM
U0122/56
The steering control ECU detects an error in reception (from skid control ECU) via CAN communication.
  1. CAN communication system
  2. Skid control ECU
U0126/56
The steering control ECU detects an error in reception (from steering angle sensor) via CAN communication.
  1. CAN communication system
  2. Steering angle sensor
