FRONT POWER SEAT CONTROL SYSTEM DESCRIPTION
  1. The driver seat is equipped with slide, reclining, lifter, front vertical, and lumbar support adjustment functions.
  2. The passenger seat is equipped with slide, reclining, lifter, and front vertical adjustment functions.
  3. The memory call function uses the key ID code of the key to memorize and reproduce the appropriate driving position for each individual who possesses a master key or sub key.

FUNCTION OF MAIN COMPONENT
The following functions are available.

Component
Function
Seat slide motor
Receives signal from front power seat switch, and slides seat forward and rearward.
Seat reclining motor
Receives signal from front power seat switch, and tilts and reclines seat.
Seat front vertical motor
Receives signal from front power seat switch, and raises and lowers front of seat cushion.
Seat lifter motor
Receives signal from front power seat switch, and raises and lowers seat cushion.
Lumbar support adjuster motor
Activated based on signal from lumbar support switch. Adjusts lumbar support.
Seat position sensor
Is built into each seat adjuster and sends position data to front power seat switch so that it can detect seat positions at all times.
Seat control switch
Based on switches operated, seat adjuster signals are input into position control ECU and seat is adjusted accordingly.
Seat memory switch
When seat memory SET switch and seat memory switch are pressed simultaneously, signal is input to outer mirror control ECU and seat position is recorded.
Then, when seat memory switch is pressed, signal is input to outer mirror control ECU and seat position changes according to memory.

SYSTEM OPERATION
The front power seat functions which can be adjusted with power seat motors and/or memorized are shown in the chart below.
For the driver side memory function, the seat memory switch operation is first transferred from the outer mirror control ECU to the position control ECU and switch via the CAN communication line. Then, either the seat position is stored in memory or a previously stored seat position is recalled.
