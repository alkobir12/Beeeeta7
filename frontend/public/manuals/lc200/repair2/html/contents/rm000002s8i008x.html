DTC    B2325    LIN Communication Bus Malfunction

for Preparation Click here


DESCRIPTION

The main body ECU (cowl side junction block LH) intermittently monitors the LIN communication bus between the components related to the door, double lock control relay*2 and sliding roof*1. DTC B2325 is stored when a malfunction in the LIN communication bus between the components related to the doors, double lock control relay*2 and sliding roof*1 is detected consecutively 3 times.

HINT:
*1: w/ Sliding Roof System
*2: w/ Double Locking System


DTC Code
DTC Detection Condition
Trouble Area
B2325
The main body ECU (cowl side junction block LH) detects a malfunction in the LIN communication bus between components related to the doors and sliding roof consecutively 3 times.
  1. Master switch
  2. Front power window regulator motor LH
  3. Front power window regulator motor RH
  4. Rear power window regulator motor LH
  5. Rear power window regulator motor RH
  6. Sliding roof ECU*1
  7. Double lock door control relay*2
  8. Main body ECU (cowl side junction block LH)
  9. Harness or connector
