DTC    P0575    Cruise Control Input Circuit

DTC    P0607    Control Module Performance

for Preparation Click here


DESCRIPTION

This DTC indicates the internal abnormalities of the ECM.

DTC Code
DTC Detection Condition
Trouble Area
P0575
When either of the following conditions is met:
  1. STP signals input to the ECM supervisory CPU and control ECU are different for 0.15 seconds or more.
  2. 0.4 seconds have passed after cruise cancel input signal (STP input) is input to the ECM.
ECM (for 2UZ-FE, 1GR-FE)
P0607
When the cruise control main switch is turned off, the ECM recognizes that the cruise control system is operating.
ECM (for 1VD-FTV)

HINT:
The ECM receives signals from each sensor to control all functions of the cruise control system. When this trouble code is stored, fail-safe remains on until the engine switch is turned off.
