DTC    B279A    Theft Deterrent System Communication Line High Fixation

for Preparation Click here


DESCRIPTION

If the communication line (EFIO-IMI) to the ID code box (immobiliser code ECU) is stuck on HI output, the ECM outputs this DTC.

DTC Code
DTC Detection Condition
Trouble Area
B279A
When the communication line (EFIO-IMI) between the ECM and the ID code box (immobiliser code ECU) is stuck on HI output.
  1. Harness or connector
  2. ID code box (immobiliser code ECU)
  3. ECM
