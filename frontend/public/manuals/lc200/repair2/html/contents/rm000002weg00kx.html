DESCRIPTION

The entry and start system uses the wireless door lock buzzer to perform various vehicle exterior warnings. When the conditions of each warning are met, the certification ECU (smart key ECU assembly) sends a buzzer signal to the wireless buzzer, and the wireless door lock buzzer sounds*.

HINT:
*: For Europe and China, the wireless door lock buzzer does not sound.

NOTICE:
