LIGHTING SYSTEM > Headlight (HI-BEAM) Circuit

for Preparation Click here


DESCRIPTION

The main body ECU receives a headlight hi switch information signal from the light control switch, and illuminates the headlight hi beam.

7.CHECK HEADLIGHT (HI BEAM)
