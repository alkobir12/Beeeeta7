DTC    B1244    Light Sensor Circuit Malfunction

for Preparation Click here


DESCRIPTION

This DTC is stored when a failure of the automatic light control sensor circuit is detected.

DTC Code
DTC Detection Condition
Trouble Area
B1244
When either condition below is met:
  1. Malfunction of the automatic light control sensor.
  2. Open or short in the light sensor circuit.
  1. Automatic light control sensor
  2. Harness or connector
  3. Main body ECU
