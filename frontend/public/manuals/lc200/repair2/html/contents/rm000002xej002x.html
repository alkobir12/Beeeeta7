for Preparation Click here



1. INSPECT SEAT MEMORY SWITCH



  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Switch Condition
    		Specified Condition
    4 (M1) - 6 (E)
    		1 switch pressed
    		Below 1 Ω
    3 (M2) - 6 (E)
    		2 switch pressed
    2 (M3) - 6 (E)
    		3 switch pressed
    5 (MRY) - 6 (E)
    		SET switch pressed

    If the result is not as specified, replace the seat memory switch.
