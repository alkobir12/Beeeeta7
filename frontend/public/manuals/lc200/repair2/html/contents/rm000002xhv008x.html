DTC    B2785    Communication Malfunction between ECUs Connected by LIN

for Preparation Click here


DESCRIPTION

The certification ECU (smart key ECU assembly) intermittently monitors the LIN communication bus between the components related to certification. DTC B2785 is output when a malfunction in the LIN communication bus between the components related to certification is detected continuously 3 times.

DTC Code
DTC Detection Condition
Trouble Area
B2785
The certification ECU (smart key ECU assembly) detects a malfunction in the LIN communication bus between components related to certification continuously 3 times.
  1. Certification ECU (smart key ECU assembly)
  2. Main body ECU (cowl side junction block LH)
  3. ID code box (immobiliser code ECU)
  4. Steering lock ECU
  5. Harness or connector

When using the intelligent tester with the engine switch off to troubleshoot:
Connect intelligent tester to the vehicle, and turn a courtesy switch on and off at 1.5 second intervals until communication between the intelligent tester and vehicle begins.
