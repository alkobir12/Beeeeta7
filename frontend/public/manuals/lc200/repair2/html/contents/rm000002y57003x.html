1. INSTALL VENTILATION VALVE SUB-ASSEMBLY



  1. Apply adhesive to 2 or 3 threads of the ventilation valve.

    Adhesive:
    Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent




  1. Install the ventilation valve to the cylinder head cover sub-assembly LH.

    Torque:
    27 N*m{ 275 kgf*cm , 20 ft.*lbf }

    HINT:
    After applying the specified torque, rotate the ventilation valve clockwise until the port facing in the direction indicated in the illustration.



2. INSTALL VENTILATION VALVE COVER

  1. Install the ventilation valve cover to the ventilation valve.



3. CONNECT VENTILATION HOSE

  1. Connect the ventilation hose to the ventilation valve.



4. INSTALL V-BANK COVER SUB-ASSEMBLY



  1. Attach the 2 V-bank cover hooks to the bracket.

  1. Install the V-bank cover with the 2 nuts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }
