CYLINDER HEAD > REASSEMBLY

for Preparation Click here



1. INSTALL STUD BOLT

NOTICE:
If a stud bolt is deformed or the threads are damaged, replace it.



  1. Using an E10 "TORX" socket wrench, install the stud bolts A, B and C.

    Torque:
    for stud bolt A, C:
    9.0 N*m{ 92 kgf*cm , 80 in.*lbf }
    for stud bolt B:
    15 N*m{ 153 kgf*cm , 11 ft.*lbf }






2. INSTALL NO. 1 STRAIGHT SCREW PLUG



  1. Using a 14 mm hexagon wrench, install 2 new gaskets and the 2 straight screw plugs.

    Torque:
    85 N*m{ 868 kgf*cm , 63 ft.*lbf }



3. INSTALL VALVE SPRING SEAT

  1. Install the valve spring seats to the cylinder head.



4. INSTALL VALVE STEM OIL SEAL



  1. Apply a light coat of engine oil to a new stem oil seal.

    NOTICE:
    Pay close attention when installing the intake and exhaust oil seals. For example, installing the intake oil seal into the exhaust or installing the exhaust oil seal to the intake can cause installation problems later.

    HINT:
    The intake valve oil seal is gray/brown and the exhaust valve oil seal is black/silver.




  1. Using SST, push in the oil seal.

    SST
    09201-41020  

    NOTICE:
    Failure to use SST will cause the seal to be damaged or improperly seated.



5. INSTALL INTAKE VALVE



  1. Apply plenty of engine oil to the tip area of the intake valve shown in the illustration.

  1. Install the valve, inner compression spring and spring retainer to the cylinder head.

    NOTICE:
    Install the same parts in the same combination to their original locations.




  1. Using SST, compress the compression spring and place the 2 spring retainer locks around the valve stem.

    SST
    09202-70020   (09202-00010, 09202-01010, 09202-01020)




  1. Using a plastic-faced hammer and 5 mm pin punch, lightly tap the valve stem tip to ensure a proper fit.

    NOTICE:
    Do not damage the valve stem tip.



6. INSTALL EXHAUST VALVE



  1. Apply plenty of engine oil to the tip area of the exhaust valve shown in the illustration.

  1. Install the valve, inner compression spring and spring retainer to the cylinder head.

    NOTICE:
    Install the same parts in the same combination to their original locations.




  1. Using SST, compress the compression spring and place the 2 spring retainer locks around the valve stem.

    SST
    09202-70020   (09202-00010, 09202-01010, 09202-01020)




  1. Using a plastic-faced hammer and 5 mm pin punch, lightly tap the valve stem tip to ensure a proper fit.

    NOTICE:
    Do not damage the valve stem tip.
