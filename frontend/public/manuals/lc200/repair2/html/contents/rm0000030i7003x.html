DTC    U0100    Lost Communication with ECM / PCM "A"

for Preparation Click here


DESCRIPTION

The engine control unit and the transmission control unit are located inside the ECM. The engine control unit intercommunicates with the transmission control unit with the Controller Area Network (CAN). If there is a problem in this intercommunication, the ECM stores a DTC.

DTC Code
DTC Detection Condition
Trouble Area
U0100
No communication with the ECM continues.
ECM

1.CHECK DTC OUTPUT (IN ADDITION TO DTC P0100)

  1. Connect the intelligent tester to the DLC3.

  1. Turn the engine switch on (IG).

  1. Turn the intelligent tester on.

  1. Enter the following menus: Powertrain / ECT / Trouble Codes.

  1. Read the DTCs using the tester.
