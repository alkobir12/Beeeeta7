REAR NO. 2 SEAT ASSEMBLY (for Face to Face Seat Type) > REASSEMBLY

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL REAR SIDE SEATBACK PAD LH



  1. Using hog ring pliers, install the seatback pad with new hog rings.



2. INSTALL REAR SIDE SEAT BAND SUB-ASSEMBLY



  1. Install the seat band with the screw.



3. INSTALL REAR SIDE SEATBACK COVER SUB-ASSEMBLY LH



  1. Install the seatback cover.

  1. Pull out the seat band.

  1. Using hog ring pliers, install new hog rings to the seatback cover.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



4. INSTALL REAR SIDE SEAT CUSHION PAD LH


5. INSTALL REAR SIDE SEAT CUSHION COVER SUB-ASSEMBLY LH

  1. Install the seat cushion cover.




  1. Close the 2 fasteners, and then close the cushion cover.




  1. Using hog ring pliers, install new hog rings to the seat cushion cover.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.



6. INSTALL REAR SEAT CUSHION LEG SUB-ASSEMBLY

  1. Install the spring to the seat cushion leg.

  1. Install the seat cushion leg.




  1. Install the 2 seat leg plates.




  1. Install the 2 hinge pins and 2 new E-rings.
