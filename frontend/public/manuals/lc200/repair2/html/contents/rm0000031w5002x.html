REAR CRANKSHAFT OIL SEAL > INSTALLATION

for Preparation Click here



1. INSTALL REAR CRANKSHAFT OIL SEAL



  1. Using SST and a hammer, tap in a new oil seal as shown in the illustration.

    SST
    09223-56010  

    Standard depth A:
    2.7 to 3.7 mm (0.106 to 0.147 in.)

    NOTICE:
    1. Keep the lip free from foreign matter.
    2. Do not tap on the seal at an angle.
    3. Make sure that the lip of the oil seal is properly installed.



2. INSTALL DRIVE PLATE AND RING GEAR SUB-ASSEMBLY (for Automatic Transmission)



  1. Install the rear crankshaft balancer weight labeled C, ring gear labeled B and rear drive plate spacer labeled A with 8 new bolts.




  1. Using a wrench, hold the crankshaft.




  1. Uniformly install and tighten the 8 bolts in the sequence shown in the illustration.

    Torque:
    182 N*m{ 1856 kgf*cm , 134 ft.*lbf }



3. INSTALL FLYWHEEL SUB-ASSEMBLY (for Manual Transmission)



  1. Temporarily install the flywheel with 8 new bolts.

    NOTICE:
    1. Align the crankshaft knock pin and flywheel knock pin hole.
    2. Do not strike or damage the flywheel installation bolts. Be sure to handle them carefully.
    3. Make sure there is no oil on the bolts.




  1. Using a wrench, hold the crankshaft.

  1. Uniformly install and tighten the 8 bolts in the sequence shown in the illustration.

    Torque:
    182 N*m{ 1856 kgf*cm , 134 ft.*lbf }



4. INSTALL CLUTCH DISC ASSEMBLY (for Manual Transmission)



  1. Insert SST into the clutch disc, then insert the clutch disc into the flywheel.

    SST
    09301-00120  

    NOTICE:
    Take care not to insert the clutch disc in the wrong direction.



5. INSTALL CLUTCH COVER ASSEMBLY (for Manual Transmission)



  1. Align the matchmark on the clutch cover with the one on the flywheel.

  1. In the order shown in the illustration, temporarily install the 8 bolts starting from the bolt located near the knock pin on the top.

  1. Check that the disc is in the center by lightly moving SST up and down, and left and right.

    SST
    09301-00120  

  1. Evenly tighten the bolts by following the order shown in the illustration.

    Torque:
    39 N*m{ 400 kgf*cm , 29 ft.*lbf }



6. INSTALL AUTOMATIC TRANSMISSION ASSEMBLY

  1. Install the automatic transmission assembly (Click here).



7. INSTALL MANUAL TRANSMISSION UNIT ASSEMBLY

  1. Install the manual transmission unit assembly (Click here).



8. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).

  1. Connect the cables to the negative (-) main battery and sub-battery terminals.
