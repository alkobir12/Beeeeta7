WINCH UNIT > INSTALLATION

for Preparation Click here



1. INSTALL WINCH ASSEMBLY



  1. Using a crane or equivalent, install the winch assembly.

    CAUTION:
    Be careful as the winch assembly is very heavy.




  1. Connect the wire with the nut.

    Torque:
    9.3 N*m{ 95 kgf*cm , 83 in.*lbf }

  1. Connect the connector.




  1. Move the cover in the direction indicated by the arrow shown in the illustration and attach the 2 claws.




  1. Install the mounting bracket with the 9 bolts.

    Torque:
    for bolt A:
    33 N*m{ 336 kgf*cm , 24 ft.*lbf }
    for bolt B:
    19 N*m{ 194 kgf*cm , 15 ft.*lbf }



2. INSTALL WINCH CONTROL WIRE



  1. Install the winch control wire with the 2 nuts.

    Torque:
    5 N*m{ 51 kgf*cm , 45 in.*lbf }



3. INSTALL TRANSMISSION OIL COOLER AIR DUCT (w/ Oil Cooler)



  1. Install the oil cooler air duct with the 4 bolts.

    Torque:
    4.9 N*m{ 50 kgf*cm , 43 in.*lbf }



4. INSTALL RADIATOR SIDE DEFLECTOR RH (w/o Oil Cooler)



  1. Install the deflector with the 4 clips.



5. INSTALL RADIATOR SIDE DEFLECTOR LH



  1. Install the side deflector with the 4 clips.



6. INSTALL FRONT UPPER CENTER BUMPER RETAINER



  1. Install the bumper retainer with the 3 bolts.



7. INSTALL HEADLIGHT ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL HEADLIGHT ASSEMBLY LH

  1. for Standard:
    Install the headlight assembly LH (Click here).

  1. for HID headlight:
    Install the headlight assembly LH (Click here).



9. INSTALL FRONT BUMPER EXTENSION RH

HINT:
Use the same procedures described for the LH side.



10. INSTALL FRONT BUMPER EXTENSION LH



  1. Install the bumper extension with the 3 bolts.



11. INSTALL FRONT BUMPER COVER

  1. w/o TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Connect the winch control wire connector and attach the 10 claws to install the bumper cover.

  1. w/ TOYOTA Parking Assist-sensor System or w/ Fog Light:
    Connect the No. 4 engine room wire connector and winch control wire connector, and attach the 10 claws to install the bumper cover.



  1. Install the 3 clips, 4 screws and 4 bolts.





  1. Using a T30 "TORX" socket, install the 6 screws.





12. INSTALL RADIATOR GRILLE ASSEMBLY



  1. Attach the 2 clips and 8 claws to install the radiator grille.

  1. Install the 3 screws.



13. INSTALL FRONT BUMPER WINCH COVER SUB-ASSEMBLY


14. INSTALL UPPER RADIATOR SUPPORT SEAL

  1. for Gasoline Engine:
    Install the upper radiator support seal (Click here).

  1. for Diesel Engine:
    Install the upper radiator support seal (Click here).



15. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



16. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.



17. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
