STARTER > INSTALLATION

for Preparation Click here



1. INSTALL STARTER ASSEMBLY



  1. Install the starter with the 2 bolts.

    Torque:
    80 N*m{ 816 kgf*cm , 59 ft.*lbf }




  1. Connect the 2 starter hoses.




  1. Attach the harness clamp and connect the wire harness.

  1. Connectl the starter wire with the nut.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }

  1. Connect the starter connector.



2. INSTALL FUEL COOLER ASSEMBLY

  1. Install the fuel cooler assembly (Click here).



3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
