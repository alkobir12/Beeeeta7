1. INSTALL RELEASE CYLINDER BLEEDER PLUG

  1. Install the bleeder plug to the cylinder body.

    Torque:
    11 N*m{ 110 kgf*cm , 8 ft.*lbf }



2. INSTALL CLUTCH RELEASE CYLINDER KIT

  1. Install 2 new cylinder cups onto a new piston.

  1. Install a new spring into the cylinder body.




  1. Apply lithium soap base glycol grease to the portions indicated by the arrows in the illustration.

  1. Install the piston into the cylinder body.

    NOTICE:
    Do not damage the inside of the cylinder body.

  1. Install the push rod into the cylinder body.

  1. Install a new boot onto the cylinder body.
