REAR CENTER SEAT OUTER BELT ASSEMBLY (for Rear No. 1 Seat) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LHD and RHD.
  2. The procedures listed below are for the LHD.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL NO. 1 SEAT 3 POINT TYPE BELT ASSEMBLY LH



  1. Install the belt with the nut labeled A.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. Install the belt sensor with the 3 nuts labeled B.



2. INSTALL REAR SEAT SHOULDER BELT HOLE COVER



  1. Install the seat belt as shown in the illustration.




  1. Attach the 3 claws to install the shoulder belt hole cover.



3. INSTALL REAR LOWER SEATBACK COVER SUB-ASSEMBLY LH



  1. Attach the 4 claws to install the cover.

  1. Install the 4 screws.



4. INSTALL REAR SEATBACK HINGE COVER LH



  1. Attach the claw to install the cover.

  1. Install the screw.



5. INSTALL SEATBACK COVER WITH PAD

  1. Install the seatback cover with pad.




  1. w/ Center Armrest:
    Pull out the seat belt.




  1. w/o Center Armrest:
    Pull out the seat belt.

  1. w/ Rear Seat Side Airbag:
    Pass the side airbag wire harness through the hole in the seatback.



  1. w/ Seat Heater System:
    Pass the seatback heater wire harness through the hole in the seatback.







    2. Connect the seatback heater wire harness and install a new cable tie.




  1. w/ Rear Seat Side Airbag:
    Install the seatback cover bracket to the seat frame with the cap nut.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

    NOTICE:
    After the seatback trim cover is assembled, make sure the side airbag strap is not twisted.




  1. w/ Center Armrest:
    Using hog ring pliers, install new hog rings to the seatback frame.



  1. w/o Center Armrest:




    1. Using hog ring pliers, install new hog rings to the seatback frame.

    2. Attach the hook.



6. INSTALL REAR SEAT BELT HOLE COVER LH



  1. Attach the 4 claws to install the cover.

  1. Install the screw.



7. INSTALL SHOULDER BELT ANCHOR COVER



  1. Attach the 2 claws to install the cover.



8. INSTALL REAR NO. 1 SEAT HEADREST SUPPORT ASSEMBLY



  1. w/ Center Armrest:
    Attach the 4 claws to install the 2 supports.




  1. w/o Center Armrest:
    Attach the 8 claws to install the 4 supports.



9. INSTALL REAR SEAT HEADREST ASSEMBLY


10. INSTALL REAR SEATBACK BOARD SUB-ASSEMBLY LH



  1. w/ Center Armrest:

    1. Push the board down to attach the 2 claws on the bottom.

    2. Attach the 2 claws on the top of the board to install it.




  1. w/o Center Armrest:

    1. Push the board down to attach the 3 claws on the bottom.

    2. Attach the 3 claws on the top of the board to install it.



11. INSTALL REAR SEATBACK COVER



  1. Attach the 4 claws to install the cover.



12. INSTALL SEAT CUSHION COVER WITH PAD

  1. Install the seat cushion cover with pad.

  1. w/ Rear Seat Side Airbag:
    Pass the side airbag wire harness through the hole in the seat cushion.



  1. w/ Seat Heater System:




    1. Pass the seatback heater wire harness through the hole in the seat cushion.




    2. Connect the 2 seat heater connectors.

  1. w/ Rear Seat Side Airbag:
    Attach the side airbag wire harness clamps.



13. INSTALL REAR NO. 1 SEAT INNER BELT ASSEMBLY LH



  1. Install the belt with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the vehicle body.

    HINT:
    The No. 1 seat 3 point type belt anchor is fixed with the same bolt as the rear No. 1 seat inner belt LH. Therefore, connect it when installing the rear No. 1 seat inner belt LH.



14. INSTALL REAR SEAT UNDER TRAY COVER LH



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



15. INSTALL REAR SEAT CUSHION COVER RH



  1. Attach the 2 claws to install the cover.

  1. Install the 4 screws.



16. INSTALL REAR UNDER SIDE COVER LH



  1. Attach the 2 claws and 2 clips to install the cover.

  1. Install the 5 screws.




  1. Attach the 10 claws.



17. INSTALL REAR SEATBACK STAY COVER LH



  1. Attach the 2 claws to install the cover.

  1. Install the screw.



18. INSTALL SEAT BELT ANCHOR COVER CAP



  1. Install the anchor cover cap with the screw.




  1. Attach the claw to close the cap.



19. INSTALL REAR NO. 1 SEAT HINGE SUB-ASSEMBLY RH



  1. Install the hinge with the 2 nuts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



20. INSTALL REAR NO. 1 SEAT HINGE SUB-ASSEMBLY LH



  1. Attach the cable clamp to connect the cable.




  1. Install the hinge with the 2 nuts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. w/ Rear Seat Side Airbag:
    Attach the wire harness clamp.

  1. w/ Seat Heater System:
    Attach the wire harness clamp.



21. INSTALL REAR NO. 2 SEAT PROTECTOR

  1. Install the wire harness, and attach 2 claws to close the protector.




  1. Attach the claw to install the protector to the seat hinge.

  1. Install the clip.




  1. w/ Rear Seat Side Airbag:
    Attach the claw to install the wire harness connector.

  1. w/ Seat Heater System:
    Attach the claw to install the wire harness connector.



22. INSTALL REAR NO. 2 SEAT LEG SIDE COVER



  1. Pass the fold seat stopper band through the seat leg side cover and attach it to the seat cushion frame with the bolt.




  1. Attach the 4 claws to install the seat leg side cover.

  1. Install the 4 screws.



23. INSTALL UPPER SEAT TRACK RAIL COVER RH



  1. Attach the 2 claws to install the cover.



24. INSTALL UPPER SEAT TRACK RAIL COVER LH



  1. Attach the 2 claws to install the cover.



25. INSTALL REAR NO. 1 SEAT RECLINING COVER RH



  1. Attach the 4 claws to install the cover.

  1. Install the 2 screws.



26. INSTALL REAR NO. 1 SEAT RECLINING COVER LH



  1. Attach the 3 claws in the order shown in the illustration to install the cover.

  1. Install the 2 screws.



27. INSTALL RECLINING ADJUSTER RELEASE HANDLE LH



  1. Install the release handle with the screw.



28. INSTALL SEAT ADJUSTER BOLT COVER



  1. Attach the 2 claws to install the cover.



29. INSTALL REAR NO. 1 SEAT ASSEMBLY LH

  1. Install the rear No. 1 seat assembly (Click here).
