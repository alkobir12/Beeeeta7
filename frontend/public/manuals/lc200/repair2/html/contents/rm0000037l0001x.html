TOYOTA PARKING ASSIST-SENSOR SYSTEM > Clearance Sonar Main Switch Circuit

for Preparation Click here


DESCRIPTION

When the clearance sonar main switch turns on, the ON signal is input into the parking assist ECU*1 or clearance warning ECU*2.

HINT:
*1: w/ Parking Assist Monitor System
*2: w/o Parking Assist Monitor System
