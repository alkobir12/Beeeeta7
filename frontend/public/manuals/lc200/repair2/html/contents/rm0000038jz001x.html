FRONT BUMPER (for Standard) > REASSEMBLY

for Preparation Click here


HINT:
When installing the front bumper protector, heat the front bumper surface using a heat light.

Standard Heating Temperature:
Item
Temperature
Front Bumper
20 to 30°C (68 to 86°F)

NOTICE:
Do not heat the front bumper excessively.



1. INSTALL FRONT NO. 2 BUMPER PROTECTOR

  1. Clean the front bumper surface.

    1. Using a heat light, heat the front bumper surface.

    2. Remove the double-sided tape from the front bumper.

    3. Wipe off any tape adhesive residue with cleaner.




  1. Install a new bumper protector.

    1. Remove the peeling paper from the face of 2 new bumper protectors.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    2. Install the 2 bumper protectors as shown in the illustration.



2. INSTALL FRONT BUMPER PROTECTOR

  1. Clean the front bumper surface.

    1. Using a heat light, heat the front bumper surface.

    2. Remove the double-sided tape from the front bumper.

    3. Wipe off any tape adhesive residue with cleaner.




  1. Install a new bumper protector.

    1. Remove the peeling paper from the face of 2 new bumper protectors.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    2. Install the 2 bumper protectors as shown in the illustration.



3. INSTALL FRONT BUMPER GUARD (w/ Garnish)



  1. Attach the 6 clips to install the bumper guard.

  1. Install the 4 nuts.



4. INSTALL FRONT BUMPER EXTENSION MOUNTING BRACKET



  1. for Type A:
    Install the front bumper extension mounting bracket.

    1. Install the bracket with the 2 bolts.




  1. for Type B:
    Install the front bumper extension mounting bracket.

    1. Attach the 2 claws to install the bracket.

    2. Install the 2 bolts.



5. INSTALL HEADLIGHT WASHER ACTUATOR SUB-ASSEMBLY LH (w/ Headlight Cleaner System)

HINT:
Use the same procedures for the RH side and the LH side.

  1. Attach the 2 claws.




  1. Install the headlight washer actuator sub-assembly with the bolt.

    Torque:
    1.1 N*m{ 11 kgf*cm , 10 in.*lbf }




  1. Connect the headlight washer hose.



6. INSTALL HEADLIGHT WASHER ACTUATOR SUB-ASSEMBLY RH (w/ Headlight Cleaner System)

HINT:
Use the same procedures described for the LH side.



7. INSTALL TYPE 1 HEADLIGHT WASHER NOZZLE SUB-ASSEMBLY LH (w/ Headlight Cleaner System)



  1. Attach the 2 claws to install the headlight washer nozzle.




  1. Return the headlight washer nozzle to its original position.



8. INSTALL TYPE 1 HEADLIGHT WASHER NOZZLE SUB-ASSEMBLY RH (w/ Headlight Cleaner System)

HINT:
Use the same procedures described for the LH side.



9. INSTALL LOWER RADIATOR GRILLE LH



  1. Attach the 7 claws to install the lower radiator grille.

  1. w/ Headlight Cleaner System:
    Attach the 2 headlight cleaner hose clamps.



10. INSTALL LOWER RADIATOR GRILLE RH

HINT:
Use the same procedures described for the LH side.



11. INSTALL FRONT BUMPER HOLE COVER LH (w/o Fog Light)



  1. Install the bumper hole cover with the 3 screws.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



12. INSTALL FRONT BUMPER HOLE COVER RH (w/o Fog Light)

HINT:
Use the same procedures described for the LH side.



13. INSTALL FOG LIGHT ASSEMBLY LH (w/ Fog Light)



  1. Install the fog light with the 3 bolts.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Attach the 2 clamps.



14. INSTALL FOG LIGHT ASSEMBLY RH (w/ Fog Light)

HINT:
Use the same procedures described for the LH side.



15. INSTALL NO. 1 ULTRASONIC SENSOR RETAINER (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 1 ultrasonic sensor retainer on the other side.

  1. Align the keyhole and protrusion as shown in the illustration.

  1. Install the ultrasonic sensor retainer to the front bumper cover.

    NOTICE:
    Do not damage the bumper with the protrusion when installing the retainer.



16. INSTALL NO. 1 ULTRASONIC SENSOR (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 1 ultrasonic sensor on the other side.

  1. Attach the 2 claws to install the ultrasonic sensor.

  1. Connect the connector.



17. INSTALL NO. 4 ENGINE ROOM WIRE


  1. w/o TOYOTA Parking Assist-sensor System, w/ Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 2 connectors.





  1. w/ TOYOTA Parking Assist-sensor System, w/ Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 4 connectors.





  1. w/ TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 2 connectors.
