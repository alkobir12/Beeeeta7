for Preparation Click here


HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).


HINT:
When installing the front bumper protector, heat the front bumper surface using a heat light.

Standard Heating Temperature:
Item
Temperature
Front Bumper
20 to 30°C (68 to 86°F)

NOTICE:
Do not heat the front bumper excessively.



1. INSTALL WINCH CONTROL WIRE



  1. Install the winch control wire with the 2 nuts.

    Torque:
    5 N*m{ 51 kgf*cm , 45 in.*lbf }



2. INSTALL FRONT LICENSE PLATE BRACKET



  1. Install the license plate bracket with the 2 nuts.



3. INSTALL FRONT NO. 2 BUMPER PROTECTOR

  1. Clean the front bumper surface.

    1. Using a heat light, heat the front bumper surface.

    2. Remove the double-sided tape from the front bumper.

    3. Wipe off any tape adhesive residue with cleaner.




  1. Install a new bumper protector.

    1. Remove the peeling paper from the face of a new bumper protectors.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    2. Install the 2 bumper protectors as shown in the illustration.



4. INSTALL FRONT BUMPER PROTECTOR

  1. Clean the front bumper surface.

    1. Using a heat light, heat the front bumper surface.

    2. Remove the double-sided tape from the front bumper.

    3. Wipe off any tape adhesive residue with cleaner.




  1. Install a new bumper protector.

    1. Remove the peeling paper from the face of a new bumper protectors.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.

    2. Install the 2 bumper protectors as shown in the illustration.



5. INSTALL LOWER RADIATOR GRILLE LH



  1. Attach the 7 claws to install the lower radiator grille.



6. INSTALL LOWER RADIATOR GRILLE RH

HINT:
Use the same procedures described for the LH side.



7. INSTALL FRONT BUMPER HOLE COVER LH (w/o Fog Light)



  1. Install the bumper hole cover with the 3 screws.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



8. INSTALL FRONT BUMPER HOLE COVER RH (w/o Fog Light)

HINT:
Use the same procedures described for the LH side.



9. INSTALL FOG LIGHT ASSEMBLY LH (w/ Fog Light)



  1. Install the fog light with the 3 bolts.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Attach the 2 clamps.



10. INSTALL FOG LIGHT ASSEMBLY RH (w/ Fog Light)

HINT:
Use the same procedures described for the LH side.



11. INSTALL NO. 1 ULTRASONIC SENSOR RETAINER (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 1 ultrasonic sensor retainer on the other side.

  1. Align the keyhole and protrusion as shown in the illustration.

  1. Install the ultrasonic sensor retainer to the front bumper cover.

    NOTICE:
    Do not damage the bumper with the protrusion when installing the retainer.



12. INSTALL NO. 1 ULTRASONIC SENSOR (w/ TOYOTA Parking Assist-sensor System)



HINT:
Use the same procedure to install the No. 1 ultrasonic sensor on the other side.

  1. Attach the 2 claws to install the ultrasonic sensor.

  1. Connect the connector.



13. INSTALL NO. 4 ENGINE ROOM WIRE


  1. w/o TOYOTA Parking Assist-sensor System, w/ Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 2 connectors.





  1. w/ TOYOTA Parking Assist-sensor System, w/ Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 4 connectors.





  1. w/ TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Install the No. 4 engine room wire.

    1. Attach the 9 clamps to install the engine room wire.



    2. Connect the 2 connectors.
