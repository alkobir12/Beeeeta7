REAR BUMPER (w/ Towing Hitch) > INSTALLATION

for Preparation Click here


HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL NO. 2 LUGGAGE COMPARTMENT SIDE COVER PROTECTOR



  1. Install the protector with 2 new grommets.

  1. Install the 2 screws.



2. INSTALL NO. 1 LUGGAGE COMPARTMENT SIDE COVER PROTECTOR

HINT:
Use the same procedures described for the LH side.



3. INSTALL REAR BUMPER ARM BRACKET LH



  1. Install the bumper arm bracket with the 2 bolts.

  1. Connect the connector.



4. INSTALL REAR BUMPER ARM BRACKET



HINT:
Use the same procedure to install the bumper arm bracket on the other side.

  1. Install the bumper arm bracket with the bolt.



5. INSTALL REAR NO. 2 BUMPER REINFORCEMENT



  1. Install the bumper reinforcement with the 2 bolts.



6. INSTALL REAR BUMPER SIDE SUPPORT LH



  1. Attach the 6 claws to install the bumper side support.

  1. Install the 3 screws.



7. INSTALL REAR BUMPER SIDE SUPPORT RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL UPPER REAR BUMPER RETAINER LH



  1. Attach the 2 clips to install the bumper retainer.



9. INSTALL UPPER REAR BUMPER RETAINER RH

HINT:
Use the same procedures described for the LH side.



10. INSTALL REAR COMBINATION LIGHT ASSEMBLY LH



  1. Connect the connector.

  1. Attach the 2 clips to install the rear combination light.

  1. Install the 2 bolts.



11. INSTALL REAR COMBINATION LIGHT ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



12. INSTALL REAR BUMPER COVER

  1. w/o TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Attach the 14 claws to install the bumper cover.

  1. w/ TOYOTA Parking Assist-sensor System or w/ Fog Light:
    Connect the No. 2 frame wire connector and attach the 14 claws to install the bumper cover.



  1. Install the 7 bolts, 6 screws and 2 clips.





  1. Open the tail gate and install the 4 clips.



  1. Close the tail gate.



13. INSTALL REAR NO. 1 BUMPER PLATE


  1. Attach the 20 claws to install the bumper plate.





14. INSTALL REAR QUARTER PANEL MUDGUARD LH



  1. Install the mudguard with the clip.

  1. Using a T30 "TORX" socket, install the 6 screws.



15. INSTALL REAR QUARTER PANEL MUDGUARD RH



  1. Install the mudguard with the clip.

  1. Using a T30 "TORX" socket, install the 7 screws.
