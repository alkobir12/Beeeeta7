FRONT DOOR BELT MOULDING > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.



1. INSTALL FRONT DOOR BELT MOULDING ASSEMBLY LH



  1. Attach the claw to install the belt moulding.



2. INSTALL FRONT DOOR GLASS RUN LH



  1. Install the front door glass run.



3. INSTALL FRONT DOOR GLASS SUB-ASSEMBLY LH



  1. Insert the door glass into the door panel along the glass run as indicated by the arrows in the illustration.

    NOTICE:
    Be careful not to damage the glass.




  1. Install the door glass to the window regulator with the 2 bolts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



4. INSTALL FRONT INNER DOOR GLASS WEATHERSTRIP LH

  1. Install the front inner door glass weatherstrip LH.



5. INSTALL FRONT DOOR SERVICE HOLE COVER LH



  1. Apply butyl tape to the door.

  1. Pass the front door lock remote control cable and front door inside locking cable through a new front door service hole cover.

    NOTICE:
    1. When installing the service hole cover, pull the links and connectors through the service hole cover.
    2. There should be no wrinkles or folds after attaching the service hole cover.
    3. After attaching the service hole cover, check the sealing quality.




  1. Connect the 2 connectors.

  1. Attach the 9 clamps.

  1. Install the bolt as shown in the illustration.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



6. INSTALL OUTER REAR VIEW MIRROR ASSEMBLY LH



  1. Attach the claw and Install the mirror with the 3 nuts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Attach the clamp.

  1. Connect the connector labeled A.



7. INSTALL FRONT DOOR TRIM BOARD SUB-ASSEMBLY LH

  1. Connect the connector.




  1. Connect the front door lock remote control cable and front door inside locking cable to the front door inside handle sub-assembly.




  1. Attach the 4 claws and 13 clips to install the front door trim board sub-assembly.

  1. Install the 3 screws.



8. INSTALL DOOR ASSIST GRIP COVER LH



  1. Attach the 8 claws to install the door assist grip cover to the door trim panel.



9. INSTALL FRONT DOOR ARMREST BASE PANEL ASSEMBLY LH

  1. Connect the connector.




  1. Attach the 5 claws and install the front door armrest base panel.



10. INSTALL FRONT DOOR INSIDE HANDLE BEZEL LH



  1. Attach the clip and claw, and install the front door lower frame bracket garnish.



11. INSTALL FRONT LOWER DOOR FRAME BRACKET GARNISH LH



  1. Attach the clip and claw, and install the front door lower frame bracket garnish.



12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
