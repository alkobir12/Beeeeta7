FRONT DOOR WINDOW FRAME MOULDING > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.
  3. When installing the window frame moulding, heat the vehicle body and window frame moulding using a heat light.

Standard Heating Temperature:
Item
Temperature
Vehicle Body
40 to 60°C (104 to 140°F)
Window Frame Moulding
20 to 30°C (68 to 86°F)

NOTICE:
Do not heat the vehicle body and window frame moulding excessively.



1. INSTALL FRONT DOOR REAR WINDOW FRAME MOULDING LH

  1. Clean the vehicle body surface.

    1. Using a heat light, heat the vehicle body surface.

    2. Remove the double-sided tape from the vehicle body surface.

    3. Wipe off any tape adhesive residue with cleaner.



  1. Install a new window frame moulding.

    1. Using a heat light, heat a new window frame moulding and the vehicle body surface.

    2. Remove the peeling paper from the face of the window frame moulding.

      HINT:
      After removing the peeling paper, keep the exposed adhesive free from foreign matter.




    3. Attach the clip and double-sided tape to install the window frame moulding.

      HINT:
      Press the window frame moulding firmly to install it.



2. INSTALL FRONT DOOR BELT MOULDING ASSEMBLY LH



  1. Attach the claw to install the belt moulding.



3. INSTALL FRONT DOOR GLASS RUN LH



  1. Install the front door glass run.



4. INSTALL FRONT DOOR GLASS SUB-ASSEMBLY LH



  1. Insert the door glass into the door panel along the glass run as indicated by the arrows in the illustration.

    NOTICE:
    Be careful not to damage the glass.




  1. Install the door glass to the window regulator with the 2 bolts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



5. INSTALL FRONT INNER DOOR GLASS WEATHERSTRIP LH

  1. Install the front inner door glass weatherstrip LH.



6. INSTALL FRONT DOOR SERVICE HOLE COVER LH



  1. Apply butyl tape to the door.

  1. Pass the front door lock remote control cable and front door inside locking cable through a new front door service hole cover.

    NOTICE:
    1. When installing the service hole cover, pull the links and connectors through the service hole cover.
    2. There should be no wrinkles or folds after attaching the service hole cover.
    3. After attaching the service hole cover, check the sealing quality.




  1. Connect the 2 connectors.

  1. Attach the 9 clamps.

  1. Install the bolt as shown in the illustration.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



7. INSTALL OUTER REAR VIEW MIRROR ASSEMBLY LH



  1. Attach the claw and Install the mirror with the 3 nuts.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

  1. Attach the clamp.

  1. Connect the connector labeled A.



8. INSTALL FRONT DOOR TRIM BOARD SUB-ASSEMBLY LH

  1. Connect the connector.




  1. Connect the front door lock remote control cable and front door inside locking cable to the front door inside handle sub-assembly.




  1. Attach the 4 claws and 13 clips to install the front door trim board sub-assembly.

  1. Install the 3 screws.



9. INSTALL DOOR ASSIST GRIP COVER LH



  1. Attach the 8 claws to install the door assist grip cover to the door trim panel.



10. INSTALL FRONT DOOR ARMREST BASE PANEL ASSEMBLY LH

  1. Connect the connector.




  1. Attach the 5 claws and install the front door armrest base panel.



11. INSTALL FRONT DOOR INSIDE HANDLE BEZEL LH



  1. Attach the 4 claws to install the bezel.



12. INSTALL FRONT LOWER DOOR FRAME BRACKET GARNISH LH



  1. Attach the clip and claw, and install the front door lower frame bracket garnish.



13. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
