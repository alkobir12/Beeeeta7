1. INSTALL REAR TELEVISION CAMERA ASSEMBLY

  1. Connect the connector.

  1. Attach the 4 claws to install the rear television camera assembly.




  1. Using a T30 "TORX" socket wrench, install the rear television camera with the 2 screws.



2. INSTALL BACK DOOR GARNISH



  1. Install the back door grip with the 2 screws.



3. INSTALL BACK DOOR SIDE GARNISH LH



  1. Attach the 3 clips to install the back door side garnish.



4. INSTALL BACK DOOR SIDE GARNISH RH

HINT:
Use the same procedures described for the LH side.



5. INSTALL CENTER BACK DOOR GARNISH



  1. Attach the 5 clips and 2 claws to install the back door garnish.
