CLOCK > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL CLOCK ASSEMBLY



  1. Install the clock with the 2 screws.



2. INSTALL NO. 1 CENTER INSTRUMENT CLUSTER FINISH PANEL



  1. Connect the connector.

  1. Attach the 10 claws to install the finish panel.



3. INSTALL CLOCK ASSEMBLY (w/o Multi-display)



  1. Install the clock with the 2 screws.



4. INSTALL NO. 1 RADIO BRACKET (w/o Multi-display)



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



5. INSTALL NO. 2 RADIO BRACKET (w/o Multi-display)



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



6. INSTALL RADIO RECEIVER ASSEMBLY (w/o Multi-display)

  1. Connect the connectors.




  1. Insert the radio receiver to attach the 10 claws on its backside.

    NOTICE:
    When inserting the radio receiver, do not press the knobs on it.




  1. Install the radio receiver with the 2 screws and 2 bolts.

    Torque:
    Bolt:
    12 N*m{ 122 kgf*cm , 8 ft.*lbf }



7. INSTALL NO. 4 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



8. INSTALL NO. 3 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



9. INSTALL NO. 1 SPEAKER OPENING COVER ASSEMBLY



  1. Attach the 8 claws to install the opening cover.
