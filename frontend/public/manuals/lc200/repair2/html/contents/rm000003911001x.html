REAR NO. 1 SEAT ASSEMBLY (for 60/40 Split Seat Type 60 Side) > REASSEMBLY

for Preparation Click here


CAUTION:
Wear protective gloves. Sharp areas on the parts may injure your hands.

HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL REAR SEAT LOCK CONTROL LEVER LH



  1. Install the lock control lever with the bolt.

    Torque:
    13 N*m{ 133 kgf*cm , 10 ft.*lbf }



2. INSTALL REAR SEAT CUSHION FRAME SUB-ASSEMBLY LH



  1. Temporarily install the seat cushion frame with the 5 nuts and bolt.

  1. Tighten the 5 nuts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. Using a T40 "TORX" socket, tighten the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



3. INSTALL NO. 1 SEAT LEG ASSEMBLY LH



  1. Using a T40 "TORX" socket, install the seat leg assembly with the 2 bolts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }



4. INSTALL REAR SEAT INNER BELT ASSEMBLY



  1. Install the seat belt with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    The anchor part of the seat belt must not overlap the protruding part.



5. INSTALL SEAT HEATER CONTROL SUB-ASSEMBLY LH (w/ Seat Heater System)



  1. Attach the 2 claws to install the seat heater control.



6. INSTALL REAR SEAT CUSHION HOLDER BRACKET LH (w/ Seat Heater System)



  1. Install the holder bracket with the 2 screws.

  1. Connect the seat wire connector.



7. INSTALL REAR NO. 1 SEAT LOCK CABLE ASSEMBLY



  1. Attach the clamp to install the seat lock cable.

  1. Attach the 3 cable clamps to connect the 3 cables.

  1. Connect the cable and install a new cable tie.




  1. Install the lower seat track bracket with the 2 nuts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }



8. INSTALL FOLD SEAT LOCK CONTROL CABLE SUB-ASSEMBLY



  1. Install the 2 fold seat lock control cables.

  1. Attach the 2 cable clamps to connect the 2 cables.



9. INSTALL REAR SEATBACK FRAME SUB-ASSEMBLY LH



  1. Install the lower seatback cover.




  1. Temporarily install the seatback frame with the 4 bolts.

  1. LH Side:
    Using a T40 "TORX" socket, tighten the 2 bolts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. RH Side:
    Using a T55 "TORX" socket, tighten the 2 bolts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



10. INSTALL NO. 2 FOLD SEAT LOCK CONTROL CABLE ASSEMBLY



  1. Attach the clamp to install the lock control cable.

  1. Attach the 2 cable clamps to connect the cable.



11. INSTALL RECLINING ADJUSTING CABLE ASSEMBLY LH



  1. Attach the clamp to install the adjusting cable.

  1. Attach the 2 cable clamps to connect the cable.



12. INSTALL NO. 1 SEAT 3 POINT TYPE BELT ASSEMBLY LH



  1. Install the belt with the nut labeled A.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

  1. Install the belt sensor with the 3 nuts labeled B.



13. INSTALL REAR SEAT SHOULDER BELT HOLE COVER LH



  1. Install the seat belt as shown in the illustration.




  1. Attach the 3 claws to install the shoulder belt hole cover.



14. INSTALL REAR LOWER SEATBACK COVER SUB-ASSEMBLY LH



  1. Attach the 4 claws to install the cover.

  1. Install the 4 screws.



15. INSTALL REAR SEATBACK HINGE COVER LH



  1. Attach the claw to install the cover.

  1. Install the screw.

  1. Attach the claw to install the cover.

  1. Install the screw.

  1. Install the screw.



18. INSTALL REAR SEAT RECLINING COVER LH



  1. Attach the claw to install the cover.

  1. Install the screw.

  1. Attach the 2 clips to install the cup holder.




  1. Install the 2 screws.



20. INSTALL NO. 1 SEAT ARMREST PLATE (w/ Center Armrest)



  1. Attach the 2 claws and 4 clips to install the 2 armrest plates.



21. INSTALL REAR CENTER SEAT HEADREST ASSEMBLY (w/ Center Armrest)


22. INSTALL REAR CENTER SEAT ARMREST ASSEMBLY (w/ Center Armrest)



  1. Using a T40 "TORX" socket, install the center seat armrest with the 2 bolts.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }



23. INSTALL SEATBACK STOPPER PLATE


  1. w/ Center Armrest:

    1. Install the bush to the stopper plate.




    2. Temporarily install the stopper plate with the 3 bolts.

    3. Using a T40 "TORX" socket, tighten the 2 bolts.

      Torque:
      42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    4. Tighten the bolt.

      Torque:
      15 N*m{ 153 kgf*cm , 11 ft.*lbf }



  1. w/o Center Armrest:

    1. Install the bush to the stopper plate.




    2. Temporarily install the stopper plate with the 3 bolts.

    3. Using a T40 "TORX" socket, tighten the 2 bolts.

      Torque:
      42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    4. Tighten the bolt.

      Torque:
      15 N*m{ 153 kgf*cm , 11 ft.*lbf }



24. INSTALL REAR SEATBACK HEATER ASSEMBLY (w/ Seat Heater System)

  1. Set the seatback heater with the name stamp side facing the seatback cover.



  1. Install the seatback heater with new tack pins.





25. INSTALL REAR SEPARATE TYPE SEATBACK COVER



  1. w/ Center Armrest:
    Using hog ring pliers, install the seatback cover with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.




  1. w/o Center Armrest:
    Using hog ring pliers, install the seatback cover with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.




  1. w/ Rear Seat Side Airbag:
    Connect the seatback cover bracket to the seatback pad.



26. INSTALL SEATBACK COVER WITH PAD

  1. Install the seatback cover with pad.




  1. w/ Center Armrest:
    Pull out the seat belt.




  1. w/o Center Armrest:
    Pull out the seat belt.

  1. w/ Rear Seat Side Airbag:
    Pass the side airbag wire harness through the hole in the seatback.



  1. w/ Seat Heater System:
    Pass the seatback heater wire harness through the hole in the seatback.







    2. Connect the seatback heater wire harness and install a new cable tie.




  1. w/ Rear Seat Side Airbag:
    Install the seatback cover bracket to the seat frame with the cap nut.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }

    NOTICE:
    After the seatback trim cover is assembled, make sure the side airbag strap is not twisted.




  1. w/ Center Armrest:
    Using hog ring pliers, install new hog rings to the seatback frame.



  1. w/o Center Armrest:




    1. Using hog ring pliers, install new hog rings to the seatback frame.

    2. Attach the hook.

  1. Install the screw.

33. INSTALL REAR SEAT CUSHION HEATER ASSEMBLY (w/ Seat Heater System)

  1. Install the seat cushion heater with new tack pins.





34. INSTALL REAR SEPARATE TYPE SEAT CUSHION COVER



  1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

    NOTICE:
    1. Be careful not to damage the cover.
    2. When installing the hog rings, avoid wrinkling the cover.




  1. Attach the 3 pieces of fastening tape.



35. INSTALL SEAT CUSHION COVER WITH PAD

  1. Install the seat cushion cover with pad.

  1. w/ Rear Seat Side Airbag:
    Pass the side airbag wire harness through the hole in the seat cushion.



  1. w/ Seat Heater System:




    1. Pass the seatback heater wire harness through the hole in the seat cushion.




    2. Connect the 2 seat heater connectors.

  1. w/ Rear Seat Side Airbag:
    Attach the side airbag wire harness clamps.



36. CONNECT NO. 1 SEAT 3 POINT TYPE BELT ASSEMBLY LH



  1. Connect the belt anchor.

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the vehicle body.



37. INSTALL REAR NO. 1 SEAT BELT INNER ASSEMBLY LH



  1. Install the belt with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not overlap the anchor part of the seat belt and protruding parts of the vehicle body.

    HINT:
    The No. 1 seat 3 point type belt anchor is fixed with the same bolt as the rear No. 1 seat inner belt LH. Therefore, connect it when installing the rear No. 1 seat inner belt LH.
