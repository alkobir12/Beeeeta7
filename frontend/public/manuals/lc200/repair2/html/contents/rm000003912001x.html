REAR NO. 1 SEAT ASSEMBLY (for 60/40 Split Seat Type 40 Side) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL REAR SEAT CUSHION LOCK STRIKER SUB-ASSEMBLY


  1. Install the 4 strikers with the 10 bolts.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }






2. INSTALL REAR NO. 6 AIR DUCT (w/ Rear Air Conditioning System)

  1. Install the duct with the 5 screws.



  1. Connect the 2 connectors.





3. INSTALL FRONT FLOOR CARPET ASSEMBLY

  1. Install the floor carpet.



4. INSTALL REAR AIR DUCT GUIDE (w/ Rear Air Conditioning System)



  1. Attach the claw to install the guide.

  1. Install the screw.

    HINT:
    Use the same procedures for both sides.



5. INSTALL AIR DUCT PLUG (w/ Rear Air Conditioning System)



  1. Attach the 2 claws to install the plug.

    HINT:
    Use the same procedures for both sides.



6. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH

  1. w/ Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).

  1. w/o Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).



7. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY RH

  1. w/ Sliding Roof:
    Install the front quarter trim panel assembly RH (Click here).

  1. w/o Sliding Roof:
    Install the front quarter trim panel assembly RH (Click here).



8. INSTALL REAR SEAT COVER CAP (w/ Rear No. 2 Seat, except Face to Face Seat Type)



HINT:
Use the same procedure to install the rear seat cover cap on the other side.

  1. Attach the 3 claws to install the rear seat cover cap.



9. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



10. INSTALL REAR NO. 2 SEAT ASSEMBLY

  1. for Face to Face Seat Type:
    Install the rear No. 2 seat assembly (Click here).

  1. except Face to Face Seat Type:
    Install the rear No. 2 seat assembly (Click here).



11. INSTALL REAR DOOR SCUFF PLATE LH



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



12. INSTALL REAR DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.



13. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.



14. INSTALL REAR NO. 2 SEAT PROTECTOR



  1. Attach the 10 claws to install the 2 seat protectors.



15. INSTALL REAR NO. 1 SEAT PROTECTOR



  1. Attach the 10 claws to install the 2 seat protectors.



16. INSTALL REAR NO. 1 SEAT ASSEMBLY LH

  1. Install the rear No. 1 seat assembly LH (Click here).



17. INSTALL REAR NO. 1 SEAT ASSEMBLY RH



  1. Temporarily install the seat assembly with the 4 bolts.

    NOTICE:
    Be careful not to damage the vehicle body.

  1. Tighten the bolts in the order shown in the illustration.

    Torque:
    37 N*m{ 377 kgf*cm , 27 ft.*lbf }




  1. w/ Rear Seat Side Airbag:
    Connect the connector.

  1. w/ Seat Heater System:
    Connect the connector.



18. INSTALL REAR NO. 3 SEAT CUSHION HINGE COVER



  1. Attach the 2 clips and 2 claws to install the cover.



19. INSTALL REAR NO. 1 SEAT CUSHION HINGE COVER



  1. Attach the 2 clips and 2 claws to install the cover.



20. INSTALL REAR NO. 4 SEAT CUSHION HINGE COVER

  1. Return the seat to the upright position.




  1. Attach the 6 claws to install the cover.



21. INSTALL REAR NO. 2 SEAT CUSHION HINGE COVER



  1. Attach the 6 claws to install the cover.



22. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



23. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).



24. INSPECT REAR NO. 1 SEAT ASSEMBLY RH

  1. w/ Seat Heater System:
    Check the seat heater operation.

    1. Turn the engine switch on (IG).

    2. Turn the seat heater switch on.

    3. Wait 5 minutes or more and confirm that the seat surface becomes warm.
