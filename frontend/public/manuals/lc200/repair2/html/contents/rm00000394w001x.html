SEAT HEATER SWITCH (w/ Seat Heater System) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL SEAT HEATER SWITCH



  1. Attach the 2 claws to install the heater switch.



2. INSTALL SUSPENSION CONTROL SWITCH



  1. Attach the 4 claws to install the control switch.




  1. Connect the 2 connectors.

  1. Attach the wire harness clamp.



3. INSTALL UPPER CONSOLE PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 14 claws to install the console panel.



4. INSTALL CONSOLE CUP HOLDER BOX SUB-ASSEMBLY



  1. Attach the 4 claws to install the box.



5. INSTALL REAR UPPER CONSOLE PANEL SUB-ASSEMBLY



  1. Attach the 9 claws to install the panel.



6. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



7. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY


  1. Install the shift lever knob and twist it in the direction indicated by the arrow.





8. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



9. INSTALL NO. 1 INSTRUMENT PANEL FINISH CUSHION



  1. Attach the 7 claws to install the panel cushion.



10. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



11. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.
