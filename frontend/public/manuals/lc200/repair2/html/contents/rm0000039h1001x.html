REAR DOOR LOCK > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LH side and RH side.
  2. The procedures listed below are for the LH side.



1. INSTALL REAR DOOR INSIDE LOCKING CABLE ASSEMBLY LH



  1. Install the rear door inside locking cable assembly.




  1. Attach the 3 claws.



2. INSTALL REAR DOOR LOCK REMOTE CONTROL CABLE ASSEMBLY LH



  1. Install the rear door lock remote control cable assembly.




  1. Attach the claw.



3. INSTALL REAR DOOR LOCK ASSEMBLY LH



  1. Apply MP grease to the sliding parts of the rear door lock assembly.

  1. Insert the rear door lock assembly to the rear door outside handle release plate, and set it to the rear door panel.

  1. Make sure that the rear door outside handle frame release plate is securely connected to the rear door lock assembly.

  1. Using a T30 ''TORX'' wrench, the 3 screws.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



4. INSTALL REAR DOOR SERVICE HOLE COVER LH

  1. Apply butyl tape to the door.




  1. Pass the rear door lock remote control cable and rear door inside locking cable through a new rear door service hole cover.

    NOTICE:
    1. When installing the service hole cover, pull the links and connectors through the service hole cover.
    2. There should be no wrinkles or folds after attaching the service hole cover.
    3. After attaching the service hole cover, check the sealing quality.




  1. Connect the 2 connectors.

  1. Attach the 6 clamps.




  1. Install the bolt as shown in the illustration.

    Torque:
    8.4 N*m{ 86 kgf*cm , 74 in.*lbf }



5. INSTALL COURTESY LIGHT ASSEMBLY (w/ Courtesy Light)



  1. Connect the connector.

  1. Attach the claw of the courtesy light to the rear door trim.



6. INSTALL REAR DOOR TRIM BOARD SUB-ASSEMBLY LH

  1. Connect the connector.




  1. Connect the rear door lock remote control cable and rear door inside locking cable to the rear door inside handle sub-assembly.




  1. Attach the 4 claws and 9 clips to install the rear door trim board sub-assembly.

  1. Install the 3 screws.



7. INSTALL ASSIST GRIP COVER LH



  1. Attach the 9 claws to install the door assist grip cover to the door trim panel.



8. INSTALL REAR DOOR INSIDE HANDLE BEZEL LH



  1. Attach the 4 claws to install the bezel.



9. INSTALL REAR DOOR ARMREST BASE PANEL ASSEMBLY LH



  1. Connect the connector.

  1. Attach the 7 claws to install the rear door armrest base panel.



10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
