WIRELESS DOOR LOCK BUZZER > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL WIRELESS DOOR LOCK BUZZER



  1. Connect the connector.

  1. Attach the clamp to install the buzzer.



2. INSTALL FRONT BUMPER COVER



HINT:
For the front bumper cover with garnish, use the procedures described below.

  1. w/ Headlight Cleaner System:
    Connect the headlight cleaner hose.

  1. w/o TOYOTA Parking Assist-sensor System, w/o Fog Light:
    Attach the 10 claws to install the bumper cover.

  1. w/ TOYOTA Parking Assist-sensor System or w/ Fog Light:
    Connect the No. 4 engine room wire connector and attach the 10 claws to install the bumper cover.



  1. Install the 3 clips, 4 screws and 4 bolts.





  1. Using a T30 "TORX" socket, install the 6 screws.





3. INSTALL RADIATOR GRILLE ASSEMBLY



  1. Attach the 2 clips and 8 claws to install the radiator grille.

  1. Install the 3 screws.



4. INSTALL UPPER RADIATOR SUPPORT SEAL


  1. Install the radiator support seal with the 7 clips.





5. INSTALL REAR FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



6. INSTALL REAR FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.
