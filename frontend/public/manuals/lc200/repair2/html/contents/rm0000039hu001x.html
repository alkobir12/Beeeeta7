CIGARETTE LIGHTER > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL CIGARETTE LIGHTER BEZEL STAY



  1. Attach the 2 claws to install the bezel stay.



2. INSTALL CIGARETTE LIGHTER ASSEMBLY



  1. Attach the claw to install the cigarette lighter socket and retainer assembly.

  1. Install the cigarette lighter knob and element assembly.



3. INSTALL CIGARETTE LIGHTER COVER



  1. Attach the 2 claws to install the cover.



4. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



5. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



6. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



7. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



8. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.
