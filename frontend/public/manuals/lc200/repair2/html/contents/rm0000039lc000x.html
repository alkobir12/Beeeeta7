1. INSPECT CLEARANCE SONAR MAIN SWITCH



  1. Measure the resistance according to the value(s) in the table below.

    Standard Resistance:
    Tester Connection
    		Switch Condition
    		Specified Condition
    3 (IG) - 6 (ECU)
    		Clearance sonar main switch on
    		Below 1 Ω
    3 (IG) - 6 (ECU)
    		Clearance sonar main switch off
    		10 kΩ or higher

    If the result is not as specified, replace the clearance sonar main switch.
