ULTRASONIC SENSOR (for Rear) > INSTALLATION

for Preparation Click here



1. INSTALL NO. 2 ULTRASONIC SENSOR RETAINER



HINT:
Use the same procedure to install the No. 2 ultrasonic sensor retainer on the other side.

  1. Align the keyhole and protrusion as shown in the illustration.

  1. Install the ultrasonic sensor retainer to the rear bumper.

    NOTICE:
    Do not damage the bumper with the protrusion when installing the retainer.



2. INSTALL NO. 3 ULTRASONIC SENSOR RETAINER



HINT:
Use the same procedure to install the No. 3 ultrasonic sensor retainer on the other side.

  1. Attach the claw to install the ultrasonic sensor retainer as shown in the illustration.



3. INSTALL NO. 2 ULTRASONIC SENSOR



HINT:
Use the same procedure to install the No. 2 ultrasonic sensor on the other side.

  1. Attach the 2 claws to install the ultrasonic sensor.

  1. Connect the connector.



4. INSTALL NO. 3 ULTRASONIC SENSOR



HINT:
Use the same procedure to install the No. 3 ultrasonic sensor on the other side.

  1. Attach the 3 claws to install the ultrasonic sensor.

  1. Connect the connector.
