  1. for LHD:

  1. for RHD:

  1. for LHD:

  1. for RHD:
    Attach the 6 clamps to install the antenna cord.

  1. Attach the 3 claws to install the nozzle.

  1. Attach the 2 claws to install the nozzle.



8. INSTALL DEFROSTER NOZZLE ASSEMBLY



  1. Attach the 11 claws to install the nozzle.



9. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY



  1. Attach the 5 hooks (A).

  1. Attach the 5 hooks (B) to install the front passenger airbag on the instrument panel.




  1. Install the 2 screws.




  1. Connect the 2 connectors and install the instrument panel wire assembly to the front passenger airbag.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Attach the claw and install the wire.
