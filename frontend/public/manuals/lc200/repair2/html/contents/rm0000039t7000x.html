1. INSTALL ENGINE OIL LEVEL SENSOR

  1. Install a new gasket to the sensor.




  1. Install the sensor with the 4 bolts.

    Torque:
    7.0 N*m{ 71 kgf*cm , 62 in.*lbf }

  1. Connect the connector.



2. INSTALL NO. 2 ENGINE UNDER COVER



  1. Install the under cover with the 2 bolts.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }



3. INSTALL NO. 1 ENGINE UNDER COVER SUB-ASSEMBLY



  1. Install the under cover with the 10 bolts.



4. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



5. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY LH



  1. Push in the clip indicated by the arrow in the illustration to install the fender splash shield.

  1. Install the 3 bolts and screw.
