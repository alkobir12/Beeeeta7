FUEL PUMP (for Double Tank Type) > REASSEMBLY

for Preparation Click here



NOTICE:

Do not disconnect the hoses indicated in the illustration.



1. INSTALL NO. 1 FUEL SUCTION SUPPORT



  1. Attach the 2 claws to the claw holes to install the fuel suction support.



2. INSTALL FUEL MAIN VALVE ASSEMBLY



  1. Apply a light coat of gasoline to 2 new O-rings, and install them onto the fuel main valve.




  1. Install the fuel main valve to the fuel filter case.

    NOTICE:
    Make sure the O-rings are not cut or pinched during the installation.



3. INSTALL FUEL PUMP



  1. Connect the fuel pump wire harness connector to the fuel pump.




  1. Apply a light coat of gasoline to a new O-ring. Then install the spacer and O-ring to the fuel pump.




  1. Attach the 5 claws to the claw holes and install the fuel pump to the fuel filter case.



4. INSTALL NO. 1 FUEL SUB-TANK



NOTICE:
Make sure that the fuel tube passes into the section marked by the circle.




  1. Attach the 3 claws to the claw holes and install the fuel sub-tank.




  1. Attach the 3 claws to the claw holes.




  1. Connect the jet pump (labeled B) to the sub-tank.

    1. Attach the claw on the end of the tube to the claw hole.

  1. Connect the jet pump (labeled A) to the sub-tank.




  1. Connect the fuel pump connector.



5. INSTALL FUEL SENDER GAUGE ASSEMBLY



  1. Set the sender gauge to the fuel sub-tank. Then slide the sender gauge downward to install it.




  1. Connect the fuel sender gauge connector.
