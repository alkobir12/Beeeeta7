1. INSTALL NO. 1 HEIGHT CONTROL BOLT CUSHION

  1. Install the 3 bolt cushions and 3 bolt holders to the pump and motor.



2. INSTALL HEIGHT CONTROL RESERVOIR ASSEMBLY



  1. Using a 5 mm hexagon wrench, install the reservoir with the 5 bolts.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }



3. INSTALL HEIGHT CONTROL COMPRESSOR BRACKET ASSEMBLY



  1. Install the bracket with the 3 nuts.

    Torque:
    5.5 N*m{ 56 kgf*cm , 49 in.*lbf }



4. CONNECT NO. 4 FRAME WIRE



  1. Connect the 2 connectors, clamp and frame wire.



5. INSTALL HEIGHT CONTROL CAP TO RESERVOIR HOSE



  1. Install the hose to the reservoir tank, and push the connector up to attach it.




  1. Install the hose, 2 breather plugs and 3 clips to the reservoir hose.



6. INSTALL HEIGHT CONTROL HOSE ASSEMBLY



  1. Install the hose to the reservoir and motor with the 2 clips.

  1. Connect the clamp to the reservoir.




  1. Check that the direction of the hose clamp is as shown in the illustration.
