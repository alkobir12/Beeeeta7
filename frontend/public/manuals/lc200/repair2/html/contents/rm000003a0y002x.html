1. INSTALL NO. 2 INLET TURBO OIL PIPE SUB-ASSEMBLY (for Bank 2)



  1. Temporarily install a new gasket and the No. 2 inlet turbo oil pipe with the union bolt and bolt.

  1. Tighten the union bolt and bolt in the order shown in the illustration.

    Torque:
    for union bolt:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
    for bolt:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



2. INSTALL NO. 2 TURBO OIL PIPE (for Bank 2)



  1. Install a new gasket and the No. 2 turbo oil pipe with the 2 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

    HINT:
    The gasket claws should face the pipe.



3. INSTALL NO. 2 INLET COMPRESSOR ELBOW (for Bank 2)



  1. Install a new gasket and the No. 2 inlet compressor elbow with the 2 bolts.

    Torque:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }

    HINT:
    Install the No. 2 inlet compressor elbow with the "L" mark facing toward the outside of the vehicle.



4. INSTALL NO. 2 TURBOCHARGER SUB-ASSEMBLY WITH EXHAUST MANIFOLD LH (for Bank 2)



  1. Set a new gasket to the No. 2 turbocharger.

  1. Install the exhaust manifold LH to the No. 2 turbocharger with 3 new nuts.

    Torque:
    60 N*m{ 612 kgf*cm , 44 ft.*lbf }

    HINT:
    The gasket claw should face toward the outside of the vehicle.




  1. Set a new gasket to the cylinder head LH.




  1. Install the No. 2 turbocharger with exhaust manifold LH and 10 collars to the cylinder head LH with 10 new nuts.

    Torque:
    36 N*m{ 367 kgf*cm , 27 ft.*lbf }

    HINT:
    Install the collars with the colored side facing the nuts.




  1. Install a new gasket and the No. 2 inlet turbo oil pipe to the No. 1 oil pan with the union bolt.

    Torque:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }




  1. Connect the 2 connectors to the turbocharger.



5. INSTALL NO. 2 VENTILATION TUBE SUB-ASSEMBLY (for Bank 2)



  1. Temporarily install a new gasket and the No. 2 ventilation tube with the union bolt and bolt.

  1. Tighten the union bolt and bolt in the order shown in the illustration.

    Torque:
    for union bolt:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
    for bolt:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

    NOTICE:
    Clean and remove any oil labeled 1shown in the illustration.

  1. Connect the No. 2 vacuum transmitting hose.



6. INSTALL NO. 2 TURBOCHARGER STAY (for Bank 2)



  1. Install the No. 2 turbocharger stay with the 2 bolts.

    Torque:
    49 N*m{ 495 kgf*cm , 36 ft.*lbf }



7. CONNECT NO. 2 OUTLET TURBO OIL HOSE (for Bank 2)

HINT:

Align the white paint marks on the oil hose and pipe, and connect the hose.



8. INSTALL NO. 2 TURBO WATER PIPE SUB-ASSEMBLY (for Bank 2)

  1. Tighten the union bolt and bolt in the order shown in the illustration.

    Torque:

    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
    for bolt:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }

  1. Connect the water hose to the pipe.



9. INSTALL FRONT WATER BY-PASS JOINT (for Bank 2)



  1. Install a new gasket and the front water by-pass joint.

    Torque:
    50 N*m{ 510 kgf*cm , 37 ft.*lbf }

18. INSTALL NO. 1 TURBOCHARGER SUB-ASSEMBLY WITH EXHAUST MANIFOLD RH (for Bank 1)



  1. Set a new gasket to the No. 1 turbocharger.

  1. Install the exhaust manifold RH to the No. 1 turbocharger with 2 new nuts and the bolt.

    Torque:
    60 N*m{ 612 kgf*cm , 44 ft.*lbf }




  1. Set a new gasket to the cylinder head RH.




  1. Install the No. 1 turbocharger with exhaust manifold RH to the cylinder head RH with the 10 collars and 10 new nuts.

    Torque:
    36 N*m{ 367 kgf*cm , 27 ft.*lbf }

    HINT:
    Install the collars with the colored side facing the nuts.




  1. Install a new gasket and the No. 1 inlet turbo oil pipe to the cylinder block with the union bolt.

    Torque:
    Case is dry:
    29 N*m{ 296 kgf*cm , 21 ft.*lbf }
    Case is wet:
    23 N*m{ 235 kgf*cm , 17 ft.*lbf }

    NOTICE:
    1. The case is "dry" when there is absolutely no engine oil on the union bolt and cylinder block bolt hole.
    2. The case is "wet" when there is engine oil on the union bolt and cylinder block bolt hole.

27. INSTALL NO. 1 INTAKE AIR CONNECTOR PIPE (for Bank 1)



  1. Install the No. 1 intake air connector pipe with the bolt. Then tighten the hose clamp.

    Torque:
    for bolt:
    21 N*m{ 214 kgf*cm , 15 ft.*lbf }
    for clamp:
    6.0 N*m{ 61 kgf*cm , 53 in.*lbf }




  1. Connect the 4 connectors and attach the 5 wire harness clamps.



28. INSTALL NO. 1 ENGINE OIL LEVEL DIPSTICK GUIDE (for Bank 1)



  1. Apply a light coat of engine oil to a new O-ring and install it to the No. 1 engine oil level dipstick guide.

  1. Install the No. 1 engine oil level dipstick guide with the 2 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }
