TURBO MOTOR DRIVER > INSTALLATION

for Preparation Click here



1. INSTALL TURBO MOTOR DRIVER



  1. Install the 2 turbo motor drivers to the brackets with the 8 screws.

    Torque:
    2.0 N*m{ 20 kgf*cm , 18 in.*lbf }

  1. Connect the 4 connectors to the turbo motor driver.

    NOTICE:
    1. Mach the 10 pin and 4 pin connector colors when connecting them to the turbo motor driver.
    2. Make sure to connect the white connectors to the upper side and the black connectors to the lower side.




  1. Insert the bracket tab into the slot labeled A and insert the 2 stud bolts into the bracket hole as shown in illustration.

  1. Install the 2 nuts and bolt.

    Torque:
    20 N*m{ 199 kgf*cm , 14 ft.*lbf }




  1. Connect the connector. Then move the lock lever as shown in the illustration to lock the connectors.



2. INSTALL FRONT FENDER LINER RH

  1. Install the fender liner with the 5 clips.

  1. Using a T30 "TORX" socket, install the 3 screws.

  1. Connect the liner to the front bumper cover with the screw.



3. INSTALL FRONT FENDER SPLASH SHIELD SUB-ASSEMBLY RH



  1. Install the splash shield with the clip, and then install the 3 bolts and screw.



4. CONNECT CABLE TO NEGATIVE NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).

  1. Connect the cables to the negative (-) main battery and sub-battery terminals.
