SEAT BELT CONTROL ECU (for RHD) > INSTALLATION

for Preparation Click here



1. INSTALL SEAT BELT CONTROL ECU



  1. Install the ECU with the nut.

    Torque:
    7.0 N*m{ 71 kgf*cm , 62 in.*lbf }

  1. Connect the 2 connectors.



2. INSTALL LOWER NO. 2 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connector.

  1. Attach the 3 claws to install the finish panel.

  1. Install the 4 bolts.



3. INSTALL NO. 3 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 6 claws to install the panel garnish.



4. INSTALL FRONT PASSENGER SIDE KNEE AIRBAG ASSEMBLY (w/ Passenger Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Attach the 4 claws to install the front passenger side knee airbag.

  1. Install the 4 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



5. INSTALL LOWER INSTRUMENT PANEL (w/o Passenger Side Knee Airbag)



  1. Attach the 4 claws and connect the DLC3.

  1. Install the instrument panel with the 5 bolts.



6. INSTALL NO. 2 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Attach the 4 claws to install the under cover.



7. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



8. INSTALL NO. 1 INSTRUMENT PANEL FINISH CUSHION



  1. Attach the 7 claws to install the panel cushion.



9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL (w/ Passenger Side Knee Airbag)

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



10. CHECK SRS WARNING LIGHT (w/ Passenger Side Knee Airbag)

  1. Check the SRS warning light (Click here).
