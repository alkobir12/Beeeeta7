RADIO RECEIVER (w/ Multi-display) > INSTALLATION

for Preparation Click here



1. INSTALL NO. 2 RADIO BRACKET



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



2. INSTALL NO. 1 RADIO BRACKET



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



3. INSTALL RADIO RECEIVER ASSEMBLY WITH BRACKET

  1. Connect the connectors.




  1. Insert the radio receiver to attach the 5 claws on its backside.

    NOTICE:
    When inserting the radio receiver, do not press the knobs on it.




  1. Install the radio receiver with the 2 screws and 2 bolts.

    Torque:
    Bolt:
    12 N*m{ 122 kgf*cm , 8 ft.*lbf }



4. INSTALL MULTI-DISPLAY ASSEMBLY WITH BRACKET

  1. Connect the connectors.




  1. Insert the display and attach the 2 clips and 6 claws on its backside.

    NOTICE:
    When inserting the display, do not press the knobs on it.




  1. Install the display with the 2 screws and 2 bolts.

    Torque:
    Bolt:
    12 N*m{ 122 kgf*cm , 8 ft.*lbf }



5. INSTALL NO. 4 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



6. INSTALL NO. 3 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



7. INSTALL NO. 1 SPEAKER OPENING COVER ASSEMBLY



  1. Attach the 8 claws to install the opening cover.



8. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



9. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



10. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



11. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



12. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



13. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
