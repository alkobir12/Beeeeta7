RADIO RECEIVER (w/o Multi-display) > INSTALLATION

for Preparation Click here



1. INSTALL HAZARD WARNING SIGNAL SWITCH ASSEMBLY



  1. Attach the 2 claws to install the hazard warning switch.



2. INSTALL CLOCK ASSEMBLY



  1. Install the clock with the 2 screws.



3. INSTALL NO. 1 RADIO BRACKET



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



4. INSTALL NO. 2 RADIO BRACKET



  1. Install the bracket with the 3 bolts.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



5. INSTALL RADIO RECEIVER ASSEMBLY WITH BRACKET

  1. Connect the connectors.




  1. Insert the radio receiver to attach the 10 claws on its backside.

    NOTICE:
    When inserting the radio receiver, do not press the knobs on it.




  1. Install the radio receiver with the 2 screws and 2 bolts.

    Torque:
    Bolt:
    12 N*m{ 122 kgf*cm , 8 ft.*lbf }



6. INSTALL NO. 4 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



7. INSTALL NO. 3 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



8. INSTALL NO. 1 SPEAKER OPENING COVER ASSEMBLY



  1. Attach the 8 claws to install the opening cover.



9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
