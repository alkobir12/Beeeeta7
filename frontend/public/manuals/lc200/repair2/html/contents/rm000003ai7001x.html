STEREO COMPONENT AMPLIFIER > INSTALLATION

for Preparation Click here



1. INSTALL NO. 2 AMPLIFIER BRACKET



  1. Set the aligning protrusions of the bracket labeled A, into the holes of the amplifier.

  1. Install the bracket with the 2 screws labeled B.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



2. INSTALL NO. 1 AMPLIFIER BRACKET



  1. Set the aligning protrusions of the bracket labeled A, into the holes of the amplifier.

  1. Install the bracket with the 2 screws labeled B.

    Torque:
    3.0 N*m{ 30 kgf*cm , 26 in.*lbf }



3. INSTALL AMPLIFIER COVER



  1. Attach the 3 clips to install the cover.



4. INSTALL STEREO COMPONENT AMPLIFIER ASSEMBLY WITH BRACKET



  1. Install the amplifier with the 3 bolts.

    Torque:
    7.5 N*m{ 76 kgf*cm , 66 in.*lbf }

  1. Connect the 3 connectors.



5. INSTALL FRONT FLOOR CARPET ASSEMBLY



  1. Open the tail gate and back door, insert the carpet into the cabin from the rear, and install it to the floor.



  1. Attach the 2 clips and 8 claws.
