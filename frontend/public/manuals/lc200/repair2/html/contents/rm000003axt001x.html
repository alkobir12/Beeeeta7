1. INSTALL FRONT EVAPORATOR TEMPERATURE SENSOR



NOTICE:
If reusing the evaporator, do not insert the sensor into a location where the sensor was previously inserted.

  1. Insert the sensor to a location that is 1 fin to the right or left of its previous location.

    Standard Dimension:
    Area
    		Specified Condition
    a
    		50 mm (1.97 in.)
    b
    		34.3 mm (1.35 in.)
    c
    		20.9 mm (1.97 in.)



2. INSTALL NO. 1 COOLER EVAPORATOR SUB-ASSEMBLY

  1. Install the evaporator.

  1. Attach the 6 claws to install the unit case.



  1. Install the 7 screws.





3. INSTALL SERVO MOTOR



  1. Install the rear air mix damper control servo motor RH.

    1. Attach the claw to install the lever and servo motor.

    2. Install the 2 screws.




  1. Install the rear mode control servo motor.

    1. Attach the claw to install the plate and servo motor.

    2. Install the 2 screws.

  1. Set the damper servo so that the cutout part engages with the tooth of the gear, and attach the claw to install the servo motor unit.




  1. Install the 3 screws.



4. INSTALL SERVO MOTOR



  1. Install the front air mix damper control servo motor LH.

    1. Attach the claw to install the plate and servo motor.

    2. Install the 2 screws.




  1. Install the front mode control servo motor LH.

    1. Attach the claw to install the plate and servo motor.

    2. Install the 2 screws.




  1. Attach the 3 claws to install the plate.

  1. Set the damper servo so that the cutout part engages with the tooth of the gear, and attach the claw to install the servo motor unit.




  1. Install the 4 screws.



5. INSTALL SERVO MOTOR

    1. Attach the claw to install the plate and servo motor.

  1. Install the control air bypass damper control servo motor.

    1. Attach the claw to install the plate and servo motor.

    1. Attach the claw to install the plate and servo motor.

6. INSTALL REAR AIR MIX DAMPER CONTROL SERVO MOTOR RH (for 4 Zone Type)



  1. Install the servo motor with the 3 screws.



7. INSTALL COOLER EXPANSION VALVE (w/o Cool Box)



  1. Sufficiently apply compressor oil to 4 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the cooler evaporator.

  1. Install the 2 O-rings to the air conditioner tube and accessory assembly.

  1. Install the cooler expansion valve and air conditioner tube and accessory assembly to the evaporator.

  1. Using a 4 mm hexagon wrench, install the 2 bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }




  1. Install new packing.



8. INSTALL AIR CONDITIONER TUBE AND ACCESSORY ASSEMBLY (w/ Cool Box)



  1. Sufficiently apply compressor oil to 2 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the air conditioner tube and accessory assembly.

  1. Install the air conditioner tube and accessory assembly to the evaporator.

  1. Using a 4 mm hexagon wrench, install the 2 hexagon bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }

  1. Install the bracket with the screw.



9. INSTALL COOLER EXPANSION VALVE (w/ Cool Box)



  1. Sufficiently apply compressor oil to 2 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the No. 2 connector tube.

  1. Install the No. 2 connector tube, expansion valve and No. 3 connector tube.

  1. Using a 4 mm hexagon wrench, install the 2 hexagon bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }




  1. Sufficiently apply compressor oil to 2 new O-rings and the fitting surface of the hose joint.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the 2 O-rings to the No. 1 connector tube.

  1. Install the No. 1 connector tube.

  1. Using a 4 mm hexagon wrench, install the 2 hexagon bolts.

    Torque:
    3.5 N*m{ 36 kgf*cm , 31 in.*lbf }




  1. Using a 4 mm hexagon wrench, install the bracket with the hexagon bolt and screw.




  1. Install new butyl tape.




  1. Install new packing.



10. INSTALL AIR CONDITIONING RADIATOR ASSEMBLY



  1. Install the radiator.

  1. Install the bracket with the screw.



11. INSTALL AIR CONDITIONER HARNESS

  1. Attach the clamps to install the harness.



  1. Connect the connectors.





12. INSTALL QUICK HEATER ASSEMBLY (w/ PTC Heater)



  1. Install the quick heater with the 2 screws.

  1. Attach the 3 clamps.



13. INSTALL COOL BOX LIQUID TUBE (w/ Cool Box)



  1. Lubricate 2 new O-rings with compressor oil and install them to the tube.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Connect the liquid tube with the piping clamp.

    NOTICE:
    After connection, check the claw engagement of the piping clamp.




  1. Attach the clamp.



14. INSTALL ASPIRATOR



  1. Attach the 2 claws to install the aspirator.



15. INSTALL NO. 4 AIR DUCT SUB-ASSEMBLY



  1. Install the duct with the screw.



16. INSTALL NO. 5 AIR DUCT SUB-ASSEMBLY



  1. Install the duct with the screw.



17. INSTALL BLOWER ASSEMBLY




  1. Attach the claw to install the blower unit.

  1. Connect the connector and clamp.

  1. Install the screw.
