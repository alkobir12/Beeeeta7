DTC    B2070    VSC Buzzer

for Preparation Click here


DESCRIPTION

When the master cylinder solenoid (skid control ECU) detects a malfunction in the VSC warning buzzer circuit, a malfunction signal is sent to the seat belt control ECU, and this DTC is stored.

DTC Code
DTC Detection Condition
Trouble Area
B2070
While the engine switch is on (IG), the skid control ECU buzzer circuit malfunction signal is received by the seat belt control ECU.
  1. Vehicle stability control system
  2. Seat belt control ECU
