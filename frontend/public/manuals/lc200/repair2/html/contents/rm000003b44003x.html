AIR CONDITIONING PANEL (w/o Multi-display) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LHD vehicle and RHD vehicle.
  2. The procedures listed below are for the LHD vehicle.



1. INSTALL AIR CONDITIONING CONTROL ASSEMBLY

  1. Connect the connectors.




  1. Insert the radio receiver and attach the 5 claws on its backside.

    NOTICE:
    When inserting the radio receiver, do not press the knobs on it.



2. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



3. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



4. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



5. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



6. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



7. INSTALL RADIO RECEIVER ASSEMBLY WITH BRACKET

  1. w/ Cassette Tape Player:
    Install the radio receiver assembly with bracket (Click here).

  1. w/o Multi-display:
    Install the radio receiver assembly with bracket (Click here).



8. INSTALL CENTER NO. 1 INSTRUMENT CLUSTER FINISH PANEL


9. INSTALL NO. 4 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



10. INSTALL NO. 3 INSTRUMENT PANEL REGISTER ASSEMBLY



  1. Connect the connector.

  1. Attach the 6 claws to install the register.



11. INSTALL NO. 1 SPEAKER OPENING COVER ASSEMBLY



  1. Attach the 8 claws to install the opening cover.



12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).
