FUEL SENDER GAUGE ASSEMBLY (for Fuel Sub Tank) > INSTALLATION

for Preparation Click here



1. INSTALL FUEL SENDER GAUGE ASSEMBLY



  1. Install a new gasket to the sender gauge.

  1. Install the sender gauge with the 5 screws.

    Torque:
    1.5 N*m{ 15 kgf*cm , 13 in.*lbf }

    NOTICE:
    Be careful not to bend the arm of the fuel sender gauge.

  1. Connect the sender gauge connector.



2. INSTALL REAR FLOOR SERVICE HOLE COVER



  1. Install the service hole cover with new butyl tape.



3. INSTALL REAR NO. 7 AIR DUCT (w/ Rear Air Conditioning System)



  1. Attach the 4 clips to install the air duct.

    HINT:
    Attach the clips in the order shown in the illustration.



4. INSTALL REAR FLOOR MAT ASSEMBLY



  1. Attach the 5 clips to install the floor mat.



5. INSTALL REAR AIR DUCT GUIDE (w/ Rear Air Conditioning System)



  1. Attach the claw to install the guide.

  1. Install the screw.

    HINT:
    Use the same procedures for both sides.



6. INSTALL AIR DUCT PLUG (w/ Rear Air Conditioning System)



  1. Attach the 2 claws to install the plug.

    HINT:
    Use the same procedures for both sides.



7. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY LH

  1. w/ Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).

  1. w/o Sliding Roof:
    Install the front quarter trim panel assembly LH (Click here).



8. INSTALL FRONT QUARTER TRIM PANEL ASSEMBLY RH

  1. w/ Sliding Roof:
    Install the front quarter trim panel assembly RH (Click here).

  1. w/o Sliding Roof:
    Install the front quarter trim panel assembly RH (Click here).



9. INSTALL REAR SEAT COVER CAP (w/ Rear No. 2 Seat, except Face to Face Seat Type)



HINT:
Use the same procedure to install the rear seat cover cap on the other side.

  1. Attach the 3 claws to install the rear seat cover cap.



10. INSTALL REAR FLOOR MAT REAR SUPPORT PLATE



  1. Attach the 6 clips to install the support plate.



11. INSTALL REAR DOOR SCUFF PLATE LH



  1. Attach the 3 claws and 4 clips to install the scuff plate.

  1. Install the screw.



12. INSTALL REAR DOOR SCUFF PLATE RH

HINT:
Use the same procedures described for the LH side.



13. INSTALL REAR STEP COVER



HINT:
Use the same procedure to install the step cover on the other side.

  1. Attach the 2 claws to install the step cover.

  1. for Face to Face Seat Type:
    Install the rear No. 2 seat assembly (Click here).

  1. except Face to Face Seat Type:
    Install the rear No. 2 seat assembly (Click here).



15. INSTALL REAR NO. 1 SEAT ASSEMBLY RH (for 60/40 Split Seat Type 40 Side)

  1. Install the rear No. 1 seat assembly RH (Click here).



16. INSTALL REAR NO. 1 SEAT ASSEMBLY LH (for 60/40 Split Seat Type 60 Side)

  1. Install the rear No. 1 seat assembly LH (Click here).
