1. INSTALL NO. 2 COOLER EVAPORATOR SUB-ASSEMBLY



  1. Install the evaporator.



2. INSTALL NO. 1 COOLER BLOWER MOTOR SUB-ASSEMBLY



  1. Attach the 4 claws to install the blower motor.

  1. Install the 2 screws.



3. INSTALL NO. 3 COOLER THERMISTOR



  1. Install the thermistor.




  1. Install a new cool box insulator, as shown in the illustration.



4. INSTALL UPPER COOLING UNIT CASE



  1. Attach the 2 hooks and close the case, as shown in the illustration.




  1. Install the cooling unit case.



5. INSTALL LOWER COOLING UNIT CASE SUB-ASSEMBLY



  1. Install the lower cooling unit case with the 4 holding springs.

  1. Connect the 3 connectors.

  1. Install the screw.



6. INSTALL LIQUID HOSE



  1. Sufficiently apply compressor oil to a new O-ring and the fitting surface of the cooler evaporator.

    Compressor oil:
    ND-OIL 8 or equivalent

  1. Install the O-ring on the liquid hose.

  1. Install the liquid hose to the evaporator with the bolt.

    Torque:
    5.4 N*m{ 55 kgf*cm , 48 in.*lbf }
