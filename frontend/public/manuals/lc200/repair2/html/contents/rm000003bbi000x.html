DTC    C1784    Steering Angle Sensor Communication Error

for Preparation Click here


DESCRIPTION

The steering sensor signal is sent to the suspension control ECU through the CAN communication system. When there is a communication malfunction, it will be detected by the diagnosis function.

DTC Code
Detection Condition
Trouble Area
C1784
A steering angle sensor signal malfunction is detected, or the steering angle sensor power malfunction signal is detected for 5 seconds or more.
  1. Vehicle stability control system
  2. Suspension control ECU
