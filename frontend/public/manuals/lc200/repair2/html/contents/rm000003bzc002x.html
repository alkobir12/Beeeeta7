REAR UPPER ARM > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the RH side and LH side.
  2. The procedures listed below are for the LH side.
  3. A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. TEMPORARILY INSTALL REAR UPPER CONTROL ARM ASSEMBLY LH (w/ Active Height Control)



  1. Temporarily install the rear upper control arm and 2 washers with the 2 bolts and 2 nuts.



2. TEMPORARILY INSTALL REAR UPPER CONTROL ARM ASSEMBLY LH (w/o Active Height Control)



  1. Temporarily install the rear upper control arm and 2 washers with the 2 bolts and 2 nuts.



3. STABILIZE SUSPENSION

  1. Install the rear wheels.

    Torque:
    for aluminum wheel:
    131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
    for steel wheel:
    209 N*m{ 2131 kgf*cm , 154 ft.*lbf }

  1. Lower the vehicle.

  1. Press down on the vehicle several times to stabilize the suspension.



4. TIGHTEN REAR UPPER CONTROL ARM ASSEMBLY LH

  1. Tighten the 2 nuts.

    Torque:
    150 N*m{ 1530 kgf*cm , 111 ft.*lbf }

    NOTICE:
    Perform this procedure with all 4 wheels on the ground.



5. INSTALL REAR STABILIZER CONTROL TUBE INSULATOR (w/ KDSS)



  1. Install the rear stabilizer control tube insulator with the 2 bolts.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }



6. INSTALL UPPER ARM BUSH HEAT INSULATOR (w/o KDSS)



  1. Install the upper arm bush heat insulator with the bolt.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }



7. CONNECT SPEED SENSOR WIRE HARNESS



  1. Connect the speed sensor wire harness with the bolt.

    Torque:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }



8. INSTALL REAR HEIGHT CONTROL SENSOR SUB-ASSEMBLY LH (w/ Active Height Control)



  1. Install the sensor with the 2 bolts and nut.

    Torque:
    for bolt:
    13 N*m{ 127 kgf*cm , 9 ft.*lbf }
    for nut:
    5.6 N*m{ 57 kgf*cm , 50 in.*lbf }

  1. Connect the connector and 2 clamps.



9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL (w/ Active Height Control)

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



10. PERFORM VEHICLE OFF SET CALIBRATION (w/ Active Height Control)

  1. Perform the vehicle off set calibration (Click here).



11. ADJUST REAR HEIGHT CONTROL SENSOR SUB-ASSEMBLY LH (w/ Active Height Control)

NOTICE:
  1. Make adjustments from the link that deviates the most from the specified vehicle height value.
  2. When the front and rear are at the same level, make adjustments from the front first.
  3. If adjustment cannot be completed through the vehicle height offset calibration, adjust the sensor link using the following procedure.




  1. Loosen the nut and adjust the link installation position by moving the height control sensor link up or down in the long hole of the bracket.

    HINT:
    When the link is moved 1 mm (0.0394 in.), the vehicle height changes by approximately 2 mm (0.0787 in.).

  1. Tighten the nut of the height control sensor link.

    Torque:
    5.6 N*m{ 57 kgf*cm , 50 in.*lbf }



12. MEASURE VEHICLE HEIGHT (w/ KDSS)

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Set the tire pressure to the specified value(s) (Click here).

  1. Bounce the vehicle to stabilize the suspension.




  1. Measure the distance from the ground to the top of the bumper and calculate the difference in the vehicle height between left and right. Perform this procedure for both the front and rear wheels.

    Height difference of left and right sides:
    15 mm (0.591 in.) or less

    HINT:
    If not as specified, perform the vehicle tilt calibration.



13. CLOSE STABILIZER CONTROL WITH ACCUMULATOR HOUSING SHUTTER VALVE (w/ KDSS)

NOTICE:
  1. Perform the inspection on a level surface.
  2. Perform the inspection with the vehicle empty.
  3. Ensure that the wheels are on the ground and facing straight ahead.
  4. Perform the inspection with the vehicle load completely on the suspension.

  1. Using a 5 mm hexagon socket wrench, tighten the lower and upper chamber shutter valves of the stabilizer control with accumulator housing.

    Torque:
    14 N*m{ 143 kgf*cm , 10 ft.*lbf }



14. INSTALL STABILIZER CONTROL VALVE PROTECTOR (w/ KDSS)



  1. Install the valve protector with the 3 bolts.

    Torque:
    18 N*m{ 184 kgf*cm , 13 ft.*lbf }

  1. Attach the clamp, and connect the connector to the valve protector.



15. ADJUST HEADLIGHT ASSEMBLY (w/ Active Height Control)

  1. for Standard:
    Adjust the headlight (Click here).

  1. for HID:
