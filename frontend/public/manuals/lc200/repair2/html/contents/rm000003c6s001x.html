REAR CENTER SEAT INNER BELT ASSEMBLY (for Rear No. 1 Seat) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for the LHD and RHD.
  2. The procedures listed below are for the LHD.



1. INSTALL REAR SEAT INNER BELT ASSEMBLY



  1. Install the seat belt with the bolt.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    The anchor part of the seat belt must not overlap the protruding part.



2. INSTALL REAR NO. 1 SEAT RECLINING COVER RH



  1. Attach the claw to install the cover.

  1. Install the screw.



3. INSTALL REAR NO. 1 SEAT ASSEMBLY LH

  1. Install the rear No. 1 seat assembly (Click here).
