DOOR CONTROL RELAY (for RHD) > INSTALLATION

for Preparation Click here



1. INSTALL DOUBLE LOCK DOOR CONTROL RELAY ASSEMBLY



  1. Install the double lock door control relay assembly with the nut.

  1. Connect the connector.



2. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (w/ Driver Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



3. INSTALL LOWER INSTRUMENT PANEL SUB-ASSEMBLY (w/o Driver Side Knee Airbag)



  1. Attach the 4 claws and connect the DLC3.

  1. Install the instrument panel with the 5 bolts.



4. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



5. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



6. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 2 claws to install the panel garnish.



7. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 3 claws to install the panel garnish.



8. INSTALL INSTRUMENT SIDE PANEL RH



  1. Attach the 6 claws to install the side panel.



9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
When disconnecting the cable, some systems need to be initialized after the cable is reconnected (Click here).



10. CHECK SRS WARNING LIGHT

  1. Check the SRS warning light (Click here).
