HINT:
A bolt without a torque specification is shown in the standard bolt chart (Click here).



1. INSTALL SPARE PLATE SUB-ASSEMBLY (w/ Tire Carrier)



  1. Install the plate with the 4 bolts.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



2. INSTALL SPARE WHEEL CARRIER LOCK STRIKER ASSEMBLY (w/ Tire Carrier)



  1. Install the striker with the 2 bolts.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }



3. INSTALL SPARE WHEEL CARRIER AUXILIARY STOPPER (w/ Tire Carrier)



  1. Install the stopper with the 2 bolts.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



4. INSTALL SPARE WHEEL CARRIER LOCK ASSEMBLY (w/ Tire Carrier)



  1. Attach the 4 claws to install the spare wheel carrier lock to the spare wheel carrier lock control cable.



5. INSTALL SPARE WHEEL CARRIER LOCK CONTROL CABLE ASSEMBLY (w/ Tire Carrier)



  1. Install the spare wheel carrier lock control cable to the spare wheel carrier lock and attach the clamp.

  1. Close the spare wheel carrier lock cover.




  1. Install the spare wheel carrier lock control cable with the 5 bolts.

    Torque:
    5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

  1. Attach the clamp.



6. INSTALL SPARE WHEEL CARRIER SUB-ASSEMBLY (w/ Tire Carrier)

  1. Clean the threaded surfaces on the vehicle body with a non-residue solvent.

  1. Apply adhesive to the threads of the 6 bolts.

    Adhesive:
    Toyota Genuine Adhesive 1324, Three Bond 1324 or equivalent



  1. Install the spare wheel carrier with the 6 bolts.

    Torque:
    28.4 N*m{ 290 kgf*cm , 21 ft.*lbf }




  1. Install the spare tire.

    Torque:
    90 N*m{ 918 kgf*cm , 66 ft.*lbf }



7. INSTALL SPARE WHEEL COVER SUB-ASSEMBLY (w/ Tire Carrier)



  1. Attach the clip to install the cover.

  1. Install the 2 nuts.



8. INSTALL SPARE WHEEL CARRIER HINGE BRACKET (w/ Tire Carrier)



  1. Attach the 2 claws to install the bracket.
