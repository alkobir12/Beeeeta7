REAR STABILIZER BAR (w/o KDSS) > INSTALLATION

for Preparation Click here



1. INSTALL STABILIZER LINK SUB-ASSEMBLY LH



  1. Install the stabilizer link to the stabilizer bar with the bolt and nut.

    Torque:
    48 N*m{ 489 kgf*cm , 35 ft.*lbf }




  1. Install the 2 retainers, 2 cushions and bracket with the nut.

    Torque:
    12 N*m{ 122 kgf*cm , 9 ft.*lbf }



2. INSTALL STABILIZER LINK SUB-ASSEMBLY RH

HINT:
Use the same procedures described for the LH side.



3. INSTALL REAR STABILIZER BAR SUB-ASSEMBLY

  1. Install the 2 rear stabilizer bushes to the rear stabilizer bar.

  1. Install the rear stabilizer bar.



4. INSTALL REAR STABILIZER BRACKET LH



  1. Install the stabilizer bar bracket with the 2 bolts.

    Torque:
    56 N*m{ 571 kgf*cm , 41 ft.*lbf }



5. INSTALL REAR STABILIZER BRACKET RH

HINT:
Use the same procedures described for the LH side.



6. CONNECT REAR STABILIZER END BRACKET LH



  1. Connect the stabilizer end bracket with the 2 bolts.

    Torque:
    36 N*m{ 367 kgf*cm , 27 ft.*lbf }



7. CONNECT REAR STABILIZER END BRACKET RH

HINT:
Use the same procedures described for the LH side.



8. INSTALL REAR WHEEL

Torque:
for aluminum wheel:
131 N*m{ 1336 kgf*cm , 97 ft.*lbf }
for steel wheel:
209 N*m{ 2131 kgf*cm , 154 ft.*lbf }
