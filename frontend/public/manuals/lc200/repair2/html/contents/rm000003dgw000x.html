LUMBAR SWITCH (for Manual Seat) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL LUMBAR SWITCH (w/ Lumbar Support)



  1. Install the switch with the 2 screws.



2. INSTALL FRONT SEAT CUSHION SHIELD LH


  1. for 4 Way Seat Type:




    1. Attach the 3 claws in the order shown in the illustration to install the cushion shield.

    2. Install the 2 screws.

  1. w/ Lumbar Support:
    Connect the lumbar switch connector.



  1. for 8 Way Seat Type:




    1. Attach the 3 claws in the order shown in the illustration to install the cushion shield.

    2. Install the 3 screws.




  1. w/ Seatback Board:
    Attach the 2 rubber bands to the hooks.




  1. w/o Seatback Board:
    Attach the 2 rubber bands to the hooks.



3. INSTALL RECLINING ADJUSTER RELEASE HANDLE LH



  1. Attach the claw to install the reclining adjuster release handle.



4. INSTALL VERTICAL SEAT ADJUSTER KNOB (for 8 Way Seat Type)



  1. Install the snap ring to the vertical seat adjuster knob.

  1. Install the vertical seat adjuster knob to the front seat.



5. INSTALL VERTICAL ADJUSTING HANDLE LH (for 8 Way Seat Type)



  1. Install the vertical adjusting handle with the 2 screws.



6. INSTALL VERTICAL ADJUSTER COVER LH (for 8 Way Seat Type)



  1. Attach the 2 claws to install the vertical adjuster cover.



7. INSTALL FRONT SEAT ASSEMBLY LH

  1. Install the front seat assembly (Click here).
