LUMBAR SUPPORT ADJUSTER ASSEMBLY (for Manual Seat) > INSTALLATION

for Preparation Click here


HINT:
  1. Use the same procedures for LHD and RHD vehicles.
  2. The procedures listed below are for LHD vehicles.



1. INSTALL LUMBAR SUPPORT ADJUSTER ASSEMBLY LH (w/ Lumbar support)



  1. Install the lumbar support adjuster with the 2 screws.

  1. Connect the lumbar support adjuster connector.




  1. Attach the 4 hooks to install the seatback spring.

  1. Install the 4 springs.



2. INSTALL SEATBACK COVER WITH PAD

  1. Install the seatback cover with pad to the seatback frame.



  1. w/ Seatback Board:




    1. w/ Front Seat Side Airbag:
      Install the seatback cover bracket to the seat frame with the nut.

      Torque:
      5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

      CAUTION:
      After the seatback trim cover is assembled, make sure the side airbag strap is not twisted.




    2. Attach the hooks.

    3. Using hog ring pliers, install new hog rings to the seat frame.



  1. w/o Seatback Board:




    1. Attach the 4 claws to install the 2 headrest supports.




    2. w/ Front Seat Side Airbag:
      Install the seatback cover bracket to the seat frame with the nut.

      Torque:
      5.0 N*m{ 51 kgf*cm , 44 in.*lbf }

      CAUTION:
      After the seatback trim cover is assembled, make sure the side airbag strap is not twisted.




    3. Close the 2 fasteners, and then close the seatback cover.




    4. Using hog ring pliers, install new hog rings to the seat frame.



3. INSTALL FRONT SEAT HEADREST SUPPORT (w/ Active Headrest)

  1. Attach the 4 claws to install the 2 headrest supports.



4. INSTALL FRONT SEATBACK BOARD SUB-ASSEMBLY LH (w/ Seatback Board)



  1. Move the seatback board in the direction of the arrow to attach the 2 hooks and install the seatback board.

  1. Install the 2 screws.



5. INSTALL FRONT INNER SEAT CUSHION SHIELD LH



  1. Attach the claw and clip to install the cushion shield.

  1. Install the screw.



6. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH



  1. Install the front seat inner belt assembly with the nut.

    Torque:
    42 N*m{ 428 kgf*cm , 31 ft.*lbf }

    NOTICE:
    Do not allow the anchor part of the front seat inner belt assembly to overlap the protruding part of the front seat adjuster.

  1. Connect the connectors and attach the clamps.



7. INSTALL FRONT SEAT CUSHION SHIELD LH


  1. for 4 Way Seat Type:




    1. Attach the 3 claws in the order shown in the illustration to install the cushion shield.

    2. Install the 2 screws.

  1. w/ Lumbar Support:
    Connect the lumbar switch connector.



  1. for 8 Way Seat Type:




    1. Attach the 3 claws in the order shown in the illustration to install the cushion shield.

    2. Install the 3 screws.




  1. w/ Seatback Board:
    Attach the 2 rubber bands to the hooks.




  1. w/o Seatback Board:
    Attach the 2 rubber bands to the hooks.



8. INSTALL RECLINING ADJUSTER RELEASE HANDLE LH



  1. Attach the claw to install the reclining adjuster release handle.



9. INSTALL VERTICAL SEAT ADJUSTER KNOB (for 8 Way Seat Type)



  1. Install the snap ring to the vertical seat adjuster knob.

  1. Install the vertical seat adjuster knob to the front seat.



10. INSTALL VERTICAL ADJUSTING HANDLE LH (for 8 Way Seat Type)



  1. Install the vertical adjusting handle with the 2 screws.



11. INSTALL VERTICAL ADJUSTER COVER LH (for 8 Way Seat Type)



  1. Attach the 2 claws to install the vertical adjuster cover.



12. INSTALL FRONT SEAT ASSEMBLY LH

  1. Install the front seat assembly (Click here).
