STEERING CONTROL ECU (for LHD) > INSTALLATION

for Preparation Click here



1. INSTALL STEERING CONTROL ECU



  1. Install the steering control ECU to the junction block with the bolt and nut.

    Torque:
    8.0 N*m{ 82 kgf*cm , 71 in.*lbf }



2. INSTALL STEERING CONTROL ECU WITH JUNCTION BLOCK



  1. Front side:

    1. Connect the 5 connectors.

  1. Rear side:

    1. Install the steering control ECU with junction block with the bolt and 2 nuts.

      Torque:
      8.0 N*m{ 82 kgf*cm , 71 in.*lbf }

    2. Attach the 2 clamps.

    3. Connect the 7 connectors.



3. INSTALL LOWER INSTRUMENT PANEL (w/o Driver Side Knee Airbag)



  1. Attach the 4 claws to install the instrument panel.

  1. Install the 2 bolts.



4. INSTALL DRIVER SIDE KNEE AIRBAG ASSEMBLY (w/ Driver Side Knee Airbag)



  1. Connect the connector.

    NOTICE:
    When handling the airbag connector, take care not to damage the airbag wire harness.

  1. Install the driver side knee airbag with the 5 bolts.

    Torque:
    10 N*m{ 102 kgf*cm , 7 ft.*lbf }



5. INSTALL NO. 1 SWITCH HOLE BASE



  1. Connect the connectors.

  1. Attach the 4 claws to install the switch hole base.



6. INSTALL LOWER NO. 1 INSTRUMENT PANEL FINISH PANEL



  1. Connect the connectors.

  1. Attach the 2 claws to install the sensor.




  1. Attach the 2 claws to connect the 2 control cables.




  1. Attach the 14 claws to install the finish panel.

  1. Install the 2 bolts.




  1. Attach the 2 claws to close the hole cover.



7. INSTALL COWL SIDE TRIM BOARD LH



  1. Attach the 2 clips to install the trim board.

  1. Install the cap nut.



8. INSTALL NO. 1 INSTRUMENT PANEL UNDER COVER SUB-ASSEMBLY (w/ Floor Under Cover)



  1. Connect the connectors.

  1. Attach the 3 claws to install the under cover.

  1. Install the 2 screws.



9. INSTALL FRONT DOOR SCUFF PLATE LH



  1. Attach the 7 claws and 4 clips to install the scuff plate.



10. INSTALL NO. 2 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 2 claws to install the panel garnish.



11. INSTALL NO. 1 INSTRUMENT CLUSTER FINISH PANEL GARNISH



  1. Attach the 3 claws to install the panel garnish.



12. INSTALL INSTRUMENT SIDE PANEL LH



  1. Attach the 6 claws to install the side panel.



13. INSTALL LOWER CENTER INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY



  1. Connect the connectors.

  1. Attach the 7 claws to install the panel.



14. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY RH



  1. Attach the 7 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



15. INSTALL NO. 1 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



16. INSTALL LOWER INSTRUMENT PANEL PAD SUB-ASSEMBLY LH



  1. Connect the connectors and 2 clamps.

  1. Attach the 8 claws to install the panel pad.

  1. Install the screw.

  1. Install the clip.



17. INSTALL NO. 2 INSTRUMENT PANEL FINISH PANEL CUSHION



  1. Attach the 7 claws to install the panel cushion.



18. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL

NOTICE:
